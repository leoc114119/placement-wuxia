## A. 战斗公式（模块 01/03/04 使用）

### F-01 伤害公式（定稿 ✅，13 §1）
```
伤害 = (攻击力 − 防御力) × 品阶系数 × 暴击倍率
```
- **破防下限**（✅）：`攻击 − 防御 < 0` 时取 **1**（保底伤害，避免 0 飘字）
- **未命中**（✅）：未命中 = 0 伤害，独立于破防下限（"打不中"≠"打不动"）
- 一次出招 = 一段伤害（替代网金两段式）

### F-02 攻击力 / 防御力（🔧，64 §5）
```
攻击力 = 基础攻击 30 + 臂力×2 + 武器攻击 + 武功等级×成长系数
防御力 = 基础防御 20 + 根骨×1.5 + 防具防御
```
- 外功成长系数：一阶 **3** / 二阶 **5** / 三阶 **8**（🔧）
- 例：臂力 27 + 武器 20 + 清风剑法 5 级×3 → 30+54+20+15 = 119 攻

### F-03 品阶系数（✅ 双用途，64 §3）
| 品阶 | 系数 |
|---|---|
| 一阶（入门） | 1.0 |
| 二阶（上乘） | 1.3 |
| 三阶（必杀） | 1.7 |

> 双用途：① 伤害倍率（F-01）；② 升级学点倍率（F-10，`30×系数²×等级`）

### F-04 暴击 / 命中 / 闪避（🔧，64 §6）
```
暴击率   = 胆识 × 0.3%（胆识 15 → 4.5%）
暴击倍率 = 1.5
命中率   = 85% + 实战/100万 ×1%（上限 100%）
闪避率   = 机敏 × 0.2%（上限 25%）
```
- 判定顺序：**命中判定**（未命中=0 伤害）→ **暴击判定**（伤害×1.5）→ 破防下限兜底

### F-05 行动条速度（✅ 结构 2026-08-20 Leo 拍板，数值 🔧）
```
行动条满值 = 100（0~100%，满 100 即行动）
填充速度(/秒) = (100 + 内功等级×3 + 机敏×1) / 10
峨眉门派特色：+10%（叠加于上式结果）
```
- 例：内功 10 级 + 机敏 27 → (100+30+27)/10 = 15.7/s → 约 6.4s 出手一次（与原 1000 满值版节奏一致）
- **超时**（Leo 2026-08-20 定）：自动模式无操作超时；手动模式行动条满后 90s 无操作 → 当前回合自动 AI 代行，再 90s → 切回自动模式；**防死循环超时保留**：战斗总时长 90s 双方未全灭 → 存活 hp 总量高者胜（总量相同判玩家负）

### F-06 移动距离（🔧 后置，64 §8，MVP 若静止版则不实现）
```
移动距离(格) = 基础 2 + 装配轻功加成 + ⌊轻功等级 / 5⌋
装配轻功加成：一阶 +1 / 二阶 +2
```

## B. 属性公式（模块 05 使用）

### F-07 气血 / 内力（✅ 结构定稿 + 🔧 数值，13 §5.1 / 64 §4）
```
气血 = 100（基础气血常量，Leo 2026-08-20 定）
     + 基础内功等级×50 + 装配内功等级×X（X = 60 🔧）
内力 = 基础内功等级×5  + 装配内功等级×Y（Y = 6  🔧）
```
- **基础气血常量 100**：玩家初始气血（初始未装配内功、内力 0，见 `docs/80` §1）
- **基础内功**（wx-000）：全局生效，每级 +50 气血 / +5 内力
- **装配内功心法**：装配为当前运功生效，每级 +X 气血 / +Y 内力
- 术语：11 表字段用「每级气血加成/每级内力加成」（PR-03 咬合修正 ✅）

### F-08 战力（🔧 初稿，模块 05）
```
战力 = 攻击×3 + 防御×2 + 气血/10 + 内力/5
```
> 初稿权重，待 Leo 调；用于顶栏战力/敌我对比/排行榜。

### F-09 六维初始（🔧，64 §1 D-09）
- 模板 B（胆识后置）：**臂力27 / 根骨27 / 机敏27 / 定力27 / 悟性27 / 胆识15**（总值 150）
- 约束：单项 15~30，六项总值 ≤ 150
- 六维映射：臂力→攻击(×2) / 根骨→防御(×1.5) / 机敏→闪避·速度 / 定力→抗性 / 悟性→学武效率 / 胆识→暴击率
- **胆识不吃基础武学**，仅实战（每 100 万 +1）+ 稀有装备
- 基础武学提升：每 10 级 +1 六维，封顶 100 级 = +10

## C. 学点经济（模块 05/07/09 使用）

### F-10 学点消耗（✅ 已拍板，64 §9.2）
```
升级费/级 = 30 × 品阶系数² × 等级（取整）
等级上限：基础 20 / 一阶 100 / 二阶 80 / 三阶 70（✅ Leo 保留）
学习条件（✅，无拜师费）：
  二阶 = 某门一阶武功 ≥60 级 + 实战 ≥10W
  三阶 = 某门二阶外功 ≥40 级 + 二阶内功 ≥50 级 + 实战 ≥100W
```

### F-11 学点产出（✅ 已拍板 ×3，64 §9.1）
```
离线闭关：90 学点/分钟（=5,400/时，每日自修上限 2h ✅ D-06 MVP 生效 → ≤10,800/日）
          （v1.0 广告加时：每广告 +30 分钟，可突破 2h 上限）
在线扫荡：300 + 150×档位系数 /场
在线首通：900×档位系数
```
- 日产出验证：≈1.7~1.8 万/日，30 天 ≈53 万 → 支撑 **1 个月达成三阶**（✅ Leo）

## F. 其他已定规则（非公式）

### F-18 门派技能触发概率（✅ Leo 2026-08-19 拍板）
```
触发率 = 5% + 实战/1000W × 20%（封顶 25%）
```
- 例：实战 0 → 5%；实战 250W → 10%；实战 500W → 15%；实战 1000W → 25%（封顶）
- **暂不做门派贡献系统**（原「贡献→概率」方案后置，任务系统 MVP 不做）
- 适用：模块 07 门派技能，战斗内纯自动概率触发（不消耗内力）

### R-01 战斗补给（✅，13 §5c）
- 战斗中不可补血/内；阵亡 →「失血过多」状态（禁推图/战力受限）→ 战斗外治疗（金疮药/闭关养伤）
- 内力跨场消耗：耗尽只能普攻；大还丹战斗外补

### R-02 内力体系（✅，13 §5）
- 普攻不耗内力；武功耗内力（品阶越高耗越多）；门派技能纯概率触发不耗内力
- 内力上限由内功决定（F-07）

### R-03 助战规则（✅ 后置，Leo 2026-08-20 定）
- **MVP 不做助战**：战斗 = 玩家 **1v 多**（1v1~1v6），我方仅 1 棋子（原 3v3=1 主+2 好友作废）。
- 助战系统（模块 10）整体后置；助战入口 MVP 隐藏/置灰。
- 6v6 为侠客系统上线后的最大上限（远期保留）。

### R-04 装备获取（✅，64 §10.3 / D-05）
- **纯掉落，无合成**；MVP 商店**不卖装备**（银两只买药）

### R-05 武器绑定出招 + 范围档位（✅ Leo 2026-08-19 拍板 D-07 + 范围更新）
- **装配的武功需匹配武器类型才可出招**（剑法需装备剑，拳法可空手）
- 装备不匹配时：该武功**无法出招**（降级为普攻）
- **攻击范围 = 武器形态 × 武功等级档位**（03 §3.3/§3.3b）：
  - 剑/拳 = 移动小十字 3×3→5×5→7×7；棍/棒 = 中心大十字 每向 3→5→7
  - 鞭/刀 = 正前方扇形 中长 3→4→5；暗器 = 可移动单格 射程 **4→6→9**（Leo 2026-08-20 定，满档可及初始行距 9）
  - **档位随武功等级提升（阈值 Lv 20/40/60），不限制武功阶数**（一阶 60 级同样最大范围）
- **范围出界**：越界格子无效、不参与结算（clamp）
- 适用：模块 01 战斗出招判定/范围计算、模块 06 装备（武器部位）、模块 07 武学配置（装配校验）

### R-06 体力与挂机续航（✅ 结构 Leo 2026-08-19 定，2026-08-20 更新，数值 🔧）
```
每场战斗（挂机/手动/Boss）统一扣 1 体力（tili，独立于内力，上限 100 初稿 🔧）
逃跑不扣体力；体力耗尽 → 挂机自动停止，提示「体力不足，休息片刻」
恢复方式：待定（自然恢复 / 银两购 / v1.0 广告）
```
- **每场损耗 = 后台真实战斗模拟（推荐）**：复用模块 01 战斗核心 headless 跑一遍，输出真实 hp/neili 损耗——损耗随 **NPC 强度 × NPC 数量 × 角色攻防** 自然变化；数值不够打高图 → 损耗大增 → 必须备药（"战力→续航"压力闭环）
  - **headless 归属（Leo 2026-08-20 确认）**：MVP 为**纯函数本地跑**（与云端 settle 同构，`net/cloud` 先 mock），settle 云函数接口契约保留（02 MVP §6），正式上云时切换；文档标注「本地结算，防作弊前置」
- **NPC 刷新（Leo 2026-08-20 定，取代 spawnCountRange [1,6]）**：场景全清后按**玩家实战档位**刷新数量——`<100: 固定 1`；`100≤实战<1W: 随机 1-3`；`≥1W: 随机 1-6`（概率 1-3 档 50/35/15、1-6 档 10/25/30/20/10/5）；刷新间隔 MVP 定 30s
- **自动补药**：气血 <30% 自动用金疮药、内力 <30% 自动用大还丹（阈值 30% 初稿 🔧）；药耗尽 → 挂机停止
- 药品：大还丹（补内力，200 银两/限购 10）/ 金疮药（补气血，100 银两/限购 5）（F-13）
- 适用：模块 04 挂机系统、模块 05 人物属性（tili 字段）、模块 06 装备（背包药）、模块 01（headless 战斗核心）

### R-07 敌方组队与战斗规模（✅ Leo 2026-08-20 拍板，来源 `docs/80` §2/§3）
```
MVP 战斗 = 玩家 1v 多（不做好友助战，6v6 为远期上限）
敌方数量 = 按玩家当前实战分档（战斗生成时判定）：
  < 100           → 固定 1
  100≤实战<10000  → 随机 1-3（50/35/15，期望 1.65）
  ≥ 10000         → 随机 1-6（10/25/30/20/10/5，期望 3.3）
敌方类型 = 从当前场景 SceneConfig.npcs（mob）按布点顺序循环填充，数量超出可重复
Boss 战    = Boss 本体固定 1 + 护卫按档位（<100:0、100~1W:0~1 随机、≥1W:1~2，护卫从场景小怪选）
```
- 适用：模块 01 战斗生成、模块 03 NPC、模块 04 挂机、模块 08 Boss

### R-08 冷却机制（✅ CodeBuddy 建议，Leo 2026-08-20 确认）
- 武功表加 `cooldown` 字段（单位=**回合**，行动一次计 1 回合，冷却随自身行动递减）
- MVP 初值：外功 0 / 特技 2 / 绝学 5 / 暗器 1
- 冷却中的武功：手动按钮置灰不可点；自动模式不选
- 适用：模块 01 出招判定、模块 07 武学配置、11 武功数据表字段

### R-09 武功内力消耗初值（✅ CodeBuddy 建议，Leo 2026-08-20 确认，🔧）
```
普攻 0 / 轻功 10 / 外功：一阶 20、二阶 50、三阶 100 / 绝学 150
野猫剑法（新手过渡）10（一阶 20 × 50%）
门派技能：纯概率触发不耗内力（F-18）
```
- 初始 0 内力 → 未学内功前武功不可出招（仅普攻），学基本内功后逐步解锁
- 适用：模块 01 出招判定、模块 10 武学系统 §3.3、11 武功数据表
