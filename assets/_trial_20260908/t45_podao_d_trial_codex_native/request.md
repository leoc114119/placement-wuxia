## 验证方法

- 只读引用当前正式 runtime 身体帧；逐帧记录身体 PNG SHA-256、画布事实、脚底与边界透明检查。
- 使用 Pillow 确定性画一把长宽单刃朴刀占位刀；不调用 ImageGen/mxai，生成额度 `0`。占位刀只验证几何、握持点、统一右上轴线、层序与遮挡，不代表最终朴刀审美或刃面。
- 每帧记录 `gripPoint{x,y}`、`angleDeg`（屏幕坐标：0°向右、Y 向下、顺时针为正）、`layerOrder`、原拳 ROI 多边形与由身体 alpha 裁出的遮挡 mask SHA。
- 每帧输出三联图：`FULL FRONT`（完整裸刀叠前）、`D OCCLUSION`（裸刀前景、ROI 内原拳保持顶层）、`BACK LAYER`（刀在身体后）。每套同时出原尺寸与 2x 最近邻放大。
- 技术检查：柄在 ROI 两侧保留可见段、D 遮挡确实减少刀层、无运行时写入、8/8 画布/脚底/边界/尺寸/哈希门通过。
