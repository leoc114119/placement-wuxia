手机武侠像素游戏 UI 风格锚一页纸（style anchor sheet），暖棕木色与米色绢帛双材质体系，精美像素风格。画布均分为多个展示区块——
【面板区块】三块不同尺寸的九宫格面板：深棕色木质面板（暖棕木纹、浅金色卷云纹包角）、米色绢帛面板（绢帛纹理、细鎏金边）、半透明深色胶囊条；
【按钮区块】两排按钮三态展示：木质横匾按钮（正常/按下变亮/禁用变灰三态）、金色描边圆形按钮（同三态）；
【边框与分隔】卷云纹包角细节放大图、1px 淡金分隔线、铆钉与挂穗小件；
【色板条】底部一条色板：暖棕木色系四格、米色绢帛系三格、淡金强调色两格、朱砂红与靛蓝点缀色各一格。
纯深灰背景，布局整齐如设计规范页，无大段文字（仅按钮上可有「开始」「取消」二字示范），精美像素风，无水印。
