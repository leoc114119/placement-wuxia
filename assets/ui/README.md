# 放置武侠 · UI 素材说明

> 本文件是给 AI 编程助手(ZCode)看的"素材说明书"。
> 每个素材放进来后,在此登记:用途、尺寸、九宫格边距、状态、风格备注。
> **AI 靠这份说明 + 文件名理解素材,写清楚它才能用对。**

## 整体风格(来自 04-UI风格规范-v0.1)

活泼年轻的水墨国风:宣纸底 + 淡墨线条 + 朱砂/竹青/淡金点缀,清透明亮。
所有素材必须保持这一风格统一。

- 主色(墨):`#2B2B2B` / `#444`
- 辅色(宣纸):`#F8F4EA` / `#F0E6D4`
- 强调(朱砂):`#E2574C` / `#FF7E67`
- 点缀(青/金):`#4A7A6B` / `#7FB069` / `#D4AF37`

## 拼装注意(给 AI)

1. 按钮三态:正常 / 按下优先做,悬浮态可省略(移动端无 hover)
2. 面板九宫格必须正确裁切,否则圆角/描边会拉伸变形
3. 图标全部保持水墨简笔风格,统一 1px 描边风格
4. 所有颜色引用规范色值,禁止引入规范外的鲜艳色
