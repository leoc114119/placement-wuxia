# 放置武侠 · 独立图标/图片素材矩阵

> 状态：**活跃维护（2026-08-19 建立）**
> 定位：盘点主界面可独立分拆的图标/图片素材，记录每个元素的用途、状态、生图 prompt。
> 原则：**所有可拆分的图标/图片都应该作为独立素材生成**，不依赖界面 prompt 内的代码绘制 SVG 占位——拿界面图给 GPT Image / 即梦等生图工具时效果更可控。
> 风格：所有图标生成 prompt 必须带 `docs/76-生图风格前缀-v0.1.md` 中的风格前缀。

## 5. 工作流约定（拿给 GPT Image 生成时）

> **核心原则（Leo 2026-08-19 明确）**：喂 GPT Image 的框架图要去掉占位图标——占位 SVG/临时代码图标会干扰 GPT 对布局结构的理解，生成的 UI 稿会带偏。**框架图 = 干净布局 + 文字标注，图标位置留空让 GPT 自己发挥。**

1. **截图前开「生图模式」**：preview/main-ui-preview.html 顶部的「🔳 生图模式」开关，开启后隐藏所有占位图标（头像/银两/学点/商店/设置/Tab 图标/武学图标/角色立绘等），只保留布局框、卡片、Tab 文字 → 此时截图即干净框架图
2. **分两批送生图**：
   - 批 A：干净框架图 → GPT Image 生成整屏 UI 高保真（图标由 GPT 自绘）
   - 批 B：本表 §3 独立图标清单 → 单图标高保真（需要精细控制的图标单独生成，再拼装）
3. **选择依据**：
   - 需要 GPT 自绘、追求整屏风格统一 → 用批 A 框架图
   - 需要精确语义（如"学点=书卷""门派=山门"）→ 用批 B 单图标，之后替换 preview 的 img 引用
4. **验收**：生图完成后对照 §2 列表逐项替换；preview 的 img 引用保持可切换
