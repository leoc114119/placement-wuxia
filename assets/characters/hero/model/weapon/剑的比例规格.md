# 剑资产比例规格（生成用 · 交 PM2 接入）

> 目的：让新生成的剑**直接接进现有挂点，不用再调挂点参数**。
> 全部比例以**全剑长 L 归一化**（L = 剑尖 → 柄头 的总长）。

## 一、几何比例（照这个画，接进去就是对的）

| 项 | 比例 | 说明 |
|---|---|---|
| **握点**（拳头握住的那个点） | **距柄头 0.126 L** | ★最关键的一项：它是挂点锚，决定剑在手里"插多深" |
| **护手中心** | 握点上方 **0.139 L** | 护手紧贴拳头上方 |
| **护手宽度** | **0.244 L** | 横宽 |
| **剑尖** | 握点上方 **0.874 L** | |
| **柄段总长**（柄头→护手） | **0.265 L**（要求 0.24~0.28） | 太长则握点位置要重标 |
| 剑身（护手→剑尖） | 0.735 L | |

## 二、画布要求（这决定我要不要再做处理）

- **剑竖直、剑尖朝上**（不要斜放；斜放我要再旋转一次，多一次误差）
- **握点落在画布正中**（或告诉我握点在图上的位置，我来换算）
- **方形画布**，剑占画面高度约 **85%**，剑尖与柄头都完整入画不要切
- 纯白背景、只有这一把剑、**无文字/水印/签名**、无剑鞘/人物/场景/阴影

## 三、观感规格（由"游戏里只有约 70~90px 长"决定，不是审美偏好）

| 项 | 要求 |
|---|---|
| 块面 | **大块面、强对比**；**不要细碎纹样**（护手卷草/剑身云纹缩到 70px 会糊成一团） |
| 剑身 | **略宽于常见古剑**（现行版本约 0.06 L 偏细） |
| 中脊线 | 一道**深色**脊线（缩小后仍看得出剑的走向） |
| 护手 | **简洁**（一笔成型的宽十字/一字），宽度约 0.24 L |
| 剑柄 | **粗壮**（便于整把握住），只用简单斜向缠绳线，不要编花 |
| 剑首 | 圆润简洁 |

## 四、交给我时

只需：**图** + 一句话"剑有多长/握点在哪"（不给也行，我能量）。
**挂点参数（0.75×身高 / 位置 / 三轴角度）不用你管**——我会做"握点居中"处理再挂，挂点参数沿用现成那组。

## 五、3D 剑的面数与其它硬规格（Leo 09-14 问「多少面」）

| 项 | 建议值 | 依据 |
|---|---|---|
| **三角面** | **填 2,000**（★Tripo 面数控制的**最低档就是 2k**，Leo 09-14 告知；2k 已远超本尺寸所需），上限 5,000 | 剑在游戏里只有 **70~90px 长**；实测规律"人物在 240×320 下 2 万面与 10 万面无差别"，剑更小 ⇒ 阶梯再低一档。超过 5,000 纯浪费 |
| 贴图 | **512~1K 足够** | 同上，别上 4K |
| **骨骼** | **不要绑骨（关掉）** | 剑是**静态网格**，直接挂到手骨 `R_Hand`；挂点机制不需要骨架，绑骨只会多一步并可能改比例 |
| 相对量级 | 角色 **48,419 面** ⇒ 一把 2,000 面的剑是其 **4%** | 且只挂主角、run/jump 收剑 ⇒ 性能账里权重≈0 |
| 比面数更要紧 | **轮廓干净、块面清楚** | 同 2,000 面：块面大 ⇒ 缩小后清楚；细纹样 ⇒ 缩到 70px 糊成一团（剑C 太丑的真因） |

## 六、为"装备系统换色"而提的生成规格（Leo 09-14 定方向：生成一把，后面换色出多把）

**能靠换色撑到哪一档**：
| 变体 | 换色可行？ | 成本 |
|---|---|---|
| 同款不同材质/品质（银/玄铁/赤铜…） | ✅ | ≈0 |
| 同款不同纹样（柄绳/护手花纹） | ✅（UV 不变，改贴图） | 一张图 |
| **不同造型**（护手形状/剑身宽窄/单双刃） | ❌ 几何变了 | 每把另出一份 |

**★两条生成时必须满足的要求**：
1. **贴图按部件分区，且分区之间不混色**：剑身 / 护手 / 柄 / 剑首 各占**独立 UV 区域**、边界干净 ⇒ 换色时可**按部件分别调**（剑身银→玄铁、护手金→铜、柄红→黑）⇒ 3×3×3 即 **27 把剑**、零额外资产。
2. **贴图基底中性/灰白**（别自带重固有色调）⇒ 后面调色不串色。

**配套约定**：装备系统**只存"颜色组"**（每把剑 = 一组部件颜色值），不存贴图 ⇒ 加一把剑＝加一行配置。

## 七、★★变体口径（Leo 2026-09-14 定稿）：长度 × 颜色 ＝ 几十把剑

**结论：靠"调剑长 + 调部件颜色"就能出几十把剑，不需要再为每把剑花钱/重做资产。**

| 维度 | 范围 | 说明 |
|---|---|---|
| **剑长（×人物身高）** | **最短 0.50 ／ 默认 0.75 ／ 最长 1.20** | ★Leo 实测："在这个范围内看起来和动出来都没什么问题"（超出此范围未验） |
| **部件颜色** | 4 个部件各自调（剑身/护手/柄/剑首） | 用"几何分段 + 材质色×贴图"，零资产成本、不串色 |

**组合数**：仅"长度 3 档 × 4 部件各 3 色" 就 ≈ **240 把**；实际按长度连续 + 颜色任意取，几十把是轻松量级。

**配套（已验证成立）**：
1. **挂点参数不随这些变化**（长度由 `lenRatio` 缩放、颜色改材质色）⇒ 一把的挂点全通吃；
2. **不依赖 UV 分区**——3D 剑按几何分段（剑首/柄/护手/剑身）各挂一个材质，换色不会串到别的部件；
3. 动作层面：挂点绑拳心、剑跟手摆，run/jump 收剑 ⇒ **长度在 0.5~1.2 内摆动均无问题**（Leo 实测）。

⚠️ **边界**：①超出 0.5~1.2 的范围**未验**；②换**造型**（不是长度/颜色）的剑仍要重新走一遍"握点居中 + 段界重标"。
