**通用口径**：动作**全部为原地**（根位移水平分量 x/z ＝ 0，实测四条源本来就都是 0；**水平移动距离与格间路径由游戏代码控制**）；动作来自**我们自己的重定向**（Mixamo/动捕 → 本模型 41 骨，映射 **40/41**）；runtime 播的是这些 JSON，**不出 PNG 帧**。

¹ 循环接缝＝首帧与末帧各骨四元数夹角的最大值（0°＝接得上）。

**Leo 定的 jump 三条口径**：①演出区间＝原动作 **0.20~1.70s（1.5 秒）**，含蓄势前摇；②**直上直下**（只保留竖直分量）；③水平位移由代码控制。
**★给 runtime 的接口要求**：
- **jump**：本区间**结束在"落地缓冲的蹲姿"**（y=−0.169）⇒ **播完需从蹲姿混合回站立**；若要"播完即站立"则改区间 0.50~2.00（代价＝丢蓄势）。
- **idle**：接缝 0.28° ⇒ **可直接循环播放**。
- **atk / cast**：一次性播完。**游戏内出招速度/演出时长由代码侧控制**（Leo 2026-09-14 定：「后面代码那边会控制这个出招速度的」）⇒ **资产侧不裁时长**，本目录交付的即完整源（atk 1.50s / cast 4.53s / idle 6.67s），由 runtime 用 timeScale 决定实际演出快慢。

## 已知边界

- **模型无指骨** ⇒ 手是固定形态，"握剑"要靠角度/遮挡或挂一个握拳部件（一次性处理，非逐帧）。
- **模型无武器**（单 mesh 纯角色）⇒ 剑需另备 3D 资产或贴图平面片，挂在 `R_Hand` 上。
- 换装粒度：**整套换**（换 GLB）可行且动作零重做；**混搭**（逐件）需要分部件模型，另说。
  ⚠️ Tripo「分部件生成」与「纹理生成」**互斥**（API 侧实测同开报 1004；网页版是否互斥未验证）。
- 旧版模型仍留在 `~/Downloads`，**未入仓**（25MB）；观感台的 `588k` A/B 按钮需要它时才放置。
