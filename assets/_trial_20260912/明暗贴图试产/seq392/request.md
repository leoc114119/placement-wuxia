# T45 seq=392 · 五向全身 cel 明暗分块

## 范围

对 `left`、`leftdown`、`leftup`、`right`、`rightup` 五个方向分别进行一次 Codex 原生 ImageGen 图像编辑。`rightdown` 的单张全身明暗图作为统一世界光照参照，不作为目标构图来源。

## 冻结要求

- 每个方向的目标图只使用对应的同方向输入图作为几何、构图、五官、轮廓、服饰结构和配色真源。
- 输出保持对应输入的同构图、同方向、同宽高比；允许后续只做一次等比例缩放到输入的精确尺寸。
- 仅把柔和明暗转为清晰三档 cel 明暗分块：亮面 / 中间面 / 暗面。
- 五向均使用 `rightdown` 单张全身明暗图作为光照逻辑参照：光从同一世界方向来，明暗分档方式与参照一致。
- 不加细节、不重画五官、不改轮廓、袖子或手臂位置、不改配色、不改背景、不写文字。
- 不使用 mxai；本批原生 ImageGen cost=0。
