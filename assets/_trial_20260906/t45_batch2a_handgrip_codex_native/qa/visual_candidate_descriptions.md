# T45 批 2a 握手形候选描述

- `shanzei_a_right`: 右侧独眼山贼，画面右手抬起握拳，另一手腰前握拳，双脚站稳。
- `shanzei_a_rightup`: 背斜侧朝右上，双手下垂但均为闭合握拳，后脑/右肩为主。
- `shanzei_a_rightdown`: 正斜侧朝右下，双拳收在腰前，眼罩/单眼/胸口可见。
- `shanzei_b_right`: 右向偏斜侧，前手抬起握拳，另一手腰前握拳。
- `shanzei_b_rightup`: 背斜侧朝右上，前后两手均闭合握拳，红头巾后结清楚。
- `shanzei_b_rightdown`: 正斜侧朝右下，双拳前置，红头巾和双眼清楚。

六张均未画武器、刀柄、刀鞘或其他道具；待 Leo 目验。
