## 0. 模块目标

**跑通闭关闭环**：点「闭关修炼」→ 切室内 2.5D 场景 → 选择闭关武学 → 人物打坐 → 学点/熟练度随时间累积 → 每日 2h 封顶 → 离线期间自动闭关，回来自动结算。

**验收标准：** 闭关界面显示打坐人物 + 选中的武学 + 学点跳动；每日累计 2h 后停止并提示；离线 1 分钟以上重进 → 弹离线收益（按实际闭关时长结算，≤2h/日）。

## 1. 数据

```
interface BiquanState {
  active: boolean           // 是否闭关中
  martialId: string|null    // 当前闭关武学
  startedAt: number         // 本次闭关开始时间戳
  dailyUsedMin: number      // 今日已修时长（分钟，≤120）
  lastSettleAt: number      // 上次结算时间戳（离线续算用）
}
```

- 每日重置：`dailyUsedMin` 按自然日清零（存档字段，日期变化时重置）

## 2. 核心流程

### 2.1 进入闭关

```
场景内点「闭关修炼」→ 切换室内 2.5D 场景图（scene_closed，全屏切换）
  ├─ 未选武学 → 弹「尚未选择闭关武学」→ 武学阁按钮引导（11 §2.1）
  ├─ 已选武学 → 打坐动画 + 选中武学名显示
  └─ 每日已满 2h → 弹「今日已修至极致，明日再来」（11 §2.3 ✅ D-06）
```

### 2.2 闭关产出（F-11 ✅）

```
学点 +90/分钟（=5,400/时）
武学熟练度：随闭关时长累积（当前闭关武学；用于武学升级）
闭关不产：实战 ❌、装备 ❌（12 §1.2 边界）
```

### 2.3 每日上限（D-06 ✅ MVP 生效）

- `dailyUsedMin` 满 120 → 停止产出，弹「今日已修至极致，明日再来」
- **广告加时（v1.0 后置）**：每看一个广告 +30 分钟闭关时长（可突破 2h 上限）

### 2.4 离线自动闭关

- 玩家关闭游戏时若在闭关 → 服务端记录闭关状态与武学，离线期间持续结算（受 2h 上限约束）
- 重进 → 超过 1 分钟离线弹离线收益弹窗：「正在结算闭关所得…」→ 学点入账 + 熟练度入账（11 §2.2）
- 与模块 04 挂机的离线结算对齐（同一 settle 云函数）

### 2.5 退出闭关

- 点「出关」→ 回江湖场景；本次闭关已结算部分保留
- 换武学需确认：「换修 [武学名]，当前进度保留」（11 §2.3）

## 5. 测试要求

- 能跑：微信开发者工具 / 浏览器
- 观察：① 点闭关 → 切室内场景 + 打坐人物 + 学点跳动；② 选武学 → 显示当前闭关武学；③ 每日 2h 到 → 停产出 + 提示；④ 离线 2 分钟重进 → 离线收益弹窗按实际时长结算；⑤ 出关回场景
