## 0. 模块目标

**跑通 Boss 挑战闭环**：玩家实战达标 → 点「挑战Boss」或挂机自动触发 → 切战斗界面（3v3 战棋）→ 胜：掉落入包 + 进入下一场景；负：回到场景（失败提示）。

**验收标准：** 场景右侧 Boss 入口显示当前 Boss 与实战要求；实战不足置灰；达标可挑战；挂机中遇到 Boss 自动切战斗；击败后掉落入包、Boss 入口更新为下一场景 Boss。

---

## 1. 数据（引用 config/场景与NPC配置.md §BossConfig）

```
interface BossConfig {
  npcId: string                 // 引用 NpcConfig（type='boss'）
  challengePractice: number     // 挑战 Boss 的实战要求（当前场景达标才可挑战）
  defeatReward: DropReward      // 击败掉落（保底蓝+，64 F-14 基准）
}
```

- 每个场景一个 Boss（`SceneConfig.boss`），打掉后解锁下一场景
- Boss NPC 配置复用 NpcConfig（type='boss'：独立立绘/放大 1.3/名字朱砂/气场 aura）

---

## 2. 挑战触发

### 2.1 手动（场景内底部第三按钮「挑战Boss」）

```
点「挑战Boss」
  ├─ 实战 ≥ challengePractice → 切模块 01 战斗界面（对手 = Boss 配置）
  ├─ 实战不足 → 弹「实战不足（当前 X / 需 Y），先去闯荡历练」
  └─ Boss 已击败 → 按钮置灰「已击败」→ 场景切换入口出现
```

### 2.2 挂机自动（模块 04 联动）

- 挂机推图中遇到当前场景 Boss → **自动触发 Boss 战** → 切模块 01 战斗界面（与手动同路径）
- 战斗中「挂机状态」保持：Boss 战结束后若胜则继续挂机下一场景；**Boss 战败 → 挂机停止 + 提示**（需玩家确认再挂，Leo 2026-08-20 定）
- 助战好友在 Boss 战同样生效（模块 10，R-03 手动/自动均有效）—— ⚠ **MVP 不做助战（R-03 后置），本条仅后期生效**

---

## 3. 战斗对接（模块 01）

- 对手 = **Boss NPC 配置 + 护卫**（Leo 2026-08-20 定，R-07）：Boss 本体固定 1；护卫按玩家实战档位 `<100:0 / 100~1W:0~1 / ≥1W:1~2`（从本场景 mob 选，保范围博弈）
- 我方 = **玩家 1 人**（MVP 不做好友助战，R-03 后置）
- 复用 01 战斗界面，**无新增战斗逻辑**；仅对手来源不同（Boss 配置 vs 普通怪配置）

---

## 4. 结算与奖励

| 结果 | 处理 |
|---|---|
| 胜利 | ① 掉落按 `defeatReward.dropTable` 权重随机入包（模块 06 bag.addDrop）；② **首通额外奖励仅发一次**（存档字段 `firstKill[]`，首通学点/实战/银两 = Boss 击杀 ×2，config 示例）；重复挑战 = 普通掉落；③ 解锁下一场景（场景切换配置） |
| 失败 | 回场景，统一「失血过多」（R-10：hp=maxHp×30% + 疗伤 60s），疗伤后可重试 |

---

## 5. 渲染要求

- 场景内 Boss 入口：图标 + Boss 名 + 「挑战Boss」按钮（实战不足置灰 + 显示缺口）
- Boss 战斗中：Boss 立绘放大 + 名字朱砂 + 气场光晕（NpcAppearance.aura='boss'）
- Boss 击败后：入口变「已击败」灰态

## 7. 测试要求

- 能跑：微信开发者工具 / 浏览器
- 观察：① 实战不足 → 挑战按钮置灰并显示缺口；② 达标 → 可挑战切战斗（Boss + 护卫）；③ 战斗胜利 → 掉落入包 + 场景解锁（首通奖励仅一次）；④ 挂机中自动触发 Boss 战，**战败挂机停止**；⑤ Boss 已击败 → 入口灰态
- 边界：Boss 战中关闭游戏 → 重进回到场景（未结算不吞奖励）；Boss 战失败 → 失血过多（hp 30%）疗伤 60s 后可重试；重复挑战 Boss 仅普通掉落
