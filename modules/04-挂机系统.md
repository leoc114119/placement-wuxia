> 状态：**规格草稿（待 Leo 审）**

## 0. 模块目标

**跑通挂机自动推图**：点「挂机」按钮 → 角色自动寻怪 → 每场打怪播小动画 → 自动结算收益（学点/实战/银两）→ 几秒一场循环 → **每场扣 1 体力 + 气血/内力损耗 = 后台真实战斗模拟（复用模块 01 战斗逻辑，按 NPC 强度/数量/角色攻防计算）→ 自动补药配置保证续航 → NPC 全清后随机刷新 1-6 只继续挂**。Boss 挑战时切换战斗界面（模块 01）。点「挂机」再退出挂机回手动模式。

**验收标准：** 挂机后看到——角色自动走向最近的 NPC → 打怪小动画（我方武学 × 敌方 + 伤害飘字）→ 血条/内力条/收益条/体力显示 → 每场扣体力、气血/内力按真实战斗模拟变化（损耗与 NPC 强度/数量/自身攻防相关）→ 数值不足自动吃药 → 击杀后 NPC 消失、收益入账 → **场景全清 → 随机刷新 1-6 只（越多总收益越大、总损耗越大）**。手动模式功能不受影响（可退出挂机）。

## 1. 挂机状态机

```
手动模式 (模块02)
   │ 点「挂机」
   ▼
挂机模式 ──► 循环：
   ① 检查体力（≤0 → 停止挂机，提示「体力不足，休息片刻」）
   ② 找最近存活 NPC（普通怪，Boss 单独处理）
   ③ 角色自动走向它（寻怪）
   ④ 进入打怪动画（约 2~3 秒/场）
   ⑤ 结算：收益入账 + 扣 1 体力 + **后台真实战斗模拟得出血气/内力损耗**（§3.3）
   ⑥ 气血/内力过低 → 自动补药（读挂机补药配置）
   ⑦ NPC 消失，返回 ①
   │ 全部 NPC 清空 → 随机刷新 1-6 只（Leo 拍板）→ 继续 ①
   │ 点「挂机」/退出 / 体力耗尽
   ▼
手动模式
```

- 挂机模式标志：`gameState = 'manual' | 'hangup'`
- 手动模式下 NPC 正常走动；挂机模式下 NPC 仍可走动但角色主动寻它

## 2. 挂机 UI（加载在场景内，按钮上方）

```
┌─────────────────────────────────────┐
│  ⚔ 清风剑法  ×  山贼·马大壮         │  ← 打怪动画区：我方武学 × 敌方
│        -248   -132（伤害飘字）       │
├─────────────────────────────────────┤
│ [气血▮▮▮▮▮▮▯ 3200/4500] [内力▮▮▮▮▯ 1500/2500] │  ← 血条/内力条
│ [体力 ▮▮▮▮▮▮▮▯ 68/100]             │  ← 体力条（每场 -1）
├─────────────────────────────────────┤
│ 学点 +180/s │ 实战 +1200 │ 银两 +20 │  ← 收益条（青牛山下档位1 示例）
│ 补药：大还丹 ×7 · 金疮药 ×3          │  ← 自动补药状态
└─────────────────────────────────────┘
```

### 2.1 打怪动画区
- 文案：`⚔ {当前武学名} × {敌方名}`
- 伤害飘字：-248（朱砂）、-132（白）上浮消失动画
- 每场时长：`SceneConfig.hangup.fightDuration`（2~3 秒）
- 动画循环：触发战斗 → 飘字出现 → 战斗结束 → 结算 → 下一场
- **战斗指示（Leo 定）**：角色与 NPC 头顶出现「交叉动态小剑」（两把斜交 X 形剑，上下浮动 + 微旋），仅战斗中显示，战斗结束移除（§3.2 ②④）

> **挂机产出数据源**：读取当前场景 `SceneConfig.hangup`（xuedianPerSec / shizhanPerFight / yinliangPerFight / dropChance / tiliCost，场景配置表在 `config/scenes.ts`，见模块 02 §1.2）。收益条数值 = hangup 配置实时计算，不是写死。

### 2.2 血条/内力条/体力条
- 角色当前气血/内力/体力（读 Player 数据）
- 血条：朱砂渐变；内力条：竹青渐变；**体力条：淡金渐变**；墨底 + 淡金描边
- 数值文案：`气血 3200/4500`、`内力 1500/2500`、`体力 68/100`
- 气血/内力每场变化（损耗模拟，§3.3）；体力每场固定 -1

### 2.3 收益条 + 自动补药状态
- 三格：学点 +180/s · 实战 +1200 · 银两 +20（读 hangup 配置实时算）
- **补药状态行**：自动补药配置 + 背包药剩余数量（大还丹 ×7 · 金疮药 ×3，读模块 06 背包）
- 药耗尽 → 该行朱砂提示「补药不足，气血/内力耗尽将停止挂机」

## 3. 自动战斗逻辑（打小怪，不进战斗场景）

### 3.1 寻怪
- 找距离角色最近的存活普通 NPC（曼哈顿距离）
- 角色自动移动靠近（复用模块 02 移动逻辑，`state='hangup'`）
- 到达攻击距离（0.06 逻辑坐标）→ 开始打怪动画

### 3.2 打怪结算（关键：几秒一场，不切战斗场景）

```
每场流程（Leo 2026-08-19 交互确认）：
 ① 角色自动走到最近存活 NPC（复用模块 02 移动逻辑）
 ② 触发战斗：角色与 NPC 头顶出现「交叉动态小剑」战斗指示（持续整场）
 ③ 播放打怪小动画（2~3 秒，飘字显示伤害；伤害值 = §3.3 headless 模拟结果）
 ④ 战斗结束：交叉小剑消失
 ⑤ 结算：
    收益入账（学点 += 击杀学点、实战 += 击杀实战、银两 += 击杀银两）
    扣 1 体力（SceneConfig.hangup.tiliCost，默认 1）
    气血 -= headless 模拟 hp 损耗、内力 -= headless 模拟 neili 损耗（§3.3）
 ⑥ NPC hp = 0 → 从场景消失
 ⑦ 收益条/血条/内力/体力刷新 → 回到 3.1 找下一只
```

**战斗指示（交叉动态小剑）**：两把剑（斜交 X 形，朱砂/白色描边）悬浮在角色与 NPC 头顶，上下浮动动画 + 轻微旋转，表示"战斗中"；仅战斗中显示，战斗结束移除。Canvas 绘制，非素材。

- 数值公式：`学点收益 = 怪物学点系数 × 倍率`（倍数由助战/道具加成，本模块先写死）
- 伤害数值：直接按玩家攻击力 vs NPC 防御算一次（或简化：写死动画显示值，结算走后端 settle 云函数——对齐架构"客户端只展示，数值计算在后端"）

### 3.3 每场损耗 = 后台真实战斗模拟（Leo 定：按 NPC 强度/数量/角色攻防算，或直接模拟真实战斗数据）

> **推荐方案（Leo 认可）：复用模块 01 战斗核心跑 headless 模拟**——挂机每场在后台用真实战斗逻辑算一遍（同一套攻防/行动条/随机数），输出真实损耗与胜负。不写估算公式，损耗天然随「NPC 强度 × 数量 × 角色攻防」变化，且与正式战斗完全一致（防"挂机损耗和手动战斗不符"）。

```
模拟输入：我方攻防血内（Player） × 敌方 NPC 配置（血/攻/防/速/武功）
模拟过程：复用模块 01 战斗循环（行动条/出招/伤害/暴击/命中/闪避），headless 无渲染
模拟输出：我方 hp 损耗、neili 损耗、击杀轮数、我方是否阵亡
结算：
  气血 -= 模拟 hp 损耗
  内力 -= 模拟 neili 损耗
  收益 = 单只击杀奖励（学点/实战/银两）——N 只 = N 场 = N×单只（NPC 越多总收益越大）
  总损耗 = Σ 各场模拟损耗（NPC 越多总损耗越大）
```

- **与角色攻防的关系**：攻强 → 击杀轮数少 → 受击少 → 损耗小；防强 → 单次受击伤害低 → 损耗小。数值不够打高级地图 → 损耗大增 → 必须备药/补药（形成"战力 → 续航"压力闭环，Leo 定）
- **与 NPC 数量的关系**：刷新 1-6 只随机，逐只打（每只一场、扣 1 体力）；一批总收益 = Σ单只、总损耗 = Σ单场 → **越多收益越大、损耗越大**
- **headless 模式**：模块 01 战斗加 `runBattleHeadless(units) → { hpLoss, neiliLoss, rounds, result }`（无渲染，同步/快进执行）；动画播放只是展示，数值以模拟结果为准
- 备选简化（若 headless 集成成本高）：公式版 `单只气血损耗 = max(1, NPC攻 − 我防) × ⌈NPC血 / 我单次伤害⌉ × 攻速比`（系数 🔧 待 64），MVP 可先用，后切 headless

### 3.4 自动补药（Leo 定：挂机需配置补气血/内力药，否则每场后不会自动补充）

```
补药配置（挂机前可设置，读背包药物）：
  healHp    : 气血 < 30% 时自动用 金疮药（补气血）
  healNeili : 内力 < 30% 时自动用 大还丹（补内力）
  药耗尽    : 提示「补药不足，气血/内力耗尽将停止挂机」

每场结算后检查：
  if (hp / maxHp < 30%) and 背包有金疮药 → 使用，hp += 恢复量
  if (neili / maxNeili < 30%) and 背包有大还丹 → 使用，neili += 恢复量
  两者都耗尽且 hp/neili 归零 → 挂机停止（失败处理）
```

- 药品数值：大还丹（补内力）/ 金疮药（补气血）——恢复量 🔧 待 64（F-13 药品定价已定：大还丹 200/限10、金疮药 100/限5）
- 失败处理：气血归零 → 挂机停止，弹「气血耗尽，已停止挂机」（失血过多状态，13 §5c）

### 3.5 NPC 刷新（Leo 定：全部消失后随机刷新 1-6 只）

- 场景内存活 NPC 数量 = 0（且非 Boss 关）→ **随机刷新 1~6 只**（`spawnCountRange: [1, 6]`，Leo 2026-08-19 定）
- 刷新来源：当前场景 `SceneConfig.npcs` 布点表（按权重随机挑类型与位置）
- 刷新节奏：清空后立即刷新（不等待）；刷新后挂机循环继续
- **数量影响**：刷新 N 只 → 后续 N 场战斗 → 总收益 N×单只、总损耗 Σ 各场（越多收益越大、损耗越大）
- 手动模式同样生效（场景空 → 刷新，保持场景有怪可打）

### 3.6 Boss 处理
- 挂机中若附近有 Boss 或推图推进到 Boss 关 → **切换模块 01 战斗界面**（不播小动画，走正式战斗）
- 挂机期间遇 Boss：暂停挂机 → 进入 Boss 战 → 战斗结束回挂机

## 4. 血条/内力条/体力数据来源

- 客户端展示用（只读）；结算数值走后端 settle 云函数
- Player 数据字段：`hp / maxHp / neili / maxNeili / tili / maxTili / xuedian / shizhan / yinliang`
- **体力（tili）**：挂机/推图场次资源（每场 -1，上限 100 初稿 🔧）；恢复方式待定（自然恢复/银两购/v1.0 广告）
- **补药配置**：`healHpThreshold=0.3 / healNeiliThreshold=0.3 / autoHeal=true`（挂机设置，读模块 06 背包药）
- **NPC 刷新数量**：`spawnCountRange: [1, 6]`（Leo 定；场景级可覆盖）
- 挂机开始/结束：调用云函数 `settle` 开启/结束挂机段；离线时由服务端结算（模块 09 闭关里也有离线，需对齐）

- 能跑：微信开发者工具 / 浏览器
- 观察：① 点「挂机」出现挂机 UI（含体力条 + 补药状态行）；② 角色自动走向最近 NPC；③ **靠近后角色与 NPC 头顶出现交叉动态小剑（战斗中指示）**；④ 打怪动画+飘字（飘字 = headless 模拟结果）；⑤ 每场扣 1 体力、气血/内力按真实战斗模拟变化（强怪/多怪损耗大、数值高损耗小）；⑥ 气血/内力 <30% 自动吃药（药数量减少）；⑦ **战斗结束小剑消失、NPC 消失**、收益条增长（N 只总收益 = Σ）；⑧ **场景全清 → 自动刷新 1-6 只（数量随机）继续挂**；⑨ 遇 Boss 切战斗界面、结束后回挂机；⑩ 点「停止挂机」回手动模式
