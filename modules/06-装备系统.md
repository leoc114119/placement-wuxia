## 0. 模块目标

**跑通一条装备闭环**：战斗掉落装备 → 进背包 → 穿戴（8 部位）→ 属性生效 → 分解换银两 → 商店买药/买装备。界面 = 装备包裹 Tab（装备 + 背包二级 Tab）。

**验收标准：** 打怪掉装备进背包，穿戴后人物属性/战力变化，分解得银两，背包 6×5 网格正常展示。

## 1. 装备数据（Equipment）

```
interface Equipment {
  id: string           // 唯一 id（instId）
  itemId: string       // 模板 id（config 引用）
  name: string         // 实例名：「精铁·长剑」
  slot: 'weapon' | 'cloth' | 'cape' | 'shoes' | 'head' | 'necklace' | 'gloves' | 'ring'
  level: 1|2|3|4|5     // 档位：布衣/精铁/百炼/玄铁/天蚕（12 §2.2）
  quality: 'white'|'green'|'blue'|'purple'|'orange'   // 品质（64 §0 色映射）
  attrs: { attack?: number; defense?: number; hp?: number; neili?: number; ... }
  bound: boolean       // 是否已绑定（掉落即绑定，防交易）
}
```

### 1.1 档位与品质（12 §2.2）

| 档位 | 实战要求 | 代号 |
|---|---|---|
| 1 | 无要求 | 布衣 |
| 2 | 1W | 精铁 |
| 3 | 10W | 百炼 |
| 4 | 50W | 玄铁 |
| 5 | 100W | 天蚕 |

- 每档 5 品质：白 → 绿 → 蓝 → 紫 → 橙（品质决定加成倍率）
- 品质色（64 §0）：白 #F8F4EA / 绿 #7FB069 / 蓝 #4A7A6B / 紫 #6B5B95 / 橙 #FF7E67

### 1.2 部位属性倾向（12 §2.3）

| 部位 | 属性 |
|---|---|
| 武器 | 攻击（并决定武功范围类型，03 §3.3；**装配武功需匹配武器类型才可出招**，D-07 ✅ R-05） |
| 衣服 / 披风 / 鞋子 | 防御 |
| 头部 / 项链 / 护手 / 戒指 | 气血 |

### 1.3 数值基准（引用 `config/公式与数值总览.md`）

| 数值 | 公式编号 | 状态 |
|---|---|---|
| 各档装备攻/防/血基准 | F-14 | 🔧 |
| 品质倍率 | F-15 | 🔧 |
| 档位系数（奖励/掉落） | F-16 | ✅ |
| 品质色映射 | F-17 | ✅ |
| 分解银两 = 品质基准 × 档位系数 | F-12 | ✅结构/🔧数值 |
| 银两收支（药品定价/限购） | F-13 | ✅ |
| 掉落率表 | `config/场景与NPC配置.md`（DropReward.dropTable） | 🔧 |

## 2. 背包（Bag）

### 2.1 数据结构

```
interface Bag {
  items: BagItem[]              // 装备 + 道具
  capacity: number              // 30 格（6×5）
}
interface BagItem {
  instId: string                // 装备=Equipment.id；道具=消耗品 id
  type: 'equip' | 'item'
  qty: number                   // 道具数量（装备恒 1）
}
```

### 2.2 界面（65 §1 + 72 §4）

- **装备包裹 Tab → 背包二级 Tab**：顶部分类（全部/装备/药水/材料）+ **6×5 网格（30 格）** + 格子数量角标
- 新装备入包：淡金印章「新」角标
- 点击/长按格子 → 详情（穿戴/使用/分解）——**交互细节开工后补全**（72 §0 边界）

### 2.3 排序/筛选

- 按战力 / 品质 / 部位 / 获取时间排序（65 §1.1，MVP 先做品质+部位）

## 3. 穿戴 / 卸下

### 3.1 规则

| 操作 | 规则 |
|---|---|
| 穿戴 | 同部位只能穿 1 件；替换件自动回背包；弹「已换装 [新]（战力 +N）」 |
| 卸下 | **允许空部位**（基础数值兜底，无装备不惩罚）；弹「该部位已空，属性回落 [N]」 |

### 3.2 装备属性生效

- 穿戴/卸下 → 调 `模块05.attr.ts` 的 `applyEquipBonus()` 重算衍生属性 → 战力/战斗面板刷新
- 界面 = 装备包裹 Tab → **装备二级 Tab**：人物形象居中 + 左右各 4 装备槽 + 底部装备总加成面板（72 §4，原型 v11.10 已定）

## 4. 掉落 / 分解 / 商店

### 4.1 掉落

- 来源：战斗胜利 / 挂机结算（模块 04 调 `bag.addDrop()`）
- 掉落结果按 `DropReward.dropTable` 权重随机（config/场景与NPC配置.md）
- 掉落提示条 → 点击直达背包（65 §0）

### 4.2 分解（65 §2）

- 规则：品质 → 银两（白最低、橙最高）；分解数值 **64 数值初稿 §8** 🔧
- 批量分解：背包底部「批量分解」（MVP 可只做单件）

### 4.3 商店（65 §3）

- MVP 卖：**大还丹 / 金疮药**（银两购买）+ 少量装备
- 入口：顶栏银两「市」+ 背包「去集市」
