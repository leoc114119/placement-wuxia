## 0. 模块目标

**跑通一条属性计算链**：六维（基础值）→ 加装备/武学/实战加成 → 算出衍生属性（攻击/防御/气血/内力/战力）→ 界面展示 → 战斗/NPC 读取用。

**验收标准：** 打开武学 Tab「基础属性」页能看到六维数值；换装/升武学后数值即时刷新；战力条正确变化。

---

## 1. 六维基础属性（PlayerAttr）

```
interface PlayerAttr {
  li: number    // 臂力  → 伤害、负重
  dan: number   // 胆识  → 暴击、临场发挥
  gen: number   // 根骨  → 生命上限、防御
  ji: number    // 机敏  → 闪避、出手抢先
  ding: number  // 定力  → 抗负面、内功抗性
  wu: number    // 悟性  → 学武速度、领悟上限
}
```

### 1.1 初始值（64 §1 D-09）

- 单项 15~30，六项总值 ≤ 150
- 初稿建议 **模板 B（胆识后置）**：臂力27 / 根骨27 / 机敏27 / 定力27 / 悟性27 / 胆识15
- 建号自由分配（若做）：各单项下限 15、上限 30、总值 ≤150

### 1.2 提升来源（10 §2.1）

| 属性 | 提升来源 |
|---|---|
| 臂力/根骨/机敏/定力/悟性 | 基础武学（每 10 级 +1，封顶 100 级 = +10）+ 稀有装备 |
| 胆识 | **不吃基础武学**，仅实战（每 100 万 +1）+ 稀有装备 |

## 2. 衍生属性（DerivedAttr）——计算链核心

```
interface DerivedAttr {
  attack: number      // 攻击
  defense: number     // 防御
  hp: number          // 气血上限
  maxHp: number       // 同 hp（当前值单独存）
  neili: number       // 内力上限
  maxNeili: number    // 同 neili
  power: number       // 战力（排行榜/敌我强度对比）
}
```

### 2.1 计算公式（引用 `config/公式与数值总览.md`）

| 公式 | 编号 | 状态 |
|---|---|---|
| 攻击力 = 30 + 臂力×2 + 武器攻击 + 武功等级×成长系数 | F-02 | 🔧 |
| 防御力 = 20 + 根骨×1.5 + 防具防御 | F-02 | 🔧 |
| 气血 = 基础内功×50 + 装配内功×60 | F-07 | ✅结构/🔧数值 |
| 内力 = 基础内功×5 + 装配内功×6 | F-07 | ✅结构/🔧数值 |
| 战力 = 攻击×3 + 防御×2 + 气血/10 + 内力/5 | F-08 | 🔧 |
| 六维初始模板 B / 上限规则 | F-09 | 🔧 |

> **数据流**：六维 + 装备加成 + 武学加成 → `computeDerived()` 实时计算 → 缓存 → 变更时广播刷新。
> 模块内不重复贴公式，只引用编号（单一数据源原则，与 config 配置表一致）。

### 2.2 当前值（hp/neili 现量）

- `hp` / `neili` 当前值独立存储（PlayerState），扣血/消耗/恢复都改当前值
- 上限变化时：当前值按比例缩放或取 min（不超出新上限），规则写死在 `clamp()`

## 3. 属性变更与刷新

| 触发 | 变化 | 刷新对象 |
|---|---|---|
| 穿戴/卸下装备 | 装备属性增减 | 战力 + 战斗面板 + 顶栏 |
| 基础武学升级 | 六维 +1（每 10 级） | 六维面板 + 衍生属性 |
| 武学装配/升级 | 攻/血/内变化 | 战斗面板 |
| 实战增加 | 胆识每 100 万 +1 | 六维面板 |
| 回血/补内力 | 当前值变化 | 血条/内力条 |
