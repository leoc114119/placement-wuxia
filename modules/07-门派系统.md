## 0. 模块目标

**跑通门派完整流程**：未入门（看门槛）→ 入门（实战达标）→ 学门派武学（学点 + 前置等级）→ 装配 → 战斗中门派技能概率触发。

**验收标准：** 门派 Tab 能看到 6 门派列表与入门门槛；入门后能按条件学武；战斗时已装配的门派技能按概率触发（飘字/加成）。

## 3. 核心流程

### 3.1 入门

```
门派 Tab → 门派列表 → 查看门派
  ├─ 实战 ≥ entryRequirement → 「拜入门下」（朱砂按钮）
  ├─ 实战不足 → 「实战不足（当前 X / 需 Y）」置灰
  └─ 已入门 → 显示门派面板（武功学习/门派技能/当前触发概率）
```

- 未入门派前：只能学基础武学（10 §3.2，属性门槛只在江湖武学）
- **只可拜一个门派**（退派：贡献清零，重入需重新积累）

### 3.2 武功学习（品阶制）

```
学习条件 = 学点 + 前置武功等级 + 实战门槛（✅ 无拜师费、不花银两，64 §9.2/§10.3 拍板）
例：清扬九剑（三阶）需 三仙剑法 Lv.50
```

- 学点消耗 = **F-10**（`30 × 品阶系数² × 等级`，一阶 1.0 / 二阶 1.3 / 三阶 1.7，✅ Leo 拍板）
- 进阶条件 = **F-10**（二阶：一阶武功≥60 + 实战≥10W；三阶：二阶外功≥40 + 二阶内功≥50 + 实战≥100W，✅ Leo 拍板）
- 已学武学进模块 05 的「已学武学列表」，装配到武学配置（72 §3c 武学配置装备位：外功/内功/轻功/特技/绝学）
- **外功装配校验（D-07 ✅）**：外功需匹配武器类型才可出招，装配时校验（R-05，联动模块 06 武器槽）

### 3.3 门派技能（纯自动 · 概率触发）

- **触发**：战斗中纯自动按概率触发（不消耗内力）
- **概率**：随实战提升 → **F-18**（`5% + 实战/1000W × 20%`，封顶 25%，Leo 2026-08-19 拍板 D-04）；**暂不做门派贡献系统**（任务系统后置再接入，届时可替换公式）
- **联动**：模块 01 战斗在行动时检查 `sect.skill`，命中触发概率 → 生效（加攻/反击/中毒/狂战/防御）

## 7. 测试要求

- 能跑：微信开发者工具 / 浏览器
- 观察：① 实战不足 → 拜入门派置灰；② 达标 → 入门成功；③ 学武条件不足（学点/前置）→ 按钮置灰并提示缺什么；④ 学成功 → 已学武学列表出现可装配；⑤ 战斗中出现门派技能触发（飘字/加成）
