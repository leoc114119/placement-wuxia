# 放置武侠 · 可访问性分级

> 状态：**草案（待 Leo 审）**
> 日期：2026-08-19
> 定位：Studio 流程资产（Phase 4 预制作）。定义本项目可访问性目标档位与检查矩阵，**UX 规格（design-strategist 产出）必须引用本分级**；美术资产（`docs/studio/30-UI资产规格.md`）已按本分级落地约束。
> 依据：`04-UI风格规范-v0.1.md`（规范色值）、`02-MVP开发规格-v1.md`（受众/验收）、微信小游戏平台特性。

---

## 0. 结论速览

> **本项目建议档位：Standard（WCAG 2.1 AA 核心项）。**
> 理由：微信小游戏受众横跨老中青（中老年玩家占比高且持续上升），放置类游戏「挂机/离线」长时间看屏，状态可读性 = 留存底线；Standard 多为代码级实现（字号/对比/热区/动画开关），对美术管线影响小、成本可控，与 L2.5 美术目标不冲突。Comprehensive（语音、自定义主题、辅助技术适配）后期按数据再评估，不进 MVP。

---

## 1. 三档分级定义

| 档位 | 定位 | 核心要求 |
|---|---|---|
| **Basic** | 合规底线（审核不被打回） | 关键文字与背景有基本区分；可点元素能点中；无强制高频频闪 |
| **Standard** | 目标档（推荐） | WCAG 2.1 AA 核心项：正文对比度 ≥4.5:1、大字/图形 ≥3:1；最小字号、点击区 ≥88rpx；状态双编码（图标+颜色）；特效可关/可降级；尊重系统「减弱动态效果」 |
| **Comprehensive** | 进阶 | AA 全项 + 尽量 AAA；文本可自定义缩放至 150%；全量字幕/语音替代；外部输入与辅助技术适配 |

---

## 2. 建议档位论证（为什么 Standard 起步）

| 论据 | 说明 |
|---|---|
| 受众结构 | 微信生态 45+/55+ 用户占比持续上升；放置/武侠题材对中老年玩家吸引力强，视力退化（老花）、操作精度下降是普遍问题 |
| 玩法特性 | 挂机/离线 = 长时间盯屏；「闭关中/失血/中毒」等状态看不清 = 直接流失；数值「变大变强」反馈需大字醒目 |
| 成本 | Standard 项几乎全是代码级（字号档位、对比色、热区、动画开关），**不增加素材成本**；美术侧只需遵守 30 文档的「图标双编码、按钮文字用墨/深朱砂底、金青只上深底」等约定 |
| 风险 | Basic 仅满足审核底线，不构成产品竞争力；Comprehensive 前期投入高、收益面窄，留到用户数据出来后按需做 |
| 决策 | **MVP 按 Standard 落地；设置页预留 Comprehensive 扩展位（字号档位、特效等级、色盲模式开关）** |

## 3. 检查矩阵（Basic / Standard / Comprehensive）

| 特性 | Basic | **Standard（本项目目标）** | Comprehensive | 落地方式 |
|---|---|---|---|---|
| 对比度 | 正文 ≥3:1，大字 ≥2:1 | 正文 ≥4.5:1，大字/图形 ≥3:1（AA） | AA 全项 + 正文 ≥7:1 | 色板对照见第 4 节；代码统一用可访问组合 |
| 最小字号 | ≥20rpx | 正文 ≥24rpx；关键数值 ≥28rpx；按钮 ≥30rpx；辅助 ≥22rpx（下限） | 可自定义缩放至 150% | Canvas 文字由代码渲染，天然可缩放；字号档位「标准/大」两档起 |
| 点击区域 | ≥64rpx | **≥88×88rpx（44pt）**；相邻可点元素间距 ≥16rpx | ≥88rpx + 全界面间距优化 | 图标按钮视觉 64~72rpx + 代码扩展透明热区至 88rpx |
| 色盲友好 | 关键状态用图标+颜色双编码 | 双编码 + **色盲模式开关**（朱砂/竹青替换色） | 色盲模式 + 自定义主题 | 详见第 5 节；30 文档图标已按双编码设计 |
| 动画安全 | 特效可关 | 特效等级 高/中/低/关 + 尊重系统「减弱动态效果」；无 ≥3Hz 频闪 | 全动效可自定义 | 设置项 + 读系统 `reduceMotion` 默认降级 |
| 字幕/文本 | 无要求（文本代码渲染） | 关键提示文本对比度/字号达标 | 全量文本、语音替代 | 文本不进素材图，代码渲染 |
| 输入/操作 | 默认触控 | 触控 + 热区达标 + 误触防护（重要按钮不贴边、确认二次点击） | 外部输入/辅助技术 | UI 布局规范 |
| 反馈 | 操作有基本反馈 | 按下态 + 结果提示（toast/数值跳动）均有 | 多通道反馈（音/形/动） | 30 文档按钮三态 + toast |

## 4. 对比度矩阵（对照 04 规范色值）

> 计算基于 WCAG 2.1 相对亮度公式。结论：**正文只用墨系 on 宣纸系；朱砂只用于大字/强调；金/青只上深墨底**。

### 4.1 可行组合（✅ 达标 / ⚠️ 有条件 / ❌ 不可用于信息）

| 前景 | 背景 | 对比度 | 结论 | 用途 |
|---|---|---|---|---|
| 墨 `#2B2B2B` | 宣纸 `#F8F4EA` | **12.9:1** | ✅ AA 正文 | 正文、标题、图标主色（最常用） |
| 深灰 `#444` | 宣纸 `#F8F4EA` | **8.9:1** | ✅ AA 正文 | 次要文字、说明 |
| 墨 `#2B2B2B` | 浅杏 `#F0E6D4` | **11.4:1** | ✅ AA 正文 | 面板内文字 |
| 白 `#FFFFFF` | 墨 `#2B2B2B` | **14.2:1** | ✅ AA 正文 | HUD/深底白字（金/青底上白字亦好） |
| 淡金 `#D4AF37` | 墨 `#2B2B2B` | **6.7:1** | ✅ AA 正文 | 品质徽章、深底金字 |
| 黛青 `#4A7A6B` | 宣纸 `#F8F4EA` | **4.5:1** | ✅ AA 大字/图形（正文临界） | 图形标识、大字标签 |
| 朱砂 `#E2574C` | 宣纸 `#F8F4EA` | **3.4:1** | ⚠️ 仅大字/图形（≥3:1） | 强调数值、标题（须 ≥28rpx 加粗） |
| 朱砂 `#E2574C` | 墨 `#2B2B2B` | **3.8:1** | ⚠️ 仅大字 | 深底朱砂点缀 |
| 墨 `#2B2B2B` | 朱砂 `#E2574C` | **3.8:1** | ⚠️ 仅大字 | 主按钮文字（须 ≥30rpx 加粗） |
| 白 `#FFFFFF` | 朱砂 `#E2574C` | **3.7:1** | ⚠️ 仅大字 | 主按钮白字（不推荐小字用） |
| 白 `#FFFFFF` | 深朱砂 `#C94A40` | **4.6:1** | ✅ AA 正文 | **推荐主按钮底色加深一档 + 白字** |
| 竹青 `#7FB069` | 宣纸 `#F8F4EA` | **2.3:1** | ❌ 信息级不足 | 仅装饰/大面积色块（须配图标/文字） |
| 淡金 `#D4AF37` | 宣纸 `#F8F4EA` | **1.9:1** | ❌ 信息级不足 | 仅装饰线、点缀 |
| 天青 `#A8C4C8` | 宣纸 `#F8F4EA` | <2:1 | ❌ | 仅氛围晕染，不承载信息 |
| 白 `#FFFFFF` | 宣纸 `#F8F4EA` | **1.1:1** | ❌ | 禁止白字 on 宣纸 |

### 4.2 对美术/代码的硬约束（写进 30 文档的落地项）

1. 正文/说明文字：**墨 `#2B2B2B` 或深灰 `#444` on 宣纸系**（≥8.9:1）。
2. 强调数值/标题：可用朱砂 `#E2574C`，但**必须 ≥28rpx 加粗**；小字号强调改用墨色。
3. 主按钮文字：**方案 A（推荐）** 按钮底色加深至深朱砂 `#C94A40` + 白字（4.6:1）；**方案 B** 保持 `#E2574C` + 墨字，按钮文字 ≥30rpx 加粗。两者都避免「浅朱砂 + 白字小字号」。
4. 金/青：只用于**深墨底**（徽章/标签）或纯装饰；不在宣纸底上承载信息。
5. 血条：墨底 + 朱砂填充（对比足够），血量低于阈值时附加图标/文字提示，不单靠颜色。

## 5. 色盲友好（朱砂 vs 竹青 的可区分性）

### 5.1 问题
- 朱砂 `#E2574C` 与竹青 `#7FB069` 在**红绿色盲（protanopia/deuteranopia）**下明度与色相接近，仅靠颜色无法区分——**不能用「朱=敌人/危险、青=自己/安全」作为唯一编码**。

### 5.2 方案（Standard 档落地）
1. **双编码铁律**：所有状态/阵营/品质信息 = 「图标/形状/文字 + 颜色」双通道。
   - 中毒 = 毒雾骷髅图标 + 黛青雾；失血 = 血滴图标 + 朱砂；增益 = 祥云 + 淡金；减益 = 灰云 + 深灰。
   - 品质 = 文字标签（凡品/精良/稀有/绝世/传说）+ 白/绿/蓝/紫/橙。
   - 敌我 = 位置 + 阵营标识 + 颜色（不只靠红蓝）。
2. **色盲模式开关**（设置页，默认关）：开启后替换色相分离——
   - 朱砂 `#E2574C` → 琥珀橙 `#E8A33D`
   - 竹青 `#7FB069` → 湖蓝 `#5A8CA6`
   - 其余保持；两色明度差拉大，保证单色可辨。
3. **验收**：把关键界面截图过一遍色盲模拟滤镜（deuteranopia/protanopia）人工检查，信息不丢失才通过。

## 6. 动画安全（大招特效）

### 6.1 原则
- **特效等级：高 / 中 / 低 / 关**（设置项）。
  - 高 = 完整粒子 + 全屏水墨爆发；
  - 中 = 粒子减半、无频闪；
  - 低 = 静态水墨爆发帧 + 淡入淡出（时长 ≤1.2s）；
  - 关 = 无特效，仅伤害数字与位移。
- 默认「中」；读取系统「减弱动态效果」（`wx.getSystemInfo` / 设备无障碍设置）开启时自动降到「低」。
- **禁止 ≥3Hz 频闪**；全屏闪光时长 ≤0.2s 且可关。
- 转场/数字跳动动画：时长 ≤0.5s，可随特效等级关闭（挂机数字跳动降为静态显示）。

### 6.2 落地
- 特效开关为纯代码配置（`config/numbers.ts` 或设置存储），**不影响素材**——大招素材按「高」档制作，中/低/关由代码裁剪/替换实现，美术零成本。

## 7. 指标速查表（Codex 开工前抄进代码约定）

| 指标 | 值 |
|---|---|
| 正文最小字号 | 24rpx（≈12pt） |
| 关键数值字号 | ≥28rpx 加粗 |
| 按钮文字字号 | ≥30rpx 加粗 |
| 辅助/标签最小字号 | 22rpx（低于此禁止） |
| 点击区域最小 | 88×88rpx（44pt） |
| 相邻可点元素间距 | ≥16rpx |
| 正文对比度 | ≥4.5:1（用 4.1 可行组合） |
| 大字/图形对比度 | ≥3:1 |
| 状态编码 | 图标/形状/文字 + 颜色双编码 |
| 特效等级 | 高/中/低/关，默认中，尊重系统减弱动态 |
| 频闪 | 禁止 ≥3Hz；全屏闪光 ≤0.2s 且可关 |

## 8. 与 UX 规格的引用关系

- **design-strategist 的 UX 规格（`docs/studio/11-MVP-UX规格.md`）必须引用本分级**：字号档位、热区、状态双编码、特效开关、色盲模式等交互决策以本文件 Standard 档为准。
