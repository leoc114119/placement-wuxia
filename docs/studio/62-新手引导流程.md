# 放置武侠 · 新手引导流程 v0.1

> 状态：**评审稿（待 Leo 审）**
> 日期：2026-08-19
> 定位：首次启动 → 建号（拜师）→ 学武 → 首战 → 挂机 的完整引导设计。
> 硬性目标：① **10 分钟内完成**；② **不打断挂机核心**（闭关第 1 分钟即开启，挂机计时全程不中断）；③ 文案水墨武侠语感（称"少侠"、短句口语）；④ 不引导阵法/羁绊/侠客（版本边界）。
> 口径：3v3（1 主玩家 + 2 好友助战）；装备 D-05 进 MVP；色值只用 04 规范色。
> 关联：61-UI界面清单.md（入口）、11-MVP-UX规格.md（各环节 UX）。

---

## 0. 引导设计原则

| 原则 | 规则 |
|---|---|
| 挂机优先 | 引导第 1 步（G3）即开启闭关，之后任何引导节点不阻塞挂机计时；节点切换不打断学点跳动 |
| 10 分钟上限 | 节点 ≤ 8 个，单节点 ≤ 120s，总时长 ≤ 10 分钟；超时自动收起气泡不卡流程 |
| 强制 vs 可跳过 | 核心操作（布阵/开战/穿戴/分解）**强制演示**；剧情文案/世界观**可跳过**（3s 后跳过按钮亮起） |
| 中断恢复 | 引导中断（切后台/强杀）不丢进度：按已过节点续接，已完成节点不再重放；挂机收益照常结算 |
| 版本边界 | 全程不出现阵法/羁绊/侠客/门派任务；好友助战仅作"可选"提及（新手可能无好友） |
| 语感 | "少侠""闯荡""拜师""习武"；正反馈短句，不写长说明文 |

## 1. 引导节点总览

| # | 节点 | 触发条件 | 强制/可跳过 | 预算时长 | 完成条件 |
|---|---|---|---|---|---|
| G1 | 开场（世界观一句话） | 首次启动 | 可跳过（3s 后） | ≤15s | 点击进入建号 |
| G2 | 建号·拜师选门派 | G1 后 | 强制（决定武学线） | ≤60s | 选定 1 门派 |
| G3 | 初入山门 + 自动闭关 | G2 后 | 强制 | ≤30s | 闭关已开启 |
| G4 | 学武（基础 + 门派一阶） | G3 后 | 强制 | ≤90s | 学会 1 门武功 |
| G5 | 首战准备（闯荡→选关→布阵） | G4 后 | 强制（战斗操作） | ≤120s | 进入战斗回放 |
| G6 | 首战回放 + 结果 | G5 后 | 强制（战斗演示） | ≤120s | 结算完成 |
| G7 | 首战结算（掉落 + 装备穿戴） | G6 后 | 强制 | ≤60s | 已穿戴/已查看装备 |
| G8 | 回归挂机（闭关确认 + 预告） | G7 后 | 可跳过 | ≤30s | 返回主界面 |

> 合计预算 ≤ 8.5 分钟，留 1.5 分钟操作余量。G5/G6 为最耗时节点（战斗回放受倍速影响，引导默认 2x 播放）。

## 2. 分节点详情

### G1 开场（世界观一句话）

| 项 | 内容 |
|---|---|
| 目标 | 一句话交代"为什么而战"，不展开剧情 |
| 画面 | 天青→宣纸水墨晕染 + 书法字（04 §0 加载过场） |
| 文案 | "查小侠归隐后，江湖绝学流失、群邪抬头。少侠，你便是天命之子——去寻残卷、学绝学，还江湖太平。" |
| 交互 | 点击任意处跳过；右下角"跳过"按钮 3s 后亮起 |
| 兜底 | 点击跳过直接进 G2；不阻塞 |

### G2 建号·拜师选门派

| 项 | 内容 |
|---|---|
| 目标 | 选定门派 → 决定门派武学树起点（10 门派武学） |
| 画面 | 六大门派卡（清风派/太极门/峨眉/天山派/狂刀谷/丐帮，05 §4a 门派卡）；推荐标记"新手推荐：清风派"（淡金印章） |
| 文案 | "江湖六大门派，择一拜师。剑走轻灵，可入清风派——新手最宜。" |
| 交互 | 点门派卡 → 门派详情（武学方向/武器偏好，简版）→"拜师"（朱砂底） |
| 强制理由 | 门派决定可学武学线，误选影响首日体验；提供推荐标记 + 后改门派标注"超 MVP"（此版不可换） |
| 兜底 | 30s 未选 → 默认推荐门派 + 弹"先入清风派，他日可另投名师"（提示可换后置） |

### G3 初入山门 + 自动闭关（挂机开启 ✅）

| 项 | 内容 |
|---|---|
| 目标 | **立即开启闭关**，挂机从第 1 分钟开始积累 |
| 画面 | 主界面修习面板高亮；闭关武学 = 基础武学"基本内功"（默认已选） |
| 文案 | "先在洞府闭关打坐，学点自会滚滚而来——少侠且去闯荡，武学不等人。" |
| 交互 | 自动开启闭关（无需点击）；"开始闭关"按钮点击确认 → 学点跳动开始（朱砂大字 +N） |
| 强制理由 | 挂机核心必须第一步建立；不阻塞后续节点（节点期间学点持续跳动） |
| 兜底 | 网络失败 → 本地先计，后台重试；学点跳动照常显示（本地估算，结算以云端为准） |

### G4 学武（基础武学 + 门派一阶）

| 项 | 内容 |
|---|---|
| 目标 | 学会 1 门武功 → 战力提升（02 §5 验收"学到新武功→战力提升"） |
| 画面 | 武学阁；引导点"基本剑法/搏击格斗"（对应 G2 门派武器）→ 详情 →"修习" |
| 文案 | 学点足："学点已足，习武去也！"；修习成功："修习有成！[武学名] 已入武学库。" |
| 步骤 | ① 武学 Tab → ② 选基础武学 → ③ 详情 → ④"修习"（校验学点+银两）→ ⑤ 印章动画 + 战力 +N |
| 强制理由 | 学武是核心成长入口，必须亲手点一次 |
| 兜底 | 学点不足（异常情况）→ 弹"学点不足，先去闯荡一番"，跳到 G5 先推图 |

### G5 首战准备（闯荡 → 选关 → 布阵）

| 项 | 内容 |
|---|---|
| 目标 | 走到布阵完成，理解"布阵 → 开战"流程 |
| 画面 | 闯荡 Tab → 第 1 关（stage-01-01，1v1 弱敌，14 无好友渐进）→ 关卡详情 →"挑战"（扣内力提示）→ 布阵 |
| 文案 | 选关："首关小试牛刀，前方是几个山贼喽啰。"；布阵："拖拽落位，或一键布阵；有好友可邀其助战（每日三次）。" |
| 步骤 | ① 闯荡 Tab → ② 点 stage-01-01 → ③ 挑战确认（扣内力 N）→ ④ 布阵（一键布阵兜底）→ ⑤"开始论剑" |
| 强制理由 | 布阵/开战是战斗核心操作，必须亲手走一遍 |
| 兜底 | 无好友 → 自动 1 人上阵，不阻塞；布阵超时 → 一键布阵自动填入 |

### G6 首战回放 + 结果

| 项 | 内容 |
|---|---|
| 目标 | 看懂战斗回放（A 方案：客户端只播 log） |
| 画面 | 战斗 HUD（血条/行动条/倍速）；引导默认 2x；结束弹结果 |
| 文案 | "此战已由云峰判官裁定，少侠只管观战——可倍速、可快进。"；胜利："这一战，名动江湖！" |
| 步骤 | ① 回放自动播放 → ② 演示点 2x/4x → ③ 结果弹窗（奖励列表） |
| 强制理由 | 战斗演示是理解游戏的关键；回放本身 ≤30s（1v1 弱敌） |
| 兜底 | 云函数结算失败 → 弹"云峰论剑暂不可达，稍后再战"重试按钮；本地缓存战报重拉 |

### G7 首战结算（掉落 + 装备穿戴）

| 项 | 内容 |
|---|---|
| 目标 | 理解"掉落 → 装备 → 变强"闭环（D-05 装备进 MVP） |
| 画面 | 结果弹窗掉落列表 → 点装备卡 → 装备详情 → 属性对比 →"穿戴" |
| 文案 | "此战得了件 [装备名]（品质色），穿上它再战江湖！"；穿戴后："已换装，战力 +N。" |
| 步骤 | ① 结果弹窗点掉落装备 → ② 详情（对比当前）→ ③"穿戴" → ④ 战力 +N 提示 |
| 强制理由 | 装备闭环是本版核心，必须亲手穿一次 |
| 兜底 | 未掉落装备（概率）→ 跳过穿戴，只提示"装备随缘，学点已入账"；引导不因随机卡死 |

### G8 回归挂机（闭关确认 + 预告）

| 项 | 内容 |
|---|---|
| 目标 | 回到主界面，确认挂机在跑，预告离线收益 |
| 画面 | 主界面修习面板 + 淡金印章"已存" |
| 文案 | "闭关已开，学点不断。少侠且去忙，稍后回来领闭关收益——离线也有收获。" |
| 交互 | 点"收下祝福"（可跳过）→ 引导结束，进入自由游玩 |
| 兜底 | 无（结束节点） |

## 4. 强制 / 可跳过矩阵（验收锚点）

| 节点 | 类型 | 理由 | 跳过方式 |
|---|---|---|---|
| G1 | 可跳过 | 剧情文案不阻塞 | 3s 后"跳过"按钮 / 点击任意处 |
| G2 | 强制 | 门派决定武学线 | 不提供跳过；30s 自动默认推荐 |
| G3 | 强制 | 挂机核心建立 | 不提供跳过（自动执行，几乎无成本） |
| G4 | 强制 | 学武核心操作 | 不提供跳过；异常（学点不足）跳 G5 |
| G5 | 强制 | 布阵/开战操作 | 不提供跳过；一键布阵兜底 |
| G6 | 强制 | 战斗演示 | 不提供跳过；2x 播放压缩时长 |
| G7 | 强制 | 装备闭环 | 不提供跳过；未掉落时跳过穿戴步骤 |
| G8 | 可跳过 | 收尾提示 | "收下祝福"即结束 / 点空白处 |

> 二次进入（老玩家/换机重装）：读档有数据 → 跳过 G1~G8 全部引导，直接进 Home（仅 G3 关闭中提示）。

## 6. 验收标准

- [ ] 首次玩家 **10 分钟内**完成 G1~G8（真机计时，含战斗回放）
- [ ] 闭关在 **第 1 分钟**（G3）已开启；G4~G7 全程学点持续跳动，无节点阻塞挂机
- [ ] 所有可跳过节点有跳过出口；强制节点有兜底（自动默认/一键/跳转）
- [ ] 全程无"阵法/羁绊/侠客/门派任务"字样（版本边界）
- [ ] 文案全部称"少侠"、短句口语、水墨武侠语感；无长说明文
- [ ] 引导中断（切后台）后回来不重放已完成节点，挂机收益正常结算
- [ ] 色值只在 04 规范色内
