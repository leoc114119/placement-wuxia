## 〇、三分钟摘要（Leo 先读这段）

**结论先行：主推「B 江湖衣钵（世代传承）」——最贴你拍板的"放置版大侠式人生"，双支柱兼得，且是组装现有资产（年表+连锁+世界观全保留），改动量中可控。**

### 一个关键视角转变（先于方案）

你否掉传统战斗模式，不是要"砍掉战斗"，而是**战斗不该再当主玩法**。所有方案共用一个底层转变：

> **战斗从"主角"降级为"试金石"**——新的主玩法来自"放置的产出物"（时间赌注 / 世代人生 / 江湖名声 / 武学炼制 / 世界演化），battle-core 只做"验证 + 高潮"环节。这直接回应"不想在传统模式里改良"。

### 五方向一览（详见正文）

| # | 方向 | 核心动词 | 一句话 | 双支柱 | 改动量 |
|---|---|---|---|---|---|
| A | 闭关心流 · 时间赌局 | **闭关**（押注） | 挂机时间第一次成了赌注——闭关越久赌越大，回归开"顿悟盲盒" | 构筑强 | 小~中 |
| B | 江湖衣钵 · 世代传承 ★ | **传**（传承） | 你挂机的不是等级，是一整段人生——角色会老，衣钵传下一代，世代堆成江湖 | **双支柱兼得** | 中 |
| C | 江湖声名 · 名声传播 | **扬名**（传播） | 挂机产出的不是金币是"名声"——你的故事像涟漪传遍江湖，传闻会变形 | 剧情强 | 中 |
| D | 武学炉火 · 相生相克炼制 | **炼**（合成） | 武学不是学的是"炼"的——按相生相克投入炉火，炼出独一无二的武学 | 构筑强 | 小~中 |
| E | 江湖推演 · 因果演化 | **定**（干预） | 挂机时整个江湖在动——你的落子改变门派兴衰正邪消长，回来看到世界变了 | 剧情强 | 大 |

### 主理人推荐

- **主玩法 = B（江湖衣钵）**：最贴已拍板定位；世代周期天然容纳 A 的闭关赌局、C 的名声传承（每代人生里都可闭关、都可扬名）——B 是"容器型"主玩法，A/C 是容器里的人生事件，互相不冲突
- **快速验证备选 = A（闭关心流）**：改动最小（闭关系统已开发到模块 09），"回归揭晓"是放置品类少见的强钩子，适合 verify-first 小预算验证
- **黑马 = C（江湖声名）**：差异化最大，但需强可视化，适合第二曲线
- D/E 入备选池（D 同类玩法竞争多、E 引擎风险大，均不适合打头阵）

## 一、方法论：怎么从"传统改良"跳到"重新发明"

### 1.1 放置游戏的"挂机产出物"清单（传统 vs 新）

| | 传统放置 | 本方案尝试 |
|---|---|---|
| 挂机产出 | 金币/经验/装备（**数值**） | 时间赌注 / 世代人生 / 江湖名声 / 武学素材 / 世界演化（**意义与剧情**） |
| 回归动作 | 收菜（点击领奖） | 揭晓 / 传承 / 看舆论 / 开炉 / 看世界（**仪式感**） |
| 玩家身份 | 数值优化师 | 修炼者 / 掌门 / 江湖名人 / 炼武师 / 执棋人 |

**核心洞察**：放置游戏的体验上限 = "回归那一刻"的情绪。传统放置把回归做成"收菜"（多巴胺峰值低），本方案全部把回归做成"揭晓/传承/看世界"（多巴胺峰值高、且每次回归有叙事意义）。

### 1.2 发散矩阵：武侠特有题材 × 放置形态

```
                    放置形态
            挂机=产出    挂机=周期     挂机=传播     挂机=世界
武侠题材    ─────────────────────────────────────────────
闭关顿悟   → A 闭关心流（时间=赌注）
师徒传承   → B 江湖衣钵（世代=周期）
江湖名声   → C 江湖声名（故事=传播）
武学相生相克 → D 武学炉火（武学=炼成）
势力消长   → E 江湖推演（江湖=活的）
```

> 筛选原则：① 武侠题材必须成为**机制内核**（不是贴皮）；② 放置形态必须"前所未有"（挂机的产出物变了）；③ 两者杂交后仍满足"碎片化/单手/轻量"小游戏约束。

### 1.3 五方向全部满足的共性

- ✅ 竖屏 + 单手 + 即点即玩（每次在线操作 ≤ 30 秒）
- ✅ TS + Canvas 2D 原生（无新引擎依赖；战斗/武学/世界观的现有代码全部可复用）
- ✅ 原创红线（门派/武学/人物全原创命名）
- ✅ 两根支柱至少兼得一支（剧情人生感 or 构筑爽感），B 双支柱兼得

## 二、方向 A：闭关心流 · 时间赌局

### A.1 一句话新奇点
**"挂机时间第一次成了赌注"**——你选一门武学闭关 1~24 小时，赌一次顿悟；闭关越久赌注越大，回归揭晓的一刻是开盲盒：顿悟 / 精进 / 走火入魔。

### A.2 核心动词 + 核心循环
> **核心动词：闭关**（押注：赌多久、赌什么、怎么护法）

```
① 选武学 + 押注闭关时长（1h/4h/8h/24h）+ 配护法/丹药（资源换成功率、降心魔）
② 挂机闭关：修炼进度条走动；离线持续；偶发"心魔叩关"（回归时多一步镇压抉择）
③ 回归揭晓（核心爽点）：三重结算——
    顿悟  → 大幅熟练度 + 领悟新招/解锁连锁（稀有）
    精进  → 保底收益（不亏）
    走火入魔 → 退回一档境界 + 异象故事（可恢复，非真损失）
④ 用顿悟成果装配/强化武学连锁 → 挑战「心魔幻境」（battle-core 验证战）
⑤ 循环：破境 → 解锁更长闭关 / 更高赌注 / 更高阶武学
```

### A.3 上头点 / 成瘾钩子（心理学 × SDT）

| 钩子 | 机制 | 心理学依据 |
|---|---|---|
| 回归即揭晓 | 顿悟判定 = 可变比率强化（斯金纳箱） | 随机奖励：不可预测的回报最上瘾 |
| 赌徒心态 | 闭关 4h 后再加 4h → 顿悟率更高 | 沉没成本 + 承诺升级：停不下来 |
| 风险管理 | 护法/丹药配置决定成功率 | 胜任：胜率由玩家策略 + 运气共同决定 |
| 损失厌恶 | 走火入魔真实存在，但可恢复 | 损失厌恶：惩罚制造紧张，可恢复化解挫败 |
| 破境仪式 | 揭晓动画（屏息→光芒→结果） | 心流 + 悬念：回归的仪式感 |

**SDT**：自主（赌多大赌什么全自主）/ 胜任（护法配置 = 玩家技能，可优化）/ 关联（闭关间"江湖传闻你正在闭关"——世界知道你在修炼）。

### A.4 武侠味怎么体现
闭关、顿悟、心魔、走火入魔、护法、瓶颈、破境——**武侠修炼的核心母题直接变成机制**，"闭关三年"的武侠概念与"真实时间挂机"天然同构：时间不再是抽象的等待，而是武侠修为本身。

### A.5 放置味怎么体现
- 挂机 = 闭关（不是打怪收菜，是**修炼赌局**）
- 离线 = 闭关持续（离线越久，赌注越大——离线时长从"收益"变成"筹码"）
- 回归 = 揭晓（把"收菜"变成"开盲盒"，放置的回归时刻从拿奖励变成赌结果）

### A.6 与已定地基的关系
| 项 | 处理 |
|---|---|
| 复用 | **modules/09 闭关系统直接升级**（打坐/学点/熟练度/每日2h/离线结算已有，加"时长押注+顿悟判定"）；battle-core 复用为「心魔幻境」验证战；60 武学表 + 武学连锁复用（顿悟=连锁解锁入口之一）；装备系统复用（护法=装备位） |
| 让位 | 传统挂机打怪（模块 04）降级为"历练"辅助线；年表 idea 合并（顿悟/心魔可作年卡事件类型） |
| 改动量 | **小~中**（闭关升级 + 顿悟判定 + 揭晓动画 + 幻境战斗入口） |

### A.7 受众与风险
- **受众**：放置老玩家（对"等"厌倦 → "赌"新鲜）+ 数值追求者
- **风险①** 顿悟概率平衡：高=无惊喜低=挫败 → 保底"精进"兜底 + 概率可见（玩家看得见成功率构成）
- **风险②** 在线内容偏薄：闭关 + 验证战两端 → 心魔幻境做多层验证（每层一个境界对手）
- **风险③** 赌注负面情绪 → 走火入魔做成"可恢复"（退回一档 + 异象故事化），惩罚是"故事的"不是"资产的"
- **验证方式**：MVP 跑"1h 赌局"最小闭环，测**回归留存**（3 天观察玩家是否反复回归"揭晓"）

**MDA**：M=闭关时长/成功率计算/顿悟判定；D=押注→揭晓→验证→再押注；A=Sensation（揭晓光芒）+ Challenge（风险管理）+ Fantasy（修炼者）

## 三、方向 B：江湖衣钵 · 世代传承 ★ 双支柱兼得

### B.1 一句话新奇点
**"你挂机的不是角色等级，是一整段人生"**——角色会老，你把毕生所学与记忆传给下一代，一代代人生堆叠成你的江湖（放置 = 世代周期）。

### B.2 核心动词 + 核心循环
> **核心动词：传**（把毕生所学、记忆、名声传给下一代）

```
① 培养当代角色：挂机修炼 + 年卡抉择（人生感）+ 搭配武学（构筑感）——一代人 = 一个完整"人生+构筑"周期
② 角色年老（人生进度条将尽）→ 触发「收徒」事件：3 个候选传人（天赋/性格/出身各异）
③ 做传承抉择（成本 = 舍弃）：传武学衣钵 / 传记忆（命途印记）/ 传名声 / 传宝物——四选二，直接决定下一代起点
④ 旧角色「谢幕」：江湖小记回顾一生（年表回放 + 成就 + 遗憾）→ 下一代继承，开始新人生
⑤ 世代累积「衣钵」（永久资产：传人图鉴 + 血脉/门派传承强化）→ 解锁世代专属武学与事件
```

### B.3 上头点 / 成瘾钩子（心理学 × SDT）

| 钩子 | 机制 | 心理学依据 |
|---|---|---|
| 人生感密度极致 | 每代 = 完整人生 + 临终传承的情感时刻 | 叙事沉浸：一代人一次完整弧光 |
| 损失厌恶 → 转化 | 角色会死，但"传承"把死亡变成新生 | 损失厌恶转化：死亡不是惩罚，是叙事高潮 |
| 世代滚雪球 | 每代起点更高，衣钵永久累积 | 多巴胺：长线成长的滚雪球效应 |
| 传人图鉴 | 收集传人天赋/性格/出身组合 | 收集欲：我的江湖家族史 |
| 跨代关联 | NPC 记得"你师父当年救过我" | 关联：被世界记住的归属感 |

**SDT**：自主（传人选择 + 传承抉择全自主，正邪门派皆可）/ 胜任（每代构筑 + 传承搭配 = 策略深度）/ 关联（传人图鉴 + 跨代 NPC 记忆 = 家族归属）。

### B.4 武侠味怎么体现
师徒传承、衣钵、香火、门派延续、遗愿、师门恩义——**武侠核心母题**，且"传"这个动作天然是武侠的（不是游戏化"转生"的皮）：武侠世界观的"传承"概念直接成为**核心机制**，而非装饰。

### B.5 放置味怎么体现
- 挂机 = 一代人的修炼岁月（挂机对象从"数值"变成"一段人生"）
- "老去"不是数值卡点，而是**人生周期**——放置的"周期感"第一次有了叙事意义
- 离线 = 一代人在成长（离线回归 = "看看这一代人生走到哪了"）

### B.6 与已定地基的关系
| 项 | 处理 |
|---|---|
| 复用 | **年表 idea 完整保留**（每代人生 = 年卡序列，人生感支柱直接落地）；**武学连锁保留**（构筑 = 传承抉择的素材，"传什么"逼玩家想清楚自己的套路）；battle-core 复用（世代比武/门派试炼验证）；世界观 v0.2 完美契合（有缘人成长线 = 每代人的目标线；查小侠传说 = 传承原型的最高叙事） |
| 让位 | 传统挂机打怪（模块 04）降级为"游历"辅助线；门派系统保留但"拜师"反向为"收徒"（新增传承分支） |
| 改动量 | **中**（新增寿数/传承/传人系统；年表、连锁、battle-core、世界观**全保留**——是"组装"不是"重做"） |

### B.7 受众与风险
- **受众**：剧情玩家 + 放置玩家 + 大侠式人生玩家（直接对标该品类）
- **风险①** 角色死亡致流失 → 传承机制把死亡变成"新生" + 谢幕给"江湖小记"情感补偿
- **风险②** 世代周期太长等不及 → 一代 3~7 天可成型（放置节奏验证期定）
- **风险③** 传承决策复杂 → MVP 只做"四选二"三选一简化版
- **验证方式**：MVP 跑"一代人生"（约 1 周），测**7 日留存** + "传承时刻"情感反馈（谢幕页停留/分享）

**MDA**：M=寿数/年卡/传承抉择/衣钵累积；D=培养→传→继承→再培养；A=Narrative（一生+传承）+ Fantasy + Sensation

## 四、方向 C：江湖声名 · 名声传播

### C.1 一句话新奇点
**"挂机产出的不是金币，是名声"**——你的侠名/恶名像涟漪一样传遍江湖，传闻会变形（夸大/歪曲），而"你被传成了什么样"决定你的际遇。

### C.2 核心动词 + 核心循环
> **核心动词：扬名**（做一件事，让它在江湖上传开）

```
① 做「扬名之举」：行侠（救人/除害）/ 作恶（夺宝/劫掠）/ 著书 / 传艺 / 比武——每次举动带"话题性 + 传播半径 + 正邪偏向"
② 挂机传播：名声沿「江湖网络」（NPC/驿站/酒馆节点）传播，传闻在传播中变形（夸大/歪曲/张冠李戴）
③ 回归看「江湖舆论简报」：门派招揽 / 仇家寻仇 / 徒弟慕名 / 陌生人下战书 / 说书人把你的故事编成段子
④ 用名声兑换际遇：声望换武学缘分 / 残卷线索 / 人脉 / 地盘
⑤ 循环：名声越大 → 能做的事越大 → 但树敌越多（名声双刃剑）
```

### C.3 上头点 / 成瘾钩子（心理学 × SDT）

| 钩子 | 机制 | 心理学依据 |
|---|---|---|
| 回归好奇心 | "我的名声传成什么样了？" | 好奇 + 悬念：每次回归的揭晓欲 |
| 传闻变形 | 传播中故事被改写 → 意外惊喜/意外麻烦 | 随机奖励 + 叙事意外 |
| 被世界记住 | NPC 记得你、说书人传你的故事 | 关联：归属与存在感 |
| 名声双刃 | 恶名反噬（被围攻/被正派追杀） | 损失厌恶 + 后果张力 |
| 自由意志 | 正邪自由选，但"舆论不归你管" | 自主：选择自由 vs 后果不由己的张力 |

**SDT**：自主（正邪抉择自由）/ 胜任（管理名声传播半径 = 策略）/ 关联（江湖记得你——最强关联感）。

### C.4 武侠味怎么体现
侠名/恶名、江湖传闻、说书人、人脉、"人在江湖身不由己"——**武侠"名声"母题就是核心机制**（传播模拟），不是装饰性设定：玩家真切体验到"名声是把双刃剑"的武侠命题。

### C.5 放置味怎么体现
- 挂机 = 名声传播（挂机的"东西"从数值变成**"我的故事在传"**）
- 回归 = 看舆论 + 收际遇（放置的回归时刻从"收菜"变成"看我的人生被如何讲述"）
- 传播按"回合"推进（每 N 小时一波舆论潮），离线时长 = 故事传了多远

### C.6 与已定地基的关系
| 项 | 处理 |
|---|---|

### C.7 受众与风险

**MDA**：M=扬名举动参数/传播模拟/舆论事件；D=扬名→传播→舆论→际遇→更大举动；A=Narrative（我的传说）+ Fantasy + Sensation（涟漪可视化）

## 五、方向 D：武学炉火 · 相生相克炼制

### D.1 一句话新奇点
**"武学不是学的，是炼的"**——挂机采"武学矿"，在线按相生相克把素材投入炉火，炼出独一无二的武学；炼错会"炉毁"（合成 × 武侠 × 放置）。

### D.2 核心动词 + 核心循环
> **核心动词：炼**（把武学素材按相生相克投入炉火，炼出武学）

```
① 挂机产出武学「残篇/心法碎片」（素材带相性属性：剑/拳/刀/毒/柔/刚…）
② 在线「开炉」：选 2~3 个素材投入——
    相生（剑+剑=进阶剑法；剑+柔=轻灵剑）→ 成功炼成
    相克（剑+毒=毒剑或失败；刚+柔=冲突）→ 失败炉毁（素材损失）
③ 炼成武学 → 装配/连锁 → 变强（构筑爽感直接兑现）
④ 挑战「炉火秘境」（battle-core 验证战）→ 掉落高阶素材/隐藏配方
⑤ 循环：高阶配方 → 稀有武学 → 更强
```

### D.3 上头点 / 成瘾钩子（心理学 × SDT）

| 钩子 | 机制 | 心理学依据 |
|---|---|---|
| 合成欲/收集欲 | 素材收集 → 配方解锁，图鉴式驱动 | 收集欲：清单驱动的完成强迫 |
| 开炉揭晓 | 炼出稀有 = 开箱快感；炉毁 = 损失厌恶对冲 | 随机奖励 + 损失厌恶 |
| 相性记忆 | 记住相生相克表 = 玩家技能 | 胜任：知识即实力 |
| 隐藏配方 | 配出隐藏组合的发现乐趣 | 发现：非线性惊喜 |
| 构筑直连 | 炼出的武学直接进连锁/克制 | 构筑爽感：付出即兑现 |

**SDT**：自主（炼什么全自主）/ 胜任（相性知识 + 配方 = 技能）/ 关联（稀有武学可"传名江湖"——作品被世界记住）。

### D.4 武侠味怎么体现
武学相生相克、炉火纯青、武学真意、自创武功——**"相生相克"本就是武侠核心世界观**（非皮，是机制内核）：玩家在"炼"的过程中切身理解"刚柔相济、阴阳相生"的武侠哲学。

### D.5 放置味怎么体现
- 挂机 = 采武学矿（素材不是无脑金币，而是**有相性的资源**——每一次采集都在为"炼什么"做决策储备）
- 回归 = 开炉炼制（放置的"收菜"变成"开炉验货"——放进去的是选择，出来的是武学）

### D.6 与已定地基的关系
| 项 | 处理 |
|---|---|
| 复用 | 60 武学表 = 素材库 + 产物库（素材直接取武学名拆分）；**武学连锁 idea 被重塑**为"炼制的相性结果"（连锁 = 炼出来的相性组合，更本质）；battle-core 复用（秘境验证战）；装备系统复用（掉落） |
| 让位 | 传统打怪挂机降级为"采矿区"；年表 idea 可让位或保留为"炉火奇遇"事件 |
| 改动量 | **小~中**（新增合成系统：素材生成/相性判定/开炉 UI；战斗/武学全复用）——注意：对"学习武学"路径是重塑（学 = 炼？还是双轨？需 Leo 定） |

### D.7 受众与风险
- **受众**：合成/收集玩家（合成大西瓜/2048/放置奇兵受众）
- **风险①** 合成玩法微信已常见 → **必须靠"相生相克"武侠内核立住**（不是 merge 换皮），每步炼制有武侠叙事
- **风险②** 素材种类初期要够 → 60 武学拆素材绰绰有余
- **风险③** 配方可见性 → 隐藏配方有线索引导（江湖传闻给提示），不全黑盒
- **验证方式**：MVP 跑"3 种素材相生/相克"最小闭环，测**炼制留存**（合成欲驱动的回访）

**MDA**：M=素材相性/炼制判定/配方表；D=采→炼→装→战→采高阶；A=Sensation（炉火揭晓）+ Challenge（相性记忆）+ Discovery（隐藏配方）

## 六、方向 E：江湖推演 · 因果演化

### E.1 一句话新奇点
**"挂机时整个江湖在动"**——你的每次落子（扶持门派/打压邪派/传武于人）像涟漪改变门派兴衰与正邪消长，你回来看到的江湖，是你和大家一起"演"出来的。

### E.2 核心动词 + 核心循环
> **核心动词：定**（在关键抉择"定"下因果，挂机看整个江湖演化）

```
① 在线落子：在「江湖棋局」上做关键干预——扶持某门派 / 打压光明教 / 把残卷线索给某人 / 结盟或敌对
② 挂机推演：江湖按「因果规则」多轮演化（门派兴衰 / 人物恩怨 / 残卷易主 / 正邪消长）
③ 回归看「江湖志」简报：谁崛起了 / 谁覆灭了 / 谁与你结仇 / 哪卷残卷现世
④ 收「演化红利」+ 根据新格局再落子
⑤ 循环：格局越复杂 → 干预越关键 → 你的影响力（声望/势力）越大
```

### E.3 上头点 / 成瘾钩子（心理学 × SDT）

| 钩子 | 机制 | 心理学依据 |
|---|---|---|
| 操纵感/上帝感 | 我在改变一个活的世界 | 权力感：世界因我而变 |
| 回归好奇 | 演变成什么样了——回归即"看世界" | 好奇 + 悬念 |
| 损失厌恶 | 我的门派衰落了 / 我扶持的人背叛了我 | 损失厌恶 + 因果意外 |
| 随机事件 | 残卷现世等随机事件 | 随机奖励 |
| 我塑造的 NPC | 我培养的人走向由我决定 | 关联：养成 + 命运交织 |

**SDT**：自主（落子方向全自主）/ 胜任（推演预判 = 策略技能）/ 关联（我塑造的江湖人物 = 情感联结）。

### E.4 武侠味怎么体现
江湖格局、势力消长、正邪大战、因果报应、灵绝顶——**世界观 v0.2 的"群邪再起"设定直接变成"推演引擎的角色"**：玩家不是看故事，是参与塑造"乱世如何演进"。

### E.5 放置味怎么体现
- 挂机 = **世界在动**（放置的挂机对象从"我的角色"升级为"整个世界"）——放置品类前所未有
- 回归 = 看世界 + 收红利（放置的回归时刻从"收菜"变成"看江湖史"）
- 离线时长 = 世界演进了几回合

### E.6 与已定地基的关系
| 项 | 处理 |
|---|---|
| 复用 | 世界观 v0.2 **完整复用**（六门派/光明教/残卷 = 推演棋子）；武学连锁保留（落子的"武学"资源）；battle-core 复用（介入战斗：亲自下场改变推演） |
| 让位 | 年表 idea 被**替代**（推演事件网 > 年卡线性；人生感由"我培养的 NPC 命运"承担——注意：任务书说年表可让位但人生感不可丢，推演的人感 = NPC 命运关联）；传统打怪挂机降级 |
| 改动量 | **大**（推演引擎 = 全新系统：因果规则 + 状态模拟 + 事件生成；战斗/武学复用）——MVP 风险最高，必须砍成"简版推演"（回合制状态机，非实时模拟） |

### E.7 受众与风险
- **受众**：策略/模拟经营/轻量 4X 玩家
- **风险①** 引擎开发量大 → MVP 砍成"回合制状态推演"（5 门派 + 1 邪派 + 10 回合）
- **风险②** 世界演化反馈弱会无聊 → **强可视化**（江湖地图 + 事件流 + 说书人播报）
- **风险③** 落子意义感不足 → 每次干预要有"可感知的涟漪"（干预后第 1 回合就出变化）
- **验证方式**：MVP 跑"5 门派 + 光明教 + 10 回合推演"原型，测**"看世界"回访率**（回归好奇心）

**MDA**：M=因果规则/推演回合/干预动作；D=落子→推演→看简报→再落子；A=Narrative（活江湖）+ Fantasy + Challenge（策略）
