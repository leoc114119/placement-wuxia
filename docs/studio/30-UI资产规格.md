## 0. 一句话总则

> **每个素材 = 04 风格圣经的前置模板 + 本文件对应类别的模板 + 占位符填充。色值只用规范色，禁止引入规范外鲜艳色；素材一律无文字（文字由代码渲染，保证可缩放/可维护）。**

## 0a. 素材管线分级（Leo 2026-08-19 拍板：AI 生图仅草图级）

> **结论：AI 生图达不到生产级 UI 质量（Leo 实测反馈），UI 框架全面走代码绘制；AI 素材仅用于「背景/角色」类氛围内容，且一律视为草图，生产前需人工验收。**

> **角色形象（Leo 2026-08-19 拍板：MVP 简装）**：MVP 固定 1 个形象（`hero_1`），装备只影响数值、外观不变；**换装/部件式立绘（头/发/衣/武器分层）v1.0 预留**——美术生成管线届时按"部件独立生成 + 代码叠放"扩展。

| 素材类 | 生产方式 | 说明 |
|---|---|---|
| **按钮 / 面板 / 提示条 / 弹窗** | **代码绘制**（Canvas 程序化） | 几何 + 墨线描边 + 水墨晕染 + 圆角残破；风格可控、严格 04 色板、零素材体积。AI 素材仅作草图参考 |
| **进度条 / 血条 / 内力条** | **代码绘制** | 墨底 + 朱砂/竹青/黛青填充 + 毛笔刷边缘（30 §4.2 已如此） |
| **底部 Tab / 选中态 / 角标** | **代码绘制** | 简笔图标可代码画（山/书/包/人形）+ 三重编码选中态 |
| **背景（bg_main 类）** | AI 生图（可接受） | 氛围内容，远景山峦/水墨晕染，AI 质量足够，水印代码裁切 |
| **角色（hero_idle 类）** | AI 生图（可接受） | 内容型资产；AI 半写实水墨可用，水印裁切 |
| **大型图标 / 状态图标** | 代码绘制优先；AI 当草图 | 简笔 icon 代码画；复杂 icon 先用 AI 草图定方向再代码重绘 |

**验收更新**：UI 框架类素材（按钮/面板/条/Tab）以**代码绘制为唯一生产方式**，不再依赖 AI 素材；AI 素材只进 `assets/ui/` 的背景/角色目录。

## 1. 风格基线（引用 04，禁止偏离）

| 维度 | 规范 |
|---|---|
| 风格 | 活泼年轻的水墨国风：明快清透、灵动轻盈，**不老气、不 Q 版、不深沉** |
| 线条 | 毛笔笔触但轻盈有弹性，有动感，避免厚重浓墨 |
| 质感 | 淡墨晕染 + 透亮留白；面板宣纸/羊皮纸底，边缘做旧残破 |
| 图标 | 水墨简笔（一勾一划），不是精细写实 |
| 按钮 | 墨笔勾边 + 朱砂印章式点缀，按下有晕染反馈 |
| 排版 | 留白优先，信息克制；大字少而醒目（朱砂），小字灰墨 |

## 2. 尺寸与格式基准（微信小游戏适配）

### 2.1 设计基准稿

| 项 | 值 | 说明 |
|---|---|---|
| 设计稿 | **750 × 1334**（宽 750rpx） | 对齐微信 rpx 体系：750rpx = 屏宽 |
| 出图倍率 | **2x**（文件像素 = 设计 rpx × 2） | 保证主流 2x DPR 屏幕清晰；3x 高端屏由引擎整体缩放，可接受 |
| 画布适配 | Canvas 2D 按屏宽 750rpx 布局，高度自适应 | 背景用 cover 裁切模式 |

### 2.2 格式与体积预算

| 素材类 | 格式 | 说明 | 体积上限 |
|---|---|---|---|
| 按钮/面板/图标/提示条 | **PNG（带 alpha）** | 需透明底（圆角/残破边缘）；兼容性最好，Canvas drawImage 直接可用 | 图标 ≤ 50KB；按钮 ≤ 150KB；面板 ≤ 300KB（2x） |
| 全屏背景 | **JPG 或 WebP** | 无透明需求，压缩率高 | ≤ 400KB |
| 可选优化 | WebP | 同视觉质量体积约 −60%；**先验证目标微信版本 Canvas 解码 WebP 正常再全量切** | — |

> 小游戏有包体限制，MVP UI 总体预算建议 **≤ 2MB**（2x PNG 全部素材）。超限再统一转 WebP/压缩。

### 2.3 生图输出与裁切注意

- 多数工具默认输出 1024×1024 方形：按钮/提示条是横条、面板是 8:5，**生成时提示词指定"主体居中+四周留白"构图，交付前裁切到规格尺寸**。
- 透明底：优先选支持透明 PNG 输出的工具；不支持时出**纯宣纸/纯白底**，交付前统一去底（remove.bg / PS / 即梦抠图），并在 README 登记实际尺寸。
- 生成后人工验收 4 项，不合格直接重生成、不 PS 硬修（去底除外）：
  1. 色值全在规范色板内；
  2. 无任何文字、无人物（UI 类）；
  3. 主体居中、构图干净；
  4. 四角/边缘装饰在九宫格边距内（见 3.3）。

### 2.4 AI 工具水印处理（Leo 2026-08-19 拍板：代码裁切）

> ImageGen 等 AI 生图工具会**自动在素材右下/底部加"AI 生成"水印**，违反 §2.3 验收第 2 条（无任何文字）。处理方案：**代码层裁切**（零成本，不重生成，保留风格）。

**通用裁切函数**（ZCode 实现参考，放 `src/systems/render.ts` 或 `assets/loader.ts`）：

```ts
/**
 * 绘制 AI 素材并裁切底部水印。
 * @param trimY 底部裁切比例（默认 0.06 = 6%，覆盖两行 "AI生成" 水印）
 */
export function drawAssetTrimWatermark(
  ctx: CanvasRenderingContext2D,
  img: HTMLImageElement,
  dx: number, dy: number, dw: number, dh: number,
  trimY = 0.06,
) {
  const srcH = img.height * (1 - trimY);
  ctx.drawImage(img, 0, 0, img.width, srcH, dx, dy, dw, dh);
}
```

**按素材类的裁切建议**：

| 素材类 | 推荐裁切 | 理由 |
|---|---|---|
| `bg_*` 全屏背景 | 底部 6%（cover 适配时几乎不可见） | 背景下边缘细节裁切无感 |
| `btn_*` 按钮 | 底部 4%（保留底边毛笔残破） | 按钮下边裁多会失去质感 |
| `panel_*` 面板 | 底部 5% | 面板底边对称裁切可接受 |
| `icon_*` 图标 | 右下角 12% × 12% source rect 裁切 | 图标水印在右下角精确裁 |
| `toast_*` 提示条 | 底部 5% | 同面板 |

**验收更新**：§2.3 第 2 条"无任何文字"在 AI 素材类改为"**水印已被代码裁切不可见**"。

## 3. 命名规范

### 3.1 前缀表

| 前缀 | 类别 | 目录 |
|---|---|---|
| `bg_` | 全屏背景 | `assets/ui/`（根或 `panels/` 均可，README 登记为准） |
| `panel_` | 面板（可九宫格） | `assets/ui/panels/` |
| `toast_` | 提示条 | `assets/ui/panels/` |
| `btn_` | 按钮（可九宫格） | `assets/ui/buttons/` |
| `icon_` | 图标 | `assets/ui/icons/` |

### 3.2 状态后缀（按钮）

| 后缀 | 状态 | 说明 |
|---|---|---|
| `_normal` | 正常 | 必做 |
| `_pressed` | 按下 | 必做（移动端无 hover，_hover 省略） |
| `_disabled` | 禁用 | 建议做（灰化/降饱和，仍在墨色系内） |
| `_selected` | 选中 | 标签/页签类用 |

### 3.3 九宫格（Nine-slice）约定

- 九宫格边距以 **rpx 逻辑尺寸**标注，2x 文件换算 ×2。
- 原则：**装饰（圆角、印章、做旧、纹样）必须全部落在边距内，中央区域必须纯纹理可拉伸**。生成时把做旧集中在四角四边，中央留均匀宣纸纹理。
- 按钮的朱砂印章若在角落，直径需 ≤ 边距，避免拉伸变形。

## 5. 每类资产风格要点（引用规范色值）

### 5.1 按钮
- 主按钮：**朱砂 `#E2574C`** 渐变底（左上浅右下深，可用珊瑚 `#FF7E67` 提亮左缘），**墨 `#2B2B2B` 细线勾边**，左下角一枚小朱砂印章点缀，右下角淡金 `#D4AF37` 云纹一角；按下态 = 墨色晕染加深 + 印章压印感。
- 次按钮：**宣纸 `#F8F4EA`** 底 + 墨线勾边，极轻微做旧；按下态 = 淡墨晕染。
- 图标按钮：宣纸/透明底 + 墨色简笔符号 + 细墨线圆角方框。
- 按钮面**干净无文字**（文字由代码渲染：主按钮文字用墨色或深朱砂底白字，见 31 文档对比度约束）。

### 5.2 面板 / 提示条
- 弹窗面板：宣纸底（羊皮纸质感、细噪点）+ 四边细墨线描边 + **回纹/云纹简单纹样**（墨，淡）+ 左上/右下角做旧残破（磨损、晕染）；中央大面积均匀留白供九宫格拉伸。
- 提示条：深墨 `#2B2B2B` **半透明**底（约 60%）+ 淡金 `#D4AF37` 细线描边，两端半圆，水墨晕染质感。
- 背景：写意水墨山水，**天青 `#A8C4C8`** 淡晕染 + 宣纸留白，墨笔近景 + 淡墨远山，中景大块留白（供 HUD/面板叠放）。

### 5.3 图标
- 水墨简笔，一勾一划，灵动有弹性；墨 `#2B2B2B` 为主，局部**单一**点缀色（朱砂/黛青/淡金选一）。
- 六维属性用**抽象符号 + 形状区分**，不单靠颜色（色盲友好，见 31 文档）：臂力=拳形/力纹、胆识=火焰/战意、根骨=磐石/山形、机敏=燕形/风纹、定力=莲花/静水、悟性=书卷/慧目。
- 状态图标用「图标 + 颜色」双编码：中毒=毒雾骷髅（黛青 `#4A7A6B` 雾）、失血=血滴（朱砂 `#E2574C`）、增益=祥云（淡金）、减益=灰云（深灰 `#444`）。

### 5.4 通用约束
- 禁止规范外鲜艳色（如纯红 `#FF0000`、纯蓝 `#0000FF`、荧光绿）。
- 线条统一「轻盈有弹性」的毛笔质感，不厚重。
- 所有素材无文字、无水印、无外文。
