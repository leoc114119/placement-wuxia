### 0b. 完整战斗流程（Leo 2026-08-19 定，机制闭环）

```
进入战斗（手动点怪 / Boss 战 / 挂机遇 Boss）
  ① 布阵展示：我方 **1 人（玩家）**y=10、敌方 y=1（数量按玩家实战档位 1~6，R-07）；初始视角 = 玩家位置
  ② 行动循环（逐棋子）：
     行动条填充（F-05：(100+内功×3+机敏×1)/10 + 峨眉+10%）→ 满 100 行动：
       自动模式：AI 走位 + 自动出招（外功 > 特技 > 绝学 > 暗器 > 普攻兜底）
       手动模式：行动条满 → 角色上方出「特/轻/绝」+ 绿色移动格 → 玩家操作
                 90s 无操作 → 当前回合自动 AI 代行；再 90s → 切回自动模式（F-05）
       普攻自动：移动到位敌人相邻即自动普攻（按武器光影）
       施放武功/绝学/暗器 → 范围光影 → 范围内敌人受击 → 伤害/状态结算（§5b）
     出招后行动条归 0 → 下一棋子
  ③ 一方全部阵亡 → 战斗结束（胜/负遮罩 + 战报）；防死循环超时 90s → 存活 hp 总量高者胜
  ④ 结算：
       胜利 = 奖励入账（学点/实战/银两）+ 掉落入包（06），保留战损 hp/内力
       失败 = 回场景 hp=maxHp×30%（保底30）+「失血过多」疗伤 60s（R-10）
       逃跑 = 无损失、无结算、不扣体力，直接回场景
  ⑤ 战斗回放：battleLog 关键帧可查看（ADR-001 全离线回放架构）
```

### 1b. 视觉风格：2.5D 等距战棋（Leo 2026-08-19 定，参考老网金）

> **核心变更（不影响战斗逻辑）**：从完全垂直俯视 8×8 → **等距/菱形 2.5D 投影**；棋盘以角色为中心可平移；**战斗朝向随机**；战斗逻辑/范围/行动条仍走 8×12 逻辑坐标。

#### 1b.1 等距投影（固定方向 A，Leo 定）

```
俯视坐标 (x, y)   →   等距屏幕坐标 (px, py)
  方向 A（cos30° 正菱形，尖朝上）：
    px = (x - y) * tileHalfW + centerX
    py = (x + y) * tileHalfH + centerY

tileHalfW = tileSize * cos(30°) ≈ tileSize * 0.866
tileHalfH = tileSize * sin(30°) = tileSize * 0.5
```

- 棋盘格呈**菱形**铺排（尖朝上，参考截图：右上 + 左下方向的对角菱格）
- **战斗朝向随机**：我方/敌方上下位置随机 —— 本场可「我方在下、敌方在上」（从下往上进攻），也可「我方在上、敌方在下」（从上往下）；**逻辑层固定 我方 y=10 / 敌方 y=1，仅渲染层按朝向翻转映射**
- 远近有景深：远处格子略小、近处略大（可选优化，MVP 可统一大小）
- 角色立绘贴格子中心，比格子略大、立于格面上方

#### 1b.2 镜头跟随角色（竖屏视窗 = 以角色为中心的菱形，Leo 确认预览 ✅）

- **屏幕 = 以主角色为中心的菱形视窗**：竖屏（375×667）下 8×12 等距棋盘 > 屏幕是**预期**，不追求一屏显示全部格子；镜头始终聚焦主角周围（主角附近格子为屏幕中心）
- 主角移动 → 镜头跟随平移，不脱出棋盘
- 接近边缘 → 镜头停止平移（不让主角出屏）
- 镜头模式切换：可固定镜头（关闭跟随）/ 自动跟随（默认）
- **无缩放功能**（Leo 定：不需要放大/缩小）
- 验证：`preview/battle-preview.html`（竖屏 8×12 等距棋盘预览，可拖拽/点选/手动操作）

#### 1b.3 范围指示（高亮）

- 玩家选中技能时 → 该技能范围内所有格子**菱形高亮**（朱砂描边 + 浅色填充）
- 可攻击目标格子高亮更深；不可攻击但范围经过的格子高亮较浅（仅范围提示）
- 出招范围模式（03 §3.4）：小十字可拖拽指定落点 → 显示拖拽落点的菱形预览

#### 1c. 棋子头顶信息（Leo 2026-08-19 定：方便知道哪个是哪个）

每个棋子（角色/NPC/好友）头顶显示三行信息，悬浮在立绘上方：

```
┌─────────────┐
│   清风剑客    │  ← 名称（行 1）：**我方=竹青字，敌方=朱砂字，Boss=朱砂大字+加粗**（颜色编码，一眼区分）
│ ██████░░░░░ │  ← 行动条（行 2）：淡金进度条（0~100，行动条满发亮）
│ ███████░░  │  ← 血条（行 3）：朱砂渐变 + 数值（当前/上限）
└─────────────┘
```

| 项 | 规格 |
|---|---|
| **名称（颜色编码）** | **我方棋子 = 竹青 #4A7A6B**（青色字）；**敌方 = 朱砂 #E2574C**（红色字）；双方名字**颜色必须不同**（Leo 强调）；底 = 半透明深色（统一，靠字色区分）；**Boss 名字 = 朱砂加深 + 加粗 + 边框**（一眼识别） |

## 4. 战斗模式：自动 vs 手动（Leo 定）

### 4.1 自动模式（默认进入）
- 角色**自动寻敌** → 自动走近 → 走到攻击范围 → **自动出招**（已装配的武功按优先级自动选择：外功 > 特技 > 绝学 > 暗器 > 普攻）
- 玩家**无需操作**，观看战棋表演
- 适用场景：快速通关 / 挂机中遇 Boss 自动切战棋 / 新手友好 / 大招时机让 AI 决策

### 4.2 手动模式（Leo 2026-08-19 细化）

**行动条满时**，角色上方出现三个悬浮技能按钮 + 绿色移动范围：

```
        [特] [轻] [绝]      ← 角色上方悬浮按钮（有对应武功才显示；内力不足/冷却置灰，冷却=R-08）
          ●（角色）
     ┌ 绿色可移动格子范围 ─┐   ← 行动条满时同时显示（可点击）
     │ ▢ ▢ ▢ ▢ ▢ │
     │ ▢ ● ▢ ▢ ▢ │       移动力 = 基础 + 轻功等级加成（F-06）
     │ ▢ ▢ ▢ ▢ ▢ │
     └─────────────────────┘
```

| 操作 | 行为 |
|---|---|
| **点击绿色格子** | 角色移动到该格（消耗行动次数）；**移动到位后若敌人相邻（1 格）→ 自动普攻**（普攻不需要手动） |
| **点 [轻]** | 轻功跳跃：显示**更大范围的跳跃格**（金色），点击任意格 → 角色直接跳过去（无视路径/阻挡，超出普攻距离先拉近距离） |
| **点 [特]** | 释放装配的外功（范围 = 武器形态 × 等级档位，§5）；**以选中范围为中心播放武功光影**（§5b），范围内所有敌人受击 + 结算 | 
| **点 [绝]** | 释放装配的绝学（大范围/高伤，消耗内力多；冷却后置）；**播放绝学全屏/大范围光影**（§5b），范围内所有敌人受击 + 结算 |
| **不操作** | 行动条满后不操作 → 行动条保持满（不自动移动，等玩家指令） |

- 行动条满前提：行动条满 + 内力够 + 未死亡（§5）
- **普攻自动**：只要移动到敌人 1 格距离，自动普攻，无需手动（Leo 定）
- 走位 + 出招 = 老手深度（控制大招时机、走位规避）

### 4.3 模式切换
- 右下角 [⚙] 按钮：**自动 ↔ 手动**，任何时候可切换
- 切到手动：暂停自动出招，等待玩家指令
- 切回自动：恢复 AI 决策，继续自动走位出招

## 5. 出手规则（与 01 §4 联动）

```
行动条满 → 立即行动：
  ① 移动（自动：向最近敌移动一格；手动：玩家点绿色格子 / 点[轻]跳跃）
  ② 普攻自动：移动到位后敌人相邻（1 格）→ 自动普攻（自动/手动模式都生效）
  ③ 出招判定（手动：玩家点[特]/[绝]；自动：AI 自动选技能）：
     行动条满（满 100）
     内力够（按 R-09 内力消耗表：普攻0/轻功10/外功一阶20/二阶50/三阶100/绝学150）
     未死亡（hp > 0）
     装配武功匹配武器类型（R-05，不匹配降级普攻）
  ④ 行动后 actionBar 归 0
```

- 行动条基础满值 100（01 §4.1），填充速度 = (100 + 内功×3 + 机敏×1)/10 + 峨眉 +10%（F-05）
- 攻击范围 = 武器形态 × 武功等级档位（03 §3.3 + §3.3b：剑/拳小十字 3×3→7×7、棍/棒大十字 3→7、鞭/刀扇形 3→5、暗器单格 4→6→**9**；阈值 20/40/60 不限阶数）；**范围越界格子无效不结算（clamp）**
- 移动范围 = F-06（基础 2 格 + 轻功加成；[轻]跳跃范围更大）
- 范围模式（03 §3.4）：小十字 = 跟随移动或拖拽指定；十字/扇形/单格 = 固定位置

### 5b. 施放光影 + 范围结算（Leo 2026-08-19 补充）

#### 5b.1 施放光影（以选中范围为中心播放）

| 施放类型 | 光影表现 |
|---|---|
| **武功（[特]）** | **每种武功光影不一样**（数据表"特效"字段联动）：剑气横扫 / 刀罡劈斩 / 掌风冲击 / 枪芒穿刺 / 棍影扫荡 / 鞭影缠绕……以**选中范围为中心**播放对应光影 |
| **绝学（[绝]）** | **绝学专属大光影**：全屏/大范围特效（如三阶必杀剑气冲霄、太极归元气场扩散），视觉冲击最强 |
| **暗器** | 暗器飞行轨迹 + 落点爆炸小特效 |
| **普攻** | **按武器不同光影不同**（R-05 武器绑定）：剑 = 剑光横扫 / 刀 = 刀光 / 拳 = 拳风 / 棍 = 棍影 / 鞭 = 鞭影 / 暗器 = 飞射轨迹 |

- 光影实现：Canvas 粒子/光效叠加（动画层，不影响逻辑）；每种武功一个 `fx` 配置（11 武功表"特效"字段驱动）
- 光影播放时机：出招 → 以选中范围中心播光影（约 0.4~0.8s）→ 命中判定 → 结算

#### 5b.2 范围结算（范围内所有敌人同时受击）

```
施放武功/绝学/暗器 → 攻击范围内【所有】敌人同时受击：
  ① 命中判定（F-04：命中率/闪避，未命中=0）
  ② 伤害结算：每个受击敌人 = F-01 公式（攻防×品阶系数×暴击）
  ③ 状态结算：中毒 / 减速 / 反击 / 灼烧等（07 门派技能 + 11 武功特效）
  ④ 同时飘字：多个敌人头顶同时弹出伤害数字（各自独立颜色）
  ⑤ 血条/行动条/状态图标刷新
```

- 与 headless 战斗模拟同源：伤害/状态唯一真值走 settle 云函数，客户端只展示
- 普攻 = 单体（武器光影 + 单体结算）；武功/绝学/暗器 = 范围（多目标同时结算）

#### 5b.3 受击表现（Leo 2026-08-19 定：角色不动，只播命中效果）

| 效果 | 实现 |
|---|---|
| **受击命中** | **角色立绘不动**（不播受击帧），身上播**命中光效**（朱砂/白色闪光 + 溅射粒子）+ 伤害飘字（数值 = headless 结算结果） |
| **未命中（miss）** | 飘「miss」灰字，无伤害、无命中光效（F-04 判定，**后补**） |
| **反击（counter）** | 被击后按概率触发，复用出招帧 + 反击特效（**后补**，07 门派技能联动） |

> 帧需求：受击/命中/miss/反击**均不占素材帧**——纯代码光效粒子（对应 77 清单 §0.1）。

### 5c. 补充机制（Leo 2026-08-19 收尾补全）

#### 5c.1 门派技能（战斗中表现）
- 已装配门派技能（07）在战斗中按 **F-18 概率自动触发**（5% + 实战/1000W×20%，封顶 25%）
- 触发时：播放门派技能光影 + 状态飘字（如剑心通天=加攻、万毒蚀心=中毒、浴血狂战=增伤）
- **不消耗内力**（10 §4）；纯自动，无需玩家操作

#### 5c.2 战斗回放（battleLog）
- 每场战斗记录 battleLog（关键帧：行动/出招/伤害/状态/胜负）
- 战斗结束遮罩提供「回放」入口（ADR-001：全离线回放架构）
- 回放 = 客户端用 battleLog 重放（数值唯一真值在云函数 settle）

#### 5c.3 死亡与胜负
- 棋子 hp ≤ 0 → 阵亡：变灰/半透明，行动跳过
- **一方全部阵亡 → 战斗结束**（胜/负遮罩 + 战报）
- **防死循环超时（90s）**：双方均未全灭 → 存活 hp 总量高者胜，总量相同判玩家负（01 §4.5）
- **失败回写（R-10）**：回场景 hp = maxHp×30%（保底 30）+「失血过多」疗伤 60s → 恢复满血（手动/挂机/Boss 战统一）；战斗入口疗伤期间禁用
- **逃跑（[退出]）**：无损失、无结算、不扣体力（新手容错）

## 6. 战斗结束 & 结算

- **一方全部死亡** → 显示战斗结束遮罩（胜/负 + 战报 + 战斗回放 key 帧）
- **退出 = 逃跑（Leo 定）**：点顶部 [退出] → 直接退出战斗回进入前场景，**无损失、无结算**（不掉落、不扣体力、不算胜负）
- 跳回：
  - 手动点怪 → 回江湖场景，结算入账
  - Boss 战 → 胜：解锁下一场景 + 掉落入包（08）；负：回场景弹提示（失血过多疗伤后重试）
- 结算奖励：学点/实战/银两（击杀奖励）+ 掉落入包（06 bag.addDrop）
- 失败态：失血过多（R-10，hp 30% + 疗伤 60s），期间战斗入口禁用
