# 放置武侠 · MVP UX 规格 v0.1

> 状态：**评审稿（待 Leo 审）**
> 日期：2026-08-19
> 定位：MVP 七环节 UX 规格——界面构成 / 用户流程 / 交互要点。视觉约束严格来自 `04-UI风格规范-v0.1.md` 与 AGENTS.md；禁止引入规范外颜色。
> 战斗口径：**3v3 = 1 主玩家 + 2 好友助战**（敌方按关卡 3v3~3v6；6v6 为侠客系统上线后上限，Leo 2026-08-19 拍板 PR-01/D-01）。结算模型 = **A 全离线回放**（云函数一次跑完返回 battleLog，客户端只播 log、零判定）；手动大招后置（PR-02 决策）。本规格不涉及独有卖点。
> 装备口径：**D-05 已拍板装备进 MVP**（获取=掉落为主 + 商店银两购买为辅，无合成；8 部位 / 5 档 / 5 品质；分解→银两），本规格新增「环节六：背包·分解·商店」。
> 关联评审：docs/studio/10-设计评审报告.md（P0×2 / P1×13 / 待决策 13 项）

## 0. 总则（所有环节共用）

### 0.1 色板（仅用以下规范色值）

| 色类 | 色值 | 用途（遵循 04 §2） |
|---|---|---|
| 墨 | #2B2B2B | 文字、线条、血条底（偏柔和不纯黑） |
| 深灰 | #444444 | 次要文字、禁用态 |
| 宣纸 | #F8F4EA | 背景、面板底 |
| 浅杏 | #F0E6D4 | 面板次级底、内衬 |
| 朱砂 | #E2574C | 按钮主色、重点数值、血条填充 |
| 珊瑚 | #FF7E67 | 强调点缀（警示/高亮按钮 hover） |
| 黛青 | #4A7A6B | 标签、内力条、青墨装饰 |
| 竹青 | #7FB069 | 成长/进度条、正向状态 |
| 淡金 | #D4AF37 | 品质高亮、稀有标识、印章点缀 |
| 天青 | #A8C4C8 | 场景氛围、背景晕染 |
| 藕荷 | #E8D8DE | 次级氛围、女性向装饰 |

> 品质色映射（12 装备 5 品质，04 色板无紫）：白=宣纸 #F8F4EA / 绿=竹青 #7FB069 / 蓝=黛青 #4A7A6B / 紫=藕荷 #E8D8DE（临时映射，待 D-08 定是否扩板）/ 橙=珊瑚 #FF7E67。**品质名文字标签必显（色+字双编码，防色盲歧义，30 §5.3）。**

### 0.2 字体（04 §3）

- 标题/大数字：毛笔书法体（汉仪尚巍手书/叶根友毛笔类，注意授权）
- 正文：宋体/仿宋（思源宋体类）
- 禁用：黑体/微软雅黑（除非局部强调）

### 0.3 通用状态（04 §4/§5 质感）

| 状态 | 表现 |
|---|---|
| 加载 | 水墨晕染 + 书法字（如"踏入江湖…"），淡墨留白 |
| 空态 | 淡墨留白 + 一句引导文案（墨 #2B2B2B），不裸露空面板 |
| 错误 | 朱砂印章式小横幅（墨线勾边 + 朱砂字），2-4 秒自动消失 |
| 按钮 | 墨笔勾边 + 朱砂印章式点缀，按下有晕染反馈（04 §4） |
| 进度条/血条 | 墨色底 + 朱砂填充，毛笔笔刷边缘（04 §4） |
| 菜单层级 | 2-3 层，不深嵌套（04 §5） |

### 0.4 文案语气（水墨武侠 · 活泼年轻）

- 称呼玩家"少侠"；短句、口语、江湖味；轻快不古板。
- 正反馈："修习有成！""这一战，名动江湖！""内力充盈，可再战十场！"
- 负反馈/引导："学点不足，先去闯荡一番。""内力不足，歇息片刻再来。""前方凶险，少侠莫要强闯。"
- 数值展示：大字少而醒目（朱砂 #E2574C），小字密集（墨 #2B2B2B 60% 透明）。

### 0.5 触控基线

- 可点击区域 ≥ 44×44 pt（微信小游戏触控基线）
- 关键操作（学武/挑战/领取）需 2 步内可达；危险操作（清除存档）需二次确认

## 1. 环节一：最小工程（启动/主界面）

> 目标：空项目在微信里显示画面，验证 Canvas 渲染 + 主循环 + 场景切换（02 §4 步骤1）。

### 1.1 界面构成

| 元素 | 内容 | 规范引用 |
|---|---|---|
| 启动页 | 天青→宣纸水墨晕染背景；LOGO"放置武侠"书法体（墨 #2B2B2B）；副标"挂机 · 习武 · 论剑"（黛青 #4A7A6B） | 04 §0/§4 加载过场 |
| 主界面（山门庭院） | 宣纸底 + 浅杏面板；远景水墨山峦（天青晕染） | 04 §1 明快清透 |
| 顶部状态栏 | 战力（朱砂大字）、等级、银两、学点（墨小字） | 04 §5 大字醒目小字密集 |
| 底部导航 | 修习 / 武学 / 闯荡 /（侠友 若进 MVP）四个 Tab，图标水墨简笔 | 04 §4 图标水墨简笔 |

### 1.2 用户流程

```
进入：启动页(加载 0.5-1s) → 主界面
操作：无（本环节只验证显示与场景切换）
反馈：画面稳定渲染、帧率正常、无黑屏
退出：切后台/关闭；再进走读档（环节六）
```

| 状态 | 表现 |
|---|---|
| 加载态 | 水墨晕染 + "踏入江湖…" |
| 空态 | 不适用（本环节无数据面板） |
| 错误态 | 渲染失败=全屏朱砂横幅"江湖初开未成，重启试试" |

### 1.3 交互要点

- 启动页点击任意处跳过（或 1s 自动进入），防卡启动。
- 底部导航 4 个 Tab 先可点但未实装项显示"敬请期待"（淡金印章）。
- 验收：主界面 60fps 目标，切换场景无白屏。

## 2. 环节二：挂机循环

> 目标：挂机 5 分钟 → 数值可见增长；学点跳动（02 §4 步骤3、§5 验收）。对应 12 双轨产出（学点为主）。

### 2.1 界面构成

| 元素 | 内容 | 规范引用 |
|---|---|---|
| 修习面板（主界面中央） | 当前闭关武学名（书法体）、学点跳动（朱砂大字 +N）、熟练度进度条（竹青 #7FB069 填充 + 墨底） | 04 §4 进度条 |
| 内力条 | 黛青 #4A7A6B 填充 + 墨底，旁标"内力 62/100" | 04 §4 |
| 闭关武学选择区 | 当前运功内功/自修武学卡片（可切），选中高亮淡金描边 | 04 §5 信息克制 |
| 离线收益弹窗 | 宣纸面板 + 墨线残破边框；标题"闭关归来"（书法体）；收益列表（学点/熟练度）；"领取"按钮（朱砂底、宣纸字） | 04 §4 面板/按钮 |

### 2.2 用户流程

```
进入：主界面 → 修习面板
操作：① 选闭关武学（首次需选，之后默认沿用）→ ② 开始闭关 → ③ 挂机计时
反馈：学点数字跳动（+N/s）、熟练度条缓慢增长、内力条随时间恢复
退出：切场景/切后台；回归时弹离线收益
```

| 状态 | 表现 |
|---|---|
| 空态 | 未选闭关武学："尚未选择闭关武学，去武学阁挑一门吧"（武学阁按钮引导） |
| 加载态 | 离线收益计算中："正在结算闭关所得…"（0.5s 内） |
| 错误态 | 收益结算网络失败："收益结算延迟，稍后再试"（朱砂横幅，重试按钮） |
| 离线收益 | 超过 1 分钟离线即弹；按实际离线时长给收益（**上限 = 每日自修 2h，MVP 生效 ✅ D-06**） |

### 2.3 交互要点

- 学点数字用大号朱砂字体居中跳动，制造"变强感"（放置核心爽点）。
- "领取"按钮 ≥ 44pt，点击后收益入账 + 印章动画"收讫"。
- 闭关武学切换有确认："换修 [武学名]，当前进度保留"（防误操作）。
- 每日自修上限到后，弹"今日已修至极致，明日再来"（**D-06 MVP 生效 ✅**）。

## 3. 环节三：学武功

> 目标：学到新武功 → 战力提升（02 §4 步骤4、§5 验收）。对应 10 门派武学"学点+前置武功等级"、11 数据表。

### 3.1 界面构成

| 元素 | 内容 | 规范引用 |
|---|---|---|
| 武学阁（列表页） | 分类 Tab：外功/内功/轻功/门派技能（墨线分隔）；武学卡片：名称（书法体）+ 品阶标签 + 学点消耗 + 已学勾 | 04 §5 层级浅 |
| 品阶标签色 | 一阶=墨灰 #444 / 二阶=黛青 #4A7A6B / 三阶=淡金 #D4AF37（高亮） | 04 §2 青金点缀 |
| 武学详情弹窗 | 宣纸面板；品阶徽记、属性加成（根骨+10 等）、前置链（墨线连接：清风剑法→三仙剑法→清扬九剑）、学点+银两消耗、"修习"按钮（朱砂底） | 04 §4 面板 |
| 顶部资源条 | 学点 / 银两余额（朱砂大字），不足时变深灰+警示 | 04 §5 |

### 3.2 用户流程

```
进入：主界面 → 武学阁
操作：① 选分类 → ② 点武学卡 → ③ 查看详情 → ④ 点"修习" → ⑤ 校验成功/失败
反馈：成功="修习有成！[武学名] 已入武学库"（朱砂印章动画）；战力 +N 提示
退出：返回列表 / 主界面
```

| 状态 | 表现 |
|---|---|
| 空态 | 无武学可学："入门武功已学尽，江湖武学待残卷开启"（江湖武学=超 MVP 提示） |
| 加载态 | 列表加载："正在翻阅武学典籍…" |
| 错误态 | 学点不足："学点不足，先去闯荡一番"（引导去闯荡）；前置未学："需先习得 [前置武学]"；银两不足："盘缠不足，分解装备换些银两" |
| 禁用态 | 不满足条件的"修习"按钮置灰（深灰），点击弹原因 |

### 3.3 交互要点

- 学习是核心付费/资源点，反馈必须有"获得"仪式感：印章 + 水墨扩散。
- 前置链可视化：详情弹窗里用墨线画"前置→本武学"，未学前置显示为锁形（墨灰）。
- 内功武学详情内提供"设为当前运功"开关（装配当前内功，对应 13 §5.1 装配内功）。
- 数字（学点消耗/加成）一律服务端下发展示，UI 不算数值（AGENTS 铁律）。

## 4. 环节四：战斗 3v3（1 主玩家 + 2 好友助战）

> 目标：3v3 战棋最小版（1 主玩家 + 2 好友助战；02 §4 步骤5，Leo 2026-08-19 拍板 PR-01/D-01）。敌方数量按关卡配置 3v3~3v6（14 §1）。**6v6 为侠客系统上线后的最大上限，MVP 不做。** 结算模型 = A 全离线回放（云函数一次跑完返回 battleLog，客户端只播 log、零判定）；手动大招后置，本页默认不含手动大招。

### 4.1 界面构成

| 元素 | 内容 | 规范引用 |
|---|---|---|
| 战前布阵 | 棋盘（宣纸底 #F8F4EA、格线淡墨 30%）；己方 3 人（1 主玩家 + 2 好友助战，水墨简笔头像 + 好友来源标识）+ 可拖拽站位；敌方 3~6 预览（右上方，剪影，按关卡配置）；"开始论剑"按钮（朱砂底） | 04 §6 棋盘宣纸底 |
| 战斗 HUD | 棋盘居中；双方血条（墨底+朱砂填充，毛笔笔刷边缘）；行动条（水墨圆点图形化，不堆数字）；倍速按钮 1x/2x/4x（淡金高亮当前）；快进按钮 | 04 §5 图形化 HUD |
| 武功光影 | 出招时范围光影（剑小十字/棍十字…）——**全画面唯一高饱和区域**，UI 保持克制 | 04 §6 武功光影唯一彩色爆发 |
| 伤害飘字 | 朱砂 #E2574C 数字飘字，暴击更大号 + 淡金描边 | 04 §5 |
| 结果弹窗 | 胜利/失败横幅（书法体，胜利=朱砂/失败=黛青）；奖励列表（学点/实战/装备掉落）；"再来一场"/"返回" | 04 §4 |

### 4.2 用户流程

```
进入：闯荡 → 选关卡 → 布阵（含好友助战选择）→ 开战
操作：① 布阵（点击选中→点击格子放置；或一键默认阵；好友不足/助战次数用尽时 1~2 人可上阵）→ ② 开战 → ③ 云端回放播放 → ④ 倍速切换/快进 → ⑤ 结果
反馈：伤害飘字、血条变化、武功光影、AI 走位（均来自回放数据，客户端零判定）；结果页结算入账
退出：结果页 → 返回闯荡 / 再来一场
```

| 状态 | 表现 |
|---|---|
| 空态 | 好友不足：布阵时"尚缺 [N] 位好友助战，可先只身迎战"（14：无好友时 1 人可打，新手地图 1v1 温和递进）；无好友："先去邀好友同闯江湖"（侠友 Tab 引导） |
| 加载态 | 布阵确认后"论剑开始…"（水墨晕染 0.5s）；战斗为云端回放时加载"正在取回战报…" |
| 错误态 | 云结算失败："云峰论剑暂不可达，稍后再战"（重试）；结算超时：转本地重试队列 |
| 中途退出 | 战斗自动播放中切后台：回放制=下次进入重新拉取结果；实时制=按已发生进度结算（取决于 D-02） |

### 4.3 交互要点

- 布阵：点击己方角色→点击空位放置；"一键布阵"（墨线按钮）兜底；好友助战在布阵前选择（默认勾选可用好友，每日限 3 次，14 §3，次数用尽提示"今日助战已尽，且看少侠独闯"）。
- 倍速：1x/2x/4x 点击即切，按钮高亮淡金；快进=直接跳结果（需确认"跳过战斗，直接看结果？"）。
- 战斗为云端回放（A 方案）：客户端零判定、不提供手动走位/手动大招；中途切后台不影响回放结果（下次进入重新拉取 battleLog）。
- 全程不展示公式/计算过程，只展示结果数字（UI 只展示，AGENTS 铁律）。

## 5. 环节五：刷怪

> 目标：解锁链 + 掉落，能打到更高级怪（02 §4 步骤6、§5 验收）。对应 12 在线推图（学点/实战/装备掉落）。

### 5.1 界面构成

| 元素 | 内容 | 规范引用 |
|---|---|---|
| 闯荡地图 | 关卡链横排/纵排（山脚→密林→峡谷…，按实战分档）；当前关卡高亮淡金描边；已通关=朱砂印章"胜"；未解锁=墨灰剪影+锁形 | 04 §2 青金点缀 |
| 关卡详情弹窗 | 敌方预览（数量/实力，剪影+实力条）；掉落预览（学点/实战/装备品质色点）；"挑战"按钮（朱砂底，旁标内力消耗） | 04 §5 克制 |
| 战败状态横幅 | 失血过多提示："重伤未愈，闭关疗伤后再战"（12 §1.1 失血状态） | 04 §4 按钮质感 |
| 掉落展示 | 胜利后掉落列表：装备卡（品质色描边 + 名称）、学点/实战数字；"装备已入行囊"提示 | 04 §4 |

### 5.2 用户流程

```
进入：主界面 → 闯荡 → 选关卡
操作：① 点关卡 → ② 查看详情 → ③ 挑战（扣内力）→ ④ 战斗（环节四）→ ⑤ 结果（掉落+解锁）
反馈：胜利="大胜而归！"奖励入账；新关卡解锁="解锁新地图 [地名]！"；失败进失血状态
退出：结果页 → 返回地图 / 继续闯荡
```

| 状态 | 表现 |
|---|---|
| 空态 | 无下一关："前方暂无去路，待江湖新篇"（内容上限） |
| 加载态 | 地图加载："正在赶路…" |
| 错误态 | 内力不足："内力不足，先服大还丹或歇息"（引导买药/等恢复）；失血过多：禁挑战按钮置灰，提示"闭关疗伤或服金疮药"；网络失败："结算未达，重试" |
| 掉落空 | 未掉落装备："此战只余学点与实战"（正常态，不显空错误） |

### 5.3 交互要点

- 关卡链即进度可视化，通关印记（朱砂印章"胜"）是收集感来源。
- 挑战按钮二次确认（消耗内力 N 提示），防手滑。
- 失血状态需清晰：角色头像变灰 + 状态横幅，引导动作明确（疗伤/吃药）。
- 掉落装备品质色：白=宣纸 / 绿=竹青 / 蓝=黛青 / 橙=珊瑚；紫待定（PR-14/D-08）。
- 解锁新关卡 = 小型庆典反馈（淡金印章 + 水墨扩散），承接"变强"正循环。

## 6. 环节六：背包 · 分解 · 商店（D-05 已拍板：装备进 MVP）

> 目标：装备闭环落地（12 §0 核心循环：推图 → 掉装备 → 分解 → 银两 → 学武/买药 → 变强）。D-05 已拍板：装备进 MVP（获取=掉落为主 + 商店银两购买为辅，无合成；8 部位 / 5 档 / 5 品质；分解→银两）。**详细交互见 65-背包分解商店.md。**

### 6.1 界面构成

| 元素 | 内容 | 规范引用 |
|---|---|---|
| 背包（行囊） | 顶部资源行（银两/学点/战力）；8 部位展示（武器/衣服/披风/鞋子/头部/项链/护手/戒指）；装备卡（品质色描边 + 名称 + 战力）；排序/筛选 | 04 §5 信息克制 |
| 装备详情弹窗 | 宣纸面板；属性 + 与当前装备对比（差值：竹青 #7FB069 正值 / 朱砂 #E2574C 负值）；"穿戴"（朱砂底）/ "分解"（墨线）/ "卸下" | 04 §4 面板 |
| 分解确认 | "将 [装备名] 化为银两 [N]？分解后不可复原"（二次确认，品质 ≥ 蓝 再提示风险） | 04 §4 按钮 |
| 商店（集市） | 商品列表（大还丹 / 金疮药 + 装备刷新位）；银两余额（朱砂大字）；"刷新"（墨线）/ "购买"（朱砂底） | 04 §5 |
| 购买确认弹窗 | 商品名 + 数量 + 银两消耗 + "确认"（朱砂底）/ "取消" | 04 §4 |

### 6.2 用户流程

```
进入：主界面 → 行囊（主界面右下角"行囊"入口 + 掉落提示条可点击直达）
操作：① 查看掉落 → ② 点装备 → ③ 详情对比 → ④ 穿戴 / 分解 / 卸下
     商店：银两 → 买药（推图续航）→ 刷装备位 → 购买
反馈：穿戴后战力 +N（竹青）；分解银两入账飘字 + 印章"收讫"；购买成功印章"收讫"
退出：返回主界面 / 继续闯荡
```

| 状态 | 表现 |
|---|---|
| 空态 | 背包无装备："行囊空空，去闯荡江湖赚些家当"（闯荡按钮引导） |
| 加载态 | 背包加载："正在清点行囊…" |
| 错误态 | 银两不足："盘缠不足，分解装备换些银两"（引导去背包分解）；分解网络失败："分解未成，稍后再试" |
| 品质色 | 白=宣纸 #F8F4EA / 绿=竹青 #7FB069 / 蓝=黛青 #4A7A6B / 紫=藕荷 #E8D8DE（临时映射，待 D-08）/ 橙=珊瑚 #FF7E67；**品质名文字标签必显（色+字双编码）** |

### 6.3 交互要点

- 新装备入包 → 主界面"行囊"角标（淡金印章"新"）+ 掉落提示条可点击直达背包。
- 穿戴替换：旧装备自动回背包，弹"已换装 [新]（战力 +N）"。
- 分解不可逆：一律二次确认（"分解后不可复原，确认？"）；批量分解仅限白/绿，蓝+ 逐件确认。
- 商店装备为银两回收口（随机品质 + 限购/刷新），装备主来源仍为掉落；商品刷新 = 每日免费 N 次 + 银两刷新（数值见 64/65）。
- 全部数值（银两/分解产出/购买价）由服务端下发，UI 只展示（AGENTS 铁律）。

## 7. 环节七：存档闭环

> 目标：挂机→结算→存档→学武功→变强 闭环（02 §4 步骤7、§5 验收"云函数结算正确、存档可读回"）。

### 6.1 界面构成

| 元素 | 内容 | 规范引用 |
|---|---|---|
| 存档角标 | 主界面右上角小印章"已存"（淡金 #D4AF37），保存中变竹青"存…"，失败变朱砂"未存" | 04 §2 印章点缀 |
| 设置面板 | 玩家 ID（墨小字）、上次存档时间、"手动存档"按钮（墨线按钮）、"清除缓存"（朱砂警示，二次确认） | 04 §4 按钮 |
| 读档页 | 启动时加载："正在取回江湖记忆…"（水墨晕染） | 04 §4 加载过场 |

### 7.2 用户流程

```
进入：启动 → 读档（云端）→ 主界面
操作：自动存档为主（关键节点：学武成功/战斗结算/离线收益领取/每日上限重置）
     手动存档为辅（设置面板）
反馈："进度已妥存"（淡金印章 2s）；失败="存档失败，网络不稳，请重试"
退出：正常退出前自动存一次；强杀进程也走云端最近一次存档
```

| 状态 | 表现 |
|---|---|
| 空态 | 新玩家无档："新入江湖？点击开始新的传说"（开局引导，对应 05 有缘人开局） |
| 加载态 | 读档中："正在取回江湖记忆…"；读档完成="少侠，久违了"（书法字欢迎） |
| 错误态 | 读档失败："江湖记忆暂不可取回，重试或继续本地游玩"（网络错误不阻塞进游戏，本地先跑，后台重试） |
| 版本不匹配 | 存档版本落后：提示"江湖又添新篇，少侠进度已同步"（平滑迁移，不做清档） |

### 7.3 交互要点

- 存档目标：无感化——玩家不该为存档操心，自动存档角标给"安心"而非打扰。
- 关键节点存档列表（学武/战斗/离线）写进 02 接口契约 `POST /save`，字段由工程定（评审 G-02）。
- 清除缓存/重置需二次确认（朱砂警示框："将清空本机记录，云存档不受影响？"）。
- 存档成功/失败角标 3 态（已存/存中/未存）颜色区分，失败可点重试。
