## 3. 武学 Tab（Leo 定 · 3 子块）

| 子块 | 内容 |
|---|---|
| (a) 基础属性 | 进入游戏即有的六维：臂力/胆识/根骨/机敏/定力/悟性 |
| (b) 基础武学 | 基础身法/基础内功等——**提高基础六维**的养成界面 |

> **基础武学 · 分类（Leo 2026-08-19 定）**：二级 Tab 分两组——
> - **六维强化**：基本内功(根骨) / 基本身法(机敏) / 搏击格斗(臂力) / 拆招卸力(定力) / 读书识字(悟性)（每 10 级 +1 属性，封顶 100 级 +10）
> - **武器精通**：基本剑法(剑攻) / 基本刀法(刀攻) / 基本拳法(拳攻) / 基本枪法(枪攻) / 基本暗器(暗器攻)（提升对应武器基础攻击力）
> - 原型 v11.3 已落地
| (c) 武学配置 | 已学武学列表 + **等级提升（不须去门派重复学）** + **装配切换**（多武学时选配）|

> **武学配置 · 装备位布局（Leo 2026-08-19 定）**：紧凑卡片式，不用竖排列表——
> - **第一行**：外功 + 内功（宽格，各占 1/2）
> - **第二行**：轻功 · 特技 · 绝学（窄格，各占 1/3）
> - **Lv 显示在武功名下方**（朱砂小字）；未装配格=虚线空槽
> - 卡片压高（min-height 64px），无说明行；**已学武学列表与装备位同屏可见**（不滚动到第二屏）；原型 v11.1 已落地
>
> **已学武学 · 升级（Leo 2026-08-19 定）**：按类型**二级 Tab 分组**（外功 / 内功 / 轻功 / 特技 / 绝学，与装备位分类一致），选中 Tab 显示该类已学武学；空分类显示空态「尚未习得 X」；原型 v11.2 已落地

> 装备/包裹独立成 Tab（不并入武学，Leo 2026-08-19）。

## 5. 江湖 Tab（Leo 定 · 2.5D 江湖场景）

> **Leo 2026-08-19 重构定稿**：江湖 Tab = **2.5D 江湖场景**，删掉一切我们没有的功能（任务栏/活动入口/铁匠铺/图鉴/邮箱/充值等），只保留核心。

> **⚠ 实现方式（Leo 2026-08-19 定，重要）**：江湖 Tab **不走「AI 生整屏 UI 稿」流程**——它是动态界面（人物移动/NPC 行为/状态切换），**直接代码绘制（Canvas 2D）**。preview 原型即设计稿。**AI 生图只负责提供静态素材**：2.5D 背景图 + 角色立绘 + NPC 立绘；交互 UI（血条/按钮/助战入口/收益条）由代码叠加渲染在背景图之上。其他静态 Tab（武学/装备/门派）仍走「生图模式截图 → GPT Image 出整屏稿」。

### 5.1 双模式总览（Leo 2026-08-19 手绘确认）

> **江湖 Tab = 手动 / 挂机 双模式**：
> - **手动模式（默认）**：角色**手动移动**（点哪走哪）+ **手动点 NPC 开战** + 手动 Boss 挑战
> - **挂机模式（点「挂机」按钮后）**：加载**挂机 UI** → 角色自动寻怪 → **打小怪不进战斗场景，直接播放打怪小动画 → 自动结算（约几秒一场）** → 血条/内力条/收益条常显 → Boss 自动挑战时切场景图

> **战斗界面 = 自动 / 手动 双模式（Leo 2026-08-19 定）**：手动点 NPC 开战 或 BOSS 挑战时，切入战棋界面（`docs/studio/75-战斗界面规格-v0.1.md`）；8×8 棋盘+双方顶部信息栏+8 武功快捷+自动/手动模式切换（手动可手动走位+手动出招）。挂机推图不进战棋，在场景内动画。

### 5.2 场景布局（自上而下）

| 区域 | 内容 | 产出方 |
|---|---|---|
| **左上角** | 场景名称（如「青牛山下 · 野径」，场景内悬浮标签） | 代码 |

| **战斗 NPC** | 场景中 2~3 个战斗打怪 NPC（山贼/野狼/熊），**随机走动 + 主动攻击角色**；手动点它=开战 | 立绘 AI / 行为代码 |
| **Boss 挑战入口** | 场景内底部第三按钮（挂机右侧）：**闭关 | 挂机 | 挑战Boss**，点它=挑战 Boss 切场景图 | 代码 |
| **手动模式提示** | ~~常驻提示已移除~~ → **改为新手引导**（首次进入江湖时一次性引导：点场景移动/点 NPC 战斗） | 代码 |
| **挂机 UI**（仅挂机模式） | 打怪小动画区（我方武学 × 敌方名 + 伤害飘字）+ 血条/内力条 + 学点/实战/银两收益条 | 代码 |
| **场景内底部三按钮** | **闭关修炼 | 挂机 | 挑战Boss**（紧凑尺寸，悬浮场景内底部） | 代码 |

### 5.3 核心流程（双模式）

| 流程 | 细节 |
|---|---|
| **手动模式** | 点场景任意位置 → 角色走过去；点 NPC → 进入战斗（战棋界面）；点 Boss → 挑战（切场景图） |
| **挂机模式** | 点「挂机」→ 加载挂机 UI → 角色自动寻怪 → **打小怪直接播打怪动画 → 自动结算（几秒一场）** → Boss 自动挑战（切场景图）→ 再点「挂机」退出挂机 |
| **闭关** | 点「闭关」→ 切换**另一张 2.5D 室内场景图** → 手动选择闭关 → **离线后自动闭关** → 界面显示人物打坐样式 |
| **NPC** | 随机走动 + 主动攻击；手动点它=开战；**被击败后消失** |
| **助战** | 右上角助战入口 → 邀请 2 好友 → **同好友最多 10 场/天，每天刷新**（自动推图 + 手动 Boss 均有效）—— ⚠ **MVP 后置（R-03），战斗 = 玩家 1v 多** |

### 5.3b 交互决策明细（Leo 2026-08-19 拍板）

| # | 待定项 | 决策 |
|---|---|---|
| 1 | 手动移动操作 | **点击位置**（点哪走哪，点击场景位置 → 角色走过去） |
| 2 | NPC 被打败后 | **消失**（不刷新/不残留尸体） |
| 3 | 挂机打小怪形态 | **打怪小动画 + 自动结算**（不进战斗场景，约几秒一场） |
| 4 | 闭关"室内场景"形态 | **另一张 2.5D 室内场景图**（全屏切换，非主界面淡出） |
| 5 | 助战剩余场数刷新 | **每天刷新**（每日 10 场/好友，次日重置） |
| 6 | 手动点 NPC | **进入战斗（战棋界面）** |
