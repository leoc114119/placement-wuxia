## 2. Leo 的五个设计输入（全天最核心的资产）

> 以下均为 Leo 原话，**不改写**。后续任何设计判断都应回溯到这五条。

### 输入 1 · 那个画面（12:14）
> **「段誉的六脉神剑」**

补充定位（12:41）：「六脉神剑主要是**华丽的武功效果**，**指哪打哪**的神奇武功」
→ 取"华丽 + 指向"，**不取**"时灵时不灵"（该解读已被 Leo 的补充排除）

### 输入 2 · 那一次"对了"（12:14）
> **「金庸群侠传 OL 的 PK」**

→ 网金 PK 的爽点 ≠ 操作。是「我（某门派弟子，练了很久）打赢了那个具体的人」= **身份 + 养成 + 恩怨**的三重兑现。
→ 提供视频：优酷《网金online-华山论剑版：京城客栈6月12日PK》（**画面受 DRM 保护，未能观看**）

### 输入 3 · 玩家怎么玩（12:14）
> **「每天忙时点点点，闲时也可以享受江湖武侠梦」**

→ **双节奏并行，不是二选一。** 忙时轻量、闲时沉浸，共用同一套成长。

### 输入 4 · 心中的武侠（12:51）
> **「江湖恩怨。。门派对立。。不同的特色武功。。」**

→ 三个词**都不关于"怎么打"**——分别属于关系层、身份层、差异层。
→ 但 Leo 随即纠正（输入 5）：**不是只有这三层。**

### 输入 5 · 怎么打也重要（12:53）
> **「怎么打当然很重要啊，。。我用不同的武功和不同的门派战斗，还要考虑战斗中的出招，躲闪」**

→ 🔑 **"考虑"，不是"反应"。** 他要的是战中的出招决策与躲闪，但**不是 200ms 反应窗口的 QTE**（12:59 明确否决）。

## 3. 两次原型失败记录

### 原型 01 · 破招手感原型（`proto/01-破招手感原型.html`，08-28 深夜）

| 项 | 内容 |
|---|---|
| 形态 | 单点反应式：缩圈 + 按对时机 |
| Leo 判定 | 「一直在点圆圈……不过模式不错」→ **机制失败，验证流程被认可** |
| 尸检 | 决策密度四象限只点亮 1 个（Read），且只有单一维度 |
| 提取的硬约束 | ① 除"按对时机"外必须有别的事可做 ② 爽感≠好玩 ③ demo 必须自带决策或变化 |

### 原型 02 · 剑气对射原型（`proto/02-剑气对射原型.html`，08-29 12:47）

| 项 | 内容 |
|---|---|
| 形态 | 竖版 1v1；按住蓄力→拖动瞄准→松开发射；剑气可互撞抵消；内力条 + 六脉齐发；三种对手性格 |
| Leo 判定 | **「你做了一个打飞机游戏出来哈哈」** |
| 尸检 | 竖版 + 下方向上射 + 弹丸互撞 = **纵版 STG 骨架**。我把"华丽武功效果"译成了子弹特效，把"指哪打哪"译成了瞄准射击——**取其形、失其神** |
| 更深的断裂 | 只做了闭环的"释放"一环，丢了"养成"与"真人"两头 → 纯反应游戏，与网金 PK 无关 |

### ⚠️ 两次失败的共同模式

> **把"武侠体验"翻译成"游戏机制"时，我每次都滑向了最容易实现的通用动作骨架。**
> 动作游戏的壳最好写，武侠的神最难机制化 → 本能地滑向容易的一侧。

**⚠️ 关于《光与影：33号远征队》**：QTE 层不可迁移，但**结构层仍值得留档**——
- 策略层 + 操作层**并存**（非二选一）
- 一个开关切换"轻/重"两种深度（对应忙时/闲时）
- 挡住了 → 反击比自己技能还狠（高风险高回报的兑现）
- 敌人出虚招（起手相同、后续不同）
→ **只有这四层可迁移，QTE 本体不可迁移。**

## 5. 网金 PK 生态结构（从视频标题解码，未看画面）

**来源**：优酷 UP 主 1653645028641127 的 28 个网金视频标题（视频本体受 DRM 保护无法观看）

**① PK 有三种场**

| 场 | 特征 | 小游戏可行性 |
|---|---|---|
| **客栈 PK** | 小、随时、个人或小队（Leo 给的就是客栈 PK） | ✅ 可迁移 |
| **门派比武** | 门派内、有"决赛"（恒山/星宿/丐帮/血刀/少林各有） | 🟡 需先有门派系统 |
| **坛战** | 帮派团战、抢总坛（贪狼/白虎/青龙）；有战术（"暗度陈仓"）、目标（"打兽"）、分工（"加血"） | ❌ 做不了 |

**② 恩怨是具体的 ID**
- 「无敌萌客栈PK**惨遭团灭**」→「智取"无敌萌"白虎和青龙总坛」
- **江湖恩怨 = 记住一个 ID，然后找回来。不是系统，是人。**

**③ 走位是核心技术**
- 标题原文：「坛战加血据说**走位要风骚**」→ 印证"躲闪"是真实存在的核心技术

**④ "绝学"是一个游戏阶段**
- 「绝学阶段坛战」「绝学门比」「7分钟绝学武学展示」→ 与 `03` §7.3「绝学三件套」呼应

**⑤ 其他**
- 「双手机率测试」→ 有概率机制值得玩家专门测试
- 「绑脚比武」→ 有限制条件的公平赛
- 「客栈无外挂日PK」→ 外挂是社区痛点，设计上需前置防挂

### 💡 一个市场观察

网金官方早已停运，但"华山论剑版"至今仍有活跃社区（持续组织门派比武与坛战、持续录视频至今年 7 月）。
→ 这批用户 **35–50 岁、有消费力、有情怀、但已无大块时间玩 PC 端游**。
→ **正是"忙时点点点，闲时享受江湖武侠梦"的目标人群**，与 `00` A-01 的"B 武侠情怀用户"吻合，且是**已被验证的存量人群，不是假设**。

## 7. 主理人的自我复盘（为什么今天这么难）

**三条，第三条是我的责任。**

1. **感觉 vs 机制的翻译失真**
   Leo 要的是一个"感觉"，我必须交付一个"机制"。这两种语言的翻译我做了三次，三次都取其形、失其神。

2. **我没有网金的一手经验**
   所有网金知识都是二手的。Leo 的高光时刻是二十年前的肌肉记忆——**我无法复现一个我没经历过的体验**。这是硬约束，不是努力能解决的。

3. **⚠️ 角色错配——这条是我的失误**
   创意机制设计是 **design-strategist（文策渊）** 的专长；我的专长是编排、质量门、跨成员一致性检查。
   本会话无法 spawn 成员（Agent/Task 工具未挂载），Leo 授权我代行，**我接了，但我应该第一时间把这个"降级的质量风险"明确说出来，而不是默认自己能顶上。**
   → **教训：能力降级时，必须同步降级预期，而不是默默硬扛。**
