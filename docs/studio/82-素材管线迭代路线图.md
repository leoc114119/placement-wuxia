## 三、迭代方向（四层，按序吃）

### A · 工具链自动化（短中期 · CodeBuddy 可直接落地）
- **去背换模型**：rembg/U2Net（pip onnxruntime ~300MB）替代 flood-fill——封闭空隙/抗锯齿/白毛边缘全解，预计清 90% 残留类问题
- **质检门 CI 化**：探针（贴边/白岛/逐帧对比/锚点一致性）串成**转正必过门**，不过不转正
- **出图即检**：mxai 出图后立即跑探针，重残留直接打回重生成

### B · 规格单一真源（中期 · 需 ZCode 配合）
- 帧表语义（帧数/帧组/锚点/idle 映射）只存一处，生成端与 config **同源读取**——消灭 COUNT 不同步类事故
- 素材清单（assets-p0.json / ICON-MATRIX）与代码 config 双向校验脚本

### C · 自动渲染验收（中期 · 价值最大）
- 帧按渲染参数合成到场景背景（模拟 drawHero/drawNpc），自动截图 + 探针检查——白块/错位/吊飞提交前即抓

### D · prompt 模板化（流程 · 最快）
- 帧表 prompt 固定条款：朝向一致 / 主体轮廓闭合 / 腿间裙摆覆盖 / 无孤立白斑（08-22 三条教训直接进模板）

## 四、优先级建议

2. **中期**：B 单一真源（配 ZCode）

### 像素风规格（Leo 2026-08-23 定稿）

- **风格锚**：v8（gpt-image-2 文生图 → 裁切 → 一次 LANCZOS 缩到渲染尺寸 → 只转纯白背景 >250 低彩度 → 合成）——硬边像素 + 有限色板 + 平涂明暗，无渐变无抗锯齿
- **角色渲染高 = 210px**（竖版背景 1200 高时占 17.5% 屏高；替代立绘 HERO_HEIGHT_RATIO 0.21 的 140px）
- **穿透铁律**：透明化只碰纯白背景（>250 且彩度<8），衣料浅色/高光永不转透明
- **场景尺度铁律（Leo 定）**：生成场景背景必须记住人物身高——**场景物体（石头/树木/建筑/道具）不得超过角色高度的 1.5 倍**，角色是尺度锚（等距格子 tileVisualH=54，角色≈4 格高）
- **立绘转岗**：剧情对话立绘（不浪费）；游戏内战斗/场景用像素角色
- **换装**：部件分层（武器/头饰/外套叠层），武器层优先
