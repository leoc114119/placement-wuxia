## 〇、三分钟摘要（Leo 先读这段）

**结论先行：推荐「方向 C：残卷寻踪」为骨架，内嵌轻量年表 + 完整连锁，改动量按中控制，三块都可独立验收、独立砍掉。**

### 我们到底在解决什么

对标《大侠式人生》的启示只有一个：**高评分来自"人生感密度 + 构筑乐趣密度"，与表现力无关**。所以本次深化的全部工作 = 把这两样密度做进现有地基，不新增任何重系统。

### 两个核心机制（MVP 可落地）

**① 江湖年表（剧情 × 放置）** —— 剧情不打断挂机，它是挂机时间的叙事化表达。
- 挂机 + 离线时间累计，**每 4 小时 = 江湖 1 年**（初值 🔧）
- 每年过完 → 进游戏/离线回归时弹 1 张「年卡」：3~5 句文案 + 1 次抉择（2~3 选项）
- 抉择产出**命途印记**（如「剑痴」「毒君子」）——印记不判善恶，只分路线
- **印记直接解锁/强化武学连锁** → 剧情给搭配赋义的第一层咬合
- 不做《大侠式人生》式的"每年行动点分配"——那会破坏放置节奏；我们用"一年一次抉择"替代，操作密度低、代入感高

**② 武学连锁（搭配 × 自走棋）** —— 全部挂在现有 battle-core 上，增量改动。
- **三件套连锁**：外功 + 内功 + 轻功 同门派成套 → 激活连锁（如清风三件套 = 「剑心通明」行动条+15%）
- **门派克制环**：清风克天山、天山克狂刀、狂刀克太极、太极克峨眉、峨眉克清风，丐帮中立（铁衣自成一派）——只在伤害公式加一个乘区
- **连锁技（爽感时刻）**：门派技能触发判定（现有 F-18）时，若连锁已激活 → 释放升级版"连锁技"（大范围 + 专属光影，复用现有 fx 模板，零新素材）
- **自创武功**：激活跨门派/隐藏连锁时，允许玩家**给连锁命名**（存一个字符串字段）→ 低成本高情感的"我的绝学"

### 剧情与搭配如何互相支撑（任务书硬要求）

| 咬合点 | 机制 | 方向 |
|---|---|---|
| 印记 → 连锁 | 年卡抉择给印记，印记解锁连锁完全版 | 剧情决定构筑深度 |
| 残卷 → 绝学 | 年卡给残卷线索，收集解锁江湖绝学（混搭枢纽） | 剧情进度解锁混搭材料 |
| 克制 → 叙事 | 克制理由写成年卡故事（清风祖师以剑破毒…） | 剧情为机制背书，机制验证剧情 |

### 三个方向速览（详见 §5）

| 方向 | 一句话卖点 | 改动量 |
|---|---|---|
| A 江湖年表 | "挂机不是打怪，是过一生" | 中 |
| B 武学构筑 | "六十路武学，配出你的绝学" | 小 |
| **C 残卷寻踪（推荐）** | "十四卷残卷，十四种江湖，你选哪条路" | 中~大（可控为中） |

**改动量评估（对已定地基）**：全部是**增量**（新增数据表 / 新增 UI 区块 / battle-core 两处小改），无一处推倒重建。详细挂接清单见 §3.6、§4、§5。

## 一、设计总纲：两根支柱的咬合模型

### 1.1 我们反对什么

- ❌ 剧情 = 打断挂机的过场动画（放置玩家的敌人是"等待"，不是"剧情"）
- ❌ 搭配 = 数值最优解的冷计算（那是 Excel，不是武侠）
- ❌ 两个孤立模块（剧情自嗨、搭配自嗨，玩家感觉不到它们是一体的）

### 1.2 我们主张什么

```
               ┌──────────────────────────────────┐
               │        剧情（江湖年表）              │
               │   把"挂机时间"翻译成"我的江湖岁月"     │
               └───────────────┬──────────────────┘
                               │ 命途印记（路线分化）
                               ▼
               ┌──────────────────────────────────┐
               │        搭配（武学连锁）              │
               │   把"变强的表达"翻译成"我的绝学"      │
               └───────────────┬──────────────────┘
                               │ 战力/进度（过更强的年卡事件）
                               ▼
               ┌──────────────────────────────────┐
               │      叙事目标（十四部残卷寻踪）        │
               │   给"为什么变强"一个江湖式的答案       │
               └──────────────────────────────────┘
```

**一句话**：搭配是玩家变强的**表达手段**，剧情给这种表达赋予**意义与目标**；年表负责"我是谁"，连锁负责"我能打"，残卷负责"我要去哪"。

### 1.3 与已定地基的关系（划清边界）

- 任务书地基全部复用，零推翻
- **重要区分**：本草案的"连锁" ≠ 待理清单 C-03 的"羁绊"（羁绊指侠客池角色间的组合，第一版不做）；本草案的"连锁" = **武学装配三件套的组合效果**，属于武学系统内部增量，与"侠客羁绊"无冲突
- 不引入：重叙事系统 / 大型开放世界 / 任务系统 / 门派贡献 / 侠客池（全部维持"后置"状态）

## 二、Deliverable 1：剧情 × 放置循环 ——「江湖年表」系统

### 2.1 核心洞察：为什么不做"行动点分配"

《大侠式人生》的"固定寿命 + 每年行动点分配"在**单机模拟器**里成立，但放在**放置小游戏**里有一个致命错配：行动点分配是高频高决策操作，会打断"挂机 → 收菜"的松弛节奏，把目标用户（A 放置老玩家）赶走。

**我们的改造**：保留"时间 = 人生"的骨架，把"每年分配"降维成"每年一抉择"。

```
《大侠式人生》：每年 → 分配 N 个行动点（修炼/游历/结交/任务）→ 高操作
《放置武侠》  ：每 4 小时挂机 → 江湖过 1 年 → 弹 1 张年卡 → 1 次抉择
```

- 操作密度：一天回归 2~3 次 = 每天 2~3 次抉择，符合放置节奏
- 决策密度：每次抉择影响印记/武学缘分/属性，玩家会认真想
- 代入密度：年卡文案把"离线时间"叙事化——玩家回归时看到的是"这三年江湖里发生了……"

### 2.2 江湖年表（机制定义）

| 项 | 规格 |
|---|---|
| 时间换算 | 挂机 + 离线时间累计，**每 4 小时 = 江湖 1 年**（初值 🔧，节奏验证后可调 3~6h） |
| 触发时机 | **进入游戏 / 离线回归结算时**（绝不打断挂机进行中；挂机中不弹） |
| 囤积上限 | 最多囤 3 张年卡，一次性结算（防长时间离线刷屏） |
| 年卡内容 | 标题 + 3~5 句文案 + 2~3 个选项 + 结算结果 + 可选回响 |
| 第 1 年 | 固定开局卡（新手引导剧情，替代纯教程） |
| 第 2~N 年 | 按年份段 + 前置条件从事件表抽取 |

**数据结构（建议，详细字段进 `config/narrative/events.ts`）**：

```ts
interface YearCard {
  id: string            // yc-001
  yearMin: number       // 触发年份段
  require?: Condition   // 前置：实战/门派/已有印记/残卷进度
  title: string         // 年卡标题
  text: string          // 3~5 句文案（碎片化叙事）
  choices: Array<{
    text: string
    result: {           // 结算结果（三类，可叠加）
      marks?: string[]      // ① 命途印记
      grants?: string[]     // ② 即时奖励：xuedian / yinliang / attr
      unlock?: string       // ③ 武学缘分 / 残卷线索
      sect?: string         // ④ 门派好感
    }
  }>
  reply?: string        // 回响文本（后续年卡引用你的选择 → 关联感）
}
```

### 2.3 命途印记（剧情给搭配赋义的第一载体）

- 定义：`Player.marks: string[]`，年卡抉择 / 门派行为累积
- 特性：**不判善恶，只分路线**——「剑痴」不是比「毒君子」高尚，是不同的人生
- 作用（三层，见 §4 咬合）：
  1. **解锁连锁完全版**：如「剑痴」印记 → 「剑心通明」连锁效果 100%（无印记 = 80%，差别可见但不过分）
  2. **解锁武学缘分**：如「毒君子」→ 可触发天山毒系江湖武学的年卡事件
  3. **影响选项可用性**：无「侠义」印记 → 某些正派年卡选项置灰（推动重玩）

### 2.4 年卡示例（MVP 首批 8 张，覆盖第一个月节奏）

| 年 | 标题 | 事件梗概 | 选项（示例） | 结果 |

| 1 | 破庙夜雨 | 初入江湖，破庙中遇重伤老丐与诡异郎中 | ①施药救人 ②学解毒术 ③默然离去 | ①侠义印记+银两 ②毒君线索+天山好感 ③悟性+ |

### 2.5 放置节奏怎么嵌剧情（时序）

```
日常节奏（以 4h/年 计）：
  早上进游戏  → 离线 8h = 2 年 → 弹 2 张年卡（1 分钟）→ 收菜 → 挂机出发
  中午回归    → 4h = 1 年 → 弹 1 张年卡 → 收菜 → 挂机
  晚上回归    → 4h = 1 年 → 弹 1 张年卡（可囤 3 张）
  
关键设计：年卡总是"先于收菜"弹出，形成
  「看我的人生 → 拿我的人生奖励 → 继续过人生」的回归仪式
```

### 2.6 低成本实现方式

| 成本项 | 方案 | 量级 |
|---|---|---|
| 数据 | `config/narrative/events.ts` 纯配置表，无新系统 | 新增 1 文件 |
| UI | 年卡 = 全屏卡片（复用主界面卡片组件 + 文案排版），零新素材；可选配 1 张像素插画（素材管线已通） | 1 个界面组件 |
| 判定 | 年份累计写在挂机/离线结算处（+1 处）；进游戏检查囤积（+1 处） | 2 处代码 |
| 存储 | `Player.year` + `Player.marks` + `Player.usedYearCards` 三个字段 | 数据结构增量 |
| 回响 | 年卡 `reply` 字段按印记查文案（模板替换，非对话系统） | 0 新系统 |

### 2.7 结局与人生感回收（MVP 轻量版）

- **不做多结局系统**（成本高、体量不符）
- MVP 做「**江湖小记**」：玩家达成关键节点（集齐首卷 / 门派长老 / 某条印记线走深）时，弹一页"你的人生回顾"：年表回放 + 印记徽章 + 你的选择轨迹
- 完整结局线（武林盟主 → 重新制定江湖规则）沿用世界观 v0.2 目标线，中期内容

## 三、Deliverable 2：武学搭配 × 自走棋 ——「连锁增益」MVP

### 3.1 核心洞察：挂在已有的什么上面

battle-core 已经有一根现成的"概率触发钩子"——**门派技能 F-18**（纯自动、概率触发、不耗内力）。我们要做的不是新造一套触发机制，而是**给 F-18 加一个"升级形态"**。同样，伤害公式 F-01 已经留好了乘区结构，克制环只是加一个乘区。

| 现有地基 | 我们怎么挂 | 改动量 |
|---|---|---|
| F-18 门派技能触发（5%+实战，封顶 25%） | 触发时查连锁配置 → 释放"连锁技" | 1 处判定扩展 |
| F-01 伤害公式（攻−防）×品阶×暴击 | 加"克制系数"乘区（读敌方门派） | 1 处公式扩展 |
| 60 条武学表（门派/类别/品阶字段齐全） | 连锁条件直接用**现有字段**判断，表不加字段 | 0（新表 combos.ts） |
| 门派特色（清风剑气/太极反击/峨眉快/天山毒/狂刀狂/丐帮铁衣） | 连锁效果与特色同向强化，不冲突 | 0 |
| fx 光影模板（武器形态×品阶） | 连锁技 = 同模板大范围 + 换色 | 配置级 |
| 冷却 R-08 / 内力 R-09 | 连锁技沿用（冷却 2 回合、耗内 = 三阶档 100） | 0 |

### 3.2 三件套连锁（Combo）—— 机制主体

**装配位**（沿用现有装配制）：外功 ×1 + 内功 ×1 + 轻功 ×1 + 门派技能（自动）。

**连锁规则**：三件套满足"相性" → 激活连锁。MVP 相性分两级：

| 相性级 | 条件 | 强度 | 设计意图 |
|---|---|---|---|
| 本门连锁（6 条） | 外功/内功/轻功 **同门派** | 强 | 鼓励门派深度，门派 = 一套自洽打法 |
| 隐藏连锁（≥2 条） | 跨门派 + 江湖武学（残卷线） | 极强 | 鼓励混搭探索，残卷是"桥梁材料" |

**连锁表（MVP 首批 8 条，6 本门 + 2 隐藏）**：

| ID | 连锁名 | 三件套 | 常驻效果 | 连锁技（触发型） |
|---|---|---|---|---|
| CB-01 | 剑心通明 | 清扬九剑 + 紫霞真气 + 清扬身法（清风） | 行动条 +15%；剑范围提前一档 | 剑气冲霄：全屏剑气横扫 |
| CB-02 | 太极真意 | 太极拳法 + 太极一气功 + 凌云纵（太极） | 反击率 +20%；反击附带减速 | 太极归元·真：攻防转换 + 反击爆发 |
| CB-03 | 金顶佛光 | 皓月剑诀 + 素心真气 + 踏雪身法（峨眉） | 行动条 +25%（快上加快） | 皓月当空：高速三连击 |
| CB-04 | 万毒归宗 | 千毒手 + 玄阴真气 + 魅影身法（天山） | 中毒率翻倍；中毒伤害 +50% | 天罗毒雨·真：全屏中毒 |
| CB-05 | 血屠千里 | 狂血魔刀 + 狂血魔功 + 血影遁（狂刀） | 暴击率 +15%；击杀后行动条 +30% | 屠刀血海：残血斩杀 |
| CB-06 | 降龙伏虎 | 莲花掌法 + 混天功 + 游龙身法（丐帮） | 铁衣效果翻倍；防御 +20% | 降龙掌：大十字群伤 |
| CB-07 | 阴阳逆转 | 任一正派三阶外功 + 玄阴真气 + 任一轻功（隐藏） | 攻防转换；免疫中毒 | 阴阳错：攻防互换 + 爆发 |
| CB-08 | 清虚归元 | 江湖绝学内功（残卷）+ 任一外功 + 任一轻功（隐藏） | 全属性 +；连锁等级 +1 段 | 绝学技：超大范围 |

> 全部原创命名，不碰金庸真实武功名。连锁效果数值为初稿 🔧，数值阶段定稿。

**连锁等级（把"挂机变强"接进构筑）**：
```
连锁等级 = min(三件套武功等级)，分档：
  ≥10 级 → 1 段（效果 60%）
  ≥20 级 → 2 段（效果 100%）
  ≥30 级 → 3 段（效果 100% + 连锁技范围/倍率增强）
```
→ 挂机练武直接喂大连锁威力：**放置 = 构筑的燃料**，二者天然咬合。

### 3.3 门派克制（Counter）—— 战斗中的动态决策

**克制环**（五门派闭环 + 丐帮中立）：

```
清风派 ─克→ 天山派 ─克→ 狂刀谷 ─克→ 太极门 ─克→ 峨眉 ─克→ 清风派
                     丐帮：中立（不克不被克，铁衣成长自成一派）
```

| 攻击方 | 克制目标 | 效果（初值 🔧） | 世界观理由（写成年卡故事） |
|---|---|---|---|
| 清风派 | 天山派 | 对天山 +15% 伤 / 受天山 -10% 伤 | 清风祖师以剑破毒之传说 |
| 天山派 | 狂刀谷 | 对狂刀 +15% 伤 / 受狂刀 -10% 伤 | 阴毒蚀刚猛，狂怒者易中毒 |
| 狂刀谷 | 太极门 | 对太极 +15% 伤 / 受太极 -10% 伤 | 刚猛破柔劲，一力降十会 |
| 太极门 | 峨眉 | 对峨眉 +15% 伤 / 受峨眉 -10% 伤 | 以静制动，克疾风骤雨 |
| 峨眉 | 清风派 | 对清风 +15% 伤 / 受清风 -10% 伤 | 月影破剑，快剑克巧剑 |
| 丐帮 | — | 中立（无克制乘区） | 侠之大者，靠的是铁衣磨出来的硬 |

**实现**：
- `config/counters.ts`：`sectId → { counterTo: sectId, dmgBonus, dmgReduction }`
- F-01 加乘区：`伤害 = (攻−防) × 品阶系数 × 暴击倍率 × 克制系数`
- **敌方需门派字段**：NPC 表补 `sect` 归属（新增字段，不动现有数据；场景小怪默认归属"江湖散人"无克制，仅门派 NPC/Boss 带归属）
- **反馈**：攻击克制目标 → 伤害飘字金色 + 「相克」小字；被克 → 灰字「被克」（飘字已存在，加颜色变体，零成本）

**克制带来的策略**：实战档位 1v多 战斗中，对方若混编门派 → 玩家换克制装配（装配在战斗外改，符合 75 规格"战斗中不能换武功配置"）→ "根据对手配装"成为老手深度。

### 3.4 连锁技 —— 爽感时刻（触发型）

```
现有（F-18）：门派技能触发 → 播放门派技能光影
升级：触发判定时——
  ① 若三件套连锁已激活 → 释放「连锁技」（替代门派技能）
  ② 连锁技 = 门派技能效果 × 连锁等级倍率 + 专属大范围光影
  ③ 冷却沿用 R-08（2 回合）；耗内 = 三阶档 100（R-09）
  ④ 出招文案带前缀：如「剑心通明·清扬九剑」/「万毒归宗·千毒手」
```

- **爽感时刻** = 自动战斗中，你的配装"突然爆发"：全屏特效 + 招式名前缀 + 多目标飘字——玩家一眼认出"这是我配出来的那一套在发威"
- 视觉：复用 fx 模板（8c 已定：武器形态×品阶 + 全屏微震），连锁技 = 同模板大范围 + 门派色换色，**零新素材帧**
- 触发频率验证：F-18 基础 5% 封顶 25%，加上连锁激活门槛，估算单场 1v多 战斗中 1~2 次连锁技 = 恰当的"高光频率"（数值阶段用 headless 模拟验证）

### 3.5 成型反馈（Build Feedback）——"配出一套厉害的"的三层时刻

| 时刻 | 场景 | 反馈 |
|---|---|---|
| 构筑期 | 装配界面 | **连锁预览区**：三件套实时显示"已激活/未激活、效果、当前连锁等级、距下一段还差多少级"——期待感从装配时就建立 |
| 成型瞬间 | 首次集齐连锁 | 弹「你参悟出一门武功的用法！」+ 连锁卡展示（图标 + 效果）——**成型时刻的仪式感** |
| 爆发时刻 | 战斗 | 连锁技触发（§3.4）——爽感的最终兑现 |

**自创武功（低成本高情感）**：激活**隐藏连锁**（CB-07/08 类跨门派）时，额外弹输入框，**玩家可为该连锁命名**（≤8 字，存 `Player.namedCombos`）→ 之后的战斗出招文案显示玩家起的名字（如「我的归元剑诀」）。
- 成本：1 个字符串字段 + 1 次输入框
- 收益：**构筑乐趣 × 人生感同时拉满**——"这招是我自己参出来的，我给它起了名字"

## 四、剧情 × 搭配的互相支撑（咬合机制，任务书硬要求）

### 4.1 三个咬合点

| 咬合 | 机制 | 玩家体验 | 方向 |
|---|---|---|---|
| ① 印记 → 连锁 | 年卡给「剑痴」印记 → 剑心通明连锁解锁完全版；无印记 = 80% | "我过的人生决定了我的套路能多强" | 剧情决定构筑深度 |
| ② 残卷 → 绝学 | 年卡给残卷线索 → 收集解锁江湖绝学（跨门派连锁的桥梁 CB-07/08） | "我的剧情进度解锁了混搭的新材料" | 剧情进度解锁构筑空间 |
| ③ 克制 → 叙事 | 克制理由写成年卡故事（清风祖师以剑破毒…） | "我在故事里听过这个传说，在战斗里验证了它" | 剧情为机制背书 |

### 4.2 为什么这个闭环成立（而不是两个孤立模块）

- **搭配是变强的表达**：连锁/克制是"我配出来的打法"在战斗中的兑现——这是玩家主动构筑的，不是系统送的
- **剧情给搭配意义**：印记、残卷、传说让"为什么这么配"有江湖叙事上的答案——我不只是"选了数值最优解"，我是"走了一条剑痴的路"
- **互相喂养**：剧情推进（年卡/残卷）解锁构筑材料 → 构筑变强（连锁成型）→ 战力够打过更强的年卡事件/Boss → 剧情继续推进。**放置、构筑、叙事三者形成一条正反馈链**

### 4.3 MVP 边界再确认

- ✅ 年表：8 张年卡起步（后续每两周 +2）
- ✅ 连锁：8 条起步（6 本门 + 2 隐藏）
- ✅ 残卷：第一章只做 1~2 卷（作为叙事目标与隐藏连锁枢纽）
- ✅ 克制：5+1 门派环（丐帮中立）
- ❌ 不做：多结局系统、大型事件网络、对话系统、侠客羁绊、自创武功全流程（只做"命名"这一轻量动作）

## 五、Deliverable 3：三个整体创意方向（Leo 挑选）

### 方向 A「江湖年表」—— 人生感优先

| 项 | 内容 |
|---|---|
| 一句话卖点 | **"挂机不是打怪，是过一生——每次回归，江湖都替你过了几年"** |
| 核心玩法落点 | 完整年表系统（年卡 + 印记 + 江湖小记）；连锁做**基础版**（三件套 + 连锁技，克制可选）；残卷仅作背景提及 |
| 改动量 | **中**（年表新增：事件表 + 年卡 UI + 年份判定；连锁增量小） |
| 适配 | 强差异化，直接对标《大侠式人生》的人生感；回归仪式感拉满 |
| 风险 | 内容生产持续投入（年卡要不断产）；剧情跳过党会把年表玩成"签到"——用印记奖励+回响钩子对冲 |

### 方向 B「武学构筑」—— 构筑乐趣优先

| 项 | 内容 |
|---|---|
| 一句话卖点 | **"六十路武学随便配，配出一套横扫江湖的连招，就是这游戏的爽点"** |
| 核心玩法落点 | 完整连锁系统（三件套 + 克制 + 连锁技 + 自创命名 + 装配预览）；剧情只做**轻钩子**（武学缘分解锁事件 4~6 个，不做年表） |
| 改动量 | **小**（全部挂在现有 battle-core 与 60 条武学表上，§3.6 清单 9 处增量） |
| 适配 | 最稳最快，风险最低，验证"构筑乐趣密度"假设；适合先跑通再叠加剧情 |
| 风险 | 缺"人生感"，可能显得纯数值；剧情支撑弱——靠自创命名 + 武学缘分事件补一点 |

### 方向 C「残卷寻踪」—— 双支柱并重（**推荐**）

| 项 | 内容 |
|---|---|
| 一句话卖点 | **"十四卷残卷，十四种江湖——寻卷、学卷、以卷配卷，走一条只属于你的绝学之路"** |
| 核心玩法落点 | 残卷收集主线（第一章 1~2 卷）= 叙事骨架；年表事件网给线索（8 张年卡）；江湖绝学 = 跨门派连锁的桥梁材料（CB-07/08）；完整连锁 + 克制全上 |
| 改动量 | **中~大**（新增残卷系统 + 江湖绝学录入 + 寻踪事件；但全是增量，无推翻）；**可砍成中**：残卷先只做 1 卷，年卡 8 张，连锁 8 条 |
| 适配 | 完美咬合已定世界观（十四部残卷是 v0.2 现成设定！）；主线目标清晰；剧情与构筑天然一体 |
| 风险 | 内容量最大（残卷 + 绝学 + 事件）；绝学数值要控制防崩（绝学只做 1~2 部起步） |

### 5.1 主理人视角的推荐组合

> **方向 C 为骨架，内嵌 A 的轻量年表 + B 的完整连锁**，即"残卷主线 × 连锁构筑 × 年卡人生"三件套。改动量按中控制（残卷 1 卷 + 年卡 8 张 + 连锁 8 条），三块互相独立、**每块可独立验收、独立砍掉**：
>
> - 连锁（B 核心）最先落地——改动最小、爽感最直接，先行验证"构筑乐趣密度"
> - 年表（A 核心）第二批——8 张卡即可跑通"人生感"，验证回归仪式
> - 残卷（C 核心）串起来——主线目标 + 隐藏连锁枢纽，给前两者"为什么"的答案
>
> 若验证期数据不理想，任一块可单独砍，不影响其余两块与已定地基。

## 六、爽感来源论证：MDA 框架 × 自我决定论

### 6.1 MDA 拆解（本草案如何制造乐趣）

| 层 | 年表（剧情） | 连锁（搭配） |
|---|---|---|
| **Mechanics** | 时间→年份换算；年卡抉择；印记累积 | 三件套装配；连锁激活/等级；克制乘区；连锁技触发 |
| **Dynamics** | 回归→看人生→抉择→印记变化→下一段人生 | 装配→战斗验证→连锁技爆发→数据反馈→重装配 |
| **Aesthetics** | **Narrative**（我的江湖人生）+ **Fantasy**（武侠扮演）+ **Discovery**（发现隐藏事件线） | **Sensation**（连锁技全屏爆发）+ **Challenge**（配最优解/根据对手换配装）+ **Discovery**（发现隐藏连锁/自创命名） |

**对照《大侠式人生》启示**：人生感密度（年卡 = 每 4 小时一次人生事件）+ 构筑乐趣密度（每套三件套 = 一次可验证的构筑实验）——密度的来源是"频率 × 意义"：年卡虽轻但频繁且塑造身份；连锁虽小但每次触发都是构筑的兑现。

### 6.2 自我决定论（SDT）三需求论证

| 需求 | 年表（剧情支柱） | 连锁（搭配支柱） |
|---|---|---|
| **自主 Autonomy** | 每次抉择无对错、只分路线；印记系统不判善恶——"我选我的人生" | 配什么是纯玩家决策；正邪门派都可配；自创命名 = 完全自我的表达 |
| **胜任 Competence** | 年表让玩家看见"我的江湖岁月在累积、在成形"——时间没有白费 | 连锁技触发 = "我配的那一套正在发威"——构筑能力的直接确认；克制换装 = 策略能力的验证 |
| **关联 Relatedness** | 年卡回响：NPC 记得你当年的选择；门派因你的抉择亲疏有别 | 门派克制/连锁让每个门派、每条武学路线"有用"——玩家感到自己属于某个流派、被江湖记住 |

**一句话**：自主给"选择"、胜任给"验证"、关联给"归属"——这正是武侠题材最适配的三感组合，也是《大侠式人生》高分的心理学底牌。
