> 定位：回归「放置 / 武侠 / 小游戏」三要素、**完全不限定游戏类型**，为 placement-wuxia 发明"有创意又上头"的全新玩法方向，供 Leo 挑选主玩法。

---

## 一、背景（为何发这单）

placement-wuxia（微信小游戏《放置武侠》）设计回炉进行中。Leo 已拍板两根核心支柱（剧情故事 / 武侠搭配爽感）与定位（放置版大侠式人生 = 挂机过一生）。

但经过多轮战斗形态收敛（弈世苍生 → 汉家江湖 → 六边形战棋 → 俯视方格 → 侧视方格），Leo 明确：**传统战斗模式（战棋/自走棋/回合制）都"不够新意"，不想在传统模式里改良**。他拍板：**回归「放置 / 武侠 / 小游戏」三要素，完全不限定游戏类型，重新发明"有创意又上头"的玩法**。

本任务 = 用专业方法做**玩法发明发散**，产出 3~5 个方向供 Leo 挑选主玩法。

## 二、硬约束（三要素，不可违背）

1. **放置**：挂机/离线/收菜节奏；碎片化、单手、通勤可玩；长线养成感
2. **武侠**：武学/门派/江湖/人生感；原创红线（不碰金庸真实角色/武功名，可借鉴精神与框架）
3. **小游戏**：微信小游戏；竖屏；轻量即点即玩；包体受限；本团队技术 = TS + Canvas 2D 原生（不依赖大引擎）

## 三、已定不推翻的地基（新玩法要复用/兼容，不推倒）

- **两根核心支柱**：剧情故事（人生感）/ 武侠搭配爽感（构筑乐趣）
- **世界观 v0.2**：查小侠传说 / 灵绝顶群邪 / 十四部残卷 / 有缘人成长线 / 6 门派（清风/太极/峨眉/天山/狂刀/丐帮）60 武学
- **江湖年表 idea**（挂机 4h=1 年 → 年卡抉择 → 命途印记）——如与发明的主玩法冲突可让位，但"人生感"是支柱不可丢
- **武学连锁 idea**（三件套连锁/克制环/自创命名）——"构筑爽感"是支柱，具体形态可被主玩法重塑
- **已开发资产**：battle-core（行动条制可复用为"时序"）、像素/2.5D 美术管线、T05 headless 结算、主界面/江湖场景

## 四、Deliverables（写入 docs/studio/93-创意玩法方案.md）

产出 **3~5 个"有创意又上头"的完整玩法方向**（不是碎片点子，是可当主玩法的整案）。每个方向必须含：

1. **一句话新奇点**（玩家 3 秒能懂"这游戏哪不一样"）
2. **核心循环**（玩家从进游戏到上头的 3~5 步循环；放置时做什么、在线时做什么）
3. **上头点 / 成瘾钩子**（为什么让人停不下来：心流、自主、胜任、关联、随机奖励、损失厌恶等机制层面的分析，用玩家心理学/自我决定论论证）
4. **武侠味怎么体现**（武学/门派/江湖/人生感怎么溶进玩法，不是贴皮）
5. **放置味怎么体现**（挂机/离线怎么融入核心循环，不是挂机=收菜老套路）
6. **和已定地基的关系**：哪些复用（世界观/武学表/年表/连锁/资产）、哪些让位、改动量（小/中/大）
7. **受众与风险**（目标玩家、新颖度风险、验证方式）

**方法要求**：用「动词优先 + 核心循环 + MDA」框架；每个方向给出它的**核心动词**（玩家真正在做的那个动作）；避免"传统玩法 + 武侠皮"的偷懒方案；优先那些"放置体验前所未有/武侠题材前所未有"的组合。

**额外加分**：若某方向能同时满足两根支柱（剧情故事 + 搭配爽感），优先标注为"双支柱兼得"。

## 五、约束与红线

- ❌ 不做：传统战棋/自走棋/回合制/卡牌/MMORPG 的改良版（Leo 已否决传统改良）
- ❌ 不做：纯文字模拟器（竞品已做，且我们是像素生图管线）
- ❌ 不做：重内容开放世界（小游戏包体/成本养不起）
- ✅ 鼓励：放置 × 非传统类型杂交（合成、博弈、策略、经营、节奏、因果、解谜、收集……）、武侠特有题材（武学相生相克、师徒传承、江湖名声、闭关顿悟）× 放置
- 原创红线：不碰金庸真实角色/武功名；门派武学沿用已定 6 门派原创设定

## 六、汇报

完成后 SendMessage 回传主理人：产出文件路径 + 3~5 个方向的一句话摘要（Leo 能 3 分钟扫完拍板）。
