## 0. 一句话总则

> **一屏三区：顶资源条给"变强数字"，中场景给"挂机沉浸"，底 Tab 给"全功能导航"。信息克制，朱砂只给关键数字与主按钮，其余墨系安静。**

## 3. 各 Tab 界面布局

> 共性：① 每 Tab 复用同一「顶资源条」组件（高度 96rpx，内容按页调整）；② 底部 Tab 常驻（除弹窗/战斗全屏页）；③ 页内容滚屏区域在 96~1246rpx 之间；④ 弹窗统一 panel_dialog（宣纸 + 墨线残破边）。

### 3.1 江湖 Tab（= 主界面，§2）

- 承载：挂机闭关（环节二）+ 闯荡入口（环节四/五）+ 离线收益弹窗 + 失血横幅。
- 顶部资源条：战力 / 等级 / 银两 / 学点 / 实战 / 设置（§2）。
- 无独立"江湖列表"——江湖 Tab 即主界面本身，闭关面板 + 闯荡按钮即全部内容。

### 3.4 社交（好友/助战）—— 江湖界面内嵌入口（不设独立 Tab）

> **Leo 2026-08-19 拍板**：社交不占底部导航位，入口放江湖界面。好友功能（14 文档）随侠友模块逐步开放；MVP 聚焦「好友助战选人」（战斗 3v3 = 1+2 好友必需）。

```
江湖 Tab 内社交区（闭关面板下方 / 闯荡按钮附近）：
┌──────────────────────────────────────────────┐
│ [侠友]（墨线按钮/淡金印章角标）  少侠好友 2/2   │  ← 助战选人入口（14 §3）
└──────────────────────────────────────────────┘
→ 点开 → 好友列表（快照）→ 勾选 0~2 名入队 → 布阵（11 §4.3）
```

- 好友卡：头像（水墨简笔+首字占位）、好友名、战力快照、今日可助战次数、[打招呼]（互赠银两）
- 无好友空态："江湖路远，邀几位好友同行" + 邀请按钮（分享拉新）
- 后续扩展（不入 MVP）：PVP/比武/排名 等社交模块，届时评估是否升独立 Tab

关键交互位：好友卡（点击→助战选择/详情）、「打招呼」（互赠银两）、「邀请好友」（分享拉新）、助战次数角标。

**商店单设 Tab 的利弊（供 Leo 参考，本版建议不单设）：**
- 利：入口显性化，未来商店扩充（装备/刷新 v1.0）后频率上升时更顺手。
- 弊：MVP 只 2 个商品，独立 Tab 浪费一级导航位；4 Tab 已覆盖核心循环（挂机/学武/装备/社交），商店是背包的"银两花处"天然相邻。
- **触发再评估条件**：v1.0 商店装备/刷新上线且购买频率 ≥ 每日 3 次，升级为第 5 Tab（江湖/武学/背包/商店/侠友，背包降级回按钮或并入）。
