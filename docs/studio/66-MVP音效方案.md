## 0. 结论速览

- **音频方向**：活泼年轻的水墨国风（与 04 视觉同源）——古筝/竹笛/轻鼓点，明快清透，**不厚重、不阴沉、不惊悚**。
- **范围**：P0 七类音效 + 1 首 BGM；P1 三类；P2 扩展。全包 **P0+P1 ≈ 1.05MB**，建议音频主包预算 **≤1.2MB**（占小游戏主包 4MB 内 ~26%，余量给代码与美术）。
- **实现**：微信小游戏 `InnerAudioContext`，`src/systems/audio.ts` 单例管理器；战斗音效按 battleLog 动作事件触发，与 log 播放器对齐。
- **进 Epic**：不设独立音效 Epic，**E2 挂机循环（Sprint 1）内置「S2-0 音频地基 Story」**，其余按功能 Epic 分散接入（E3 学武 / E4 战斗 / E5 刷怪）。
- **待 Leo 审批**：音效候选试听（3-5 个/类）、BGM 风格确认、来源选型（AI vs 素材库 vs 外包）、总包预算确认。

## 1. 音频方向（风格圣经）

### 1.1 情感基调

| 维度 | 定位 | 对齐 |
|---|---|---|
| 总体 | 活泼年轻的水墨国风 | 04 §0「水墨是画风，年轻是气质」 |
| 情绪 | 明快、江湖气、少年侠客感；变强爽点给足仪式感 | 05 有缘人成长线 / 11 §0.4 文案语气 |
| 反面清单 | 不用厚重交响、不用惊悚低频、不用高频刺耳、不用老金庸灰朴质感 | 04 §0（不老气/不深沉） |
| 参考 | 一念逍遥 / 逆水寒 类现代国风的轻盈感 | 04 §0 |

### 1.2 声音调色板（乐器/音色池）

| 用途 | 音色 | 语感 |
|---|---|---|
| 主旋律/点缀 | 古筝、竹笛（中高音区） | 灵动机敏，少年侠气 |
| 节奏 | 板鼓 / 梆子 / 轻木鱼 | 轻快不重的打击感 |
| 氛围底 | 现代 pad / 竖琴拨弦 / 流水风声（低音量） | 清透留白，对应宣纸天青 |
| 强调/印章 | 锣、磬、铜钟（短促一声） | 仪式感，对应朱砂印章 |
| 危险/失血 | 低鼓 + 暗色弦乐（**单次、非循环、≤2s**） | 有警示但**不惊悚**（31 §6 约束） |

> 一致性规则：所有音效必须落在上面音色池内；偏离即打回（音频方向审查点在 07 清单加一条）。

### 1.3 动态层级（混音总线）

```
Master
├── BGM 总线（默认 volume 0.5）        ← 主界面循环、战斗时可 duck 至 0.4
└── SFX 总线（默认 volume 0.8）        ← 所有短音效
    ├── UI 层（点击/确认/印章）
    ├── 战斗层（命中/暴击/大招/失血）
    ├── 成长层（闭关/升级/学武）
    └── 经济层（掉落/分解）
```

- 2D Canvas 无 3D 空间音频，**不引入距离衰减**；用「层级 + 音量」区分主次。
- BGM 与 SFX 独立音量、独立开关（见 §4）。

> 命名约定：`SFX_<系统>_<动作>[_<变体>]`；文件放 `assets/audio/sfx/`。
> 格式：**全部 mp3，短音效 96kbps / mono / 44.1kHz**（iOS/Android 兼容，微信小游戏主包内引用）。

## 3. 主界面 BGM（1 首）

| 项 | 规格 |
|---|---|
| 事件名 | `BGM_MAIN`（文件 `assets/audio/bgm/bgm_main.mp3`） |
| 风格 | 古筝 + 竹笛主旋律 + 板鼓/梆子轻快节奏 + 现代 pad 底；**BPM 90-100，明快、江湖气、活泼年轻**；参考一念逍遥类现代国风，避免厚重交响 |
| 结构 | 60s 无缝循环段（建议 ABAB 双段，首尾用同和弦/同收束保证 loop 无跳变） |
| 格式 | mp3 / 96kbps / mono / 44.1kHz |
| 体积预算 | **≤800KB**（96kbps × 60s ≈ 720KB，留帧开销余量） |
| 播放策略 | 主界面常驻循环；战斗/弹窗场景 BGM 音量 duck 至 0.4（不切歌，MVP 仅 1 首）；设置关闭或系统静音时停 |

> 验证要求：Leo 试听 3-5 个候选，重点听「loop 接缝是否跳变」「是否活泼不沉重」。

## 4. 音频开关（对齐 31 可访问性）

### 4.1 入口与默认

- **入口**：设置面板（11 §7 存档设置所在面板）新增「声音」区：**BGM 开关 + 音效开关**两个独立开关，**默认开**。
- **存储**：`wx.setStorageSync('settings.audio', { bgm: boolean, sfx: boolean })`，每次启动读取。
- **总开关**：MVP 不加第三个总开关（两个足够），P2 可加。

### 4.2 尊重系统静音

- `wx.setInnerAudioOption({ obeyMuteSwitch: true })` 全局设置 + 每个 `InnerAudioContext` 保持默认：iOS 跟随设备静音键，Android 跟随媒体音量（平台不支持静音键）。
- BGM 建议在**用户首次点击后**开始播放（平台习惯 + 尊重静音），避免一进游戏就响。

### 4.3 与 31 Standard 档联动（特效等级 高/中/低/关 + reduceMotion）

| 特效等级 | 音效行为（默认联动，可被用户手动开关覆盖） |
|---|---|
| 高 / 中 | 全部音效 + BGM 正常 |
| 低 | 战斗层降级：**保留命中/暴击，关大招音效**；BGM 音量降至 0.3；UI/成长/经济层不变 |
| 关 | 战斗层全静音（保留 UI 点击与 BGM；若用户也关音效开关则全静音） |
| 系统「减弱动态效果」开启 | 自动按「低」档执行（31 §6.1）；无 ≥3Hz 频闪音（本方案无循环警报音，天然达标） |

> 落地：特效等级开关在 `config/numbers.ts` 或设置存储（31 §8），音频管理器读取同一配置，不做两套。

## 5. 来源选型与授权

### 5.1 选型建议

| 素材 | 推荐来源 | 理由 | 风险/注意 |
|---|---|---|---|
| 主界面 BGM | **AI 生成优先**（Suno 付费订阅版；即梦 AI 音乐等备选） | 现代国风可控、出 3-5 首候选快、成本低 | 必须付费订阅才能商用；免费版不可商用；出曲后按 04/05 语感筛选 |
| 短音效（点击/战斗/闭关/升级等） | **免费素材库优先**（Pixabay / Freesound CC0·CC-BY；爱给网等国内站需逐条查授权） | 短音效量大、素材库够用；拿到后统一后期（EQ 削齿音 + 轻混响）保证同空间感 | 授权类型不一：CC0 可直接用、CC-BY 需署名、仅个人用不可商用；必须建来源记录表 |
| 外包 | 仅当上述候选均不满意且时间允许 | 定制化、风格最贴 | 成本高（BGM 数百-数千元/首级），MVP 不首选 |

### 5.2 授权注意事项（红线）

1. **逐条确认商用版权**：免费素材按条目记「授权类型 + 作者 + 来源链接」到 `assets/audio/README.md` 来源表（与 `assets/ui/README.md` 同制式）。
2. **AI 生成**：只用付费订阅产出的内容，保存生成记录（服务/账号/日期/提示词），商用合规留档。
3. **避开金庸/影视既有曲目与音色采样**（世界观已用原创代名，音乐同样必须原创，防侵权）。
4. 字体已提示授权（04 §3），音频同标准：**来源不明一律不用**。

### 5.3 验证流程（Leo 试听）

- BGM：**3-5 首候选** → Leo 试听选 1（重点：loop 接缝、活泼度、不沉重）。
- 每类 P0 音效：**2-3 个候选** → Leo 试听定 1（重点：不刺耳、不腻、符合水墨年轻感）。
- 验收三关（02 §0）：效果（Leo 满意）+ 可维护（命名规范、来源表完整）+ 稳定（格式兼容、加载无异常、静音开关生效）。

## 6. 实现策略（与主架构/工程对齐）

### 6.1 模块与接口

- 新增 `src/systems/audio.ts`（AudioManager 单例），归入主架构 systems 层，职责单一：
  - `preload()`：启动时（Boot 场景）预创建各音效实例并 set src（不 play），主界面可交互前完成。
  - `playSfx(event: AudioEvent)`：按事件枚举播放；高频事件（命中）走双实例轮换防打断。
  - `playBgm() / stopBgm() / duckBgm(vol)`：BGM 生命周期与 duck。
  - `applySettings({bgm, sfx})` / `applyAccessibility(level)`：读设置与特效等级。
- 事件枚举 `AudioEvent` 定义在 `src/types.ts`（与 60-types 字段设计同源，供 battleLog 对齐）。
- 播放配置（音量/预算/开关默认）放 `src/config/numbers.ts`（只读展示参数，遵循 ADR-004）。

### 6.2 InnerAudioContext 播放要点

- 短音效：每类 1 个实例缓存复用（`src` 指向主包内 `assets/audio/sfx/*.mp3`）；命中类 2 实例交替。
- BGM：1 个实例，`loop = true`，`volume = 0.5`（主界面）/ 0.4（战斗 duck）/ 0.3（特效低档）。
- 全部 `obeyMuteSwitch = true`（见 §4.2）。
- **不做网络音频**：MVP 音频全部随主包发布，避免加载失败与延迟（后续分包再评估）。

### 6.3 战斗音效按 battleLog 触发（与 log 播放器对齐）

- 前置：`S4-1 battleLog 契约冻结`时，动作序列需含 `action` 类型字段：`hit | crit | ult | move | cast`（见 22 §1.4 S4-1）。**这是 E4 战斗音效的硬依赖，契约评审时必须确认。**
- 触发：Battle 场景（`src/scenes/battle.ts`）log 播放器每 tick 执行动作时，按 `action` 映射调 `AudioManager.playSfx`；结果页（胜利/失败）播结果反馈。
- 倍速：**短音效不随倍速变速**（保持原速，避免音调怪异）；4x 时仅保留命中音；快进跳结果 → 立即停战斗音效、播结果音。

### 6.4 性能预算

| 项 | 预算 |
|---|---|
| 同发播放实例 | ≤6（BGM 1 + 战斗 3 + UI 2） |
| 文件体积（主包内） | P0+P1 ≈ 1.05MB，**总预算 ≤1.2MB** |
| 内存（解码后） | BGM 60s mono 解码峰值 ~5-10MB（微信流式/整段解码按平台）；若真机内存吃紧 → BGM 降至 64kbps 或 48s，或后置分包 |
| 格式兼容 | mp3 96kbps mono 44.1kHz，iOS/Android 双端均支持 |

## 7. 进 Epic 建议（对齐 22 冲刺计划）

> **建议：不设独立音效 Epic，分散接入 + E2 内置音频地基 Story**，符合增量开发铁律（02 §0a）。

| Epic | 冲刺 | 接入内容 | 对应 Story |
|---|---|---|---|
| **E2 挂机循环** | Sprint 1 | **新增「S2-0 音频地基」**：AudioManager + 点击/按钮音效（2 变体）+ 主界面 BGM + 闭关开始音效；预加载与设置开关 | S2-0（新增，依赖 E2 现有 UI） |
| **E3 学武功** | Sprint 2 | 升级/学武成功音效（learn 成功分支） | S3-2 |
| **E4 战斗 3v3** | Sprint 2 | 战斗命中/暴击/大招音效（log 播放器触发）；依赖 S4-1 契约含 action 字段 | S4-3 |
| **E5 刷怪点** | Sprint 3 | 掉落音效、失血警报 | S5-2 / S5-3 |
| E6 闭环验收 | Sprint 3 | P1 分解音效补入（背包分解在环节六，随 E6 或 E5 尾接入）；音频方向验收 | S6-1 / S6-2 |

> 理由：E2 是第一个有真实 UI 交互的 Epic（挂机面板/学点跳动/按钮），点击音效与 BGM 在此落地最自然；AudioManager 是所有后续音效的前置依赖，放 E2 开头可避免返工。E4 战斗音效**必须**与 S4-1 契约同 Sprint 对齐。
