## 0. 交互闭环（12 §0 核心循环落地）

```
推图(闯荡江湖) → 掉装备 → 背包（查看/穿戴/卸下）→ 分解 → 银两
      ↓                                              ↓
  战力提升 ←──────── 学武 / 买药(大还丹/金疮药) / 商店装备 ←── 银两花处
      ↓
  推更高图 → 更高档装备 → 更高分解收益
```

| 循环环节 | 界面 | 关键操作 | 出口 |
|---|---|---|---|
| 掉落 | 战斗结果弹窗（11 §4） | 掉落列表展示 | 提示条点击直达背包 |
| 背包管理 | Bag 行囊 | 穿戴/卸下/分解/排序筛选 | Home / 商店 |
| 银两回收 | Bag 分解 | 品质→银两 | 银两入账 → 学武/买药 |
| 银两花处 | Shop 集市 | 买药 / 买装备 / 刷新 | 推图续航 / 战力提升 |

## 1. 背包（行囊）

### 1.1 入口与布局

| 项 | 内容 |
|---|---|
| 入口 | 主界面右下角"行囊"按钮（墨线按钮）；掉落提示条可点击直达；新装备入包 = 淡金印章"新"角标（61 §3） |
| 布局 | 顶部资源行（银两/学点/战力，朱砂大字）→ 筛选/排序条 → 装备列表 → 底部操作（去集市 / 批量分解） |
| 视觉 | 宣纸底面板 + 浅杏 #F0E6D4 内衬行；装备卡 = 品质色描边 + 名称（书法体）+ 战力（墨小字）+ 部位标签 |

### 1.2 8 部位展示（12 §2.3 属性倾向）

| 部位 | 属性倾向 | 图标建议（30 §4.3） |
|---|---|---|
| 武器 | 攻击（并决定可装配武功的范围类型，03 §3.3） | 剑/刀/掌 简笔 |
| 衣服 | 防御 | 袍形 |
| 披风 | 防御 | 披风形 |
| 鞋子 | 防御 | 靴形 |
| 头部 | 气血 | 冠/笠形 |
| 项链 | 气血 | 链形 |
| 护手 | 气血 | 护腕形 |
| 戒指 | 气血 | 环形 |

> MVP 展示形态：**部位分组列表**（先按 8 部位分组，再按战力/品质排序），比角色剪影 8 格更简单可靠；剪影式布局后置。

### 1.3 穿戴 / 卸下

| 操作 | 流程 | 规则 |
|---|---|---|
| 穿戴 | 点装备 → 详情 → "穿戴"（朱砂底）→ 替换 | 同部位只能穿 1 件；替换件自动回背包；弹"已换装 [新]（战力 +N）" |
| 卸下 | 点已装备 → 详情 → "卸下"（墨线）→ 确认 | **允许空部位**（基础数值兜底，无装备不惩罚）；弹"该部位已空，属性回落 [N]" |

> 战力对比：穿戴前详情弹窗显示「当前 vs 新」差值——竹青 #7FB069 +N（正向）、朱砂 #E2574C −N（负向）；对比维度 = 战力 / 攻击 / 防御 / 气血（六维加成 MVP 后置，装备词条后置）。

### 1.4 排序与筛选

| 维度 | 选项 | 默认 |
|---|---|---|
| 排序 | 战力降序 / 品质降序 / 部位分组 | 品质降序 + 部位分组 |
| 筛选 | 品质（白/绿/蓝/紫/橙，多选）/ 部位（8 类，单选） | 全部 |

> 筛选条为水墨简笔标签（30 §5.3：图标 + 颜色双编码）；筛选结果空 → 空态文案"此间无物，且放宽心去闯荡"。

## 2. 分解

### 2.1 入口

| 入口 | 路径 |
|---|---|
| 单件分解 | 装备详情弹窗 → "分解"（墨线按钮） |
| 批量分解 | 背包底部"批量分解" → 勾选白/绿（默认全选白/绿）→ 确认 |

### 2.2 品质 → 银两对应（初稿，引用 64 §10，**待 Leo 调** 🔧）

| 品质 | 基准银两 | 说明 |
|---|---|---|
| 白 | 10 | 量多，回收小头 |
| 绿 | 40 | 过渡 |
| 蓝 | 150 | 主要回收档 |
| 紫 | 500 | 高价值，分解需谨慎 |
| 橙 | 2000 | 稀有，通常穿戴/留存 |

```
分解银两 = 品质基准 × 档位系数
档位系数：布衣 1.0 / 精铁 1.5 / 百炼 2.5 / 玄铁 4.0 / 天蚕 6.0
例：百炼·蓝 = 150 × 2.5 = 375 银两；天蚕·橙 = 2000 × 6.0 = 12000 银两
```

> 品质色映射（04 规范色内，D-08 已扩板）：白=宣纸 #F8F4EA / 绿=竹青 #7FB069 / 蓝=黛青 #4A7A6B / **紫=墨韵紫 #6B5B95（Leo 拍板扩板）** / 橙=珊瑚 #FF7E67；**品质名文字标签必显**。

### 2.3 分解交互

| 步骤 | 表现 |
|---|---|
| 确认 | 单件："将 [装备名]（品质色）化为银两 [N]？分解后不可复原。" 二次确认 |
| 确认（蓝+） | 额外提示："此物品质不凡，分解后将失去，确认？" |
| 动画 | 水墨化散（装备淡出 + 墨晕）→ 银两入账飘字（朱砂 +N）→ 印章"收讫" |
| 批量 | 一键分解 白/绿（默认勾选，可取消勾选）；**蓝+ 不参与批量**，逐件确认 |
| 反馈 | 结果条："共得银两 [N]，已入囊中" |

### 2.4 边界情况

| 情况 | 处理 |
|---|---|
| 已穿戴装备 | 不可分解，按钮置灰（深灰 #444），点击提示"先卸下再分解" |
| 分解不产出 | 不产学点/实战，只产银两（12 §1.2：装备只在在线推图获得） |
| 批量上限 | 单次 ≤ 50 件；超限分批提示 |
| 网络失败 | "分解未成，稍后再试"（朱砂横幅，重试按钮；已确认的分解幂等，不重复扣装备） |
| 品质紫未定 | 紫品质装备分解数值先按基准 500 走，最终随 D-08 拍板 |

## 3. 商店（集市）

### 3.1 入口与布局

| 项 | 内容 |
|---|---|
| 入口 | 主界面顶部银两旁"市"图标；背包底部"去集市" |
| 布局 | 顶部银两余额（朱砂大字）→ 商品列表 → 底部"刷新"（墨线按钮）+ 每日免费次数角标 |
| 商品卡 | 图标 + 名称 + 单价 + 限购标记（每日已购 X/Y）+ "购买"（朱砂底） |

### 3.2 商品构成（MVP 只卖药 · 装备后置）

> Leo 2026-08-19 拍板 B3「保持纯掉落」：MVP 商店**不卖装备**（装备只从推图掉落），装备位/刷新 **v1.0 随商店装备后置**。MVP 商品仅两类药品。

| 商品 | 效果 | 定价（初稿，待 Leo 调 🔧） | 定位 |
|---|---|---|---|
| 大还丹 | 补内力（推图续航，12 §1.3） | 200 银两/瓶 | 推图核心续航，主商品 |
| 金疮药 | 补气血（失血状态治疗，12 §1.1） | 100 银两/瓶 | 偶尔需求 |

### 3.3 购买流程

```
点商品 → 购买确认弹窗（商品名 + 数量 + 银两消耗 + 余额）→ "确认"（朱砂底）→ 入账 + 印章"收讫"
银两不足 → 弹"盘缠不足，分解装备换些银两"（引导到背包分解）
```

### 3.4 刷新规则（v1.0 随商店装备后置 · MVP 不做）

> 装备位/银两刷新为 v1.0 商店装备设计的银两回收口，MVP 无装备商品故无需刷新位。预留：每日免费 3 次、银两 500/次、品质概率同掉落表（白 60/绿 25/蓝 10/紫 4/橙 1）。

### 3.5 边界情况

| 情况 | 处理 |
|---|---|
| 药品限购 | 大还丹每日限购 10 瓶、金疮药 5 瓶（初稿，防银两通胀） |
| 刷新中 | 网络失败："集市未开张，稍后再试"；刷新幂等 |
| 装备已购 | 当日该商品位售罄 → 置灰 + "售罄"（墨灰），刷新后可再买 |
| 装备档位 | 商店装备档位 ≤ 当前已解锁最高档（不卖未来档，防跳级） |

## 5. 与 12 §0 核心循环的对齐检查

| 12 §0 环节 | 本设计落地 | 验收点 |
|---|---|---|
| 推图 → 装备掉落 | 战斗结果弹窗掉落列表 + 提示条直达背包（61 §1） | 掉落 → 背包 1 步可达 |
| 学点 → 学武 | 银两用于学武（武学阁消耗），背包/商店不抢学点资源 | 银两花处含学武（12 §1.4） |
| 分解 → 银两 | 品质基准 × 档位系数（§2.2） | 分解二次确认、蓝+ 逐件 |
| 银两 → 买药 → 续航 | 大还丹/金疮药定价（§3.2） | 买药 → 推图续航闭环 |
| 战力提升 → 推更高图 | 穿戴后战力 +N；商店装备档位 ≤ 已解锁档（§3.5） | 无跳级 |

## 6. 验收标准

- [ ] 掉落 → 背包 → 穿戴 → 战力提升 全程 **1 分钟内可达**（真机）
- [ ] 8 部位展示 / 5 档 / 5 品质 全部正确，品质色只在 04 规范色内（紫=藕荷临时，待 D-08）
- [ ] 分解一律二次确认（蓝+ 额外风险提示）；批量分解仅白/绿
- [ ] 银两不足引导明确（指向分解）
- [ ] 商店装备不卖未来档；药品限购生效
- [ ] 全部数值（分解产出/售价/刷新费）由服务端下发，UI 只展示（AGENTS 铁律）
