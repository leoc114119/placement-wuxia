## 4. D-13 内功加成 X / Y

```
气血 = 基础内功等级 × 50 + 装配内功等级 × X
内力 = 基础内功等级 × 5  + 装配内功等级 × Y
```

| 项 | 初稿 🔧 | 说明 |
|---|---|---|
| 基础内功（wx-000 基本内功） | 每级 +50 气血 / +5 内力 | 13 §5.1 参考值保留 |
| 装配内功 X | 每级 +60 气血 | 装配心法略高于基础（有选择成本） |
| 装配内功 Y | 每级 +6 内力 | 同上 |

> 示例（初稿内部自洽）：基础内功 10 级 + 清风心法 10 级 → 气血 = 500 + 600 = 1100；内力 = 50 + 60 = 110。内力 110 ≈ 一阶武功 13 次 / 三阶 3 次（§9 消耗）。

## 5. 攻防基础数值与映射（13 §1 填数）

```
攻击力 = 基础攻击 30 + 臂力×2 + 武器攻击 + 武功等级×成长系数
防御力 = 基础防御 20 + 根骨×1.5 + 防具防御
```

| 项 | 初稿 🔧 |
|---|---|
| 基础攻击 / 基础防御 | 30 / 20 |
| 臂力 → 攻击 | 1 臂力 = 2 攻击 |
| 根骨 → 防御 | 1 根骨 = 1.5 防御 |
| 外功成长系数（每级） | 一阶 3 / 二阶 5 / 三阶 8 |

> 示例：玩家 10 级（臂力 27）：30 + 54 + 武器 20 + 清风剑法 5 级×3 = 119 攻；根骨 27：20 + 40.5 + 防具 10 = 70 防。对档位 1 山贼（防 15）一阶武功伤害 ≈ (119−15)×1.0 ≈ 104。

## 7. 行动条速度（13 §5b 填数）

```
行动条满值 = 1000
填充速度（/秒）= 100 + 内功等级×3 + 机敏×1
峨眉特色：内功行动速度加成 +10%（门派特色，叠加于上式结果）
```

| 项 | 初稿 🔧 |
|---|---|
| 满值 / 基础填充 | 1000 / 100 |
| 内功等级权重 | ×3 / 级 |
| 机敏权重 | ×1 / 点 |
| 峨眉门派特色 | +10%（wx-046/047 特效，13 §5b） |

> 示例：内功 10 级 + 机敏 27 → 100 + 30 + 27 = 157/秒 → 约 6.4s 出手一次；峨眉 = 172.7/秒 → 约 5.8s。

## 9. 学点经济初稿

### 9.1 学点产出（×3 口径 · Leo 拍板：保留 100/80/70 上限，1 个月达成三阶）

| 来源 | 初稿 🔧 | 说明 |
|---|---|---|
| 离线闭关 | **90 学点/分钟**（=5,400/小时） | **每日自修上限 2h（Leo 2026-08-19 拍板 D-06 MVP 生效）** → 闭关学点 ≤**10,800/日**；广告加时 v1.0（每广告 +30min，见 §9.4） |
| 在线推图·扫荡 | **300 + 150×档位系数 /场** | 主来源；档位 1=450/场、档位 2=675/场、档位 3=1,500/场 |
| 在线推图·首通 | **900×档位系数** | 一次性大额（档位 1 首通 900/关） |

> **日产出验证**：活跃玩家（闭关满 10,800 + 扫荡 5~15 场）≈ **1.7~1.8 万/日**，30 天 ≈ **53 万** —— 支撑 1 个月达成三阶（Leo 拍板），不必等 3 个月。

### 9.2 学点消耗（学习条件 + 升级费）

> **升级费与品阶系数挂钩（Leo 拍板：B 平方挂钩）**：`升级费/级 = 30 × 品阶系数² × 等级`，取整。
> **等级上限（Leo 拍板，保留）**：一阶 **100** / 二阶 **80** / 三阶 **70**（基础 20）。
> **学习条件（Leo 拍板，2026-08-19）**：学武功**不花拜师费**，只消耗学点；进阶靠「前置武功等级 + 实战门槛」卡。
> 满级贡献：一阶 100×3=300 攻 / 二阶 80×5=400 / 三阶 70×8=560 —— 三阶满 ≈ 一阶满 ×1.87，厚积薄发成立。

| 品阶 | 学习条件 | 升级费（每级） | 满级上限 | 满级累计（升级费） |
|---|---|---|---|---|
| 基础武学 | 无（拜师即学） | 10×等级 | 20 | ≈ 2,100 |
| 门派一阶 | 无前置 | 30×1.0²×等级 = **30×等级** | **100** | 30×Σ(1..100) ≈ **151,500** |
| 门派二阶 | 某门一阶武功 ≥**60 级** + 实战 ≥**10W** | 30×1.3²×等级 ≈ **51×等级** | **80** | 51×Σ(1..80) ≈ **165,000** |
| 门派三阶 | 某门二阶武功 ≥**40 级** + 二阶内功 ≥**50 级** + 实战 ≥**100W** | 30×1.7²×等级 ≈ **87×等级** | **70** | 87×Σ(1..70) ≈ **216,000** |

> **主线投入（30 天达成三阶满）**：一阶 60 级（5.5 万）+ 二阶外功 40 级（4.2 万）+ 二阶内功 50 级（6.5 万）+ 三阶满 70（21.6 万）≈ **37.8 万**，≤ 30 天产出 53 万 ✅（余量补一阶/二阶满级）。

### 9.3 养成节奏（30 天达成三阶 · Leo 拍板：1 个月必杀，产出 ×3）

```
第 1~3 天：一阶练到 60 级（30×Σ(1..60)=54,900）→ 解锁二阶（前置一阶 60 ✅，实战 ~1W 档位 2）
第 4~6 天：二阶外功 40 级（51×Σ(1..40)=41,820）
第 7~10 天：二阶内功 50 级（51×Σ(1..50)=65,025）→ 解锁三阶（前置外功 40 + 内功 50 ✅，实战 ~10W 档位 3）
第 11~22 天：三阶练满 70（87×Σ(1..70)=216,195）→ ★ 必杀达成（约第 3 周）
第 23~30 天：补一阶满 100 / 二阶外功满 80 / 第二门武功（余量 53 万 − 主线 37.8 万 ≈ 15 万）
月 2 起：江湖武学 / 特技 / 绝学 / 绝内（第二养成线，v1.0 规划，MVP 只做门派线）
```

> **三阶必杀 ≈ 第 22 天（第 3 周）达成，月底毕业**。实战节奏同步：周 1~2 档位 1~3（10W）、周 3~4 档位 4~5（100W），三阶实战条件第 3 周达成。
> 肝度 = 每天收 2 次闭关（10,800/日）+ 5~15 场扫荡，放置友好。

### 9.4 广告加速（v1.0 规划 · 不进 MVP）

> Leo 2026-08-19 拍板：广告加速 **v1.0 商业化阶段设计**，MVP 只做玩法闭环。形式（Leo 选定，商店刷新未选）：
