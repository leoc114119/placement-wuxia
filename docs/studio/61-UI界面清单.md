## 0. IA 总览（一页纸）

```
Boot 启动/读档
  │
  ▼
Home 主界面（江湖 Tab · 默认页）─────────────────────────┐
  │  顶栏：头像 | 昵称 | 实战经验        ······   银两      │
  ├─ 武学 Tab ──► Martial 武学阁（①基础属性 ②基础武学 ③武学配置-升级/装配）
  ├─ 装备包裹 Tab ──► Bag 装备包裹（8 部位装备 + 道具包裹；未来合成/放置生成）
  ├─ 江湖 Tab ──► Map 地图闯关（按实战解锁）＋ 闭关入口 ＋ **社交区（好友/助战）**
  │   ├─ 地图闯关 ──► 普通关：自动刷怪动效（掉实战/学点/装备）
  │   │             └─► BOSS 关：半自动战棋（3v3 布阵→回放→结果）
  │   ├─ 闭关入口 ──► 室内闭关场景（切全屏；得学点+熟练度，无实战无装备）
  │   └─ 社交区 ──► 侠友按钮 → 好友列表 → 勾选 0~2 助战（14 文档）
  ├─ 门派 Tab ──► Sect 门派（①入门门槛：实战达标 ②武功学习：满足进阶直学）
  │   └─ 后续：PVP/社交/比武/排名（单独模块）
  └─ 设置按钮 ──► Settings 设置/存档 ─► 确认弹窗（清除缓存）
```

> 口径（Leo 2026-08-19 重构，4 项确认）：**4 Tab = 武学 / 装备包裹 / 江湖 / 门派**（A 案，72 定稿）；顶部 = 头像/昵称/实战经验（左）+ 银两（右）；闭关在江湖（入口→室内场景，得学点+熟练度）；装备包裹独立 Tab；门派 = 入门门槛（实战达标）+ 武功学习（无任务系统）；**社交（好友/助战）不设独立 Tab，入口放江湖界面**（Leo 2026-08-19 拍板）；后续 PVP/社交/比武/排名单独模块。

**导航原则（04 §5）**：菜单层级 2-3 层不深嵌套；关键操作（学武/挑战/领取）2 步内可达；危险操作（清除缓存/分解蓝+）二次确认。

## 2. 跨场景复用弹窗/组件清单

| 组件 | 复用场景 | 规范要点 |
|---|---|---|
| 通用确认弹窗 | 学武确认 / 挑战确认 / 快进跳过 / 清除缓存 / 分解蓝+ | 宣纸面板 + 墨线残破边（04 §4） |

## 4. 与 11 章节映射（一致性锚点）

| 11 章节 | 场景 | 备注 |
|---|---|---|
| 环节一 最小工程 | Boot / Home | 启动页 + 主界面骨架 |
| 环节二 挂机循环 | Home 修习面板 + 离线收益弹窗 | 挂机核心，任何界面不阻塞计时 |
| 环节三 学武功 | Martial | 学点+银两+前置校验 |
| 环节四 战斗 3v3 | Battle（布阵→回放→结果） | 客户端零判定（A 全离线回放） |
| 环节五 刷怪 | Map | 解锁链 + 掉落 |
| 环节六 背包·分解·商店 | Bag / Shop | D-05 已拍板 |
| 环节七 存档闭环 | Settings + Boot 读档 | 自动存档为主 |
