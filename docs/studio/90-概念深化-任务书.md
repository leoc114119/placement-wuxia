## 一、任务背景

placement-wuxia：微信小游戏《放置武侠》——挂机放置 + 自走棋战棋战斗（MVP 1v多），技术栈 TS + Canvas 2D，美术已转向 2.5D 像素风（2026-08-23 定）。项目已开发到 T06 战斗界面（battle-core 已落地），Leo（产品负责人）按下暂停键进入 **「设计回炉」** 阶段：先把整个游戏设计扎实，再继续开发。

本任务：对项目做**概念深化**，产出创意草案供 Leo 拍板整体方向。

## 二、已定地基（复用，不推倒）

- **放置武侠**：挂机 → 学武功 → 战斗 → 变强；自走棋战棋（MVP 玩家 1 vs 敌方按实战档位）
- **2.5D 像素风**：战斗/场景用 HD-2D 像素角色（v8 风格锚）
- **武学系统**：外功 / 内功 / 轻功 / 门派技能四类；6 门派（华山/武当/峨眉/星宿/血刀/丐帮）60 条武学已录入（11 武学数据表）
- **世界观 v0.2**：查小侠传说 + 灵绝顶群邪 + 有缘人成长线；玩家目标线 = 无名 → 寻残卷 → 学绝学 → 平乱世 → 武林盟主
- **原创红线**：不碰金庸真实角色；门派/人物/武功全原创（可借鉴精神与框架）

## 三、Leo 拍板的两根核心支柱（本次深化必须围绕）

1. **剧情故事**：让玩家有"在过一段自己的武侠人生"的感受
2. **武侠搭配的爽感**：武学组合/构筑带来的"配出一套厉害的"的时刻

## 四、对标结论（Leo 调研《大侠式人生》：画面一般、战斗一般但高分的真实原因）

| 机制 | 它怎么做的 | 对应支柱 |
|---|---|---|
| 人生感 | 固定寿命 + 每年行动点分配（修炼/游历/结交/任务），选择塑造不同人生与结局 | 剧情故事 |
| 构筑乐趣 | 内功外功多套搭配触发"武学连锁增益"、偷师学艺、自创武功 | 武侠搭配爽感 |
| 自由意志 | 正邪双线、抉择影响江湖格局、多结局 | 剧情 + 扮演感 |

**启示**：高评分来自"人生感密度 + 构筑乐趣密度"，与表现力无关。

## 五、Deliverables（写入 `docs/studio/90-概念深化草案.md`）

1. **「剧情 × 放置循环」落地构思**
   剧情不是打断挂机的过场，而是挂机中推进的人生线；给出"抉择 → 事件 → 结局"闭环在 **MVP 可落地** 的版本（含放置节奏怎么嵌剧情、低成本实现方式）。

2. **「武学搭配 × 自走棋」连锁增益 MVP**
   内功/外功/轻功组合触发 buff / 连招的具体机制设计（克制关系、组合触发、成型反馈、爽感时刻），明确如何挂在现有 battle-core 与 60 条武学表上，不推倒重做。

3. **2~3 个整体创意方向**
   每个方向给【一句话卖点 + 核心玩法落点 + 对现有地基地改动量评估（小/中/大）】，供 Leo 挑选。

## 六、设计约束

- MVP 务实：微信小游戏体量，自走棋 1v多 已有引擎；不引入重叙事系统 / 大型开放世界
- 剧情与搭配**互相支撑**（搭配是玩家变强的表达，剧情给搭配赋予意义），不是两个孤立模块
- 用 MDA 框架与自我决定论（自主/胜任/关联）论证爽感来源
