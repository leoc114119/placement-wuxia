## 一、今日拍板（已定，写进项目真源）

### 1.1 主玩法：江湖衣钵 · 世代传承（R03-B），传承进一期

- **定位原话（Leo，写入 91 第一行）**：
  > "活人感放置，还要加上一辈子对于当武林高手的追求——不是每个人都有机会成为武林高手的，**这辈子达不到，就下辈子再来**。"
- 机制骨架：追求锚点（武林高手的公认顶点，衔接世界观 v0.2 查小侠传说/灵绝顶）→ 一代人的结构性限制（寿数+天赋随机+时间线抉择有限，"达不到"是设计使然）→ 传承=跨代积累（谢幕遗憾 → 衣钵抉择 → 下一代继承）→ 世代滚雪球 + 传人图鉴
- 核心心理学：损失厌恶转化（死亡不是惩罚是叙事高潮）+ 收集欲 + 长线追求
- 留存逻辑："这辈子没完"替代"数值永远涨"——回答放置品类"数值封顶后玩家为什么留下"

### 1.2 主框架 / 内容边界（Leo 亲自定义，以此为准）

**主框架（一期建，四大件）：**
1. 放置成长（模块 04/09 有底子）
2. **回合分配**（按时间线选择做什么——武林群侠传式养成的竖屏化，"武侠人生感"支柱的机制落点）
3. 战斗机制（试金石定位；**机制待定，见 2.1**）
4. 小游戏骨架（生活技能成长，1 个通用骨架 + 1-2 个实例）

**内容（数据表渐进，编辑器后置）：**
- 人物 / NPC / 门派 / 武功条目 / 装备 / 具体小游戏实例 / 事件文案
- 原则：框架只管机制（槽位/连锁规则/好感轴），条目全进 JSON 表；schema 冻结是编辑器后置的前提

### 1.3 经济三角 + 设计红线

```
放置（被动产出，大头）──┐
生活小游戏（主动操作）──┼→ 成长 → 战斗试金石 → 掉落反哺
战斗（验证 + 掉落）  ──┘
```

- **红线**：生活技能产出必须是某些成长材料的**唯一/最优来源**，否则小游戏沦为摆设
- 小游戏选型标准：单局 ≤60 秒、可跳过、有收集图鉴、产出直连成长

### 1.4 MVP 验收门（升级版）

- **一次完整代际转换闭环**：培养 → 寿数将尽 → 谢幕（江湖小记）→ 传承抉择 → 下一代开局
- 一代压缩到 **3-7 天**（验证期内玩家真实体验 2-3 代）；传承 MVP 简化为**三选一**
- 核心指标：7 日留存 + **"传承时刻"情感反馈**（谢幕页停留时长/分享率）
- ⚠ 代际转换是单点命门：谢幕→传承的情感体验与数值同优先级

### 1.5 武林碑排行榜（进一期）

- **好友榜**（微信开放数据域）：成本低 + 天然 viral（好友攀比=自传播）
- **量"家族底蕴"不量单代数值**：历代最高境界 + 传世绝学数 + 传承世代数——守住活人感
- 碑文/谥号化呈现（"三代习剑，未至绝顶"）——排行榜本身即活人感载体
- 全服榜后置

### 1.6 获取层：叠加武侠皮开箱（Leo 提议，带三边界）

- 包装：秘境寻宝 / 残卷拓印 / 师父遗物 / 悟道石刻——每次开箱带叙事钩子
- **边界①主从定死**：开箱是获取表现层非成长主节奏（验收：关掉开箱，人生循环仍成立）
- **边界②概率透明**：概率公示 + 保底从一期做（暴走英雄坛 2023 差评教训）
- **边界③代际隔离**：开箱产装备/消耗品当代生效；跨代只传武学/记忆/名声——代际结构天然充当开箱经济通胀控制阀
- 商业化接口预留：IAP（钥匙/礼包/月卡）落开箱位，IAA（看广告）=每日秘境次数，J-01 细节后定

### 1.7 活人感设计准绳（贯穿所有系统）

> **活人感 = 把数值事件叙事化 + 让世界对玩家状态有反馈。**

- 低成本手法：状态轴有人格后果（容貌/饥饿/年龄）、世界记得你（NPC 记忆标签）、挫折故事化（走火入魔→异象）、挂机产出叙事化（"江湖经验"而非"+2500 金币"）、时间流逝有痕迹
- 一期埋 1-2 个状态轴（建议：年龄/时间痕迹 + 一个待选）
- 代价自知：平衡复杂度上升 + 对买量模型不友好——长尾路线下均可承受

## 三、今日调研结论（背景支撑，详见 95 号文档）

1. **AI 产能三定律**：①AI 有效倍数与体量负相关（组合爆炸超线性）②单人产能 = 决策带宽 × 自动化扩容系数（生成近无限、决策串行、验证可自动化）③综合倍数取最小值不取平均——策略是让最弱环节（QA/手感）消失而非到处用 AI
2. **品类适配**：本项目（系统驱动 + 文本内容 + 竖屏放置）落在 AI 先例已验证区（Void Balls/CODEX MORTIS/FireField 等 2026 实证），有效倍数可取 6-8x
3. **市场**：武侠/仙侠放置占微信小游戏畅销榜 TOP10 四席（寻道大千#1/小小英雄#5/灵剑仙师#6/无名之辈#9），品类需求强验证；但全是"大厂买量"打法——本项目走"内容差异化+社交裂变+混合变现"长尾错位路线
4. **最佳落地品类公式**：AI 产能适配度高 × 获客不依赖买量 × 头部未占位——现行定位三条件全占；开箱 like"做得出但落不了地"，其成熟手法（数值压缩/高频小奖励/概率透明）借作弹药
5. **长尾先例**：暴走英雄坛（小团队、零买量、活 9 年）——"低成本画风+养成深度+更新流水线"模式成立；其数值透明度与新手引导教训列为设计红线
