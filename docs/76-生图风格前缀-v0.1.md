## ⛩ 风格前缀（直接复制）

```
中国Q版水墨国风武侠游戏UI设计，活泼年轻、现代国风气质（参考一念逍遥/逆水寒），明亮清透不灰暗、年轻不老气。
严格色板：宣纸米#F8F4EA为背景底、浅杏#F0E6D4与深杏#E0D2B4为次级面板；墨色#2B2B2B为文字与描边、深灰#444444为次要文字；朱砂#E2574C为主强调色、深朱砂#C94A40为按钮与重点、珊瑚#FF7E67为渐变提亮；竹青#7FB069与黛青#4A7A6B为点缀；淡金#D4AF37用于印章与装饰线。
字体：书法体（楷体/行楷）标题+宋体正文。
UI材质：宣纸底配细腻纸纹，墨色1.5px细描边，大圆角14至20px，宽松间距；面板为水墨纸卡/木匾/卷轴/竹简造型，木匾带弧形切角、铜环、流苏装饰；按钮为深朱砂圆角矩形白字或朱砂渐变墨字；进度条朱砂实色配浅灰底；选中态朱砂下划线或淡金印章角标；背景为写意水墨山水留白（中景60%留白供UI叠放）。
氛围：纸纹噪点、墨晕投影、朱砂光晕、整体明亮清透。
```

## 快速速查（界面/背景/图标 三类各自追加）

### A. 整张游戏界面图（视觉基准）
风格前缀 + 「竖版9:16完整游戏UI界面设计稿 + [页面具体内容] + 高保真UI界面、界面元素完整清晰、无人物特写」

### B. 背景图（bg_*）
风格前缀 + 「竖版9:16游戏主界面背景：远景顶部15%极淡三层远山（淡墨推远），中景y30%至85%大片宣纸留白（几乎纯宣纸，供UI叠放），近景仅最下方15%与左右两侧极小区域有山石/松枝/远亭/竹影，可有1至2只极小仙鹤点缀（占比<3%），无人物、无文字、无水印」

### C. 单个图标（icon_*，如 Tab 图标 / 简版书）
风格前缀 + 「1:1正方形透明底PNG单个图标：[图标内容]，水墨简笔，笔画清晰，主体占画面60%至70%，无文字」

## 避坑记录
- GPT Image 对「人物特写/NPC站姿」描述易触发内容审核 → 界面图弱化人物、专注UI元素
- 即梦（seedream）对人物更宽松，可承担 bg/角色
- 界面图分辨率 1K 够用（2积分），背景图 2K（6积分）
