# 开箱获取层

> 分类：06-休闲与其他 · 状态：⏳待设计 · 优先级：P2
> 来源：docs/86 §1.6

## 要点

秘境/残卷/遗物/悟道包装；三边界=主从定死/概率透明+保底/代际隔离；IAP 落钥匙礼包月卡、IAA=每日秘境次数

> 🔗 **已与回合分配合并（2026-08-31）**：开箱不再是独立系统，降级为**结算与叙事包装层**——"选择→攒箱→开箱"闭环，详见 `02-主线玩法/核心循环.md §6`（箱型映射、三条护栏、商业化挂点）。本文档保留三边界、合规与商业化细节。

## 合并后的定位

- 箱型即主题：悟道石刻(闭关) / 秘境奇遇(行走) / 采获(生活小游戏) / 战利遗物(战斗)
- 决定性强于随机：选择定**类型与保底**，箱内随机只影响**浮动量**
- 广告只加速攒箱/给次数，**不提稀有度**；月卡提容量与保底
- 红线：生活材料只能由小游戏产出（不售卖）；开箱物当代生效（代际隔离）
