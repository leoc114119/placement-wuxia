# 小游戏骨架（生活线 · 形态 = 城镇生活技能）

> 分类：06-休闲与其他 · 状态：🔶框架 v0.5（Leo 08-31 晚：+**庙祝/香火**第七生活技能 → 福缘第七维；求签非线性增长 + 掉落 buff + 广告加倍） · 优先级：P1
> 来源：docs/86 §1.2/§2.2；Leo 08-31 口述
> 别名：生活线 / 城镇线（86 号主框架"小游戏骨架"四大件之一，骨架不变，形态=生活技能）
> 原则：先框架后数值（🔧 占位）
> **定位（v0.3）**：城镇 = 养成对内线——**玩生活小游戏涨基础属性** + 产钱/材料/人脉；回合 = 江湖对外线（见 `02-主线玩法/回合分配`）
> **属性口径（v0.5）**：基础属性 = **七维**——战斗六维（臂力/根骨/机敏/定力/悟性/胆识）+ **福缘**（非战斗，掉落/机缘向）

## 1. 定位变更（2026-08-31）

原设计：生活小游戏是回合分配的四个选项之一（闭关/行走/小游戏/战斗）。
**改为独立并行线**——不占回合、不抢人生资源，原因：
1. 生活技能若占回合，玩家会为材料牺牲"人生" → 对主线最大稀释
2. 异步收菜式循环 = 第二个上线钩子，天然契合放置品类
3. 商业化挂点更清晰（加速催熟 + 扩工位 / 开新产业）

**v0.3 升级（Leo）**：城镇线职责从"产材料/钱"扩大为**六维基础属性的唯一增长入口**——每个生活技能对应一维属性，玩小游戏即练功。

## 2. 形态 = 生活技能小游戏（打工 + 采集 + 艺能 + 营生）

**循环**：接活/开工 → **主动玩小游戏（高倍）或 托管自动打工（离线·低倍）** → 结算（**属性 + 工酬/材料/人情**） → 城镇声望累积 → 解锁更高技能等级与差事

### 2.0 打工托管（Leo 08-31 晚拍板）

- **离线自动打工**：角色留在城镇自动做生活技能，离线期间持续产出（六维 + 钱 + 材料，效率 🔧 低于主动玩）
- **主动玩 = 高倍爆发**：上线亲自玩小游戏，单次收益远超托管同时长产出——小游戏是加速器不是门槛
- 托管效率与**技能等级挂钩**（等级越高自动打工产出越高）→ 放置正循环
- 与全局时间流速共享：广告 / 月卡加速同样作用于托管产出
- 商业化挂点（备选）：托管效率临时加成 / 托管差事栏位扩展

### 2.1 七维 ← → 生活技能一一对应（Leo 08-31 晚拍板；v0.5 增福缘）

| 生活技能 | 主涨属性 | 原型依据（武林群侠传） | 副产出 |
|---|---|---|---|
| **打铁/锻造** | 臂力 | 打铁满级 → 铜身铁臂 | 兵器材料、打造 |
| **打猎/狩猎** | 胆识 | 猎猛兽练胆 | 皮毛食材 |
| **钓鱼** | 定力 | 久坐养性 + 甩杆时机 | 鱼获、珍稀鱼 |
| **采药/医术** | 根骨 | 辨识百草、药理养身 | 药材、丹药 |
| **琴棋书画** | 悟性 | 忘忧谷学艺、通悟性 | 好感道具、艺能事件 |
| **烹饪/酒楼** | 机敏 | 跑堂眼疾手快、火候时机 | 食材、食疗 |
| **庙祝/香火** | **福缘**（第七维，非战斗） | 暴走英雄坛"福源"（95 号） | 香火钱消耗出口、求签 buff、正邪供奉分叉 |

- 每项技能自带等级（🔧），等级越高：小游戏收益越高 + 差事档次越高 + 对应属性增长效率越高
- 技能满级 → 领悟契机（原型：满 100 领悟绝学，如打铁→铜身铁臂）——与绝学体系接口
- **福缘定位（v0.5）**：**非战斗属性**——只吃掉落品质/机缘触发率/事件好结局/开箱保底修正（收益递减不做倍率乘数，防 luck stacking）；**不进绝学 C(6,2) 配对系统**（战斗六维配对不动）

### 2.1a 庙祝/香火：求签与福缘非线性增长（Leo 08-31 晚拍板）

**核心循环**：上香（花银两） → 求签 → 攒签 → 福缘增长 + 当日掉落 buff

```
上香/添灯油（技能练级，线性） → 求签
    ├─ 上签（累计 N 支 🔧）──→ +1 福缘（积累型）
    ├─ 上上签（累计 M 支 🔧，M>N）──→ +1 福缘（大额积累）
    │                          └─ 单支上上签 → 当日掉落 buff（即时激励）
    └─ 平签/下签 → 心情小减 / 无事（庙祝技能等级高可"解签"化解下签）
```

- **非线性设计（Leo 定口径）**：福缘不随上香次数线性涨，而是**签数里程碑制**——上签、上上签分别设累计门槛（🔧），跨门槛才 +1；前期涨得动、后期越攒越难，天然通胀曲线
- **单次上上签 = 当日掉落 buff**（🔧 幅度/时长）——运气好当天就能兑现，积累与即时反馈双通道
- **广告加倍**：掉落 buff 时长可看广告 ×2（Leo 定）——轻商业化，只加速不提稀有度（对齐开箱层护栏）
- 黄道吉日（游戏内历法）：吉日求签出签率上浮（🔧），给"哪天去拜"一个日历节奏
- 正邪分叉（提案，待议）：正线上香/放生/施药积功德；邪线可解锁血祭/供养邪神类替代入口（高风险高回报，可能反噬扣福缘）——与自由成长主线（正邪线）联动
- 护栏：钱买不到的福缘约 1/3 只能由功德/奇遇节点解锁（🔧 配比）；代际软重置（"祖上积德"=下代福缘下限+，本体大部分回归）

### 2.2 与"行走江湖/江湖际遇"的对照

| 维度 | 城镇生活（养成·稳） | 江湖际遇（主线·险） |
|---|---|---|
| 收益 | 确定性：属性/钱/材料 | 不确定：事件/机缘/传授 |
| 风险 | 低（最差白玩一局） | 高（受伤/结仇/错过窗口） |
| 情绪 | 经营、积累、手感 | 冒险、故事、缘分 |
| 定位 | **下限保障（六维+钱）** | **上限与叙事** |

### 2.3 钱的三来源（v0.3：钱整体归城镇）

1. **打工差事**：码头杂役/茶肆书局等纯营生（保底）
2. **跑镖差事**：护镖/商队，钱+名声，带风险（险档营生）
3. **家业产业**：盘铺面 → 跨代被动收入（家业继承，见 §4）

### 与"行走江湖"的对照（都是出门，收益结构互补）

| 维度 | 城镇打工（生活线·稳） | 行走江湖（主线·险） |
|---|---|---|
| 收益 | 稳定：工酬 / 材料 / 人脉 | 不确定：事件 / 机缘 / 名声 |
| 风险 | 低（最差白跑一趟） | 高（受伤 / 结仇 / 错过窗口） |
| 情绪 | 谋生、踏实 | 冒险、故事 |
| 定位 | **保底成长** | **上限与叙事** |

→ "稳 vs 险"的取舍张力；玩家倾向本身也是活人感的一部分（有人爱稳、有人爱闯）

### 差事清单（打工/营生类，不直接对应六维）

| 差事 | 产出 | 喂回主线 |
|---|---|---|
| 镖局护送（跑镖差事） | 钱 + 名声（带风险） | 名声 / 战斗前置 |
| 码头杂役 | 钱（保底） | 纯经济来源 |
| 茶肆 / 书局（备选） | 茶、书 | 好感道具 |
| 挖矿（采集） | 矿石 | 打铁/锻造原料（**原料唯一来源红线**） |

### 递进（中期，可后置）

**打工 → 盘下铺面 → 产业**：打工攒够钱与城镇声望后可盘下一间铺面，转为异步产业，成为可跨代继承的"家业"（见 §4）

## 3. 与核心循环的咬合（v0.5.1 修订）

- **辅线定位（Leo 纠偏）**：城镇休闲打工**全程是辅线**——早期成长也以回合分配为主引擎（剿匪攒学点→学武→推图）；城镇托管自动慢涨，玩家不点开也在成长，"唯一入口"是防打架的边界，不是前期重心的承诺
- **七维唯一增长入口（红线）**：基础属性只从生活技能小游戏出；回合三事（剿匪/学武/际遇）不产基础属性；福缘不进战斗配对
- 生活线产出（七维+钱+材料+人脉）→ 主线成长 → 战斗试金石 → 掉落反哺（福缘修正掉落品质与保底）
- 时间流速共享：广告 / 月卡加速同样作用于工期与托管
- 人脉接口：打工/玩小游戏认识的人 → 好感度 → 传授 / 引荐（对齐武林群侠传"关系即成长资源"）
- ~~双轨建议~~ ✅ 已定 = **打工托管**（Leo 08-31 晚拍板，见 §2.0）：离线自动打工（低倍）+ 主动玩（高倍）

## 4. ⭐ 代际接口（新增提案，待 Leo 拍板）

**"家业"跨代继承**——86 号原定跨代只传"武学/记忆/名声、装备当代生效"；打工线攒下的**铺面与城镇声望**可成为**第四类继承物**：
- 历代攒下的铺面 = 具象化的家族积累（"一间开了三代的酒坊"）
- 直接喂饱武林碑"家族底蕴"字段（历代最高境界 + 传世绝学数 + **家业规模**）
- 让"传承"从抽象变具体：上代留下的不只是剑谱，还有营生
- ⚠️ 若继承，需配衰减/维护成本（疏于打理会败落），防滚雪球

## 5. 待决（框架层）

1. ~~包装主题~~ ✅ 已定 = **城镇生活技能**（v0.3：职责扩大为六维唯一增长入口）

8. ~~六维离线双轨~~ ✅ 已定 = **打工托管**（离线自动打工低倍 + 主动玩高倍；托管效率与技能等级挂钩）
9. 求签数值框架：上签/上上签的累计门槛 N/M、单支上上签掉落 buff 幅度、吉日上浮率（全部 🔧，数值阶段定）
10. 正邪香火分叉（血祭/邪神供养）是否采纳——与正邪自由主线联动，建议采纳（正邪线多一个日常表达位）
