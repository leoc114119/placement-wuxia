## 绝学体系：按六维分系（Leo 提案 2026-08-31）

六维 = 臂力 / 根骨 / 机敏 / 定力 / 悟性 / 胆识（modules/05，模板 B：胆识后置 15）

### 核心规则（Leo 拍板方向）

| 规则 | 内容 |
|---|---|
| 一代一绝学 | 每代只能参悟 **1 门**江湖绝学；绝学按六维分系，不同系效果差异大——一代的六维成长与 build 围绕主属性展开 |
| 二代起兼修 2-3 门 | 世代 ≥2 后可同时修 2-3 门不同系绝学；兼修资格建议与**遗泽点/家族底蕴**挂钩（上代善终→下代兼修之资，待议） |
| 属性联动 | 不同系绝学同时修习产生**联动效果**（搭配爽感支柱的兑现点） |

### 六系风味定位（初稿）

| 系 | 定位 | 倾向 |
|---|---|---|
| 臂力系 | 刚猛重攻 | 攻击/负重（F-02：攻 = 30+臂力×2+…） |
| 根骨系 | 内壮厚血 | 气血上限/防御 |
| 机敏系 | 身法速攻 | 先手/闪避/行动条 |
| 定力系 | 内功心法 | 抗负面/内功抗性 |
| 悟性系 | 领悟型 | 学武速度/领悟上限（元成长，慎做） |
| 胆识系 | 搏命暴击 | 暴击/逆境（⚠️胆识后置 15、实战百万+1，数值锚点缺，见待议） |

### 联动示例（按属性对生成，C(6,2)=15 对，逐对规则生成不逐对手写）

| 组合 | 联动风味（示意） |
|---|---|
| 臂力+根骨 | 刚柔并济：攻升防升但速度降 |
| 机敏+悟性 | 料敌先机：先手+反击率 |
| 臂力+胆识 | 搏命一击：血量越低攻越高 |
| 定力+悟性 | 后发制人：受击叠内力 |
| … | 其余 11 对规则化生成 |

## 传承与绝学的咬合（接 02-主线玩法/代际传承）

- 一代一绝学 → 每代身份/流派 = 谢幕小记与武林碑碑文素材
- 二代起兼修 = **联动是跨代养成的奖励**，"融汇贯通"从第二代才成立
- 绝学谱跨代保留（领悟保留/层数重修，见代际传承 §设计要点 2）→ 兼修池 = 历代绝学谱的并集，集齐更多系 = 后代 build 空间更大
- 武林碑"传世绝学数" = 集系进度计数器
