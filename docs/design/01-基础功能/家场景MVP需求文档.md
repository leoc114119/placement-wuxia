# 家场景 MVP 需求文档

> 分类：01-基础功能 · 文档版本：**v1.0**（2026-09-02，六项交互确认项已全部拍板清零）· 状态：🟢 开发级需求（T17 前置：家场景工程化为 NPC 测试件挂载载体）
> 本文档 = 家场景工程化（proto/home_demo → 正式工程）任务卡的**任务标准、交付与验收依据**（需求文档铁律 09-02）
> 追踪来源：UI框架与导航 §0.5（视觉骨架 v8 组）· 角色帧规范 v5 · 场景状态与战斗入口数据流 v0.1（PlayerState）· NPC配置系统 v1.0（T17 接口）· proto/home_demo 交互验证（全项通过）
> 边界声明：本版**仅含**家场景本体；城镇/江湖历练/木人巷/闭关实装（占位弹窗）不在（见 §9）

---

## 1. 范围

| 项 | 口径 |
|---|---|
| 目标 | proto/home_demo 的交互与视觉**正式工程化**（game.ts 场景体系），并作为 **T17 NPC 测试件的挂载载体** |
| 载体 | 竖屏 9:16，舞台式构图（场景图居中+黑幕放 UI，网金语法） |
| 明确不含 | 城镇场景、闭关离线结算实装、打木人/打坐实装、江湖历练、背包/装备/武学面板功能（Tab 占位）——见 §9 |

## 2. 场景与渲染

| 项 | 需求 |
|---|---|
| 场景图 | home_stage（现役舞台版），`object-fit: cover` 等效，屏幕空间静态 |
| 主角渲染 | 铃兰式帧组（角色帧规范 v5），height 定尺：hero 元素高 = 目标屏高÷0.8（≈19.6%→人物实显≈15.7% 屏高）；translate(-50%,-92%)（脚底=画布 93.75%） |
| 影子 | 程序化椭圆影（深色半透明，随角色，宽≈角色宽 0.55） |
| 帧工程四件套 | 帧预解码（decode 完开播）/整数像素定位/height 定尺/资源版本号 `?v=` |
| 资源 | 全部走资源管理器+配置表（外置铁律，禁硬编码路径） |

## 3. 主角与移动

| 项 | 需求 |
|---|---|
| 点击移动 | 点击场景→主角走向目标点（钳制于可行走区 WALK），到达即停 |
| 可行走区 | **菱形贴合地板透视**：上边界随 y 减小收窄（防视觉踩墙/上家具），具体多边形工程化时按场景图实测标定（钳制算法按多边形判定，弃矩形） |
| 方向帧 | 八向（Phase 2 帧到位后启用全向；到位前 down 向+占位） |
| 动画 | 移动=walk 循环 180ms/帧；静止=idle 呼吸循环 600ms/帧（角色帧规范 §4） |
| 位置状态 | 读写 **PlayerState.pos**（会话内切战斗返回恢复战前位置；跨会话随存档） |
| 帧资源策略 | Phase 2 八向到位前，非 down 向以 down 帧占位（已验证的过渡策略） |

## 4. UI 五区（v8 视觉骨架）

| 区 | 需求 |
|---|---|
| ① 顶栏 | A2 底图+canvas 叠字架构：头像（avatar.png）+名字（PlayerState.name）+气血/内力双条（**PlayerState.vitals 真实数据**，替换 CSS 假条）+年纪（PlayerState.age=8岁1月）+辰时牌+胶囊预留；行 2 货币带=**PlayerState.inventory/资源计数**（初始 0，🔧 占位待经济数值） |
| ② 左上木牌串 | **闭关**：点击 toast「闭关功能未开放」；**木人**：点击→主角走到木人桩前→播放打桩动画（无战斗接入）；**打坐**：点击→走到坐垫→播放打坐姿势动画（不回血）——三者均为表现占位，机制二期 |
| ③ 中央沉浸区 | 纯沉浸：主角移动+NPC（T17 挂载），无其他 UI |
| ④ 右下任务框 | 占位两条示例任务（proto 现状）；点击=toast 占位 |
| ⑤ 底部铃兰导航 | 五项；MVP 仅显示与点击 toast 占位（无面板功能） |

## 5. NPC 测试件挂载（T17 接口）

| 项 | 需求 |
|---|---|
| 挂载 | 按 NPC 配置 `spawn[]` 将 `bandit_home_test` 渲染于家场景（idle_frame 静止帧+scale+facing） |
| 交互 | 点击命中判定盒 → 走向相邻 → 喊话 0.8s → 触发战斗（链路详见《场景状态与战斗入口数据流》§3，本文档不重复） |
| 返回 | 战斗结束回家场景，主角恢复战前位置快照，**NPC 保留原地可重复挑战**（MVP 测试件口径） |
| 场景出口 | 门口区域**预留出口标记**（发光地砖/木牌），点击 toast「城镇建设中」——为将来切场景预留视觉位（城镇场景未设计） |

## 6. PlayerState 接入

| 项 | 需求 |
|---|---|
| 顶栏真实化 | 顶栏全部显示字段改读 PlayerState（name/age/vitals/资源），禁 CSS 假数据 |
| 修改入口白名单 | 家场景为**只读渲染 + pos 读写**（无任何数值修改入口；战斗回写/离线领取/学武等入口均在其他场景） |
| 状态唯一性 | 家场景与战斗共享同一 PlayerState 实例（场景状态文档 §1.2） |

## 7. 存档点位（薄设计 · P1-6）

| 项 | 需求 |
|---|---|
| 存档主体 | PlayerState 全量序列化（JSON） |
| 存储位置 | MVP=本地（localStorage 等效物）；云同步二期 |
| 触发时机 | 关键节点自动存（战斗结束/离线领取/切场景）+ 手动存档位（设置内） |
| 版本迁移 | 存档带 `version` 字段（后续加字段走迁移函数） |

## 8. 验收标准（逐条可测）

| # | 验收项 | 标准 |
|---|---|---|
| V1 | 场景渲染 | 舞台构图/黑幕/主角比例与 proto 一致（对照 v13+截图） |
| V2 | 点击移动 | 点击→走向→钳制于菱形可行走多边形→到位停；角色不出现在床/墙等非地面区 |
| V3 | 位置保留 | 切战斗返回=战前位置；重开游戏=存档位置 |
| V4 | 顶栏真实化 | 名字/年纪/双条/货币全部来自 PlayerState，改数据重载即变 |
| V5 | 呼吸与走循环 | 静止呼吸微动可感知不抖动；走循环步态自然（Phase 1 验收口径延续） |
| V6 | NPC 挂载 | 山贼细作按坐标出现、可点击、触发链路通（与 T17 联合验收） |
| V7 | 三木牌占位 | 闭关=toast；木人=走到桩前播放打桩动画；打坐=走到坐垫播放打坐动画（均不触发数值变化） |
| V7b | 场景出口 | 门口出口标记可见，点击 toast「城镇建设中」 |
| V7c | 山贼重复挑战 | 战斗胜利返回后山贼原地保留，可再次点击进入战斗 |
| V8 | 架构红线 | 资源零硬编码路径；存档含 version 字段；三零 |
| V9 | 帧四件套 | 预解码/整数定位/height 定尺/版本号全部在位 |
