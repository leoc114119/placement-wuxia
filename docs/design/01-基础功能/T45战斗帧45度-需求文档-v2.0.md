## 1. 朝向口径（本次重构核心）

- 战棋六边形为**尖角朝左右（flat-top）**，中心格邻格仅有 6 个方向：**左、右、左上、右上、左下、右下**——无正上、正下。
- 战斗中**主角面向攻击者所在方向自动选帧**（FE 行为）；敌人同理面向主角。
- 因此站姿与**全套动作帧**（行走/普攻/施放/轻功/死亡）均按六向出帧，down/up 朝向帧不产。
- **右系三向实绘（右 / 右上 / 右下），左系三向（左 / 左上 / 左下）程序化水平镜像派生**，镜像零生成。

| 屏幕朝向 | 视角特征 | 生成方式 |
|---|---|---|
| 右 | 纯侧面，面朝画面正右，身体侧对镜头 | 实绘 |
| 右上 | 背斜侧，面朝画面右上方，以可见后脑与右肩为主 | 实绘 |
| 右下 | 正斜侧，面朝画面右下方，双眼与右颊可见 | 实绘 |
| 左 / 左上 / 左下 | 右系三向的水平镜像 | 程序化派生，零生成 |

## 4. 生成方法（已实证沉淀，执行代理不得更改）

1. **多参照 img2img（≤6 张）**：画风锚（家场景标准帧 `walk_q/frames/idle_down.png`，prompt 声明其佩剑不出现）+ 45° 视角基准帧 + **朝向/姿势参照**。
2. **朝向真源 = 白模站姿转面图**（Leo 提供，2048×2048 高清，09-04 重发正确版已入库目验）：右系三向的朝向以图对应姿势为准——右向=白模第 3 个（纯侧朝左）镜像、右下向=白模第 2 个（斜正面朝左下）镜像、右上向=白模第 4 个（背斜侧朝右上）直接参照。白模 5×8 跑表 `pose_run_5x8.png`（2400×1792，已验正确）作行走/跑动动作参照，整表不裁直接作参照。~~前置依赖卡点：原图待重发~~（09-04 已解除）。
3. **锚定表法铺量**：2 格表（左格=该向锚锁死，右格=目标姿势）img2img；姿势词条文本随批任务书给死，**禁代理自拟**。
4. **禁令**：禁纯文生图新起炉灶；禁链式多轮修补（轮廓收缩实证）；禁 AI 直出多帧网格；动作叙事词会诱导退化，姿势描述用纯静态画面+**画面坐标**（禁"身体左/右"类身体坐标）。
5. **执行纪律**（agent.md 四条，违反=汇报无效）：目测值必须标注"目测"；姿势类交付必须附画面内容逐项描述；同类失败连 2 次停路径升级上报；左右/方向姿势禁纯文字描述，索要示意图作参照。

## 5. 规格红线（校验门，程序化判定）

- 画布 240×320；人物视觉高 256px、脚底基线 y=300、质心 x=120（红线 9）。
- 宽高比带 0.38~0.55（待机/行走/施放）；普攻挥击/轻功/死亡免宽高比门，改高度一致性门（256±10%）。
- **横躺帧（死亡）按宽适配**：包络宽 ≤220、贴底 y=300、质心 x=120。
- 锚定表族一律 `--aspect 3:2`（2:1 被 gpt-image-2 拒绝）+ check_left_v2 **T=30**。
- 抠图统一走 mxai 语义通道（白底唯一通道）；白角≥250、通道差≤2、单连通主体、无文字、无武器（主角系）。
- 命名 `{动作}_{向}_{序号}.png`（如 `walk_right_1.png`、`atk_rightdown_2.png`、向名 right / rightup / rightdown）；落盘 `assets/characters/hero/battle45/`、`assets/characters/enemy/shanzei_a|b/battle45/`。
