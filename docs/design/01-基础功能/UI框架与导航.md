### 0.1 五区结构（竖屏）

```
┌─────────────────────────────┐
│ ① 顶部栏                     │

│       ├内力条   地图场景·时辰牌 ⋯ ① │
│  年纪    银两 铜钱 银票      商城 │
├────┬─────────────────────┬─────┤
│ ②  │                     │ ④   │
│场景 │  ③ 场景沉浸区         │ 任务区│
│驱动 │ （角色移动/NPC互动）    │ +自动 │
│按钮 │                     │ 寻路  │
│(动态)│                     │      │
├────┴─────────────────────┴─────┤
│ ⑤ 角色│装备│江湖历练│武学│聊天   │
└─────────────────────────────┘
```

### 0.2 五区定义（Leo 逐条确认）

| 区 | 内容 | 规则 |
|---|---|---|
| ① 顶部栏 | 左：头像+气血/内力双条+**年纪**（仅此处显示）；中：地图场景名+**时辰牌**（不显示年纪）+银两/铜钱/银票；右：商城+⋯菜单+①设置/公告 | 头像点开=角色详情 |
| ② 场景驱动按钮（左竖列） | **固定位置换内容**——按钮列位置固定，按场景切换内容，**不与场景物件绑定**：**家**=闭关/打木人/打坐(治疗)；**城镇**=打工(各生活技能提升) | scene→buttons 映射表驱动；实现简单+肌肉记忆稳定 |
| ③ 场景沉浸区 | **纯沉浸**：角色移动（点击移动）+NPC 互动；所有 UI 浮于四边，中间不给 UI | 大地图+镜头跟随 |
| ④ 任务区（右竖列） | 已接任务显示 + 点击**自动寻路** | |
| ⑤ 底部五 Tab | **角色 / 装备 / 江湖历练 / 武学 / 聊天**（角色与装备分列） | 江湖历练=剿匪无限流入口 |

### 0.3 关键机制口径（Q&A 确认记录）

| 项 | 定稿 |
|---|---|
| **闭关**（②首按钮·家场景） | 点击 → 马上进入**离线闯关状态**；可手动设置闯关武功 → 直接增加对应武功熟练度。= **离线放置引擎主入口**（与回合分配 v0.6.1 离线挂机机制同源，待交叉对齐） |
| **江湖历练**（⑤ Tab） | = **剿匪无限流入口**：选已通关地图 → 挂机剿匪。= **在线挂机引擎入口**（在场高倍掉落） |
| 双引擎分工 | 闭关=离线成长（武功熟练度）；江湖历练=在线收益（掉落/银两/遭遇）——放置双引擎在 UI 上各有其位 |
| 场景驱动按钮示例 | 家=闭关/打木人/打坐(治疗)；城镇=打工(生活技能→七维成长)。后续场景按此模式扩展 |

### 1.1 元素清单（七项，按优先级）

| # | 元素 | 网金原貌 | 移植口径 | 优先级 |
|---|---|---|---|---|
| 1 | **绢帛卷轴面板**（主容器） | 米黄绢帛底 + 水墨山水淡纹 + 竖卷轴杆（左右各一）+ 浅浮雕雕花外框 | **弹窗/面板主容器**：绢帛质感底、两侧卷轴杆、外框用浅雕花非重木 | ⭐⭐⭐ |
| 2 | **竖排鎏金木牌按钮** | 右上"武功/系统/装扮"，一字一牌，鎏金木牌铜包角 | 主功能入口：武功/侠客/行囊/系统，右侧竖排 | ⭐⭐⭐ |
| 3 | **菱形格物品栏** | 暗红菱形格整齐阵列，格内物品像素图标 | 背包/装备格：暗红格 + 深缝线，图标居中 | ⭐⭐⭐ |
| 4 | **双条状态栏**（红/蓝） | 底部通栏，红血蓝内力 + 数字 | 战斗/主界状态槽（HP 红/MP 蓝→我们对应气血/内力） | ⭐⭐⭐ |
| 5 | **时辰牌** | "4月30日 未时0刻"方牌 | **时间货币系统 UI 载体**：挂机结算/行动回合/年龄推进全部呈现为"X月X日 X时X刻" | ⭐⭐⭐ 玩法双命中 |
| 6 | **鎏金描边小元素** | 窗口 X、✓/✗ 鎏金按钮、买/卖木牌 tab | 关闭/确认/取消/页签 全部走鎏金描边语言 | ⭐⭐ |
| 7 | **中国结/挂饰** | 场景檐下中国结、灯笼绳结 | **场景层挂饰点缀**（屋檐/门框/摊位），UI 内少用 | ⭐⭐ |

### 1.2 🔴 比例铁律：绢帛为主，木为点缀（Leo 09-01 定）

> Leo 原话：「更多卷轴式 UI、木纹、中国结……**不用全部场景都那么多木元素**」

- **主容器（弹窗/面板）= 绢帛卷轴质感**（轻、米黄、水墨淡纹）——**木只出现在**：卷轴杆、木牌按钮、边框描线，占比 < 30%
- ❌ 反面教材：CodeBuddy 第一版合成样"通栏深红木纹状态栏"= 用力过猛，木头铺满 → **深色重木只用于底部状态栏底板与木牌按钮，其余面板一律绢帛**
- **中国结 = 场景层挂饰**（屋檐/门框/摊位），UI 内部克制使用（仅加载/节日弹窗可用）

### 1.3 配色基调

| 用途 | 色 |
|---|---|
| 面板底（绢帛） | 米黄 #E8DCC0 系 + 水墨淡纹 |
| 面板框/卷轴杆 | 中木褐 + 浅浮雕 |
| 状态栏底/木牌 | 深红木 #6B3A2A 系 |
| 描边/高亮 | 鎏金 #D4AF37 系 + 铜角 |

| 文字 | 浓墨 #2B2B2B（绢帛上）/ 鎏金（深底上） |
