### 1.1 元素清单（七项，按优先级）

| # | 元素 | 网金原貌 | 移植口径 | 优先级 |

| 1 | **绢帛卷轴面板**（主容器） | 米黄绢帛底 + 水墨山水淡纹 + 竖卷轴杆（左右各一）+ 浅浮雕雕花外框 | **弹窗/面板主容器**：绢帛质感底、两侧卷轴杆、外框用浅雕花非重木 | ⭐⭐⭐ |
| 2 | **竖排鎏金木牌按钮** | 右上"武功/系统/装扮"，一字一牌，鎏金木牌铜包角 | 主功能入口：武功/侠客/行囊/系统，右侧竖排 | ⭐⭐⭐ |

| 4 | **双条状态栏**（红/蓝） | 底部通栏，红血蓝内力 + 数字 | 战斗/主界状态槽（HP 红/MP 蓝→我们对应气血/内力） | ⭐⭐⭐ |

| 6 | **鎏金描边小元素** | 窗口 X、✓/✗ 鎏金按钮、买/卖木牌 tab | 关闭/确认/取消/页签 全部走鎏金描边语言 | ⭐⭐ |
| 7 | **中国结/挂饰** | 场景檐下中国结、灯笼绳结 | **场景层挂饰点缀**（屋檐/门框/摊位），UI 内少用 | ⭐⭐ |

### 1.2 🔴 比例铁律：绢帛为主，木为点缀（Leo 09-01 定）

> Leo 原话：「更多卷轴式 UI、木纹、中国结……**不用全部场景都那么多木元素**」

- **主容器（弹窗/面板）= 绢帛卷轴质感**（轻、米黄、水墨淡纹）——**木只出现在**：卷轴杆、木牌按钮、边框描线，占比 < 30%
- ❌ 反面教材：CodeBuddy 第一版合成样"通栏深红木纹状态栏"= 用力过猛，木头铺满 → **深色重木只用于底部状态栏底板与木牌按钮，其余面板一律绢帛**
- **中国结 = 场景层挂饰**（屋檐/门框/摊位），UI 内部克制使用（仅加载/节日弹窗可用）

### 1.3 配色基调

| 用途 | 色 |
|---|---|
| 面板底（绢帛） | 米黄 #E8DCC0 系 + 水墨淡纹 |
| 面板框/卷轴杆 | 中木褐 + 浅浮雕 |
| 状态栏底/木牌 | 深红木 #6B3A2A 系 |
| 描边/高亮 | 鎏金 #D4AF37 系 + 铜角 |

| 文字 | 浓墨 #2B2B2B（绢帛上）/ 鎏金（深底上） |
