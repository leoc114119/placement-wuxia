## 2. 沉浸感设计准绳（Leo 09-01 定）

> "暴走英雄坛让我有沉浸感，靠的是'我的小人真的站在那个世界里'。"

- **大地图 + 镜头跟随**：世界 > 一屏，角色移动镜头平滑跟随；**能自由走动的江湖 = "人在江湖"的物理载体**，服务支柱①（剧情故事/武侠人生）
- NPC 同世界驻留（非弹窗列表）：走近触发对话/交互，增强"活人感"
- 场景交互点可视（铁匠铺/药铺/告示牌等入口长在地图上，非纯菜单）

## 3. 技术规格（MVP 口径）

| 项 | 规格 |
|---|---|
| 地图构成 | **tileset 拼装**（地面/建筑/植被/道具各一套 tile 小块），禁整图铺贴 |
| 大地图生成 | **5×5 tile sheet 无缝拼接**（对应 PROJECT-MEMORY §6 地图编辑器需求：admin 上传 5×5 sheet、四方向无限无缝拼接、按名称命名） |
| 分层 | 保留 L0 地面 / L1 物件 / L2 顶层遮挡 三层（角色在 L1 走位，被 L2 遮挡形成纵深） |
| 行走帧 | 🔴 **八向行走循环（上下左右 + 四对角 × 3-4 帧 = 24-32 帧/角色）**——斜俯视 + 点击自由移动下对角移动是常态，四向帧会"面朝右斜着走"漂移穿帮；老网金/金庸群侠传即 8 向标准。**走模板换皮管线**：主角色做一套 8 向模板；**NPC 静态驻留（Leo 09-01 定）——站立待机 1-2 帧即可，不做八向**；移动矢量自由角度，动画帧取最近方向 |
| 战斗帧 | 🔴 **四向（上下左右）+ 攻击动作**——战斗是**上下对称镜像战棋**（96 号布局：玩家下两排/敌上两排），敌人可能出现在任何方向，单位需要朝上/下/左/右四向；左右翻转复用，**四向 = 实际 2 向绘制 × 翻转**（上/下各绘 1，左/右互翻）。攻击帧（预备/挥出/收招 3-4 帧）同四向。**08-23"侧视两向"旧口径作废**（那是旧战斗形态的遗留假设） |
| 移动实现 | 点击目标点 → tile 寻路（MVP 用贪心 + 障碍偏移即可）→ 播放对应方向行走帧 |
| 碰撞 | tile 级碰撞（不可行走 tile 标记），不做像素级 |
