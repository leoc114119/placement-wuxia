## 1. MVP 范围（Leo 08-31 晚重定义：三模块）

| 模块 | 内容 | 对应设计文档 |
|---|---|---|
| **① 基础界面设计与美术风格** | 主界面/城镇/战斗界面框架 + 水墨国风视觉基准（2.5D 像素 + UI 素材） | `01-基础功能/UI框架与导航`、美术资产索引 |
| **② 战斗手感打磨** | 六边形战棋（布局 v0.9）+ C 案规则（行动条/走位/轻功跳跃/集火/托管）+ 掉落流爽感 | `03-战斗系统/*`（规则 C 案 v0.5 已闭合） |
| **③ 放置无限流机制** | 剿匪体力驱动连刷 + Boss 换图 + 掉落一键变强 + 体力/年龄成本 + 托管离线收益 | `02-主线玩法/回合分配` §二/§三、`06-休闲与其他/小游戏骨架`（托管） |

**MVP 验收口径（随三模块更新）**：三个模块各自可玩、手感成立、循环闭合——砍得爽、掉得爽、变强看得见。
