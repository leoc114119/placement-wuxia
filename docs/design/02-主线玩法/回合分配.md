# 回合分配

> 分类：02-主线玩法 · 状态：🔶框架 v0.6（Leo 08-31 晚三改：**双层玩法结构**——无限流挂机+限量流每日玩法；**年龄=统一时间货币**；衰老递减+主动轮回+急流勇退） · 优先级：P0
> 来源：Leo 08-31 调研要求 + 多轮拍板；docs/86 §1.2；10-武学系统设计 / 03-战斗系统设计（学点机制）
> 原则：先框架后数值（数值以 🔧 占位）
> **总边界（v0.6）**：**回合/玩法=江湖（对外）；城镇=养成（对内，全程辅线）；年龄=一切玩法的时间成本**

## 一、竞品原型拆解（《武林群侠传》/《侠客风云传》养成模式）

### 1. 时间颗粒与总预算
- 1 个月 = 5 回合（初/上/中/下/底）；养成期 225 回合，出谷任务耗 21 → **自由分配 204 回合**
- **总回合硬上限 = "这辈子练不满"的结构性来源** → 本项目以"寿命/年龄"承接此结构（见 §二）

### 2. 每回合可选动作（七类）
打杂（谷内好感+少量经验）/ 基本功（六维式基础属性）/ 招式（战斗能力）/ 生产（材料、钱、小游戏本身）/ 忘忧谷学艺（艺能）/ 驿站（外部好感）/ 闲逛（**事件与剧情**）

### 3. 三条隐藏二级资源（关键）
| 资源 | 作用 | 本项目承接 |
|---|---|---|
| **体力** | 活动耗体力，耗尽只能休息结束回合 | **不再造体力条**——限量玩法次数=天然预算，年龄=时间成本 |
| **心情指数** | 练功经验 = 心情基数+随机+固定——状态影响效率 | 活人感状态轴承担（待决⑥） |
| **友好度** | 打杂/送礼累积 → 达标后传授武功与绝学 | 侠客缘分/师门好感 → 传授接口 |

### 4. 其他机制
技能满 100 → 领悟绝学（打铁=铜身铁臂等）；悟性决定成长速度且有剑宗/气宗路线取舍；功能逐月解锁；事件窗口期（错过不再）；时间不可逆（吃不了后悔药→多周目）→ 本项目"时间不可逆"由年龄只增不减承接；回合结束触发可选/强制事件

## 二、双层玩法结构（Leo 08-31 晚拍板，v0.6）

> 高频开箱爽感（寻道大千式）为主引擎，限量决策玩法做人生叙事——底层全都要，上层选重点

### 2.1 无限流（主引擎 · 高频爽感）

| 玩法 | 形态 | 产出 | 反馈节奏 |
|---|---|---|---|
| **江湖剿匪** | 自动连续挂机，随时开关；在场=高倍掉落流，离线=托管慢速 | 学点 / 实战 / 装备掉落 | 寻道大千式砍砍砍+装备飞出；掉落一键穿上战力即跳 |
| **剿匪地图进阶（Boss 门）**（Leo 提案） | 每张地图有 Boss 把关，**挑战 Boss 成功 → 换下一张地图**：怪物更强，收益更高、掉落更稀有（装备/材料） | 进阶地图：高额学点 / 稀有材料 / 高阶装备 | 推图目标感 + 掉落品质阶梯——"下一张图永远更好" |

- **在场反馈层（v0.6 补）**：玩家在场时掉落为可视流（数字+装备图标高频弹出），掉落率高于托管数倍（🔧）——奖励"看着挂"
- 掉落现场一键操作：对比→穿上（战力跳字）/分解/合成，"掉落→变强"回路秒级闭环
- 地图进阶 = 无限流的长线目标：单场反馈（掉落流）+ 阶段目标（换图）双节奏

### 2.2 限量流（决策层 · 人生叙事）

| 玩法 | 每日次数 🔧 | 产出 | 叙事定位 |
|---|---|---|---|
| **师门** | xN | 门派贡献 / 武学进度 | 修行正轨 |
| **游历** | xN | 际遇 / 善恶事件 / 侠客缘分 / 江湖武功 / 绝学线索 | **人生篇章**（机缘稀缺=限量合理） |
| **镖局** | xN | 钱 / 名声 | 营生险档 |
| **木人巷** | **每日 1 次**（Leo 08-31 晚定） | **高额学点** / 稀有材料 | 门派试炼——每日的"大招"位 |

- 木人巷从无限流移入限量流（Leo 08-31 晚修正）：**每日 1 次、高额学点**——限时高价值=天然的"上线必做"钩子，且避免学点通胀失控
- **自由动作 · 学武**：随时，消耗学点+银两（见 §三）
- 广告/IAP 挂点：限量次数 +1（游历多游一次/镖局多跑一趟），**只加次数不提掉落率**（合规护栏）

## 三、年龄 = 统一时间货币（Leo 08-31 晚拍板，v0.6 核心）

> **一切玩法的时间成本都换算成角色年龄**——时间不可逆，花时间=花寿命

### 3.1 计龄规则（Leo 08-31 定）

| 规则 | 内容 |
|---|---|
| **领取结算才计龄** ✅ | 离线收益**领取时**一次性计龄；**一直离线不领取=不收益、不加岁**（Leo 定）——睡觉不亏岁数 |
| **战斗年龄按体力消耗换算** ✅ | 剿匪在场：1 体力=1 场，`年龄增量 = f(消耗体力) 🔧`（Leo 08-31 晚定，替代"在场时长"口径）——刷多少场老多少 |
| 在线动作全额计龄 | 游历 1 次 ≈ 1 旬~1 月、师门/镖局 1 次 ≈ 数日、学武 1 次 ≈ 数日（全 🔧） |
| 年龄只增不减 | 承接原型"时间不可逆"——吃不了后悔药 |

### 3.2 衰老曲线（回合数/次数随年龄递减，Leo 提案）

| 年龄段 | 状态 | 玩法次数 |
|---|---|---|
| 16-45 | 巅峰期 | 全量 |
| 46-60 | 中年 | 限量次数 -1 档 🔧 |
| 61-75 | 暮年 | 再减档，产出衰减 |
| 75+ | 风烛 | 大部分玩法次数见底——边际收益塌陷 |

- **设计意图**：老年继续玩的边际收益递减 → **主动选择轮回变成理性选择**，而非等待强制Game Over

### 3.3 老玩家衰减与追赶（Leo 08-31 定）

- **老玩家收益随年龄缓慢减少**（产出系数 🔧）——自然形成天花板
- **新玩家慢慢追上**：同投入下新玩家成长更快 → 排行榜持续流动
- **老玩家持续成长的出口 = 轮回**：谢幕带遗泽进下代，冲击更高战力——"这辈子达不到，就下辈子再来"的机制化

### 3.4 主动轮回 + 急流勇退（Leo 提案）

- **主动轮回**：任意年龄可"闭关传功/坐化"，按当前成就结算遗泽 → 传承三选一 → 下代开局（不强制熬到寿终）
- **急流勇退奖励（提案 🔧）**：巅峰期（如 ≤50 岁）主动谢幕，遗泽结算加成（+20%？）——"见好就收"即武侠叙事（张无忌归隐）；硬撑到风烛反而无加成
- **何时传承 = 每代最重要的决策**

## 四、排行榜：武林碑（Leo 提案）

- 记录**战力-年龄关系**：如"21 岁破三阶 / 35 岁宗师"——成长曲线本身是故事与炫耀点
- 可开：少年英侠榜（≤25 岁战力榜）/ 效率榜（战力/年龄 🔧）/ 历代传奇榜（各代巅峰）
- 好友榜口径对齐 86 号"武林碑好友榜"

## 五、与城镇生活线的边界（v0.4 定，v0.5.1 纠偏）

- **回合/玩法 = 江湖（对外）**；**城镇 = 养成（对内，全程辅线）**——早期也是回合分配为主成长
- 城镇生活技能涨七维（**六维+福缘**），一一对应：打铁-臂力 / 打猎-胆识 / 钓鱼-定力 / 采药医术-根骨 / 琴棋书画-悟性 / 烹饪酒楼-机敏 / 庙祝香火-福缘
- **打工托管**：离线自动打工（低倍）+ 上线主动玩（高倍）——托管离线收益同样"领取才结算"（与 §3.1 一致）
- 钱归城镇三来源：打工差事 / 跑镖差事 / 家业产业（跨代被动）

## 六、学点（历史机制，已对齐）

- **学点 = 武学学习资源**：剿匪/木人巷（打点刷）获得，用于学武功
- 学习规则（老网金机制）：
  - 基础武学 / 门派武学：**学点速成**（消耗 = 学点 + 银两）
  - **特技、绝学：纯自修，不能靠学点速成**——只能苦练熟练度，稀缺性和仪式感
  - 自修 = 突破学点上限的手段
- 悟性影响学武速度；悟性经城镇琴棋书画增长；学点经济配比待 04-武学设定

## 七、善恶（正邪轴，Leo 定）

- **善恶值 = 独立维度**（不并入胆识）——江湖际遇中的行为（事件选择/任务手段）增减善恶值
- 善恶值决定际遇事件池分支：正/邪不同的事件任务、侠客缘分、江湖武功与绝内功、江湖地位通道（名门声望 vs 魔教座次）、神兵获取
- 待议（后置）：善恶增减规则、正邪互转门槛、中立区间

## 八、与战斗系统的接口

- **剿匪/木人巷 = 自动刷**（寻道大千式挂机动画），**不切入战棋**
- **战棋（C 案六边形） = 关键战**：Boss 战 / 主线节点 / 门派战，手动可托管
- 即：**日常高频砍 → 关键有仪式感**
- 实战值归属（六维外第七维？）待 04-武学/05-属性对齐
