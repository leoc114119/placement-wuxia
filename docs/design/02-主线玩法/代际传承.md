# 代际传承

> 分类：02-主线玩法 · 状态：🔶竞品调研完成，机制设计待写 · 优先级：P0
> 来源：docs/86 §1.1/1.4；竞品调研 2026-08-31
> ⚠️ 单点命门：MVP 验收门主体，情感体验与数值同优先级

## 已拍板约束（来自 86 号）

- 定位原话："这辈子达不到，就下辈子再来"
- 跨代只传：武学/记忆/名声；装备当代生效（代际隔离 = 开箱经济通胀控制阀）
- MVP 简化：传承三选一；一代压缩 3-7 天
- 情感引擎：损失厌恶转化——死亡不是惩罚是叙事高潮

## 竞品参考（2026-08-31 调研，详见当日会话）

### 范本一：太吾绘卷《传剑》（武侠同类，最贴近）
- 传承物"伏虞剑柄"承接毕生功力；世界（地图/建筑/好友）不重置
- 继承：资质、功法（**保留但层数重修**）、装备仓库直接继承、技艺书重读
- **遗惠点**：生前战斗/结义/建设积累，传剑时消费给下代买增益——"当世善终=下代资源"
- 祠堂灌顶：永久提后代资质
- ⚠️ 教训：主动传剑无门槛 → 被玩成"夺舍流"速刷

### 范本二：Rogue Legacy 血裔（三选一继承人鼻祖）
- 每死一次三选一继承人：职业+特质随机，**缺陷遗传是特色**（色盲=黑白画面、眩晕=世界翻转）——"不完美的传人"制造当世成长故事
- Manor 城堡：当世金币 → 家族建筑永久强化后代（跨代成长可视化）
- 防通胀：冥河船夫没收未花金币（当世钱当世花）+ 升级指数涨价
- 情感层：族谱叙事，"第 132 代后人走向城堡"

### 范本三：放置修仙转生类（《轮回修仙》《修仙录》《修不完的仙》）
- 转世继承：轮回点→永久天赋/灵根、已解锁功法；清零：境界/装备/临时资源
- 防通胀：转世加成递减、动态难度随轮回进化
- 《修不完的仙》"因果录"：百世轨迹记录，路线选择跨代沉淀（炼丹宗师→永久药草天赋）

### 范本四：王朝向（CK / Wildermyth，深度参考）
- CK：继承人教育规划、王朝声望树、传家宝
- Wildermyth：英雄衰老退休、后代继承特质与遗物、退休传记

### 共性规律（五维度）
| 维度 | 谱系 |
|---|---|
| 继承什么 | ①永久数值（轮回点/城堡）②能力资产（功法/图鉴）③关系与世界 ④记忆与名声 |
| 清零什么 | 当世战力、境界、装备（传家宝例外）、寿命 |
| 触发方式 | 死亡触发为主；主动传承需门槛/冷却 |
| 继承人选择 | 三选一随机+缺陷（RL）vs 血缘遗传+教育（太吾/CK） |
| 防通胀 | 当世资源当世花 + 跨代资产指数成本 + 动态难度 |

## 设计要点（初稿待议）

1. **三选一** → 学 RL：候选人各带随机天赋+缺陷，传人不完美才有当世成长故事
2. **武学继承** → 学太吾中间态：谱子/领悟保留，**层数重修**——传承感与当世成长兼得
3. **遗泽点** → 学太吾遗惠：谢幕按一生善行/成就结算"遗泽"，下代开局消费——"怎么活"决定"留什么"
4. **谢幕·江湖小记** → 对齐太吾遗志托付 + Wildermyth 传记；损失厌恶转化的落点就在这一屏
5. **传家宝** → 装备当代生效的 1-2 件例外（Wildermyth heirloom），跨代情感锚点
6. **防通胀** → 学 RL：当世银两不跨代；武林碑"家族底蕴"采用指数成本
7. **传承触发** → 必须有代价/冷却，防"夺舍流"

## 世代节奏与绝学结构（Leo 提案 2026-08-31 · 草案待议）

- **一代 = 60-80h 活跃时长 ≈ 月级一代**（口径 B 已确认 08-31：每天 2h × ~30 天）
- **一代只修 1 门江湖绝学**（按六维分系，系间差异大）→ 每代有流派身份，谢幕小记/武林碑碑文有素材
- **二代起可兼修 2-3 门** + 属性联动效果 → 联动是跨代养成的奖励；详细机制见 `04-武学设定/武学连锁与构筑.md`
- 兼修池 = 历代绝学谱并集；集齐更多系 = 后代 build 空间更大；武林碑"传世绝学数"= 集系进度

### 时间加速与商业化分层（Leo 提案 08-31 · 与 86 号 IAA 先行/IAP 版号后置双轨制兼容）

| 状态 | 时间流速 | 一代日历时长 | 层级 |
|---|---|---|---|
| 基线 | 1.0x | ~30 天 | 免费 |
| + 每日广告（看几个） | 1.2~1.6x | 19~25 天 | IAA 主力 |
| + 月卡（IAP，版号后） | 2.0x | ~15 天 | IAP 基础盘 |
| 月卡+广告叠满 | ~2.6x | ~12 天 | 上限，建议封顶不再高 |

- 加速作用于**全局时间流速**（修炼/行动点恢复/游戏内年月），不买行动点——"一生"叙事长度不变，只是过得快慢不同
- ⚠️ **与 86 号验收门冲突**：原"一代 3-7 天"被月级一代取代 4-10 倍；7 日留存时玩家未到首次传承，"传承时刻"指标首月测不到
- ✅ **验收门口径已拍板（08-31，Leo）：方案 B**——"一代 3-7 天"仅作为**调试倍率下的内部验证口径**（内部 time_scale 拉快验证代际闭环）；上线真实节奏 = 月级一代，留存指标改为 **14 日/30 日留存**，"传承时刻"反馈指标相应后移
- 📌 内容量预警：60-80h 活跃/代 → 事件池与回合分配抉择产量需求大增，"活人感与事件池"或需 P2→P1
