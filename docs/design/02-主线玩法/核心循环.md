# 核心循环

> 分类：02-主线玩法 · 状态：🔶框架 v0.3（2026-08-31 晚：双层玩法结构（无限流+限量流）；年龄=统一时间货币；衰老递减+主动轮回） · 优先级：P0
> 来源：docs/86 §1.2/1.3；Leo 08-31 口述（放置挂机+回合选择开箱 / 离线挂机武学修炼 / 活人感 / 代际循环 四系统咬合）
> 原则：**先框架后数值**——本章只立结构与接口，数值以 F-xx/R-xx 占位标 🔧
> **总边界（v0.3）**：**玩法=江湖（对外，高频开箱爽感+限量决策）；城镇=养成（对内，全程辅线）；年龄=一切玩法的时间货币**

## 1. 系统分层（不是并列模块）

| 系统 | 时间尺度 | 层级角色 | 玩家动作 | 产出 |
|---|---|---|---|---|
| **回合分配（含开箱获取层）** | 玩法次数 / 年龄 | **主引擎（决策+爽感）** | 无限流：江湖剿匪（自动连续+Boss 换图进阶，高频掉落流）+ 限量流：师门/游历/镖局/木人巷（每日次数，木人巷=每日 1 次高额学点）+ 学武（自由动作）；**一切时间成本=角色年龄** | 掉落流 + 学点/武学/机缘——全程成长主力 |
| **城镇生活线（并行）** | 小时~天（异步） | **辅助线（养成层）** | 生活技能小游戏：打铁/打猎/钓鱼/采药医术/琴棋书画/烹饪酒楼/庙祝香火 | 七维属性（唯一入口）+ 钱/材料/人脉——慢但省心，全程辅线 |
| **离线挂机（武学修炼+托管）** | 小时~天 | **供给层** | 无需操作；**领取结算才计龄，一直离线不领=不收益不加岁**（Leo 定） | 修为 / 武学进度 / 打工产出 |
| **活人感** | 贯穿 | **表现层（语法）** | 无独立入口，覆盖前两层 | 年龄痕迹 / NPC 记忆 / 挫折故事化 |
| **代际循环** | 月级（一代 ≈ 角色数十岁寿命） | **意义层** | 边际收益衰减 → **主动轮回**（急流勇退加成 🔧）→ 遗泽结算 → 传承三选一 → 下代 | 遗泽点 / 绝学谱 / 名声 → 下代初始条件；**老玩家靠轮回冲击更高战力** |

## 2. 主循环咬合结构

```
   ┌──────────── 活人感（表现层：覆盖全链路，把数值事件叙事化）────────────┐
   │                                                                      │
【爽感】无限流·江湖剿匪 ── 自动连续砍砍砍，掉落流飞出，一键穿装战力跳 ───┐  │
   │        Boss 换图进阶：更强怪→更高收益→更稀有掉落（长线目标）          ▼  │
【决策】限量流·师门/游历/镖局/木人巷 ── 每日次数预算（木人巷 1 次=高额学点）┤  │
   │        游历走正/邪事件池 → 善恶、缘分、绝学线索                        │  │
【养成】城镇生活线（辅线·异步）── 七维唯一入口 + 钱/材料/人脉 ────────────┤  │
   │        托管慢涨，主动玩加速；不抢主线资源                              ▼  │
【供给】离线挂机·武学修炼+托管 ◀── 领取结算才计龄 ◀── 七维/装备             │
   │                                                                       │
【获取】开箱层：无限流小箱（在线小时级）+ 限量流大箱（离线日级结算）          │
   │                                                                       │
【验证】战斗试金石 ◀── 修为/武学/装备/七维 ◀── 成长                          │
   │                                                                       │
【意义】代际：收益衰减 → 主动轮回（急流勇退+） → 遗泽结算 → 传承三选一       │
   └────────── 回到【爽感】，下代起点抬高（绝学谱/兼修资格/名声）────────────┘
```

## 3. 系统接口（契约）

1. **玩法 → 离线挂机**：无限流决定掉落流效率；限量流决定武学/机缘产出；**离线收益领取时一次性计龄**（不领不加岁）
2. **城镇生活线 → 七维/经济**：基础属性**只能**从生活技能来（唯一入口）；城镇全程辅线；**打工托管**=离线低倍+在场高倍（领取才结算）；钱三来源（打工差事/跑镖差事/家业产业）均归城镇
3. **离线挂机 → 战斗**：修为/武学进度 = 战力输入（战斗 GDD 唯一接口）
4. **战斗 / 事件 → 开箱获取层**：掉落经包装层呈现，三边界约束；**小箱粒度**（在线每 X 分钟 🔧）+ **大箱粒度**（离线日结算）
5. **年龄 → 全系统**：一切玩法时间成本=年龄增长；衰老档位（46-60 减次/61-75 再减/75+ 见底）压回玩法收益；老玩家收益缓降→新玩家追赶
6. **全链路 → 代际**：谢幕结算遗泽 → 下代初始条件（兼修资格、绝学谱、名声、家业？）；**急流勇退（巅峰期主动谢幕）有结算加成 🔧**

## 4. 四条红线（防互相稀释）

1. **决策必须有代价**：限量次数与年龄成本是真代价，离线产出不得淹没选择的影响
2. **七维只从城镇出，但城镇永远是辅线**：玩法不产基础属性；**回合分配从第 1 天起就是成长主引擎**；不存在"城镇打底"阶段
3. **活人感不是独立系统**：覆盖层的"叙事语法"，不做独立玩法入口
4. **开箱不喧宾夺主**：概率透明+保底；广告只加次数/时长、不提稀有度；代际隔离（开箱物当代生效）
5. **寿数不被货币污染**：IAP/广告买的是次数与加速，**买不到年龄回退**——衰老与轮回永远是玩家的时间账

## 6. 回合分配 × 放置开箱 合并模型（v0.2 · 双粒度）

> 开箱 = 结算与叙事包装层。v0.2 修正：配合双层玩法结构，开箱分两个粒度补齐爽感频率。

### 双粒度结算

| 粒度 | 触发 | 内容 | 对应玩法 |
|---|---|---|---|
| **小箱** | **每击杀一个敌人产出**（09-02 Leo：按击杀掉落，非计时） | 数秒演出+一波掉落（装备/材料/学点） | 无限流（剿匪/木人巷） |
| **大箱** | 离线结算/限量玩法单次结算 | 主题箱+叙事钩子（秘境/遗物/残卷/悟道石刻） | 离线挂机/师门/游历/镖局 |

- 在场反馈层：无限流掉落为可视流（数字+装备图标高频弹出，寻道大千式），掉落率高于托管数倍 🔧——**奖励"看着挂"**
- 掉落现场一键变强：对比→穿上（战力跳字）/分解/合成，秒级闭环

### 三条护栏（不变）

1. **决定性强于随机**：选择定类型与保底，箱内随机只影响浮动量
2. **广告只加速/加次数，不提稀有度**：广告可用点=buff 时长加倍、限量次数 +1、攒箱加速
3. **红线不破**：生活材料只走小游戏；开箱物当代生效
