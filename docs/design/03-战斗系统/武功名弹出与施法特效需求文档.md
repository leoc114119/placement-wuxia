## 一、功能总述

施放武功技能（特/绝）时，角色身上同步呈现两层演出：**武功名条**（招式名文字从头顶浮起淡出）+ **施法特效**（代码画的聚气光效，伴随整个出招时长）。目的=招式辨识度（玩家/AI 出的什么招一眼可读）+ 出招仪式感。纯表现层需求，零数值语义变更、零事件契约新增、零新素材（C 案代码画）。

## 二、行为规格（草案条目，编号暂 WF-1 起）

| 编号 | 规格 |
|---|---|
| WF-1 | **触发时机**：武功名条与特效随**施放提交（t0）**触发，与命中帧/第一段伤害同刻（演出链=t0 名条浮起+光圈亮起→命中→循环伴随→t1 第二跳）。**v1.0 Leo 裁：提交（t0）触发**（与伤害演出一体化） |
| WF-2 | **武功名条**：文字=SkillDef.name（经既有事件/快照通道传递，render 禁自查配置）；从角色头顶浮起、约 1 秒淡出；字号≈伤害数字 1.5 倍、书法感排版（复用 FONT_STACK 宋体族加粗），描边/阴影保证棋盘背景可读；位置在头顶更高一行，与 T21 伤害数字错位防重叠（沿既有错位机制） |
| WF-3 | **品阶色差**：特技=金色名条；绝学=金红名条（更华丽）；光圈同阶差（绝学更亮更大）——色值具体值 FE 自决，Leo 目验定稿 |
| WF-4 | **施法特效（C 案代码画）**：角色脚下/身上聚气光圈（脉冲光环），**持续整个出招时长**（t0 亮起→t1 熄灭，与两段时序绑定）；t1 命中帧的既有斩击弧（FX.slashSec）**保持不动**。**v1.0 Leo 裁：不加**（占位观感后再议升级） |
| WF-5 | **适用范围**：仅特/绝施放弹名条+特效；**普攻不弹**；**v1.0 Leo 裁：不弹** |
| WF-6 | **敌方同规则**：AI 施放特/绝同样弹名条+特效（玩家可读敌方招式=信息价值）；敌我名条颜色同制式 |
| WF-7 | **特效实现来源（09-07 Leo 定=老网金基础光影组合）**：Leo 提供老网金基础光影素材文件 → 素材入库门检 → 建立**基础光影件库**（元素/混合模式/时序编排可配置）→ 各武功特效=基础件的组合配方（组合结果不与原版完全一致）。触发时刻/持续时长/锚点偏移/组合配方全部常量化或配置化；代码画保留为组合件就绪前的占位与兜底。文件落位/格式/门检口径待素材文件到位后补 |
| WF-8 | **特效锚点规则（09-07 Leo 补裁）**：以**施法者为中心**的范围武功 → 特效以**施法者为中心**播放；**可移动的范围攻击**（可移动十字/六边形等，玩家选 AOE 中心格的技能类型——未来品类） → 特效以**选中的格子为中心**播放。锚点随技能施放类型分支，实现留分支点（当前全部技能=施法者锚） |
| WF-9 | **特效速度同步（09-07 Leo 补裁）**：特效播放时长与速度**完全跟随出招时长**——出招 3s=特效循环播放 3s；出招 0.5s=特效压缩加速播完（一拍不落）。特效基础时间线自定，长招循环/短招压缩 |
| WF-10 | **名条时长独立（09-07 PM 默认案）**：武功名条保持固定 ~1s 浮起淡出，**不随出招速度加速/压缩**（0.5s 快招下名条照常 1s——文字可读性与出招节奏解耦） |

## 三、影响面

- **FE（主体）**：`ui/battle-hex-render.ts`（名条绘制+光圈绘制+浮起/淡出动画）+ `config/battle-hex.ts`（WF 常量组：字号/色/周期/偏移）
- **数据通道**：名条文字来源=施放事件或快照携带 skillName（方案定，禁 render 自查）
- **BE**：预计零改动或极小（skill 事件已存在；若需携带 name 字段=事件 payload 加字段属**契约变更**，须方案确认通道）
- **素材**：零新增（C 案）
