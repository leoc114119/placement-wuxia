# 受击反馈（掉血数字 + 受击震动）

> 分类：03-战斗系统 · 状态：🟢 v1.0（2026-09-03 · Leo 三开放点按默认圈定，定稿发卡依据）· 优先级：P1（MVP 模块②战斗手感）
> 定位：敌我受击的**表现反馈层**——「受击不做受击帧，以代码震动+掉血数字替代」（Leo 拍板口径）的配套实现
> 缘起：T20 L 环 Leo 反馈「特/绝看不出对敌伤害」——伤害有配（特技 e2e 实证 11 伤/击），但 demo 敌 100 血掉 11 血条不可辨，且**受击反馈件从未实现**
> 约束：数值真值不动（数字内容=core 结算事件字段）；渲染层禁 import battle-core；契约字段零新增（damage/miss 已在事件流）；数值零改动
> 现状声明（待主架构实证复核）：战斗 demo 无掉血数字、无受击震动；「rejected 冒字」为唯一既有冒字体，可作实现参照

## 一、需求表

| # | 需求 | 口径 |
|---|---|---|
| 1 | **伤害冒字**：任一单位受击（hp 减少）→ 受击者头顶冒伤害数字，向上漂移 ~24px、~600ms 渐隐；同帧多目标受击各自冒字不合并 | 内容=事件 damage 字段直读（client 只展示） |
| 2 | **数字样式（MVP 默认）**：白字深描边、粗体、屏高比例定尺（渲染定尺铁律）；不做暴击变色/跳字（数值阶段后置） | 开放点① |
| 3 | **miss/闪避**：miss 事件 → 同位置冒「闪避」二字（同动效），无数字 | 开放点③ |
| 4 | **受击震动**：受击者水平 ±3px 衰减震动 ~200ms；死亡者不震动（死亡演出另行） | 只震受击者，不震攻击者 |
| 5 | **通用对称**：我方/敌方受击同规则（我打敌、敌打我都冒字+震动） | 开放点② |
| 6 | **触发路径全覆盖**：普攻 / 特/绝 cast 对敌 / ATK-3 移动附带普攻——凡 damage 事件必冒字；**空放无数字**（charge 演出即反馈） | 语义由事件形状自然分流 |
