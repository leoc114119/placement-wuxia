## 0. 落地定义与纪律（09-07 Leo 批，全量执行）

1. **交付方 delivery 必须显式声明 runtime 落库状态**（路径+SHA 清单），纯候选交付标注 `candidate-only`；
2. **PM 门检第一动作** = `ls` runtime 路径对照交付清单，再跑独立精扫；
3. **候选悬挂 ≤24h**：过门 24h 内必须集成进 runtime，或显式登记挂起原因——禁止隔夜悬挂；
4. **状态表述铁律**：凡书面"已入库/已交付/已过门"必须携带 commit 号+路径实测（ls/sha）证据，交接文档/快照/LOG 同样执行；
5. PM2 **每日 LOG 一条落地日结**（runtime 增量/候选存量/缺口）。

**术语**：`runtime`=正式路径 `assets/**/battle45/`（接线消费面）；`候选`=`assets/_trial_*/` 产物（过门未集成）；`缺口`=账面应有但两态皆无。
