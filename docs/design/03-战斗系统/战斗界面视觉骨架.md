## 1. 分区规格

| 区 | 定稿形态 | 实现方式 |
|---|---|---|
| ① 顶栏 | 头像+名字+气血红条(上)/内力蓝条(下)+**状态图标槽×4**（中毒骷髅/流血水滴/内伤裂纹/空）+微信胶囊；底色=暖棕木色（与木牌同色调） | 定稿组件 `components/topbar.png`；接入时叠加代码压暗层（Leo：原稿过亮，代码调不抽卡） |
| ② 棋盘 | **平顶六边形立体瓦片**：顶面草地绿/土黄交替高光、侧面深色土层、边缘高光描边；**每行 6-7 格**（代码参数）；16×16 地图、可移动区固定 8×8 | **六边形网格代码绘制**（格子/高亮全程序化）；环境底图=`battle_board_base.png`（无角色无HUD 版） |
| 棋子头顶 | 三件套从上到下：名字牌（**我方淡绿字/敌方淡红字**）→绿色行动条→红色气血条（敌我同构） | 代码绘制（billboard） |
| 特绝轻毒 | **主角色行动条满后，主角色头顶弧形弹出四个圆形武功按钮**（深色底鎏金描边金字、直径≈头部宽1.8倍）；**不是 buff 槽** | 代码绘制（交互组件） |
| 左侧按钮 | 「装备」「武功」——家场景同款木牌挂串（中国结+红绳+深木浅金包角+红穗） | 定稿组件 `components/plaque_l.png`（接入可复用家场景木牌素材配方） |
| 右下按钮 | 「托管」「加速」「逃跑」横排钮（图标+金字），暖棕木底 | 定稿组件 `components/ctrl_r.png` |
