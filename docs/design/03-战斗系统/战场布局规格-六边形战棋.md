# 战场布局规格-六边形战棋

> 分类：03-战斗系统 · 状态：🔶v0.9 草案（Leo 逐项确认） · 优先级：P0
> 来源：原 docs/96 号（2026-08-31），管线重构后归位本分类
> 配图：同目录 `战场布局-assets/`（7 张 SVG/PNG + 6 个 gen_mockup*.py 可复现脚本）

## 1. 定位

- 六边形战棋布局层 = **C 案战斗玩法的空间规则基础**（C/D 通用，C 已拍板）
- 约束：竖屏单手；棋盘区 427pt（屏 667pt 中段）；基准设备 375×667

## 2. 已确认规格（Leo 逐项确认，2026-08-31）

| 项 | 规格 |
|---|---|
| 网格 | **平顶六边形（flat-top）**，s=31 → 格 62×54pt；坐标 cube 系 |
| 竖屏分区 | HUD 110 / 棋盘 427 / 操作栏 130（375×667 基准） |
| 人偶渲染 | 溢出式 ~70pt 高（≈4 格），y 排序遮挡 |
| 地图尺寸 | 可变：**8×8 / 12×12 / 16×16**（MVP 5v5 起步） |
| 相机 | 7×7 视口 + 三档缩放（s=31/24/16）+ 包围盒自动取景（战斗双方+主角色保证在屏） |
| 部署 | 5v5：玩家下两排纵深 + 敌上两排 + 中央争夺点；部署阶段可拖拽换位 |
| 镜头主权 | 关键战手动拖动/点选；自动模式镜头跟随行动者 |
| 射程 | 沿用 battle-core **R-05**（剑/拳 1/2/3、棍棒 1/2/3 直线、鞭/刀 3/4/5 锥形、暗器 4/6/9），曼哈顿→**cube 距离**换轨（同半径面积 +~50%，MVP 沿用原值 Playtest 校准） |
