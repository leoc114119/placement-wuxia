## §二 设计

### 2.1 env 入世界系（治本，需求①）

- **env 世界锚定矩形**：`envRect = movableBounds 外扩 (width/2 + M, height/2 + M)`，M=80 余量；width/height 用**当帧实际屏尺寸**——镜头已被钳制在 movableBounds 内，屏面在 world 系的投影必然 ⊆ envRect，任意拖动位置不露边。
- **绘制**：`sx = envRect.x − cam.x + width/2`、`sy` 同构（与格子同一变换式，**复用同一 cam，禁第三套换算**）；`w = envRect.w`（cover 式铺满，允许超出屏）。层级保持在最底（cells/pieces/UI 之前），且在战区 clip 之前——env 不受 clip 影响。
- **交互零变化**：拖动钳制（clampAxis）、dragThreshold、平滑回拉全部不动——变的只是 env 跟着 cam 走。
- **缩放质量**：envRect 约 2200×1700（按 900×700 预览屏），env 1088×1920 cover 需 ~2.0× 放大 → 横向虚化可接受（软面绘制风，非硬像素格）；**美术窗口后续出横幅大图（约 2400×1600）直接换 config 路径，代码零改动**（开放点②）。

### 2.2 台面落地（融合，需求②）

**边缘形状（Leo 09-04 拍板：v8 有机缺角，翻案旧「整齐长方形」裁决）**：

- `isBoardCell(q, r)` 形状判定：棋盘矩形**最外两圈**的非可动 dirt 格按坐标哈希剔除（哈希=格坐标确定性函数，逐帧稳定不闪动）；剔除密度约 20%，只作用于 FIELD 外围 dirt——**FIELD 内格、出生锚区格一律不剔除，isMovableCell 与输入命中零改动**（纯渲染形状）。
- 撤战区矩形 clip（原「裁半格保整齐」逻辑）：改为按 isBoardCell 逐格绘制，画布自然出屏即裁——旧 clip 注释同步改写并标注「Leo 09-04 翻案 v8 缺角」。
- 被剔除格直接露出 env：棋盘边缘=不规则六边形齿边咬进地形（v8 观感）。

三层融合处理（缺角之上叠加）：

| 层 | 处理 | 实现 |
|---|---|---|
| 落地阴影 | 台面格向 env 投软阴影：边缘格逐格画下偏阴影六边形（offset ≈ 6px、alpha 0.22，底侧重），整板浮起「实体瓦片」感 | cells 之前画阴影层；参数进 config（SHADOW 组） |
| 边缘过渡 | dirt 格顶面色值**从 env 采样对齐**（一次性离线取色落 config 常量，注释标定出处），由内向外两档渐暗 | TILE.topDirt 拆 topDirtInner/topDirtOuter 两档 |
| 顶面质感 | 平色格加程序化轻噪点（同色系 ±3% 明度伪随机点阵，seed=格坐标哈希，静止不闪） | drawTile 顶面填充后叠加；纯代码零素材 |

- 格贴图槽（取证 4）**保持原样**：tileset 贴图到位后自动替换噪点回退层，本卡不做贴图。

## §四 易错点

1. **envRect 必须用当帧 width/height**：预览窗可拉伸，写死基准屏尺寸会在大窗露边。
2. **绘制顺序**：env 必须在战区 clip beginPath 之前——放进去会被矩形裁掉外圈。
3. **禁第三套坐标换算**：env 与格子共用 cam 与同一变换式；任何独立换算都会重蹈两张皮。
4. **取整抖动**：drawImg 内 Math.round 对大图 1px 抖动可接受；禁止半像素定位（性能+糊）。
5. **噪点必须静态**：seed=格坐标哈希，禁止逐帧随机（会闪成雪花屏）。
6. **dirt 取色落 config 不落运行时采样**：运行时读 env 像素=每帧 getImageData，性能不可接受；一次性离线取色。
7. **e2e 零新增**：本卡观测面走单测 probe（render 层既有模式），`__demo` 观测面不扩——拖动观感由 shot 拖动位留档 + Leo L 环目验收口。
8. **镜头逻辑零 diff 是硬门**：computeCamera/updateCamera/clampAxis 一个字不动，防「顺手优化」破坏已验收手感。
