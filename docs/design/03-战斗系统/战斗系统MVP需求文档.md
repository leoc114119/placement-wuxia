> 本文档 = T15/T16/T17 研发任务的**任务标准、交付与验收依据**（需求文档铁律 09-02）
> 追踪来源：战斗规则C案 v0.6 · 战场布局规格 v1.0 · 战斗界面视觉骨架 v8 · 角色帧规范 v5 · 场景状态与战斗入口数据流 v0.1 · NPC配置系统 v1.0 · 接入技术方案 v0.1（O1-O3 裁决）· 09-02 四项新拍板（入口/加速/奖励/托管）

## 1. 范围与入口

| 项 | 口径 |
|---|---|
| 战斗入口 | **仅一个**：家场景点击敌对 NPC「山贼细作」（bandit_home_test） |
| 触发方式 | `click`（NPC配置系统 battle.trigger） |
| 规模 | 1v 多：主角 1 人 + 敌方按 R-07 档位（MVP 示例=1 敌，可配置 1-3） |
| 明确不含 | 剿匪自动挂机动画流、木人巷、江湖历练入口、部署 UI、多地图、追击 AI（§9） |

## 2. 战斗规则（全部已拍板，实现须逐条对表）

| 规则 | 口径 | 来源 |
|---|---|---|
| 回合驱动 | 行动条轮转：满值 100，fillRate=（速度+随机）填充，离散 dt=0.05s | C 案 A1/F-05 |
| 行动预算 | **移动 / 出招二选一**（单选定版，O1）；移动到位与敌相邻=自动普攻特例保留 | O1/C 案 v0.6-A2 |
| 移动力 | 基础 2 + 轻功装配加成（一阶+1/二阶+2）+ ⌊轻功等级/5⌋（F-06）；普通移动不可穿任何单位；二阶轻功跳跃=范围/2 可穿越 | A3 |
| 集火 | 手动=点谁打谁；AI=最近敌人，同距选血少 | A4 |
| 命中/暴击/闪避 | 0.85 / 1.5x / 上限 0.25（F-04） | core 既有 |
| 伤害 | F-01（攻防+品阶系数+技能倍率） | core 既有 |
| 内力/冷却 | R-09（一阶 20/…）/ R-08（2 回合档） | core 既有 |
| 超时 | 手动 90s 无操作→托管；再 90s→自动；总时长 90s 防死循环 | core stepManualTimeout |
| 结算 | 胜=保留战损；败=hp 保底 30%+「失血过多」禁战斗 60s；逃=无损失（R-10） | core 既有 |

## 3. 棋盘与出生布点

| 项 | 口径 |
|---|---|
| 网格 | 平顶六边形 s=31（MVP 单档；s=24/16 留常量），axial 坐标 |
| 地图 | 16×16，**可移动区固定 8×8（居中）** |
| 视口 | 7×7，镜头拖动（>8px 判定）+ clamp；自动模式跟随行动者 |
| 主角出生 | 可移动区左下 3×3 随机选格；**MVP 测试件固定 seed**（可复现） |
| 敌人出生 | 右上 3×3 随机；与主角曼哈顿距离 ≥4；敌间不重叠；同 seed 派生 |
| 底图 | battle_env（纯场景）L0 静态层；格子全代码绘制 L1（立体瓦片） |

## 4. 界面需求（v8 视觉骨架七层）

| 层 | 需求 |
|---|---|
| L0 环境底图 | battle_env（纯场景版），屏幕空间静态（只拖棋盘不动景） |
| L1 格子 | 平顶六边形立体瓦片（顶面草绿/土黄高光+侧面深土层+描边），仅绘视口内 |
| L2 高亮 | 可移动=绿 / 攻击范围=红 / 选中=金 / 技能激活待施放态 |
| L3 棋子 | billboard、y 排序遮挡、朝向翻转、移动 lerp 0.3s、轻功抛物线、阵亡变灰 |
| L4 棋子 HUD | 三件套：名字牌（我方淡绿字/敌方淡红字）→ 绿行动条 → 红血条（敌我同构）；主角行动条满→头顶弧形弹出特/绝/轻/毒四钮（未学/冷却/内力不足置灰） |
| L5 定稿组件 | topbar（+代码压暗层）/plaque_l/ctrl_r（路径走资源管理器，禁硬编码） |
| L6 特效 | 代码 fx（四段时序模板沿用旧 T06 已验体系） |

**工程红线**：渲染层禁止 import battle-core（自动化检查）；帧预解码/整数定位/height 定尺/版本号防缓存（home_demo 四件套）。

## 5. 控件行为表（右下操作钮 + 顶栏交互）

| 控件 | 点击行为 | 状态显示 |
|---|---|---|
| **托管** | 手动 ↔ AI 托管 **可切**（切回保留局面）；AI=B2 五级优先表 | 托管中钮高亮 |
| **加速** | 两档 **x1/x2 切换**（作用=会话 tick 倍率，含行动条填充与动画速度） | 钮显示当前档位 |
| **逃跑** | 立即结算 fled：无损失无扣体力（R-10/C2），返回家场景战前位置 | 点击即逃（MVP 无确认框） |
| 特/绝/轻/毒四钮 | 点击=激活对应技能（进入攻击范围显示态）→ 点敌人施放；再点同钮=取消；内力不足/冷却中置灰 | 激活态高亮 |
| 装备/武功木牌 | 打开对应面板（MVP：只读查看装备与已学武功；穿戴/学武操作不在战斗内） | 面板浮层 |

## 6. 输入映射（点选流）

| 操作 | 结果 |
|---|---|
| 点可移动高亮格 | 移动（消耗本回合移动预算） |
| 点敌人（未激活技能） | 普攻（射程内）|
| 激活技能后点敌人 | 施放该技能（hex 预筛射程，不足则提示） |
| 点空白/非法目标 | 取消当前选择 |

## 7. 状态与数据流

| 项 | 来源 → 去向 |
|---|---|
| 主角战斗单位 | battle_session 读 **PlayerState**（vitals/attributes/skills/equipment）构造 |
| 敌方战斗单位 | NPC 配置 `battle.unit`（NPC配置系统 §4 示例） |
| 结算回写 | R-10 → **PlayerState.vitals**（胜=保留战损；败=hp 保底 30%） |
| 掉落 | victory 按 NPC `drops.table` 概率出 → PlayerState.inventory；MVP 掉落=纯占位 TBD（09-02 拍板：不显示具体奖励数字） |
| 返回 | 战斗结束（胜/败/逃）→ 返回家场景，主角恢复战前位置快照 |

## 8. 验收标准（逐条可测）

| # | 验收项 | 标准 |
|---|---|---|
| V1 | 入口链路 | 家场景点击山贼→走向→喊话 0.8s→黑幕过渡→战斗开场，全程无手动刷新 |
| V2 | 行动条 | 行动条满者获行动权；主角回合 pendingInput=true 等输入 |
| V3 | 二选一 | 移动后本回合不可再出招（反之亦然）；相邻敌人自动普攻特例生效 |
| V4 | 走位与轻功 | 移动范围按 F-06 高亮；不可穿单位；跳跃（若装配二阶轻功）可穿越 |
| V5 | 集火 | 点谁打谁；AI 按五级优先表行动（脚本可复现） |
| V6 | 托管/加速/逃跑 | 托管可切且 AI 接管正确；x1/x2 生效；逃跑无损失返回 |
| V7 | 特绝轻毒 | 行动条满弹出四钮；未学/冷却/内力不足置灰；施放走 hex 预筛 |
| V8 | HUD 与组件 | 头顶三件套敌我同构、名字色区分；三组件按 v8 接入 |
| V9 | 结算 | 胜/败/逃三态结算正确；R-10 回写 PlayerState；返回家场景位置正确 |
| V10 | 确定性 | 同 seed+同操作序列 → 事件流全等（node 断言） |
| V11 | 架构红线 | 渲染层零 import battle-core（自动化检查）；既有 14 用例全绿；全量用例不回归 |
| V12 | 零硬编码 | 修改 npc.json（名字/坐标/掉落）重载即生效 |
| V13 | 包体 | 素材体积符合素材需求清单 §3 预算 |
