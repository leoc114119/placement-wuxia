## 1. PlayerState · 全局主角状态（新增，全游戏唯一实例）

> 现状缺口：主角无状态对象——家场景顶栏为 CSS 假数据；battle-core `makeInitialPlayer()` 仅存在于测试。
> 本定义 = R-11 初始值**提升为全局容器**（数值口径不变），家场景 UI / 战斗 / 存档三处读写同一份。

### 1.1 字段定义

| 字段组 | 字段 | 类型/初始值 | 说明 |
|---|---|---|---|
| identity | `name` | string / "小虾米" | 显示名 |
| identity | `age` | { years: 8, months: 1 } | 年纪（出生默认 8 岁 1 月，Leo 定）；一切玩法时间成本累加于此 |
| vitals | `hp / maxHp` | 100 / 100 | 气血（R-11）——顶栏/战斗共享，战斗按 R-10 回写 |
| vitals | `neili / maxNeili` | 0 / 100 | 内力（R-11：内力上限由内功决定，F-07） |
| attributes | 六维（臂力/根骨/机敏/定力/悟性/胆识） | 模板 B（R-11） | 战斗数值直通（09-02 拍板 P1-2 口径） |
| attributes | `fortune` 福缘 | 0 | 非战斗：只影响开箱掉落与绝学条件（09-02 收窄口径） |
| skills | `skills[]` | [{ id: 'yemao-jianfa', level: 10 }] | 已学武功（引用武功 schema；特绝轻毒四钮=对应 tier 已学者） |
| equipment | `equipment` | { weapon: 'wood_sword', armor: 'cloth' } | 已穿装备（初始 R-11：木剑+布衣；决定 weapon 匹配与射程） |
| inventory | `inventory[]` | [] | 背包（掉落/材料进） |
| position | `pos` | { scene: 'home', x: 0.35, y: 0.72, facing: 'up' } | 场景位置（§2） |
| counters | `stamina` | 数值 🔧 | 剿匪体力（1 体力=1 场，C1）；年龄增量=f(消耗体力) |

### 1.2 所有权与数据流

```
PlayerState（全局单例，backend 定义 types + 初始化/读写 API）
   ├─ 家场景 UI：只读渲染（顶栏双条/年纪/货币）
   ├─ 战斗入口：battle-session 读 PlayerState + NPC.battle.unit → 构造战斗单位
   ├─ 战斗结算：R-10 回写（胜=保留战损；败=hp 保底 30%+禁战斗 60s）
   ├─ 存档：PlayerState 全量序列化 = 存档主体（P1-6 薄设计）
   └─ 修改入口白名单：战斗回写 / 离线领取结算 / 学武消耗 / 掉落入包 / 计龄——其余禁写
```

## 2. 家场景位置状态（§入口数据流 1/2）

| 场景 | 口径 |
|---|---|
| 首次进入 | 固定出生点 `x=0.35, y=0.72, facing='up'`（PlayerState.pos 初始值） |
| 会话内切战斗返回 | 内存保留——回到战前位置（pos 在进战斗前快照，战斗结束恢复） |
| 跨会话 | 存档记录 PlayerState.pos，读档恢复 |

## 3. 战斗入口链路（§入口数据流 2/2 · 点击敌对 NPC）

```
点击命中 NPC 判定盒
→ 主角自动走向 NPC 至相邻格（≤1.2 格停）
→ NPC 喊话气泡 0.8s（dialogue.greeting）
→ 黑幕淡入 0.3s
→ 加载战斗场景（env 底图+三组件+棋盘代码层）
→ battle_session 初始化：
     主角单位 ← PlayerState（vitals/attributes/skills/equipment）
     敌方单位 ← npc.battle.unit（NPC 配置）
     seed ← MVP 固定 seed（可复现调手感；正式版=时间戳）
→ 黑幕淡出 + 0.5s 遭遇提示
→ 战斗（R-10 结算回写 PlayerState.vitals）
→ 结算浮层（掉落逐条弹出 → inventory）
→ 返回家场景：主角=战前位置快照恢复
```

## 4. 出生布点规则（O3 细化）

| 项 | 规则 |
|---|---|
| 主角 | 可移动区 8×8 的**左下 3×3 区随机选格**（MVP 测试件固定 seed） |
| 敌人 | **右上 3×3 区随机**，与主角曼哈顿距离 **≥4**（防贴脸开局），敌间互不重叠 |
| seed | 测试件固定；正式=时间戳派生，快照/事件流全等断言依赖 |
