## 二、设计（三件状态 + 冲刷机制）

### 2.1 view 数据结构（全部渲染层私有，BattleHexView 扩展）

```ts
interface PendingHit { attackerId: string; targetId: string; text: string; shake: boolean; t: number }
// view 新增：pendingHits: PendingHit[]          —— 挂起冲刷队列（§2.3）
//           shakes: Map<string, number>          —— actorId → 震动已历时秒
//           dmgStagger: Map<string, { at: number; seq: number }> —— targetId → 同位错位序号
// FxItem kind 联合加 'dmg'；条目新增 dx?: number（错位横移）
```

类型定义只落 battle-hex-render.ts（渲染层私有，与 FxItem/MoveAnim 同级），不进 types.ts。

### 2.2 事件消费（宿主 main.ts，复用 evCursor 段）

| 事件 | 动作 |
|---|---|
| `basic` / `skill` 且有 targetId 且 damage>0 | 入队 `{ text: String(damage), shake: true }` |
| `miss` 且有 targetId | 入队 `{ text: '闪避', shake: false }`（闪避=未受击，不震——§六确认点 1） |
| 其余一切 | 不入队：空放 skill 事件天然无 targetId 无 damage（session:766-768）→ 不冒字；fallback/blocked damage=0；rejected 走既有 note；death/win/lose/move 等不属本卡 |

数值铁律：text=String(damage) **直读事件字段**，渲染层禁止任何换算（取整/千分位/单位）。

### 2.3 挂起冲刷队列（updateView 内；V4 + 特技时差统一机制，PM 裁决③）

入队**不立即冒字**。updateView 每帧对每条 pending 依序判定冲刷（满足其一即冲刷并出队）：

- a. **上升沿**：攻击者本帧 animState 切换到 basic/strike（在既有 anim 钟切换检测点 battle-hex-render.ts:461-467 收集本帧上升沿集合，演出循环后统一冲刷——与 slash fx 同沿）
- b. **已在态兜底**：攻击者当前 animState 已是 basic/strike（防消费帧与切换帧错位导致漏冲刷——冲刷不依赖「必须亲眼看到切换帧」）
- c. **超时**：pending 年龄 > DMG.flushDeadlineSec（覆盖攻击者中途阵亡、pendingAnim 永不触发的挂死路径）
- d. **攻击者已 dead**：立即冲刷（数字仍冒——hp 减少是既成事实）

冲刷时定位：按**当帧快照**查 targetId → renderPos → hexToWorld（不用事件帧旧坐标；受害者在受击窗口内实际静止，但取当帧=机制上恒正确）。然后：

- spawn dmg fx（§2.4，含同位错位）
- shake=true 且快照中 target animState!=='dead' → 写 view.shakes（**击杀一击：冒数字、不震动**——需求 #1「hp 减少即冒字」与 #4「死亡者不震动」的组合语义，PM 已确认按此理解落文）

三条路径的时序效果：普攻（basic 同帧切换）→ 入队与冲刷同帧，零附加延迟；特技 charge(100ms)→strike → 数字随 strike 弧出现；ATK-3（quiet，basic 演出经 pendingAnim 延后至 walk 结束，session:365-366/567-570）→ 数字随补播的 basic 出现（V4 达成）。

### 2.4 dmg 冒字（drawFx 扩展）

- 样式：白字深描边粗体——strokeText（lineJoin='round' 防尖刺）先描、fillText 后填；颜色/描边宽走 DMG 组
- 定尺：`fontPx = round(H × DMG.fontPerH)`（**屏高基准**）。与 rejected note（width×0.032 屏宽基准）刻意不同源的理由（PM 裁决①）：伤害数字挂**角色**、角色族渲染尺寸按格高/屏高系定尺（棋子高、HUD 三件套同族）；note 属**组件提示**（与按钮/浮层同族的屏宽系）。两族基准不同是既有定尺体系的现状，非本卡引入
- 动效：锚点=头顶（沿 note 同族 TILE_H 抬升基准）+ 上浮 DMG.risePx×p、渐隐 alpha=1−p、寿命 DMG.sec；寿命推进复用既有 fx 循环（battle-hex-render.ts:473-479）
- 同位错位（PM 裁决②）：同 targetId 在 DMG.staggerWindowMs 窗口内连续 spawn，按命中序横移 seq×DMG.staggerPx（不合并数值）；窗口过期序号归零

### 2.5 受击震动（drawPieces 扩展）

- view.shakes 命中者：`cx += sin(t × DMG.shakeFreq) × DMG.shakePx × (1 − t/DMG.shakeSec)` —— 水平 ±3px 衰减 ~200ms
- 只震受击者（targetId），攻击者不震；死亡不震（§2.3 冲刷时单点判定即可——session doAttack 同步置 dead 且不可逆，battle-session.ts:391-396，无需逐帧复查）
- 与既有时钟零冲突：震动是绘制位 cx 的**附加偏移**（与 :735 休眠钩子同位叠加思路、参数与触发源不同），不动 moveAnims 插值位置；衰减时钟独立于 AnimClock（view 私有，session 无感知）
- updateView 推进 shakes 计时并到期删除

### 2.6 DMG 参数组（config/battle-hex.ts 新增；展示参数，L 环真机手感可调）

| 参数 | 默认 | 说明 |
|---|---|---|
| `sec` | 0.6 | 冒字寿命（s） |
| `risePx` | 24 | 上浮量 |
| `fontPerH` | 0.026 | 屏高定尺系数（667 屏 ≈ 17px） |
| `fillColor` / `strokeColor` / `strokeWidth` | `#ffffff` / `#1c1c1c` / 3 | 白字深描边 |
| `shakeSec` / `shakePx` / `shakeFreq` | 0.2 / 3 / 55 | 震动时长/幅度/频率 |
| `staggerPx` / `staggerWindowMs` | 6 / 600 | 同位错位步长/窗口 |
| `flushDeadlineSec` | 1.5 | 挂起兜底（> walk 300ms + 余量） |
| `missText` | `'闪避'` | miss 冒字文案 |
