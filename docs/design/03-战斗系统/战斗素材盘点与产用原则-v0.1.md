## 0. 产用原则七条（审计标尺，逐件过）

| # | 原则 | 内容 |
|---|------|------|
| 1 | **整图不裁切** | 能整张直用的（如 env 环境底图）绝不裁切组件——裁切件必带烙底/白边/锯齿 |
| 2 | **简单件才可生成** | 组件级生成的仅限少细节、平涂、粗边件；细节密度高的件降级 |
| 3 | **锚定+单发生成** | 需生成的走多参照锚定（画风/比例/视角锁定）+ 单发出图（禁链式修补）+ 机械门检（尺寸/白底/边缘 alpha 程序化检查） |
| 4 | **质检门不过不接线** | alpha 纯度、边缘晕圈、尺寸对 meta、色板对角色锚 |
| 5 | **不可控降级代码画** | 连续不过门的件降级为纯代码绘制（现有 demo 全组件有代码降级路径） |
| 6 | **AI 稿禁文字** | 文字一律代码绘制（宋体奶黄+深描边同族） |
| 7 | **状态成套** | 普通/激活变体同源生成；禁在美术件上叠代码装饰（金框/亮效教训） |

**优先级口径**：P0 = 阻塞战斗手感验收 / Leo 点名；P1 = 本期 MVP 需要；P2 = 可后置观察。

## 3. 审计发现与疑点（待 Leo / 主会话拍板，不在本卡处置）

1. **env 代系差**：`battle_env_pure.png`（1088×1920）基线早于 v8 定稿（1440×2560），与切件母版不同代；现行色调以 env 为准（T24 dirt 取色自 env），组件重产（A1~A4）必须**以 env/scene 锚为环境色参照**，避免顶栏木色与场景暖调脱节——这正是「和程序衔接极不自然」的成因之一。
2. **烘焙字违例现存两件**：`plaque_l_alpha.png`（装备/武功）与 `ctrl_flee.png`（逃跑）均烘焙文字，违原则 6；重产时去字，文字并入代码字管线（CTRL_TEXT 同族宋体奶黄+深描边）。
3. **字体族双轨**：顶栏/ctrl=宋体族（原则 6 口径），但伤害冒字/rejected 冒字/弧形四钮字/头顶名字=PingFang sans 族（`battle-hex-render.ts:1000,1058,1274,1282` 等四处 fontStack）——与「宋体奶黄+深描边同族」口径存在偏差，~~待拍板~~ → **Leo 09-04 裁定：统一宋体族**（收口卡执行，8 处 fontStack+config 改宋体栈）。
4. **弧形四钮质感**：纯代码深底金边钮，《视觉骨架》未列其为定稿组件；**Leo 09-04 裁定：升级美术件** → 表 A7 立项（圆形平涂粗边件，原则 2 可控形态）。
5. **hex demo 敌型覆盖**：`spriteKinds` 仅 hero/shanzei/lang 三种，Boss 未接入；实战档位 1~6 的敌型帧矩阵（T45 敌 42 张=shanzei_a/b）与战斗规则 C 案敌档表的对表缺口在 C4/C3 一并收口。
