# 战斗上下点缀规格口径（屏幕锚定框景）v0.1

> 分类：03-战斗系统 · 状态：🟡 v0.1（2026-09-04 · ZCode 起草，停等 Leo 审阅后交美术窗口排产）
> 缘起：Leo 09-04 L 环反馈「上下还是需要有一些固定的战场背景点缀，而且要在棋盘的层级上」——T24 已把 env 入世界系（随拖动），点缀补屏幕锚定的**框景层**
> 产用原则：按《战斗素材盘点与产用原则》七条执行——**横幅整条出图（原则 1 整图不裁切）**、少细节平涂粗边（原则 2）、锚定+单发（原则 3）、门检（原则 4）

## 一、定位与视差关系

| 层 | 坐标系 | 拖动行为 | 内容 |
|---|---|---|---|
| env 环境底图 | 世界系 | **随棋盘拖动** | 营地全景（T24 已交付） |
| 棋盘/棋子/特效 | 世界系 | 随拖动 | 六边形战棋 |
| **上下点缀（本档）** | **屏幕系** | **恒定不动** | 上檐带 + 下沿带框景 |
| UI 组件（顶栏/木牌/弧钮/ctrl） | 屏幕系 | 恒定 | 现役组件 |

视差效果：拖动时中景（棋盘+营地）动、框景不动——纵深感由两层速度差自然产生，无需额外视差算法。

**渲染序**：env → 棋盘/棋子/特效 → **点缀** → UI 组件（点缀压棋盘、被 UI 压）。

## 二、形态与布局

| 项 | 上檐带 | 下沿带 |
|---|---|---|
| 形态 | 屏宽整条横幅，透明底 PNG | 屏宽整条横幅，透明底 PNG |
| 显示高 | ≈ 屏高 6~8%（目验可调） | ≈ 屏高 8~10%（目验可调） |
| 出图尺寸 | 1440×~200（2x 余量） | 1440×~260（2x 余量） |
| 锚定 | 贴屏顶（顶栏之下） | 贴屏底 |

- **遮挡让位（关键约束）**：右下 ctrl 三钮热区不可被下沿带的不透明内容压住（HIT-1 热区只认实际图形，但视觉遮挡仍影响操作观感）——下沿带构图**右段（约右 1/4）只留低矮/透明内容**（杂草/石粒级），大体量物件（篝火/木堆）放中段与左段。
- 上檐带与顶栏（1440×300 系）关系：顶栏在最上，上檐带从顶栏底边之下开始露头；树冠/旌旗类可少量探入顶栏透明区，禁止压名字/条/槽。

## 三、物件清单（默认案，Leo 挑改）

| 带 | 默认物件（v8 效果图同源） | 备注 |
|---|---|---|
| 上檐带 | 左段树冠垂枝 + 中段暗色藤蔓/枝影 + 右段旌旗一角与帐幕檐 | 暗调压边，中段稀疏，避免「门帘」式整条封死 |
| 下沿带 | 左段篝火堆（可含微光渐变，静态）+ 中段木桶/木堆/断栅 + 右段低矮杂草石粒（让位 ctrl） | 体量物件集中左/中段 |

- 风格：与 env 同代系同色域（暖棕+墨绿，夜间营地光感）；细节密度按「简单件」口径——**剪影感、粗边、少内纹**（原则 2，防生成不可控）。
- 禁：文字/字母/水印（原则 6）；切割感碎件（原则 1）。

## 四、产需与门检（美术窗口）

| 项 | 口径 |
|---|---|
| 生成方式 | 锚定单发：参照 = env 横幅图（色域锚）+ v8 效果图（物件锚），一次成图；禁链式修补 |
| 门检 | 尺寸对档（1440×200/260 ±2px）；alpha 纯度（上/下边缘不锁边，透明过渡自然）；四角+中段采样无字；色域与 env 取样差在容差带（复用 `tools/sample_dirt_colors.mjs` 思路采样比对） |
| 命名 | `assets/ui/pixel/battle/components/frame_top.png` / `frame_bottom.png`（+ meta json 尺寸档） |
| 失败降级 | 两连不过门 → B 表降级：不画点缀（env 世界系已足够，框景属增强非必需） |
