> 分类：03-战斗系统 · 状态：🟡 草案（2026-09-06 · Leo 六点对齐成稿，停等 Leo 审阅后进主架构方案）· 优先级：P1

## 一、机制总述

**出招速度**是战斗基础数值：决定招式时长（速度快=时长短）。其衍生表现=**两段式伤害**：技能伤害拆两段落、两次扣血、两跳数字——出招快者两跳密集，出招慢者两跳拉开，速度由此获得手感表达。**无打断机制**（出招不可被中断）；**无内伤**（两段均为外伤，走血条）。

## 二、Leo 六点口径（需求真源）

| # | 口径 | 备注 |
|---|---|---|
| 1 | 两段伤害 **50/50，各自独立判定** | 每段独立走 F-04 命中/掷骰链；未来暴击/闪避等效果**按段独立生效** |
| 2 | 落点：**第一段=招式落地起点；第二段=收招的终点** | 对应演出：落地瞬间（外放帧时刻）落第一跳；收招段播完落第二跳 |
| 3 | **普攻数值不受出招速度影响**；普攻帧播放速度可略延长 | 普攻保持单段结算（现行为）；其动画时长为独立表现常量（可调长一点） |
| 4 | 数值构成：**角色基础值 + 每武功速度值 + 内功加成值** | 具体数值框架**后定**（归 C 案数值域）；MVP=全局基础值+挂点预留 |
| 5 | 出招期间**施放帧循环播放** | 循环帧集见开放点① |
| 6 | 无打断、无内伤 | 出招窗口不可中断；两段均外伤 |

## 三、行为规格（草案条目，编号暂 AS-1 起，定稿后并入交互规格 v2.5）

| 编号 | 规格 |
|---|---|
| AS-1 | **招式时长** = f(出招速度)，方向=速度快时长短；公式与基础值归 C 案数值域（MVP：全局基础值常量）。普攻时长不消费此公式（独立表现常量） |
| AS-2 | **出招段**（charge 语义延伸）：时长内施放帧循环播放；期间行动条/回合推进语义不变更（BAR-3 清零仍在提交时——出招窗口是演出+结算时序，不占用额外行动） |
| AS-3 | **第一段伤害**：招式落地起点结算（演出=切外放帧瞬间）；50% 伤害，独立判定 |
| AS-4 | **第二段伤害**：收招终点结算（演出=收势帧播完）；50% 伤害，独立判定；两段 miss 独立（可一中一闪） |
| AS-5 | 事件流：两段各发一条结算事件（skill|miss ×2，各带 targetId/damage）——**每段一条**，契约形状沿用（零新增类型） |
| AS-6 | 死亡语义：第一段致死→第二段不再结算（对已死目标）；AOE 场景逐目标按段独立判定（同 v2.2 掷骰纪律，目标序×两段序，SP-2 纳入确定性） |
| AS-7 | AI 出手同规则（敌方同规则，v2.2 五点⑤延续） |
| AS-8 | 演出牵连：冒字两跳（T21 队列天然支持，同位错位防重叠）；血条两次下移；cast 三帧时刻锚定（聚气循环→外放=段1→收势=段2 终点） |

## 四、影响面与流程定位

- **语义级变更**（需主架构方案+Leo 拍板）：session 结算时序从"提交瞬间一次结清"扩展为"两段错时结算"（第二段锚在收招终点）——涉 tick 驱动/事件流/快照 hp 时序；T21 冒字与斩击弧时序对齐；e2e 时序断言配套
- **数值域**：出招速度入 C 案数值体系（新 R-xx/F-xx 编号挂靠武功 schema v0.1 的 movBonus 同层）；MVP 只落常量+挂点，完整数值框架（武功速度值/内功加成）随成长线后置
- **规格归并**：定稿后并入《战斗交互行为规格》v2.5（AS-* 条目+矩阵行）

## 五、开放点（定稿前需 Leo 圈）

| # | 事项 | 默认案 |
|---|---|---|
| ① | 循环帧集 | 出招段循环**整套施放帧**（1聚气→2外放→3收势 循环），到时定格外放帧结段1、播收势帧结段2——完整"运功"观感；备选=仅聚气帧循环（更克制，但单帧循环近似定格） |
| ② | 收招段时长归属 | 收招段**含在招式总时长内**（总时长=出招段+收招段，公式输出总长，两段按比例分）；备选=收招独立固定时长 |
| ③ | 普攻延长量 | 表现常量默认 +30%（现 300ms→390ms 量级），L 环目验可调 |
