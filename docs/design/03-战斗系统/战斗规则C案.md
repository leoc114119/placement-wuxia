## 一、C 案定位（已拍板，不重议）

- **轻战棋回合制**：走位/集火，六边形棋盘（布局见 `战场布局规格-六边形战棋.md` v0.9）
- **双模式**：日常剿匪=自动挂机动画（寻道大千式，不切战棋界面）；**关键战=切战棋**（Boss/主线节点/门派战），可托管代行
- **试金石定位**：单场短（90s 防死循环）、可跳过、胜负只影响收益不影响存档安全
- MVP 规模：**1v 多**（玩家 1 人，敌方按实战档位 1/1-3/1-6 随机，R-07）

## 四、B 层：双模式切换（Leo 08-31 晚拍板 ✅ 闭合）

### B1 关键战定义（Leo：按建议走 + 挑战型活动补充）

| 战斗类型 | 模式 | 说明 |
|---|---|---|
| 剿匪杂兵 | **纯自动动画**（不切战棋界面） | 寻道大千式掉落流；在场高倍、离线托管 |
| Boss 战（剿匪换图门） | **切战棋，手动可托管** | 打不过可反复挑战（R-10 容错）；**通关后解锁该图扫荡** |
| 主线节点 / 门派战 | **切战棋，手动可托管** | 叙事关键战，仪式感位 |
| **木人巷（挑战型活动）** | **切战棋，手动可托管**；**首通成功后解锁扫荡** | Leo 补充：挑战型活动闯关成功后可开始扫荡——之后每日 1 次可直接扫荡拿高额学点，省时间不打 |

- **扫荡原则（Leo 定）**：挑战型玩法（木人巷/闯关类）首通后才解锁扫荡；扫荡=跳过战斗直接拿奖励（略打折 🔧 或全额，数值后置）——"可跳过"红线落地

### B2 托管 AI 策略（Leo：按建议走）

MVP 优先级表（简单可测，Playtest 再调）：

```
1. 集火目标：选最近敌人；同距离选血少的（A4 同源）
2. 技能：冷却完毕 且 内力足够 → 按伤害倍率从高到低放
3. 普攻：无技能可用 → 普攻（贴脸范围内）
4. 位移：目标在射程外 → 先向目标移动（F-06），进入射程即停
5. 无自保撤退（MVP 不做）：AI 就是莽——失败惩罚轻（R-10 保底 30% 血），Playtest 再评估
```

- 敌方 AI 同构复用（最近/血少集火 + 技能优先），差异只在属性与技能池
- 实现锚点：battle-core `resolveAction` 已有行动结算骨架，AI 表即在其上加决策入口

## 五、C 层：战斗与玩法接口（Leo 08-31 晚拍板）

### C1 剿匪循环粒度（Leo 定：体力驱动）

- **1 点体力 = 1 场战斗**，可以一直刷到**体力归零**（R-06 既有规则精确咬合：每场统一扣 1，逃跑不扣，耗尽自动停）
- **掉落实时弹**（在场高倍掉落流）
- **年龄按体力消耗换算**（Leo 定）——计龄锚点从"在场时长"改为"体力消耗"：`年龄增量 = f(消耗体力) 🔧`——刷多少场老多少，躺现场不扣体力不老化，与"领取结算才计龄"同精神
- 血线/内力跨场保留（R-10 + R-06 自动补药 30%）——剿匪连刷的续航管理=核心张力

### C2 Boss 换图战（Leo：按建议走）

- Boss 战**默认切战棋**，**可托管、不可扫荡**（每张图 Boss 只打一次，扫荡无意义）
- 打不过可反复挑战（R-10 逃跑容错：无损失无扣体力）；胜利 → 换下一张图
- 逃跑/失败均不扣体力（R-06），只有胜利结算计龄

### C3 木人巷计分（Leo：**待定，不在 MVP 确定**）

- 每日 1 次 + 高额学点 + 首通解锁扫荡已定（B1）；**计分方式（限时总伤害 vs 波次 vs 通关层数）后置**——MVP 先用最简实现占位（如固定时长打桩，总伤害换学点 🔧），正式规则二期迭代
