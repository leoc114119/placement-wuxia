## 2. 验收标准（跑起来看到什么）

```
① 启动 → 进入青牛山下·野径场景（2.5D 背景 + 主角立绘）
② 点场景任意位置 → 主角两脚交替走过去（walk 帧）
③ 场景里 2 山贼 + 1 野狼 随机走动，走近触发追击（弹「迎战/暂避」）
④ 点 NPC → 进入战斗界面（8×12 等距棋盘，**我方 1 人 / 敌方按实战档位 1~3**）
⑤ 自动模式：双方自动寻敌/出招，一方全灭 → 结算
⑥ 手动模式：点格子移动 → 行动条满出「特/轻/绝」→ 范围光影 → 受击命中效果（初始 0 内力仅普攻/走位）
⑦ 击败 NPC → 消失 + 收益入账；场景全清 → 按实战档位刷新
⑧ Boss 入口：挑战独眼狼王（实战 ≥1000 置灰，Boss 1 人，初始打不过为正常进阶目标）→ 战棋 → 击败掉落入包
```
