# 放置武侠 · 任务管理总表

> 状态：**第 1 期已建（2026-08-20 开工批次）**
> 用途：每期任务流转跟踪（发单→施工→测试→验收）。
> ⚠ **正式任务管理在 Excel**：`docs/任务管理总表.xlsx`，结构 = **总表（跨期汇总，一行一任务）+ 每期一个 Sheet（素材总表按区域 + 任务明细堆叠）**。Sheet 数 ≈ 期数，不会随任务数膨胀。本 md 仅保留文档链接索引。
> 状态图例：⬜ 待发单 · 📤 已发单 · 🔧 施工中 · 🧪 C 测试中 · ✅ 已验收 · 🔁 打回
> 规则：新任务 → 总表加一行 + 当期 Sheet 尾部加区块；新一期 → 新建一个期 Sheet。
> **非研发管线（2026-08-31 起）**：Codex 客户端加入后，调研/写作/文档评估/素材管线类任务进同一看板（tasks/README v2，owner 字段区分执行者）；本表在任务 ID 表中用「非研发管线·执行者」标注。
> **素材总表铁律**：每期页顶部素材总表必须**按区域/层拆解到可执行颗粒度**（头部/场景/角色NPC/底部导航/按钮浮层，每项带用途/规格/生成方式/状态/落盘路径），禁止只列一张大图（Leo 2026-08-20 定）。
