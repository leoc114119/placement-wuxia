## 2. 敌方组队与刷新规则（P0-2 · Leo 拍板 ✅）

### 2.1 普通战斗敌方数量（战斗生成时按**玩家当前实战**判定）

| 玩家实战 | 敌方数量 |
|---|---|
| < 100 | 固定 **1** |
| 100 ≤ 实战 < 10000 | 随机 **1-3** |
| ≥ 10000 | 随机 **1-6** |

### 2.2 随机概率表（CodeBuddy 建议 🔧）

| 档位 | 概率分布（期望） |
|---|---|
| 1-3 档 | 1:50% / 2:35% / 3:15%（期望 1.65，前期偏少不劝退） |
| 1-6 档 | 1:10% / 2:25% / 3:30% / 4:20% / 5:10% / 6:5%（期望 3.3，多敌收益/损耗同增） |

### 2.3 敌方类型选择
- 从当前场景 `SceneConfig.npcs`（mob 类型）中按布点顺序循环填充，数量超出时重复。
- Boss 战敌方构成（CodeBuddy 建议 ❓待确认）：**Boss 本体固定 1 + 护卫按玩家实战档**：<100 → 0 护卫；100~1W → 0~1（50/50）；≥1W → 1~2（从场景小怪选）。理由：保住"范围预判"博弈对象。

### 2.4 场景刷新（与 2.1 同档位，取代 spawnCountRange [1,6]）
- 场景全清后刷新数量 = 按 2.1 档位生成（`<100:1`、`100~1W:随机1-3`、`≥1W:随机1-6`），刷新间隔 MVP 定 30s。

## 4. 行动条与超时（P0-4 · Leo 拍板 ✅）

| 项 | 规则 |
|---|---|
| 行动条满值 | **100**（即 0~100%），满 100 即行动（01 §4.1 正确，F-05 满值 1000 作废） |
| 填充速度 | `fillRate = (100 + 内功等级×3 + 机敏×1) / 10` 点/秒；峨眉门派特色 +10% 叠加。例：内功10级+机敏27 → 15.7/s → **6.4s 出手一次**（与原 F-05 节奏一致） |
| 自动模式 | **无操作超时**（AI 全自动，玩家无需干预） |
| 手动模式 | 行动条满后 **90s** 无操作 → **当前回合由自动 AI 代行**（移动+出招，行动条归 0）+ 提示「久未操作，本回合已自动托管」；再次累计 90s 无操作 → **自动切回自动模式** + 提示 |
| 防死循环超时 | **保留**（与手动超时是两回事）：战斗总时长 90s 双方均未全灭 → 存活 hp 总量高者胜；总量相同判玩家负（防利用）。✅待确认 |
