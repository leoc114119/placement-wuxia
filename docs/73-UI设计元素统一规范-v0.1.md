# 放置武侠 · UI 设计元素统一规范 v0.1

> 状态：**草案（待 Leo 审）**
> 日期：2026-08-19
> 定位：**底层设计元素美学统一**——把主界面（及后续所有界面）的「描边 / 圆角 / 阴影 / 间距 / 字距 / 层级 / 色板分层」收敛成一套可落地的 Design Tokens，并定义「AI 生成素材 × UI 框架」的衔接规则。所有 UI 实现（Canvas 代码绘制 / preview HTML）一律引用本规范，禁止散值。

> 范围：本规范只定义"底层元素"，不含具体页面布局（70/72 已定）、不含素材规格（30 已定）。与 04/70/72 的增量关系见 §6。

## 0. 一句话总则

> **「一屏一张画」：背景是画，UI 是浮在画上的宣纸片。描边、圆角、阴影是"层级语言"不是装饰——每屏只允许 1~2 个"厚重"元素，其余一律轻量化；所有值只从 Design Tokens 里取。**
> **墨线只描"装内容的盒子"，不描"浮在画上的纸片"；朱砂只给"要点得准的入口"和"要一眼看见的数字"。**

## 2. 设计令牌 Design Tokens

> 所有值以 **CSS 变量形式**给出（Canvas 代码绘制同值，折算 rpx×2 出 2x 像素）。**禁止使用 token 之外的游离值。**

| Token | 值 | 层级 | 用途 |
|---|---|---|---|

| `--c-ink-12` | `rgba(43,43,43,.12)` | 底·淡墨晕 | 按下晕染/底纹 |

| `--c-cinnabar-d` | `#C94A40` | 强调·深朱砂 | 按钮按下态/小字号按钮底 |

**分层语义**：主=墨（信息骨架）；辅=宣纸系（承载面）；强调=朱砂系（入口+关键值）；点缀=青/金/紫（状态+品质+装饰）；氛围=天青/藕荷（背景）。功能性色（警示/成功/危险）必须「形状/文字 + 颜色」双编码（31 §5.2）。

### 2.2 描边分级

| Token | 规格 | 适用 | 禁用于 |
|---|---|---|---|
| `--stroke-1` | `1px solid rgba(43,43,43,.25)` | 二级 Tab 容器、图标按钮、货币标签 | 承载正文的卡片 |
| `--stroke-15` | `1.5px solid #2B2B2B` | **默认**：卡片、次按钮、顶条、Tab 图标 | — |
| `--stroke-2` | `2px solid #2B2B2B` | 大图卡、弹窗 panel_dialog、主按钮 | 列表行/统计格/二级 Tab |
| `--stroke-gold` | `1px solid rgba(212,175,55,.60)` | 货币标签、品质徽章 | 信息承载 |
| `--stroke-cinnabar` | `1.5px solid rgba(226,87,76,.50)` | 警示条 | — |
| `--stroke-none` | `none` | 列表行、统计格、Tab 格 | — |

**铁律**：**一屏内 `--stroke-2` 元素 ≤ 2 个**（主按钮 + 当前主视觉卡/弹窗）；其余一律 `--stroke-1` 或 `--stroke-15` 或 `--stroke-none`。

### 2.3 圆角分级

| Token | 值 | 适用 |
|---|---|---|
| `--radius-xs` | 6px | 角标、印章、进度条 |
| `--radius-sm` | 10px | 列表行、统计格、槽位、警示条、货币标签、小按钮 |
| `--radius-md` | 14px | 卡片、二级 Tab 容器、武学卡 |
| `--radius-lg` | 18px | 顶部资源条、底部 Tab 格、弹窗 |
| `--radius-xl` | 20px | 大图卡、主按钮 |
| `--radius-pill` | 999px | 胶囊小按钮、品质标签 |

**铁律**：圆角值只允许 ∈ {6, 10, 14, 18, 20, pill}，禁止 16 / 12 / 8 / 22 等游离值。

### 2.4 阴影分级

| Token | 值 | 适用 |
|---|---|---|
| `--shadow-sm` | `0 2px 6px rgba(43,43,43,.08)` | 列表行（可选）、Tab 选中格 |
| `--shadow-md` | `0 3px 10px rgba(43,43,43,.12)` | 卡片、顶条 |
| `--shadow-lg` | `0 6px 18px rgba(43,43,43,.20)` | 大图卡、弹窗 |
| `--shadow-xl` | `0 12px 32px rgba(43,43,43,.28)` | 最高浮层（toast/加载） |
| `--shadow-none` | `none` | 列表行/统计格默认 |

**铁律**：阴影只给"抬升层级"的面（浮起的面），**不给**列表行/统计格/二级 Tab 项；阴影色统一墨色 `rgba(43,43,43,α)`，禁用彩色阴影（选中态朱砂微光 `rgba(226,87,76,.18)` 仅 Tab 选中格可用）。

### 2.5 间距分级

| Token | 值 | 适用 |
|---|---|---|
| `--sp-1` | 4px | icon↔文字、角标内边距 |
| `--sp-2` | 8px | 卡内 padding 小、元素 gap |
| `--sp-3` | 12px | 卡 padding 标准 |
| `--sp-4` | 16px | 区块间距、相邻热区最小距（31 §7 硬约束） |
| `--sp-5` | 24px | 页边距 |

### 2.6 字体层级（沿 70 §5.1，补充字距；rpx = 设计值，px = 375px 基准）

| Token | 用途 | 字体 | 字号 rpx(px) | 字重 | 色 | 字距 |
|---|---|---|---|---|---|---|
| T0 | 屏级标题 | 书法体 | 36(18) | 700 | 墨 | 2px |
| T1 | 关键数值（战力/学点跳动） | 衬线数字 | 32(16) | 700 | 朱砂 | 0 |
| T2 | 强调数值（属性加成/消耗） | 衬线数字 | 28(14) | 700 | 朱砂 | 0 |
| T3 | 区块标题（武学名/装备名） | 宋体 | 28(14) | 600 | 墨 | 1px |
| T4 | 正文 | 宋体 | 24(12) | 400 | 墨 | 0.5px |
| T5 | 次要文字（等级/单位） | 宋体 | 22(11) | 400 | 深灰 | 0.5px |
| T6 | 按钮文字 | 宋体 | ≥30(15) | 700 | 墨/白 | 1px |
| T7 | 品质标签 | 宋体 | 22(11) | 400 | 品质色+字 | 0.5px |

### 3.1 方案选定：**「水墨浮签」——半透明毛玻璃悬浮格 + 淡金印章选中角标**（推荐，方案 A）

| 未选中态 | 图标墨 #2B2B2B + 文字深灰 #444（12.9:1 / 8.9:1 ✅） | 70 §4 |

| 角标 | 背包/门派等通知角标：淡金印章 `8×8px` 右上（不承载信息，数字用墨 on 淡金 ≥3:1 或墨底白字） | 61 §3 / 31 §5 |
| 切换动画 | 淡入 ≤0.5s，随特效等级可关（31 §6） | 31 §6 |

### 3.2 备选方案（供 Leo 拍板，默认 A）

| 方案 | 形态 | 优点 | 缺点 |
|---|---|---|---|
| **A 水墨浮签（推荐）** | 毛玻璃悬浮格 + 淡金印章角标 | 轻透、可读性有保证、回归 70 编码 | 毛玻璃需引擎 blur 支持（微信 Canvas 需确认） |
| B 纯透明无底 | 图标+文字直接浮背景，选中=朱砂图标+墨字加粗+淡金角标 | 最轻、最透 | 背景复杂时图标发虚（31 对比度风险）；可读性最弱 |
| C 整条实底 | 宣纸实底条 + 顶部墨线（70 §4 原文） | 最稳、最传统 | 最"实"，正是不被接受的形态 |

## 5. AI 生成素材 × UI 框架衔接规则

> 依据 30 §0a：**UI 框架类（按钮/面板/条/Tab）一律代码绘制；AI 生图只用于「背景/角色/复杂图标草图」**。以下规则补充 30 未定义的"衔接"细则。

### 5.1 透明底
- icon 类必须**透明 PNG**（30 §2.2）；工具不支持透明 → 出纯宣纸底 + 统一去底（30 §2.3）。
- 背景/角色类可为不透明（JPG/WebP，30 §2.2）。

### 5.2 描边策略（AI 素材不叠 CSS 描边）
- AI 图标自带墨线笔画 → **代码不叠加描边**（避免双线）。验收标准：375px 基准下笔画视觉宽度 ≥1.5px。
- 若图标边缘浅淡/发虚 → 只加 `filter: drop-shadow(0 1px 1px rgba(43,43,43,.35))` 提轮廓，**不改变造型**。
- 背景/角色素材不描边；由 UI 遮罩 `.shade` 保证文字区对比。

### 5.3 投影策略（按显示尺寸分级）
| 图标显示尺寸 | 投影 | 理由 |
|---|---|---|
| 24~48px（Tab/列表小图标） | **不加投影** | 糊、发虚 |
| ≥64px（大图标/详情图） | `--shadow-sm` 可选 | 有层次 |
| 背景/角色 | 无；靠遮罩 | — |

### 5.4 色温协调
- 背景图：整体明度中低、**中景 60% 区域留白**（HUD 叠放区，30 §2.3/模板 F）；色值全在 04 色板内（天青晕染 + 宣纸留白）。
- 图标点缀色**按类别固定**（30 §6 使用说明）：属性=黛青、货币=淡金、状态=朱砂/灰、武功=墨 + 单一点缀色。
- 禁止规范外鲜艳色（30 §5.4）。

### 5.5 小尺寸可读性（24~48px）
- 主体占比 ≥60%（内容居中，不留大空白）。
- 笔画 ≥1.5px；**无细碎装饰**（≤2px 的须发/裂纹在小尺寸糊成一团）。
- 不纯线条表达：填充 8~20% 淡墨增强剪影识别。
- 语义双编码：形状 + 颜色（31 §5.2）。

### 5.6 图标入格规则
- Tab 图标：显示 32px，右下角 12%×12% 水印裁切（30 §2.4），透明直接上格，无底片。
- 若 AI 素材自带宣纸圆底片 → 统一裁为 **40px 圆片 + 1px 淡墨圆边**（本规范新增，避免各图底片大小不一）。
- 列表行小图标：显示 24~30px，`object-fit: contain`，四周留 4px 透明边防裁切。

### 5.7 背景 × UI 衔接
- bg_main 中央 y 30%~90% 保持低对比留白，UI 浮层落此区。
- HUD 文字区若背景有山石/松枝 → 加 `.shade` 渐变或局部毛玻璃 panel 底（优先半透明纸底，30 §5.2）。
