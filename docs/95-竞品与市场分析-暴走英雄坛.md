## 〇、三分钟摘要

1. **《暴走英雄坛》= 竖屏武侠养成+挂机品类的九年长尾活体**：小团队、零爆款打法、靠"低成本画风 + 养成深度 + 内容更新节奏"活到 2026 年仍在更新。它证明的不是"能爆"，是**"能持续活着"**——正是本项目"中腰部生态"定位的商业模式参照。
2. **收入规模**：无一手流水数据（小厂不披露）。代理指标推算为**稳定长尾型，非爆款**——月流水推测在数十万~数百万人民币量级（低置信度，仅供量级感知），但足以养活团队 9 年。
3. **微信小游戏市场结论：有市场，且验证刚烈**——2026 年武侠/仙侠放置在微信小游戏畅销榜 TOP10 占 **4 席**（寻道大千 #1 长期霸榜、小小英雄 #5、灵剑仙师 #6、无名之辈 #9）。但榜上产品全是"**成熟 idle 底层（开箱/咸鱼 like）+ 武侠皮 + 大厂买量发行**"的爆款打法。
4. **对本项目的判定**：品类需求真实且大 ✅；但获客打法必须与爆款打法错位——单团队无买量预算，走"内容差异化 + 社交裂变 + 混合变现"的长尾路线（与 08-29"社交=获客引擎"结论互证）。

## 二、玩法拆解（按本项目 08-30 的"框架/内容"划分法）

**它的框架：**
- 挂机修炼（离线结算）+ 文字 MUD 式养成
- 五维属性：臂力/身法/根骨/悟性/福源（总值 80，氪金可到 90，洗髓重置）——**与本项目五维几乎同构，可直接参照**
- 武学四层：基本 → 门派 → 绝学 → 江湖；轻功/内功必修 + 六系专精
- 潜能/修炼/练功/内力/江湖经验多资源循环
- **"活人感"系统**：容貌（16 岁前战败变丑）、饥饿值、年龄成长——低成本高情感回报

**它的内容：**
- 八大门派 + 逍遥散人、百余门武学、开放剧情、正邪自由、投胎轮回、结婚伴侣、装扮/养殖/经营

## 三、收入规模评估

> ⚠ **数据可信度声明**：无一手流水数据（厂商未披露、无第三方流水追踪）。以下为代理指标 + 量级推算，**置信度：低**，仅供决策感知，不得引用为事实。

**可观测代理指标：**
| 指标 | 数据 | 时点 |
|---|---|---|
| 4399 单渠道安装 | **328.6 万** | 2026-08 渠道页 |
| B站游戏渠道下载 | 5.6-5.7 万（评分 6.2，显著低于 4399 的 8.7） | 2026-08 |
| TapTap 单渠道用户 | 20 万+（评分 8.2） | 2017-12 |
| 公测期新增/活跃 | 50 万 / 近 20 万 | 2017-12 官方通稿 |
| 生存证据 | 注册资本 500 万，全职团队运营 9 年至今，持续做 IP 联动（镖人/奶龙） | 多源 |

**推算结论（量级感知，非事实）：**
- 累计用户量级：数百万（多渠道累计）
- 月流水量级：推测 **数十万 ~ 数百万人民币**——典型"稳定长尾"而非爆款（对照：延趣《时光杂货店》/《时光大爆炸》月均流水破亿，相差 1-2 个数量级）
- **关键推论**：它证明了**不依赖买量的"内容+社区"长尾模式，可以养活小团队 9 年**——这对无买量预算的单人/小团队是商业模式层面的重要先例

**长线运营的负面教训（玩家评论区一致反馈）：**
- 养成周期过长、潜能获取吝啬、后期升级停滞（"一天全任务做完升 5 级"）
- 氪金感知重、概率不透明（"概率是假的吧"、"不要冲榜"三连警告）
- 主线剧情更新停滞多年，靠活动/联动续命
- → **长尾模式的生命线是"内容更新节奏 + 数值透明度"**，两者失守则口碑阴跌（B 站 6.2 分 vs 4399 8.7 分的分化即证据）

## 四、九年长线的三个原因

1. **美术成本打到地板，辨识度拉满**：黑白漫画手绘，不参加立绘军备竞赛，省下的钱全部喂内容（对照本项目：2.5D HD 像素 + 模板换皮管线 = 同策略异实现）
2. **"养成深度 > 表现力"被验证**：文字战斗、简陋表现，玩家照埋 9 年——武侠养成用户吃的是数值/构筑/人生感
3. **更新节奏 = 生命线**：周年大版本（八周年：新剧情+多人副本+装备锻魂+星纹套装）+ 常规活动 + IP 联动（镖人、奶龙）滚动续命

## 五、微信小游戏市场评估：武侠放置品类

### 5.1 大盘（沿用 85 号文档口径，游戏工委数据）

- 2025 年小程序游戏市场 **535.35 亿元（+34.39%）**，是全行业最大增量市场
- 变现结构 IAP:IAA = **68:32**，混合变现是主流解
- 放置/挂机类集中在微信小游戏畅销榜 **#12~#80 中腰部**，头部被 SLG/塔防/模拟经营占据（08-29 调研）

### 5.2 本轮新增：武侠/仙侠放置的头部验证（2024-2026）

| 产品 | 题材/底层 | 成绩 | 发行 |
|---|---|---|---|
| **寻道大千** | 修仙 + 开箱 like | 微信小游戏畅销榜 **#1 长期霸榜**（2023 至今） | 延趣研发/三七发行 |
| **小小英雄** | **武侠** + 咸鱼 like | 微信畅销榜 **#5** | 4399 |
| **灵剑仙师** | 仙侠 + 开箱 like | 微信畅销榜 **#6** | 三七 |
| **无名之辈** | **武侠养成放置**（竖屏，垂钓/武学/英雄交互） | 微信畅销榜 #9、硬核榜 **#2** | 延趣研发 2024-01 上线/三七发行 |

**结论：武侠/仙侠放置在微信小游戏畅销榜 TOP10 占 4 席——品类需求被头部反复验证，"武侠+小游戏"不是伪命题。**

### 5.3 两套打法，本项目的位置

| | 爆款打法（榜上 4 席） | 长尾打法（暴走英雄坛） | **placement-wuxia（建议）** |
|---|---|---|---|
| 底层 | 成熟 idle 框架（开箱/咸鱼 like）+ 数值压缩 | MUD 养成 + 挂机 | 回合分配时间线 + 放置成长 + 战斗试金石 |
| 内容 | 广告素材驱动，内容浅 | 内容驱动，更新 9 年 | **内容驱动 + 编辑器渐进管线** |
| 获客 | 大厂买量（98 元/人量级） | 社区口碑（TapTap 8.2 起） | **社交裂变钩子一期就埋（08-29 已定）+ 品类热度红利** |
| 变现 | 重 IAP | IAP 长线 | 混合变现（IAP 为主 + IAA 兜底，J-01 待定稿） |
| 发行 | 三七/4399 级 | 自发行 | 单团队自发行 → **选长尾路线** |

### 5.4 市场判定

1. **有市场**：品类被 TOP10 四席验证，武侠题材在小游戏用户盘子大
2. **但红海**：榜上产品全部背靠大厂买量，正面拼买量 = 必死（98 元/人 × 单团队预算不可行）
3. **错位空间存在**：榜上爆款的"人生感/养成叙事"普遍薄弱（开箱 like 的短扳手）——本项目"放置版大侠式人生"的**人生感定位恰好是头部产品的空位**；暴走英雄坛则验证了长尾模式可活
4. **最大风险 = 获客**：无买量预算下，社交裂变钩子（08-29 已拍板"社交不是功能模块，是获客引擎"）从一期起就是生死线，不是加分项

## 附录 A · 寻道大千财务拆解（买量爆款对照系）

> 数据置信度：引力引擎（买量数据商）中高；点点数据估算中；聚合自媒体口径低（已标注）。

### A.1 数据卡片

| 指标 | 数据 | 来源/置信度 |
|---|---|---|
| 首月流水（2023-07） | 约 3 亿/月，日流水 1000 万 | 引力引擎 ·中高 |
| 买量投放 | 约 700 万/月（字节 500 万 + 广点通 200 万） | 引力引擎 ·中高 |
| 港台版《小妖问道》首月 | 2300 万 / 60 万下载 | 点点数据 ·中 |
| 现状（2026） | 安卓月约 3000 万级、微信畅销榜 20-30 名 | 自媒体 ·低（趋势合理） |
| 对照：咸鱼之王 | 月流水 2-3 亿、买量 500 万/月 | 引力引擎 ·中高 |

### A.2 巅峰月 P&L（推算，低置信）

```
月流水 3.0 亿
− 买量 ~0.7 亿（23%，健康区间）
− 平台/渠道分成 30-40% → 0.9-1.2 亿
− IAA 分成损耗 3-5%
− 研发/发行/运维 5-10%
≈ 净利 4000-9000 万/月（净利率 15-30%）
```

### A.3 三个关键认知

1. **现金机器**：700 万/月广告费现金前置，需数千万现金池 + 数据中台实时调优——月流水 3 亿的本质是"每月敢烧 700 万"的能力
2. **利润率薄**：15-30% 净利率，买量 ROI 跌破 1 即悬崖（2026 年已衰退至几千万级）——买量爆款的生命周期是结构性的
3. **规模效率的钱**：价值链（买量/数据/发行/素材）无一是单人+AI 可切入的环节

### A.4 三借三不借

- ✅ 借：数值压缩曲线 / 高频小奖励节奏 / 被素材验证过的钩子
- ❌ 不借：买量-回收模式（现金池不可得）/ 概率黑盒（透明度红线反着来）/ 品类正面竞争

## 附录 B · 暴走英雄坛营销拆解（零买量长尾参照）

**总纲：零买量 ≠ 零营销——花的是创意和内容，让产品自己成为传播素材。**

### B.1 冷启动（2017）：三个免费流量杠杆

1. **画风即营销**：黑白暴走表情包风——应用商店里唯一"长这样"的游戏，且表情包天然可二次创作
2. **TapTap 独游红利**：测试期 9.1 分 → 两次首页推荐 → 8.2 分沉淀
3. **情怀锚点**："文曲星偷练《英雄坛说》"一句话锁定目标人群

### B.2 放大期：把内容做成广告

1. **IP 生态链自建**：同名漫画（腾讯/网易漫画/有妖气连载，原班人马绘制，画风与游戏一致）+ 同名网文——**漫画/小说即广告**
2. **UGC 斗图大赛**：玩家自产表情包 = 微信时代的裂变货币
3. **背书矩阵**：暴走大事件/屎蛋说站台 + 斗鱼推荐位 + 咪咕互娱联合发行（渠道信用借力）

### B.3 长线（贯穿 9 年）

奇葩数据 PR（"78% 玩家上吊过"/男女 7:1）· 制作者人格化（老赵混论坛）· 热点借势 · 周年庆 + IP 联动（镖人/奶龙）

### B.4 翻译到 placement-wuxia

| 暴走的招 | 本项目动作 |
|---|---|
| 表情包画风 = 社交货币 | 2.5D 像素做出可晒辨识度；武林碑碑文/谢幕小记设计成"炫耀或自嘲皆可分享"的卡片 |
| 漫画/小说即广告 | AI 让内容 IP 化成本趋零：活人感事件输出条漫/段子/海报周更 |
| 奇葩数据 PR | 月度"玩家数据趣味战报"（"本服 62% 的大侠上辈子练剑"）——代际数据天然更有戏剧性 |
| 制作人人格化 | 官方"掌门"人设混社区 |
| 周期大事件 | 武林碑赛季制（碑文重刻仪式） |

⚠ **警示**：2017 TapTap 红利 + 暴走漫画国民心智不可平移；2026 微信自然量更贵——**营销素材必须一期内嵌（素材即玩法，裂变即系统）**。

## 附录 C · 本项目增长模型与财务测算

### C.1 增长阶梯（三级火箭 + 四道闸门）

| 闸门 | 指标 | 未过的处置 |
|---|---|---|
| G1 质量 | 次留≥40%、7留≥15%、激励视频 eCPM 30-80 元 | 不过闸不点火，继续调优 |
| G2 裂变 | 分享率≥10%、裂变 CPA ≤ 买量 CPA 的 1/5（跑通产品可低至 ¥0.5） | 裂变降级为锦上添花 |
| G3 投放测试 | 小额 1-5 万跑，**LTV90 ÷ CPA ≥ 1.5** 才放量 | 回产品继续调 |
| G4 放量 | 投放 1.7-5 万/天（腾讯阶段表初阶→进阶）+ 自然量（微信生态自然量流水占比可达 50%+） | — |

### C.2 100 万月流水的翻译

```
100 万/月 ≈ DAU 2-5 万 × 混变月 ARPU 5-15 元
         ≈ 日新增 5,000-15,000（裂变+自然量+投放持续供给）
         ≈ 投放 1.7-5 万/天 + 自然量
```

### C.3 利润三情景（税前、月）

|---|---|---|---|---|
| A 纯自然+裂变 | ≈0 | 56.5-63 万 | **52-60 万** | 52-60% |
| **B 轻投放（规划中位数，Leo 08-30 拍板）** | 20 万 | 56.5-63 万 | **32-41 万** | 32-41% |

### C.4 商业化双轨制（Leo 拍板 B 情景；公司主体已有）

- **轨道 1（现在）**：IAA 先行验证——无版号要求，先攒留存/裂变/90 天 LTV 数据
- **轨道 2（并行）**：版号申请（企业资质+软著+版号，周期 6-12 月+，内容稳定后提交）→ 到手开 IAP，利润结构升级
- 平台杠杆：腾讯广告金（内购分成 6:4，综合折算分成约 70%）、游戏优选/新游腾飞方案、非广告自然量（分享/搜一搜/种子计划）

### C.5 投放岗规划

- **触发条件（三条全满足才招）**：G2/G3 闸门过、日预算计划≥数千元/天、产品迭代占满创始人时间
- **画像**：投放+素材混合岗（AI 素材已可替代 ~50% 人工素材）；15-25k/月 + ROI 绩效
- **KPI**：首日/7 日付费 ROI、CPA、素材生命周期（行业均值 3-7 天）
- 备选：发行合作（让利 30-50% 换量）——fallback，不首选

### C.6 APP 双端评估（Leo 08-30 问）

- **判定：有必要，但为第二曲线（M12 闸门前不考虑）**——行业头部通行路径即"小游戏验证 → 双端放大"（寻道大千/无名之辈/一念逍遥/叫我大掌柜）
- **四价值**：买量渠道×3（字节/硬核/TapTap）、用户资产自有、付费深度（APP ARPPU 更高）、出海通道（小妖问道港台首月 2300 万）
- **成本真账**：TS+Canvas 逻辑层 100% 复用，APP=壳+平台适配层；真成本在渠道 SDK/多机型/双端运营
- **触发条件**：次留 40%+ 月流水 30 万 + 版号到手 + LTV 成立 → 建议 M18+ 启动
- **中间形态**：微信 PC 端适配（活跃+55%/商业规模+40%）零成本先做，一期上线即含

### C.7 OKR 阶梯（M24 视角）
