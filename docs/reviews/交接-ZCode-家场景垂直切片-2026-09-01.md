## 4. 🔴 踩坑清单（每条都是规范，ZCode 实现必读）

| # | 坑 | 规范 |
|---|---|---|
| 1 | 帧尺寸不一 → 走动时大小跳变 | 切帧**禁止逐帧 bbox 裁切**；统一网格画布 |
| 2 | 人物横向漂移 → 闪烁 | 每帧按非透明像素质心对齐到统一位置 |
| 3 | 白衣被抠穿 | 白底抠图**禁止纯亮度阈值**；用**边缘泛洪连通性判断**（脚本已验证：`proto` 迭代中写的 flood_cut） |
| 4 | 帧间形象重绘 → 走路不自然 | **AI 一次性直出多帧表不可用**；必须"单帧形象锚 → img2img 逐姿势生成（每帧独立目验）→ 程序合成循环" |
| 5 | 8x8 直出被模型降级 | gpt-image-2 忽略静止帧约束、seedream 砍成 4 行——**长网格指令不可靠**；拆行/拆姿势生成+脚本拼接 |
| 6 | 停下切换帧跳大 | 所有帧**统一画布+人物视觉高度一致+脚底/质心双对齐** |
| 7 | 渲染比例错乱 | 用 **height 定尺**（画布等高），禁用 width 定尺；"屏高占比"要经画布纵横比换算 |
| 8 | 浏览器缓存旧素材 | 资源 URL 全部加版本参数（cache-bust） |
| 9 | 精灵图局部坏格 | **单格修复法**：img2img 单独生成该格 → 按格内人物高度缩放 → 脚底对齐贴回（不整图重生成） |
| 10 | 左右向形象不一致 | **right = left 镜像**（一张图翻转），不单独生成 |
| 11 | 素材白边 | 泛洪抠图后对背景邻接亮像素做半透明衰减（羽化） |
| 12 | 人物悬浮感 | 锚点=脚底中心；脚下椭圆影子（窄而深）；translate 偏移量随画布实测 |
