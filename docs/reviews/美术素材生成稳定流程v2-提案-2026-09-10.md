# 美术素材生成稳定流程 v2（提案）

> 2026-09-10 · 美术 PM2 起草 · 目的：**终止"生成→交付→返工"的循环**，让每批素材一次到位
> 依据：2026-09-10 全天 T45 返工记录（清杂 3 轮 / 归一 4 轮 / 头尺测法两侧 7+ 种全废 / 左向整线作废）
> 性质：**提案，待 Leo 拍板后落规范**

## 0. 核心原则（一句话）

> **把"一致性"从后期救火（缩放 / 测量 / 标注）移回生成约束 + 一次性拍定的尺度表；每一条判据都必须可机械复算。**

今天的来回，本质是**在下游用不可靠的手段去修上游的不一致**——所以永远修不干净。新流程把保证前移。

## 1. 三道锁

### 锁 1 · 生成端锁比例（治"批间/跨代不一致"）

1. **单一比例锚图**：所有动作帧生成的第 1 参照**永远是同一张定稿的全身站立参考帧**；prompt 固定声明"角色高度与比例严格照参照图，不缩放、不拉伸、不改头身比"。
2. **一族一表**：同一动作族（如 walk3 + atk4 + jump3）尽量**在一次生成里出**。
   依据（今天实测）：同一次生成的同一张表内，源 bbox 高一致性 **0.5%**（atk 组 214/214/214/215）、动作族内 ≤2%。
3. **马尾约束（今天新增）**：prompt 锁定马尾落点范围、禁大幅甩动。
   依据：**马尾是"头忽大忽小"感知的最大干扰源**——跑动时甩到背后上方，直接改变头部剪影；同尺度叠加显示头骨是对齐的、差异全在马尾与步幅。
4. **禁跨代视觉比对**：新生成帧**不得**与上一代保留帧做"看起来一致"的比对（比例对不上就是无解，只会来回）；跨代一致性由尺度表保证，不用眼睛。

### 锁 2 · 尺度表驱动（治"尺度争议"，**最关键**）

1. **唯一的尺度定义 = 全像素 `alpha>32` 的 bbox 高**（100% 可机械测、零争议、可复算）。
2. **一张表**：每个「动作族 × 方向」一个目标 bbox 高，**由 Leo 一次性圈定**（形式上等同今天圈 0.780，但这次一次圈完整张表，约 8~12 个数）。
3. **每帧判据**：`bbox高 == 表值 ±1` → 机械可判、不依赖任何标注或人工测头。
4. **禁止**用头/脸/五官等"内容相关量"当缩放锚。
   依据：今天两侧合计 7+ 种测法（暗色跨度、肤色块、发冠、模板匹配、颅顶→脸底、双眼距、垂直投影 span）**全部未通过保留帧自验证**；且都会被马尾污染。**这条是今天所有返工的根。**

### 锁 3 · 小步门检（治"整批返工"）

1. **样张门**：新动作族 / 新口径 / 新素材批次的**第一件事是做 1 帧样张**，过门才铺量。
2. **分段交**：单次交付 **≤10 帧**（今天实测有效：10 帧返工 ≠ 30 帧返工）。
3. **口径先行**：任何加工类动作（清杂/归一/抠底/镜像）开工前先落「判据 + 自证格式 + 异常码」。
   依据：清杂 SOP 落地后**下一轮一次就过**；未落 SOP 的归一连翻 4 轮。
4. **兼容性复核**：引入**新的不对称元素**（武器/披风/单侧配饰）时，先跑"老规则前提是否被打破"清单。
   依据：`左 = 右镜像` 的前提是角色左右近似对称；**单手武器打破它**，导致左向 33 帧整线作废，并波及历史 48 行标定 + 26 行左系派生。

## 2. 每帧固定流水线（8 步，每步都有机械判据）

| # | 步骤 | 机械判据 |
|---|---|---|
| 1 | 生成 | 比例锚图 + 一族一表 + 马尾约束 |
| 2 | 隔离 / 抠底 | RGBA；alpha 极值含 0 与 255；四边零 alpha；主体单连通（`alpha>32` + 4 邻接） |
| 3 | 清杂 | 元素（连通域）为单位；**主体域删除像素=0**；两类自证 |
| 4 | 归一 | **`bbox高 == 尺度表值 ±1`**；脚底 y=300；质心 x=120（动作帧 ±20） |
| 5 | 无裁切断言 | `输出 bbox == round(源裁框 × 系数) ±1`（宽高各一） |
| 6 | 互异与抽查 | 帧间 SHA 互异；一致性抽查只看**排除马尾的头骨形态**（只作参考，**不作缩放依据**） |
| 7 | 对照图 | **必含基准帧**、同基线（仅用于目验，不用于定尺度） |
| 8 | 交付 | ≤10 帧/批；附自报数 + 逐项证据；PM2 独立复跑门检 |

## 3. 今天踩过的坑 → 新流程怎么防

| 今天的坑 | 新流程的防线 |
|---|---|
| 清理削到主体、判据口径不符 | 锁 3-3 口径先行 + 步骤 3 主体零改动自证 |
| 归一反复（0.796→0.780→重标） | 锁 2：bbox 高 + 尺度表，尺度不再"测" |
| 头尺 7 种测法全废 | 锁 2-4：禁内容相关量当锚；头只作抽查参考 |
| 马尾导致"头忽大忽小" | 锁 1-3 马尾约束 + 步骤 6 只用头骨形态 |
| 左向整线作废 | 锁 3-4 兼容性复核（引入不对称元素必跑） |
| 整批返工 | 锁 3-1 样张门 + 锁 3-2 分段交 |
| 交付带 6 对重复帧 / 尺度崩一半 | 步骤 5/6 无裁切断言 + 帧间互异 + 尺度表 |
| 长线程判据衰减 | 线程轮换 + 上下文卫生（已落 SKILL §12） |

## 4. 落地步骤（建议）

1. **Leo 圈「动作族 × 方向 目标 bbox 高表」最小版**（右向 idle/walk/atk/jump 四族；约 4~12 个数）。
2. PM2 把本流程落进《美术素材生成流程规范》+ codex SKILL（判据、自证格式、异常码）。
3. **用一个动作族做全流程样张**（1 帧 → 门检 → 铺量 3 帧），验证流程本身。
4. 通过后成为标准流程；T45 现有帧按新表复核；左向等兼容性结论。
5. 之后所有新素材（NPC/场景/UI）沿用同一套"三锁 + 8 步"。

## 5. 待 Leo 拍板（四项）

1. **是否采纳「bbox 高 + 尺度表」取代"头尺锚"**（锁 2）——这是止住返工的关键。
2. **马尾约束是否入 prompt 规范**（锁 1-3）。
3. **是否接受"一族一表"的生成排产**（同族一次生成；影响排产方式）。
4. **保留帧（旧 idle/cast）怎么办**：与新一代比例若确有差异，是重生成旧帧求全一致，还是承认两代并存、靠尺度表兜住（今天叠加显示站立帧比例一致，此项可暂缓）。
