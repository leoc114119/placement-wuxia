## 2. 结构性问题（7 类，逐条附今天的实例）

1. **规格滞后于实现**——口径是被动补的。清杂 SOP、三类证据、旋转不变、放置回落、信箱纪律……**全部是翻车之后才写的**；写进去的那条（清杂）下一轮就过 ✓，没写的就继续翻。
2. **尺度真源不可机械验证**——"这一帧的人物大小对不对"**至今没有一个可复算的定义**。基准是"保留的 idle"，但比对新帧与基准靠人眼；中间量（头 span）两侧都测不准。**今天所有尺度来回的总根因在这里。**
3. **手标注混在自动化管线里**——关键尺度锚靠"人眼点两个解剖点"。这个量既不可复算，也对姿势敏感（歪头 → 垂直投影变短 → 该帧被放大 4.8%）。
4. **批量生成 / 批量返工**——一次做 10~30 帧，任一处口径错即整批作废。今天已改"分段交"（先 7 帧），但这是补丁，不是流程。
5. **验证方依赖被验证方的自报**——门检如果只复算对方的推导表，就等于用对方的尺子量对方的活（今天 PM2 犯过这个错，被 Leo 目视抓出）。
6. **规则未随素材/机制演进复核**——"左=右镜像"是**无武器时代**的规则（当时看不出手性）；引入单手武器后没人重新验证它是否还成立 → 整条左向路线白做。
7. **上下文寿命无管理**——5 天 472 轮、68 次压缩 → 早先判据被摘要掉 → 反复重推已定事项（已用线程轮换治，但属事后）。

## 3. 总根因（一句话）

> **管线缺一个"稳定、可机械验证的真源"**——人物尺度没有可复算的定义；规则又没随素材演进复核。
> 于是每一环都退化成"靠人眼判断 + 事后打补丁"，而人眼判断在两侧不一致时就必然来回。

## 4. 重构方向（四条，按性价比排序）

### A. 尺度真源机械化（**最高优先**，直击总根因）
把"人物尺度"从"头尺"换成 **100% 可机械测量的量 + 一次性拍定的目标表**：

- **测量量 = 全像素 `alpha>32` 的 bbox 高**（无歧义、可复算、零争议）。
- **目标表 = 按"姿势族"定目标高**（站立 256 / 行走 / 蹲 / 腾空 …），**由 Leo 一次性圈定**（就像今天圈 0.780 那样，但这次是圈"每族一个数"）。
- 每帧判据：`bbox 高 == 该族目标高 ±1`（**机械可判、可复算、不依赖任何标注**）。
- 代价：**Leo 花一次时间圈那张表**（约 6~8 个数）。收益：**从此尺度不再需要"测"**，也不再有"投影 vs 轴线""斜头"这类坑。

### B. 样张门（缩返工半径）
新类别、新口径、新素材批次的**第一件事是先做 1 帧（或 1 组最小样张）**，过门后才铺量。
今天已自发形成两例（右侧 pilot、分段交 7 帧），把它变成明文流程。

### C. 口径先行（把"翻车才补"反过来）
任何**加工类动作**（清杂/归一/抠底/镜像/锚定）开工前，先落：判据口径 + 自证格式 + 异常码。
依据：清杂 SOP 落地后**下一轮一次就过**；未落 SOP 的（归一）连翻 4 轮。

### D. 规则兼容性复核（防"老规则带到新机制"）
素材或机制演进时（例：从无武器 → 带单件武器），先跑一张**兼容性清单**：
- 这条老规则的前提是什么？新机制是否打破前提？（例：镜像的前提=角色左右近对称 → 单件武器打破它）
- 受影响范围？（例：不只是新帧，历史 48 行标定 + 26 行左系派生同样在错路线上）
**触发点**：引入"新的不对称元素"（武器/披风/独眼/单侧配饰）时必跑。

## 5. 落地顺序（建议）

1. **D 立即做**（1 页清单）：先判断"左=右镜像"这条要不要废/怎么改——**它卡着 33 帧的走向**，越晚越贵。
2. **A 本周做**：出那张"姿势族目标高"表的最小版（6~8 个数），Leo 圈定 → 落规范 → 之后所有尺度判据改用它。
3. **B/C 立即写进规范**，从下个批次开始执行（成本≈0）。
4. T45 当前进度：右向 10 帧**按新判据（A）复核一遍**；右向锚点/遮罩保留；左向冻结等 D 的结论。
