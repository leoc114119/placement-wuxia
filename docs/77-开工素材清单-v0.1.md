## 0.1 立绘动效输出方案（Leo 2026-08-19 定：移动两脚/出招挥手需真实帧）

> **核心决策**：移动/出招/普攻需要**少量真实动作帧**（AI 出帧）；受击/命中效果、光影、飘字等用**代码**（不占帧）。**同一角色的所有帧合成一张「动画分帧表」生成**，解决 AI 多帧一致性漂移问题。

### 帧需求清单（每个战斗角色通用）

| 动效 | 帧数 | 帧内容 | 谁做 |
|---|---|---|---|
| **待机 idle** | 1 | 静态站立 | AI 出帧（已有 hero_idle） |
| **移动 walk** | **4** | **起步抬腿 → 迈出 → 落地 → 另一脚跟步（四帧循环，Leo 定，参考老网金）** | AI 出帧 |
| **出招 attack**（外功/绝学） | **2** | **举手预备 → 挥手挥出（Leo 定）** | AI 出帧 |
| **普攻 basic** | **1** | **正面出拳 / 出剑（帧数少，Leo 定）** | AI 出帧 |
| **受击 hit** | **0** | **角色不动，只有命中效果（光效/粒子/闪白，Leo 定）** | 代码 |
| **miss** | 0 | 未命中提示（F-04 判定后显示「miss」飘字） | 代码（后补） |
| **反击 counter** | 0 | 被击后概率触发，复用出招帧 + 反击特效 | 代码（后补） |

> **每个角色合计 = 8 帧**（idle1 + walk4 + attack2 + basic1），合成 1 张分帧表。

### 生成方式：动画分帧表（单图多帧，保一致性）

```
同一角色全部动作帧 = 一张「动画分帧表」（model sheet）：
  ┌─────────┬─────────┬─────────┬─────────┐
  │ 待机站立  │ 起步抬腿  │ 迈出落地  │ 另一脚跟步 │ ← 行1：待机 + 移动4
  ├─────────┼─────────┼─────────┼─────────┤
  │ 举手预备  │ 挥手挥出  │ 正面普攻  │   ─空─   │ ← 行2：出招2 + 普攻1 + 空1
  └─────────┴─────────┴─────────┴─────────┘
```

- **为什么单图**：AI 多帧分开生成，每帧脸/造型会漂移；**同一张图内排多格**，AI 会按同一角色保持一致
- **切割**：生成后按 2×4 等距格切出 8 张独立透明 PNG（写个 `split_sheet.py`，或由 mxai 返回单图后代码切）
- **Prompt 追加**（76 风格前缀之后）：
  > **Q版水墨国风同一角色动画帧表，2行×4列等距排列，八格动作依次为：①待机站立 ②起步抬左腿 ③左脚迈出落地 ④右脚跟步 ⑤举手蓄力 ⑥向前挥手挥出击出 ⑦正面普攻出拳/出剑 ⑧空白，每格角色完全相同、造型服装一致，纯白背景，每格独立完整全身，无任何文字无水印**
- 优先级：**主角（hero）帧表 P0**（玩家常看）；NPC/狼王帧表 P0（战斗必用）；好友可临时复用 hero 帧表（P1 换专属）

### 代码动效（不占帧，75 §5b 已有定义）

| 效果 | 实现 |
|---|---|
| 待机呼吸 | 立绘上下浮动 + 脚下阴影呼吸缩放 |
| 受击命中 | **角色不动**，身上播命中光效 + 闪白 + 伤害飘字（Leo 定） |
