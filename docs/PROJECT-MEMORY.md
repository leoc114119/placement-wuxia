## 2. 技术栈（已定，不换）

- TypeScript + 原生 Canvas 2D + 微信云开发（微信小游戏）
- 构建：微信开发者工具；渲染：Canvas 2D（自走棋无需引擎）
- 美术目标（**2026-09-01 午风格锚 v9 定稿**，Leo 6 轮样张目验）：**铃兰之剑式精美像素 × 武侠皮 × 暖调怀旧光影**——细颗粒小色块、6-8 级色阶、材质区分、刺绣像素级可读、戏剧性光源（壁炉/灯笼+光晕+长影）、深木暖调；**双轨头身比：立绘 4-4.5 头身 / 地图小人 2.5-3 头身**；**室内=透视盒子（物件 3-4 倍角色高、占比 15-20%）/ 室外=tile 大地图（物件 ≤1.5 倍、占比 ≈13%）**（08-23 场景尺度铁律仅限室外）；怀旧靠色不靠粒；场景氛围锚 `assets/ui/ref_pixel_scene_v9.png`（PASS）；管线=v8 生图→像素网格对齐→色板量化；标定过程存 `assets/ui/drafts/style_calibration/`
- **🔴 大地图转向（2026-09-01 晨 Leo 三点拍板，沉浸感准绳）**：① 视角 = **斜俯视 3/4 tile**；② 角色比例 = **暴走式 ≈13% 屏高**（渲染高 ≈170px@750×1334，待实测定稿）——为**换装 + 人物外形特效**留结构（角色分层渲染：身体+装备+特效）；③ 移动 = **点击移动**（单手放置友好，MVP 不上 A*）。**大地图 + 镜头跟随 = "人在江湖"的物理载体**（Leo 体验暴走英雄坛小游戏版后确认："能走动才有沉浸感"）。**场景物体 ≤1.5 倍角色高的比例关系保留，档位从 17.5% 下调至 13%**（08-23 铁律改写）。设计详见 `docs/design/01-基础功能/场景系统与地图.md`
- **大地图连带新增（素材管线）**：**八向行走帧**（上下左右+四对角×3-4 帧=24-32 帧/角色，Leo 纠正四向→八向：点击自由移动下对角是常态）+ **NPC 静态驻留**（站立待机 1-2 帧，不做八向，Leo 定）+ **战斗帧改四向**（上下对称镜像战棋，敌可任意方向接敌；上下各绘1+左右互翻=实际绘 2 向；08-23「侧视两向」旧口径作废）；场景从 AI 整图转 **tileset 拼装 + 5×5 sheet 无缝拼接**（地图编辑器优先级上调）；T10 素材清单待增补、T11 UI 风格锚偏复古像素窗口感
- **🔴 包体硬约束（2026-08-31 核实，微信官方一手）**：**主包 ≤4MB / 整包 ≤20MB**；**30MB 仅对「已开通虚拟支付」的小游戏开放**（官方 2023-10-09 公告）。我们一期 IAA 先行、版号未下 → **只有 20MB**，版号下来开通虚拟支付后自动升 30MB（无需改代码）。远程 CDN 无硬上限但**不得放可执行 JS**（玩法逻辑体积省不掉，只能外置资产）。详见 `docs/research/03-平台与技术/微信小游戏包体与资源加载.md`（v0.2，含重度 MMO 路线对照）
- **🔴 资源外置架构约束（2026-09-01 定，面向 ZCode 的一期架构要求）**：素材引用**一律走统一资源管理器 + 配置表，禁止代码里写死本地资源路径**。理由：微信小游戏**不支持加载本地 Bundle**，重度内容最终都得走 CDN 运行时下载（天龙八部荣耀版即此路线）；一期 20MB 够用 ≠ 二期够用，架构不预留则后期挪 CDN = 全量重构。中文字体与 BGM 一期即按外置规划
