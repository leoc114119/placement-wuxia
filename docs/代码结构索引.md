# 代码结构索引（常青更新）

> 查代码先来这里。架构原则见 `AGENTS.md`：客户端只展示、后端只结算；公式唯一真值在云函数 settle（ADR-002）；`config/numbers.ts` 只放只读展示参数（ADR-004）。

## 1. 入口与类型

| 文件 | 说明 |
|---|---|
| `game.ts` / `game.js` | 入口：主循环 + 场景切换（RAF 三路兼容层：canvas.RAF→全局→setTimeout） |

| `project.config.json` | 微信小游戏配置（appid=touristappid，禁编造） |

| 文件 | 说明 |
