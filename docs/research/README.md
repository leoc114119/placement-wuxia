## 0. 五条铁律

1. **一个知识主题 = 一个文件**：新调研先看本索引，同主题有文件就**直接更新它**（文件末尾写变更记录），**禁止新建 v2 / 续篇 / 补充篇**
2. **不按批次编号**：不再累加 98、99、100… 这类流水号；按下面的知识域归档，文件名用主题名
3. **结论与详情分离**：调研形成的**项目约束 / 决策 / 拍板** → 写进 `PROJECT-MEMORY.md`（常青单一真源）；**详细内容、数据、出处、推导** → 留在这里
4. **数据必须标置信度**：`高`（官方一手）/ `中`（多源交叉）/ `低`（推算）。**低置信度数据不得在别处引用为事实**
5. **新文件当天登记**到本索引，并在 `docs/文档总索引.md` 同步
