# 通用异常处置表（common-pitfalls）

> 症状 → 判定 → 处置 → 重跑权限。处置栏「上报」= 按 SKILL.md §3 格式写进报告卡点节。
> 逐字 prompt 引用与本表冲突时，以类别文件为准。

## A. 环境（E-ENV）

| 码 | 症状 | 判定 | 处置 | 重跑 |
|---|---|---|---|---|
| E-ENV-01 | `echo ${MX_AI_API_KEY:+OK}` 无输出 | API key 未 source 或未配置 | 重开 shell `source ~/.zshrc` 一次；仍无 → 上报（需 Leo 检查 zshrc） | 1 |
| E-ENV-02 | 脚本文件不存在 | 路径拼写核对 | 拼写无误仍缺 → 上报（禁找替代脚本） | 0 |
| E-ENV-03 | python/node 依赖缺失（ImportError 等） | — | **禁自行 pip/npm install**，上报缺失清单 | 0 |
| E-ENV-04 | 引用的参照/配方文件不存在 | `ls` 核对路径 | 不存在 → 上报（**禁挑"差不多"的文件替代**——替代=自由发挥）。配方文件名按类别文件给死的用；给匹配规则的按规则唯一匹配，匹配不唯一 → 上报 | 0 |
| E-ENV-05 | 输出目标重名已存在 | — | 停上报，禁覆盖禁加后缀 | 0 |

## B. 生图（mxai_gen.py / mxai_img2img.py，E-GEN）

| 码 | 症状 | 处置 | 重跑 |
|---|---|---|---|
| E-GEN-01 | API 报错/超时/限流 | 同命令重跑 1 次；再失败上报 | 1 |
| E-GEN-02 | 返回图 PIL `verify()` 失败/打不开 | 同命令重跑 1 次；再失败上报 | 1 |
| E-GEN-03 | 画面出现文字/数字/水印 | 同 prompt 重跑 1 次；再犯上报附图（**禁裁剪遮盖**） | 1 |
| E-GEN-04 | 主体缺失/多主体/画了手或人物（要求单体武器/头像时） | 同 prompt 重跑 1 次；再犯上报附图 | 1 |
| E-GEN-05 | 背景明显非纯白（PIL 实测角部色值，任一通道 <245 或 RGB 通道差 >12） | 记录实测色值，上报（抠图前口径问题，禁自行处理） | 0 |
| E-GEN-06 | 尺寸不符任务书预期 | 记录实际尺寸；若为 1K 档常见 1280×1280（1:1）属**正常事实**不处理；偏离任务书写死的校验值 → 上报 | 0 |
| Q-STYLE | 风格不像/不好看/构图怪 | **无权判**：直接进入停点交 Leo，禁重摇 | 0 |

## C. 抠图（E-CUT）

| 码 | 症状 | 处置 | 重跑 |
|---|---|---|---|
| E-CUT-01 | `mxai_web_cutout.js` 报登录态失效/页面超时 | 重试不超 1 次；再失败上报（需 Leo 重新导出 `/tmp/mxai_localstorage_full.json`）。**禁回退本地脚本清除** | 1 |
| E-CUT-02 | `cutout_white_bg.py` 结果全透明/全不透明（flood 失灵） | 检查输入确为纯白底（角部实测）→ 是则上报；非纯白底先走 E-GEN-05 | 0 |
| R-RESIDUE | 抠图后边缘白残留/封闭白（triage 报警） | **只检测记录**（audit/triage exit 码+块数），清除已废止统一 mxai 接口——试产阶段记录后停上报，等 Leo 决定 | 0 |

## D. 脚本/校验门（E-GATE）

| 码 | 症状 | 处置 | 重跑 |
|---|---|---|---|
| E-GATE-01 | `build_*`/`process_*`/`audit_*` exit≠0 | 先读 report.json/stderr 定位失败项 → 对照该类别文件的异常分支表；无法定位 → 上报附完整 stderr + report.json | 视上游 |
| E-GATE-02 | 校验门失败但根因在上游生图（如尺寸错/空图） | 按上游对应 E-GEN 码处置，不重复计门失败 | 随上游 |

## E. 锚定表（E-ANCHOR）

| 码 | 症状 | 处置 | 重跑 |
|---|---|---|---|
| E-ANCHOR-01 | img2img 返回图的左格与源帧像素 diff≠0（左格被改动） | 该张**作废**，同命令重跑 1 次；再犯上报附 diff 数值。判读脚本见 c03 步骤 4 | 1 |
| E-ANCHOR-02 | 右格空白（未生成内容） | 同 E-GEN-04 处置 | 1 |
