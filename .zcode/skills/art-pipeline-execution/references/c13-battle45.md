## 新视角初始化（文生图首锚，本类独有步骤）

45° 为全新视角，无现成左格——每向首锚走文生图，**Leo 目验定锚后**才得以该锚为左格锚定表铺量：

1. 文生图：`python3 scripts/mxai_gen.py --prompt "$(cat prompts/anchor45_<向>.txt)" --out raw/anchor45_<向>_raw.png --aspect 3:4`（2 分）
2. 抠图：mxai 统一通道 → 透明底
3. 归一：PIL 缩放入 240×320 画布、**人物视觉高 256px、脚底基线 y=300、质心 x=120**（红线 9 标准）；宽高比带 0.40~0.55 出界=FAIL 记录
4. **停点交 Leo 目验**：视角（俯视头身可见头顶肩）/头身比（2.5~3）/形象一致性（铃兰式特征）/空拳无武器——**不过不铺量**

### 首锚 prompt 模板（六向制：右系基础模板，朝向句按向替换；down 向旧模板作废）

```
精美像素风格游戏角色立牌，单独一个中国武侠少年，45度俯视视角：可见头顶发旋与双肩，<朝向句>。黑色高马尾青绿发带白玉冠，青绿汉服白衬袍深色腰封，白色灯笼裤黑布鞋，双手握空拳成戒备站姿（无武器，腰间无挂物），双膝微曲重心略低。纯白背景，单人全身，无文字，无水印。
```

- `<朝向句>`（辅助词条，最终以白模站姿图为准）：右向=「侧面视角：面朝画面正右方，身体侧对镜头」；右上向=「背斜侧视角：面朝画面右上方，以可见后脑与右肩为主」；右下向=「正斜侧视角：面朝画面右下方，双眼与右颊可见」。山贼锚 prompt（批 2a'）：同结构，形象换「中国武侠山贼男性：绑头巾、络腮胡、粗布短打、背负朴刀」+ 戒备持刀姿态描述；甲/乙差异特征按既有 `shanzei_a|b/prompts/` 形象描述条款照抄。

## 锚定表铺量（批 1a/1b/1c/2b'）

- prompt 模板：`q_battle_idle_sheet2.txt` 句式族，右格姿势描述逐姿势一词条（行走迈A/迈B、轻功起跳蜷缩/腾空、普攻起手/挥击/收招、施放聚气/释放/收招、死亡躺平），姿势词条文本随任务书给死，禁代理自拟。

- 入库脚本：轻量版（mxai 抠图 + PIL 归一），**禁入 build_battle_frames.py 旧管线**（其 scale 逻辑为 v5 正面口径，45° 不适用）。

## 异常分支

- 锚目验不过 → 整批停，改 prompt 重出锚（重摇权 Leo）。
- 锚定表左格 v2 FAIL → 重跑 1 次 → 上报（同 c03）。
- 右格凭空武器（主角系）→ 机械失败重跑 → 再犯上报。
- 45° 透视感不稳定（时俯时平）→ 审美性，数据记录交 Leo。
