# 类 13 · 战斗帧 45° 俯视（T45 · 78 张）—— 专用手册

> 依据：角色帧规范 §4c（视角/画布/帧集，v1.2 空拳勘误版）+ §4b（空拳+武器分层）+ 任务书 T45-battle45。
> 视觉基准：`assets/ui/pixel/battle/raw/battle_v8.png`（直立立牌微俯视、可见头顶与肩、2.5~3 头身、人高≈1.5 格）。
> 形象锚：ref_hero_v1 铃兰式（绿衣小虾米）战斗姿态化，**空拳口径**（武器由 FE 按锚点叠加，身体帧禁任何武器）。
> 敌人（山贼甲/乙）**持朴刀**（§4b 敌人不剥离，武器固定入帧）。

**预算上限：90 张 = 180 分**（78 + 重摇余量 12）；超限停上报；重摇权归 Leo。
**校验门**：锚定表族一律 `--aspect 2:1` + `check_left_v2.py`（规范 §2.3）+ 双主体高度比 ∈ [0.9,1.1]。
**呼吸帧程序化**（两帧循环，禁 AI 重绘）；受击无帧（代码震动）。
**画布（09-04 勘误，对齐 T06 旧 battle 小表）**：**128×256/帧**；归一目标=人物包络占格高 ≥93%（高 238~254px）、**宽高比 0.45~0.55（门，出界=FAIL 记录）**、底边贴格底（y=256）、水平居中；45° 帧渲染绝对人高待 FE renderH 定尺。
**命名**：`{动作}_{向}_{序号}.png`（如 `battle_idle_down.png`、`walk_down_1.png`、`die_down.png`）；落盘 `assets/characters/hero/battle45/`、`assets/characters/enemy/shanzei_a|b/battle45/`。

## 新视角初始化（文生图首锚，本类独有步骤）

45° 为全新视角，无现成左格——每向首锚走文生图，**Leo 目验定锚后**才得以该锚为左格锚定表铺量：

1. 文生图：`python3 scripts/mxai_gen.py --prompt "$(cat prompts/anchor45_<向>.txt)" --out raw/anchor45_<向>_raw.png --aspect 3:4`（2 分）
2. 抠图：mxai 统一通道 → 透明底
3. 归一：PIL 缩放入 **128×256 格**、包络高 244px（占格 95%）、底边贴 y=254、水平居中；宽高比门 0.45~0.55（09-04 勘误对齐旧表，与画布段一致）
4. **停点交 Leo 目验**：视角（俯视头身可见头顶肩）/头身比（2.5~3）/形象一致性（铃兰式特征）/空拳无武器——**不过不铺量**

### 首锚 prompt 模板（主角 down 向，逐字使用；up/side 替换朝向描述句）

```
精美像素风格游戏角色立牌，单独一个中国武侠少年，45度俯视视角：可见头顶发旋与双肩，面朝镜头略偏下。黑色高马尾青绿发带白玉冠，青绿汉服白衬袍深色腰封，白色灯笼裤黑布鞋，双手握空拳成戒备站姿（无武器，腰间无挂物），双膝微曲重心略低。纯白背景，单人全身，无文字，无水印。
```

- up 向替换朝向句：「面朝镜头背对视角：可见后脑马尾与背部」；side 向：「侧面视角：面朝画面右侧」。
- 山贼锚 prompt（批 3a）：同结构，形象换「中国武侠山贼男性：绑头巾、络腮胡、粗布短打、背负朴刀」+ 戒备持刀姿态描述；甲/乙差异特征按既有 `shanzei_a|b/prompts/` 形象描述条款照抄。

## 锚定表铺量（批 1/2b/3b）

每姿势构造 2 格表（左格=该向锚，右格目标姿势）→ `mxai_img2img.py --aspect 2:1` → `check_left_v2.py` + 高度比门 → mxai 抠图 → 归一 240×320 → 命名入库。
- prompt 模板：`q_battle_idle_sheet2.txt` 句式族，右格姿势描述逐姿势一词条（行走迈A/迈B、轻功起跳蜷缩/腾空、普攻起手/挥击/收招、施放聚气/释放/收招、死亡躺平），姿势词条文本随任务书给死，禁代理自拟。
- 死亡帧=单张躺平不分子向差异（同向内仍按向出）。
- 入库脚本：轻量版（mxai 抠图 + PIL 归一），**禁入 build_battle_frames.py 旧管线**（其 scale 逻辑为 v5 正面口径，45° 不适用）。

## 异常分支

- 锚目验不过 → 整批停，改 prompt 重出锚（重摇权 Leo）。
- 锚定表左格 v2 FAIL → 重跑 1 次 → 上报（同 c03）。
- 右格凭空武器（主角系）→ 机械失败重跑 → 再犯上报。
- 45° 透视感不稳定（时俯时平）→ 审美性，数据记录交 Leo。

## 停点产出（每批）

- contact sheet + check_left_v2 数值 + 高度比记录 + credits + 命名入库清单。
- 批间 Leo 目验通过才发下一批任务书。
