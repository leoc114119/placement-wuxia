## 1. 目标

按 NPC Schema v1.0 实现**数据驱动 NPC**：加载器扫描 `assets/npcs/*/npc.json` → 家场景渲染 NPC → 点击敌对 NPC 触发喊话并进入战斗（用首个示例 `bandit_home_test` 验证 MVP 闭环）。

## 2. 需求表（唯一真相，细化见 Schema 文档 §5）

| # | 需求 | 验收口径 |
|---|------|----------|
| 1 | 加载器：扫描 npcs/*/npc.json + schema 校验（缺字段/未知 type 报警降级 ambient） | 校验单测：正常包+异常包各 1 用例 |
| 2 | 场景渲染：按 spawn 挂 NPC（idle_frame 静止帧+scale+facing），点击命中判定盒 | 家场景可见可点 |
| 3 | 交互路由：非敌对=弹问候语；敌对=喊话气泡 0.8s → 触发战斗（调 T15 会话，传 battle.unit；战斗帧用 visual.battle_frames 帧组） | 与 T15/T16 接口对切 |

| 6 | 示例数据：`bandit_home_test/npc.json` 按 Schema 文档 §4 落库 | schema 校验过 |
