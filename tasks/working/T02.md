## 1. 目标

搭建可运行的微信小游戏工程骨架，为 T03~T07 提供地基。**本任务不含任何玩法逻辑。**

## 2. 需求表（唯一真相）

| # | 需求点 | 验收口径 |
|---|--------|----------|
| 1 | git 仓库初始化（`.gitignore` 含 node_modules/dist） | `git log` 有初始提交 |
| 2 | 微信小游戏工程结构：`project.config.json` + `game.json` + `game.js` 入口 | 微信开发者工具能导入并打开，无报错 |
| 3 | TypeScript 配置：`tsconfig.json`（strict）+ 构建链 | `npm run typecheck` 0 error |
| 4 | 骨架代码分层（按 AGENTS.md 目录规划）：`game.ts` 入口 + `types.ts` + `config/numbers.ts`（只读展示参数占位）+ `ui/render.ts`（空实现）+ `systems/` + `net/cloud.ts`（mock） | 文件存在且类型咬合通过 |
| 5 | Canvas 2D 初始化：黑色或宣纸色 #F8F4EA 清屏 + 主循环 requestAnimationFrame 跑通 | 开发者工具模拟器显示清屏色，FPS 日志可选 |
| 6 | `npm scripts`：`typecheck` / `lint`（eslint 精简配置） | 命令可跑 |

## 3. 边界

- ✅ 定死：目录结构按 AGENTS.md「目录结构(规划)」；色值用规范色（#F8F4EA 等）
- 🟡 有限自由：tsconfig 细节 / eslint 规则集 / 构建工具选择（建议 esbuild 或 tsc，写明理由）
