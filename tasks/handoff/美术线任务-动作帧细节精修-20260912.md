# 美术线任务：3D→2D 动作帧「细节精修」（gpt-image-2.5 img2img）· 2026-09-12 · PM2 起草

## 一、任务一句话

把我们已交付的动作帧（240×320，PNG-8 无损，六向 × 5 帧）**逐帧过一遍 gpt-image-2.5**，
**只提升细节与清晰度**，**人物 / 姿势 / 配色 / 构图 / 轮廓全都不许变**。

**⚠️ 风格目标（Leo 09-12 明确）**：**保留 3D 渲染质感**——要的是"3D 渲染但更清晰"，
**不是**把它画成 2D 平涂；NPC 的旧 2D 帧只是**清晰度参照物**，不是风格目标。

**起因（Leo 09-12）**：NPC 的旧 2D 帧比主角的 3D 渲染帧**清晰得多**；
主角是 3D 渲染（且我们刻意用 flatcel 压平以求"手绘感"），线条天生比手绘 2D 软。
Leo 裁定走"AI 逐帧精修"这条路，**交美术线执行**。

## 二、⚠️ 技术前提（必须先读，避免走错路）

1. **接口一次只出一张图**：`mxai_img2img.py` 收 1~6 张参考图，但 `image_urls` 返回**一张**。
   ⇒ **"六向一次放进去出六张"不可行** ✗。**必须一帧一张**：把**要精修的那一帧**当底图。
   （多图参考的用途是"让它像这些"，不是"批量输出"。）
2. **生成图没有透明通道** ⇒ 必须**用原始帧的 alpha 蒙版重新抠底**（见 §四②）。
3. **尺寸回缩**：模型在 1K 出图，要缩回 **240×320** 再走 PNG-8（尺寸必须与交付件一致）。

## 四、做法（**大图方案 · Leo 09-12 定**）

> **核心**：**把一个动作的全部帧拼成一张大图**，**一次调用**让模型整体精修，再切回逐帧。
> 比"逐帧 30 次调用"**又省又一致**（模型同时看到所有帧 → 风格不会各画各的；成本 1~2 分 vs 60 分）。

### ① 拼图（拼图脚本由 PM2 提供，或按此规格自建）

- **排布**：一行一个方向、一列一帧 → **6 行 × 5 列 = 30 格**，每格 **240×320** → 大图 **1440×1600**（≈1:1，贴合接口的 aspect 档）
- **格子之间留 4px 分隔线**（浅色细线）：让模型知道这是 30 个独立格子、别把角色画到隔壁 ✓
- 大图背景：与帧一致的深灰（`#0E0E11`），**不要纯黑**（便于看出边缘）

### ② 一次调用精修

**用 Codex 原生生图（`image_gen`，走 Plus 订阅 = 不扣积分）**：
把拼图作为参考图传进去（`referenced_image_paths`），prompt 用下面这份（写成文件，免得转义出问题）。

> ⚠️ 不要用 mxai 通道 —— 那条按积分计费（2 分/张），而原生是免费的（Leo 09-12 明确）。

**prompt（锁死，别改）**：

```
这是一张 6 行 5 列的角色动画帧拼图，每格是一个独立的动作帧，格子之间有细线分隔。
请整张图一起优化，只提升每个格子里人物的细节与清晰度。
要做的：①轮廓更干净锐利、边缘不糊 ②色块边界更明确（袍子/腰带/皮肤/头发之间）
③补充内部细节：发丝分缕、衣襟走线、腰带纹理、靴子车线、五官结构
④整体明暗与现在一致，不要加深或提亮。
⑤★**必须保留现有的 3D 渲染质感**：立体的明暗过渡、布料与头发的体积起伏、
  模型渲染出来的圆润体积感都要保住，只把"糊"变成"清"。
不要做的：不改变任何一格的人物样貌、姿势、朝向、比例、配色；
不移动任何角色在格子里的位置；不改变格子排布与数量；不改动分隔线；
不把相邻格子的人物画到一起；
★**不要把它画成平涂 2D / 线稿 / 水墨 / 厚涂插画**（我们参照的 NPC 2D 帧只是"清晰度参照物"，
不是风格目标——**风格仍然是 3D 渲染**）；
不加高光反射与写实材质；不加背景元素与文字水印。
```

### ③ 切回逐帧 + 抠底（**关键：复用原始 alpha，保证轮廓 100% 不变**）

1. 按**同一网格规格**切回 30 格，每格缩回 **240×320**
2. **用原帧的 alpha 蒙版替换生成图的 alpha**（`alpha>32` 为实心）：

```python
orig = Image.open(原帧).convert('RGBA')
gen  = Image.open(切出的格).convert('RGBA').resize((240,320), Image.LANCZOS)
gen.putalpha(orig.getchannel('A'))
```

> **为什么必须复用原 alpha**：AI 一定会在意轮廓；轮廓一变，循环播放就会**闪**。
> 复用原 alpha 后**外形像素级不变**，只有内部细节是 AI 的 ✓ 这是把闪烁风险压到最低的关键一步。

### ④ 编码

`python3 tools/glb2d/png8_encode.py <目录> <目录>` —— **必须确认输出含 `lossless`**
（显示 `quantized` 说明调色板超 256，要降色或重调，**不可交付有损件**）。

## 五、验收（四条全过才算完，逐条实测）

| # | 判据 | 怎么验 |
|---|---|---|
| ① | **清晰度确实提升** | 精修前后**并排图**（同尺寸、同放大倍数） |
| ② | **轮廓 100% 不变** | 精修件与原件的 alpha 逐像素比对，**必须完全相同** |
| ③ | **动作/姿势不变** | 同一方向的 **5 帧并排**对照原 5 帧；**并把 5 帧做成 GIF 看动不动**（帧间跳＝不合格） |
| ④ | **PNG-8 无损** | `png8_encode` 输出里编码方式必须含 `lossless` |
| ⑤ | **切片没串格** | 每格切出的内容**不越界**（不含隔壁角色的像素）；逐格看一眼即可，30 格抽查 6 格 |

**特别注意**：验收②③就是这次任务的"目的项本身"——**「看起来更像 2D 手绘」不能替代「没改动作」**。
历次教训：门检没查"本次改动的目的项"就会全绿交付坏件（见 `docs/研发缺陷日志.md` BUG-11/12/13/14）。
