**关键观察**：#1 #2 #4 **全是"确定性工程问题"，却每次靠人重来**——这才是"一搞就一天"的真正原因。**#3 是能力边界，只能绕（换动作设计）或补（runtime 合成）。**

## 二、"一劳永逸"的真实含义

**不存在"一个工具搞定所有"**。一劳永逸的正确形态是：**把可确定的部分全部固化，把不可确定的压到最小**。

```
        ┌───────────────── 不可确定（AI 能力边界）─────────────────┐
        │  姿势创作：能不能画出这个动作                              │
        │  → 已探明边界：整体姿势变化 ✅ / 换被遮挡的远侧肢体 ❌       │
        └────────────────────────────────────────────────────────┘
                                   ↓ 一旦选定源图
        ┌───────────────── 完全确定（必须固化，禁人工介入）─────────┐
        │  抠底 · 清杂 · 归一 · 切帧 · 门检 · 出证 · 落库          │
        │  → 这 7 步今天是"人肉 + 一次性脚本"，应做成一条管线       │
        └────────────────────────────────────────────────────────┘
```

## 三、方案：**确定性管线 + 明确的 AI 边界**

### 阶段 1：动作可行性预检（新增，成本 6 分/动作）

**新动作**在铺量前，先做**1 次单帧生成**，判定它属于哪一类：

| 类别 | 判据 | 处置 |
|---|---|---|
| **A 类：整体姿势变化** | 蹲/跳/跑/受击/挥砍 | ✅ 可生成（条带或链式） |
| **B 类：同侧肢体动作** | 单臂前伸、抬腿 | ✅ 可生成 |
| **C 类：换被遮挡的远侧肢体** | 换手出拳 | ❌ **不可生成** → 改动作设计 或 runtime 合成 |

**依据**：本轮 12 次实测已把边界划清。**预检花 6 分，省掉一天。**

### 阶段 2：确定性管线（核心，一次建好永久使用）

**一条命令完成 7 步**：

```
artgen.py run --batch <批次目录>
  ├ ① 抠底     多背景判据（四角参考色 + 连通域最大主体），**禁**简单"亮=白"阈值
  ├ ② 清杂     alpha>32 + 4 邻接，**连通域为单位**，附"主体域删除像素=0"证明
  ├ ③ 归一     单系数（同批同源）或刚体归一（跨源），**禁用 bbox 判尺度**
  ├ ④ 切帧    按 manifest 映射，SHA 互异断言
  ├ ⑤ 门检     几何/单连通/无裁切/尺度表/帧间互异 —— **规范红线逐条固化为断言**
  ├ ⑥ 出证     contact sheet（**自动标基准帧**）+ QA JSON + 前后对照
  └ ⑦ 落库     写 manifest + SHA 链 + 落地账
**任一项不过 → 退出码非零，状态原地退栈，不产"自报通过"。**
```

**为什么这条是"一劳永逸"**：今天 4 个瓶颈里 **#1 #2 #4 全部在这条管线内**，且**判据来自规范**（红线 9/10/14/15/16/17），改规范即改门。

### 阶段 3：AI 通道的明确分工

| 通道 | 用途 | 成本 | 边界 |
|---|---|---|---|
| **Codex 原生** | 基础帧（站立/单一姿势） | 0（订阅内） | 换姿势弱（只会沿用输入） |
| **Seedream 条带（21:9）** | **整体姿势序列**（跑/跳/受击） | 6 分/3帧 | **换被遮挡肢体 ❌** |
| **Seedream 链式** | **逐步改姿势**（已验证腿交替成功） | 6 分/步 | 同上 |
| **不做** | 换手出拳等 C 类 | — | 已 12 次证伪 |

## 四、这套方案能带来什么（对照今天的实际）

| 环节 | 今天 | 方案后 |
|---|---|---|
| 比例 | 靠人测、改 2 版 | **管线固化为断言**，不过即退回 |
| 抠图 | 失败 2 次、手动调阈值 | **多判据 + 连通域**，机械可验 |
| 门检 | 靠人看、判错 3 次 | **全部脚本化**，人只做审美门 |
| 动作可行性 | 试 12 次才发现做不出 | **预检 6 分**即知 |
| 交付率 | **48 批次 / 0 交付** | 目标：**批次即交付** |

## 五、诚实说明：这套方案**解决不了**什么

1. **画风与画质本身**——管线只保证"不失真、不变形、尺寸对"，**不提升画得好不好**；
2. **C 类动作**（换被遮挡肢体）——**做不出就是做不出**，方案只能**提前告诉你**，让你早改设计；
3. **审美判断**——仍归 Leo。
