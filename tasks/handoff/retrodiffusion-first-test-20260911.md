# Retro Diffusion 首测结论（2026-09-11）· 一次调用，$0.14

**问的**：画风能否匹配 + 能否生成"换手出拳"动画。
**答**：**画风基本可用；手确实在动（远好于我们 5 次失败的"钉死不动"）；但"交替换手"仍未确证。**

---

## 一、测试设置（可复现）

| 项 | 值 |

## 二、结果（三项结论）

### ✅ 结论 1：画风**基本可用**（此前最大风险点）

- 输出的 8 帧**保留了绿袍、白裤、马尾、发冠、整体配色与 3/4 朝右视角**；
- 人物结构没有崩坏，没有多手/少手；
- **风格差异**：Retro Diffusion 是**像素化处理**（边缘更硬、色块更整），我们的是**手绘平滑风**。放大看是"像素版"而非"同一种画风"，但**同一角色可辨、不违和**——**是否接受这个画风，需要 Leo 目视定**（这是审美判断，不是技术判断）。

### ✅ 结论 2：手**确实在动**（关键改善）

逐帧量手部（肤色块）位置：

| 帧 | 前手 x | 前手 y |
|---|---|---|
| f00 | 149 | 147 |
| f01 | 161 | 133 |
| f02 | 161 | 128 |
| f03 | 157 | 136 |
| f04 | 161 | 137 |
| f05 | — | —（收） |
| f06 | 162 | 134 |
| f07 | 156 | 134 |

**横向 149→162、纵向 147→128 都在变** —— 对比我们失败的 5 次（手位置**几乎不动**，位移 0.9px），**这是质的区别**：模型在做**真实的动作**，不是复制同一姿势。

### ⚠️ 结论 3：**"交替换手"仍未确证**（需下一步验证）

- 从手足迹看，**手在"腰侧 ↔ 前伸"之间往返**（f00 低位 → f01~f04 前伸 → f05 收回 → f06~f07 再前伸）；
- 但**现有数据无法证明"前伸的那只手换过"**（可能一直是同一只手做两次伸收）；
- **要判定"是否换手"，需要放大每帧看肩部连接**——本轮尚未做（技术原因：手臂被衣袖覆盖，自动测量不可靠，需目视）。

## 三、与既有方案的关系（为什么这次不一样）

| | 我们 5 次失败的方法 | Retro Diffusion |
|---|---|---|
| 姿势从哪来 | **prompt 描述**（"换手"） | **起始帧 + 动画专用模型的时序理解** |
| 结果 | 手钉死不动 / 三帧同图 | **手有真实位移与往返** |
| 本质差异 | 让模型"理解"姿势 | **把起始帧作为显式输入**（正是调研结论中"有效路线"的特征） |
