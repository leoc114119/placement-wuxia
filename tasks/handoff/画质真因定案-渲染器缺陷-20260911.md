# 画质真因定案：花斑/脏边全是「我的渲染器」造成的，不是模型 · 2026-09-11 · PM2

**结论：修好了，画质已经可用（Leo 目验：「右边这个很棒了」）。**

**根因不在模型、不在 3D 转 2D 这条路——在我自己写的渲染器上，两个实现缺陷。**修掉后画面质变。

---

## 一、两个真因（都是我的实现问题）

### 真因 1：贴图采样用了「最近邻」

```js
// 修前
let tx = Math.floor(u*TW);
let ty = Math.floor(vv*TH);
```

**2048×2048 的贴图，渲到 256px 的人物上——每个输出像素要代表 8×8 个纹素，但只取了其中一个。** 这必然产生噪点、花斑、脏边。
→ **修正：改成双线性插值**（取周围 4 个纹素加权平均）。

### 真因 2：直接在 240×320 上光栅化，没有超采样

三角形边缘直接落在目标分辨率上，**锯齿无法消除**，而且贴图/描边的采样全部在最低精度下进行。
→ **修正：改为 4× 渲染（960×1280）→ 箱式滤波降采样到 240×320**。新写了 `downsample.mjs`（颜色按 alpha 加权、深度/法线一并降采样，避免边缘被背景污染）。

## 三、重要修正：我之前的两个判断是错的

在摸到真因之前，我报过两个结论，**现在都要更正**：

**❌ 我之前说「落差主要是脸偏写实、眼睛小」。**
→ **错的。** 那是在**低精度渲染 + 最近邻噪点**的图上看的。4× 渲染后看，**眼睛不小、有神、有高光**，脸也正常。**问题根本不在脸上，在渲染精度上。**

**❌ 我之前说「脸型偏宽（脸宽/脸高 1.92 vs 我们 1.55）、头身比要调」。**
→ **这个测量本身就不该做。** 2D 帧是 3D 渲出来的，**比例天然一致，不需要跟老帧对比**（Leo 亲指：「我们转 2d 的帧是 3d 渲染出来的，比例肯定是没问题的，只要不把旧帧留着不就好了，主要是画质的问题」）。**我跑偏了。**

**教训**：**在排查画质问题时，先确认渲染管线本身是否正确，再去分析"画风差异"。** 我一开始就被噪点带偏，去分析脸和比例，浪费了一轮。

## 四、最终管线（四步，全套本地 0 积分）

```
① 渲染   960×1280（4× 目标），flatcel 近平涂着色，双线性贴图采样
          → 输出 color / depth / normal
② 降采样 箱式滤波 → 240×320（新写 downsample.mjs）
③ 边缘   三源检测：外轮廓 / 深度不连续 / 法线突变
④ 输出   描边（外轮廓可加粗、体内 1px）+ k-means 调色板量化 + 去斑
```

工具（`tools/glb2d/`）：
- `render.mjs` —— 蒙皮渲染 + `flatcel` 着色 + 双线性贴图 + depth/normal 输出
- **`downsample.mjs`** —— 4× 超采样降采样（新）
- **`postprocess.mjs`** —— 描边 + 量化 + 去斑（新）
