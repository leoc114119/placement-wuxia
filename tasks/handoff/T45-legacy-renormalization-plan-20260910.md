# T45 旧批重归一方案（Leo 2026-09-10 批准）· 待派美术线

**目的**：修掉旧批「包围盒自适应归一」造成的**姿势相关放大**（实测最高 +21.9%），使全向所有帧在同一真实尺度下渲染。
**性质**：**纯确定性重跑，不重新生成**（源图在仓库里）。
**本文档 = 派单需求；执行细节由美术线按此实现并自证。**

---

## 一、问题与实测数字（已定案 BUG-20250910-12）

旧批每帧各自把包围盒顶到 256，导致**越矮的姿势被放得越大**：

| 帧 | 源 bbox 高 | 旧系数 | 旧输出高 | 正确输出高 | **放大倍数** |
|---|---|---|---|---|---|
| walk_right_1 | 312 | 0.8205 | 256 | — | 1.000（基准） |
| **jump_right_1（蹲）** | **256** | **1.0000** | **256** | **210** | **1.219×（+21.9%）** |
| jump_right_2 | 290 | 0.8828 | 256 | 234 | 1.138×（+13.8%） |
| jump_right_3 | 303 | 0.7893 | 239 | 241 | 0.99× |
| **atk_right_1** | **214** | **1.1963** | **256** | **256** | 1.196×（+19.6%） |

**指纹**：`battle45` 61 帧中 57 张（除 die）**人物高全部 = 256**，无一例外。

## 二、影响范围

| 目标 | 数量 | 说明 |
|---|---|---|
| `battle45` 右向 | **30 帧** | atk 6 + cast 9 + walk 6 + jump 6 + idle 3 |
| `battle45` 左向 | **30 帧** | **右向的精确镜像**（实测 7/7 组 0px 差）→ 重归一右向后**重新镜像生成**即可，不需单独源图 |
| `die_common` | 1 帧 | 横躺帧，不设高度门，按同法处理（或保持现状并登记） |
| **合计** | **60 帧** | |

另外**同日 R1 批次**（`seq287/288/290/300/304/309/317/321`，右上/右下 20 帧与右向重渲件）同样带此缺陷——**同批修**，方法相同。

## 三、关键约束（决定了方法，不能简化）

**各帧源图不在同一尺度上。** 实测原始生图的**青玉宝石（刚体）**：锚帧 `idle_right` = **34px**，而动作帧 = **24~27px**（差 **33%**）。

→ **不能用一个"死系数"跨帧套用**。必须**按刚体归一**：以刚体（发冠青玉/白三角）的实测像素作为"真实尺度"的代理。

**为什么这样对**：输出高 = 源 bbox 高 × 系数；若系数 ∝ 1/刚体尺寸，则
```
输出高 ∝ 源bbox高 / 刚体尺寸 = 姿势高(单位) / 刚体尺寸(单位)  ← 与源尺度无关
```
**姿势自然高度被保留（蹲姿矮、站姿高），且跨帧尺度一致**。
**特例**：若一组帧的源尺度本来就相同（如 v2 批，青玉 34/35/36），刚体恒定 → 自动退化为**单系数**，即现行 v2 口径——**本方法与 v2 不冲突，v2 是其特例**。

## 四、方法（写死，禁改）

**系数公式**：
```
系数(frame) = (刚体_锚帧 / 刚体_本帧) × (256 / 源bbox高_锚帧)

其中「刚体」= 发冠部位的实测像素宽
锚帧 = assets/characters/hero/battle45/battle_idle_right.png 的源图（raw）
```

**每帧步骤**：
1. **取源图**：按 `_trial_20260905/*/manifest.json` 的 `releasePath ← candidatePath` 映射找回该交付帧的 raw；
2. **量刚体**：在 raw 上实测发冠宽（判据见 §六）；
3. **量人物 bbox**：raw 上人物非背景像素的 bbox（**不含裁切**）；
4. **算系数**（上式）并缩放；
5. **落位**：画布 240×320 RGBA / 脚底 y=300 / `alpha>32` 加权质心 x=120；
6. **宽度贴限时**：按 红线 9「组系数钳制」整体降系数（禁单帧缩放置之不理、禁裁切）；
7. **左向**：由重归一后的右向**重新镜像**（`FLIP_LEFT_RIGHT`），左向不单独归一。

**禁**：
- 禁逐帧各自把 bbox 顶到固定高度（＝本次要修的缺陷本身）；
- 禁改画布/脚底/质心口径；
- 禁重新生成（本单是纯加工）。

## 五、自证证据（交付必须包含，缺一不算交付）

1. **逐帧表**：`帧名 | 源路径 | 源SHA | 刚体宽 | 源bbox高 | 系数 | 输出bbox | 输出高`；
2. **同族内刚体一致性**：重归一后**输出刚体宽极差 ≤5%**（这是本方法的正确性判据）；
3. **姿势自然高度合理**：蹲/跃/落帧**应显著矮于**站立帧（不再是全 256）；
4. **无裁切断言**：`输出bbox == round(源bbox × 系数) ±1`（宽高各一项）；
5. **几何门**：240×320 / RGBA / 脚底 300 / 四边零 alpha / `alpha>32` 单连通；
6. **对照图**：**必须含锚帧**，且**交前须人眼过一遍并写画面逐项描述**（只给路径不算交付）；
7. **左向镜像保真**：`左 == 右镜像` 逐像素差 = 0。

## 六、刚体判据（禁饱和、禁内容相关量）

- **刚体 = 发冠青玉宝石**：色彩判据 `G>85 且 R<G−30 且 B>60 且 B<G+40`，取**最靠上**的连通块（腰带与发带同为青绿，靠"最上"区分）；
- **报宽度**（不发散量），并在**交付帧组上自证波动 ≤5%**；若某帧检测失败（被手/马尾遮挡）→ **登记该帧人工核**，禁改用内容相关量（头/脸/马尾 span）；
- **锚帧同法实测**：`idle_right` 源 = `_trial_20260905/t45_batch0_codex_native/raw/idle_right_attempt1.png`，实测青玉宽 **34**、人物高 **1102**。

## 七、执行顺序（小步，先 1 组）

1. **第 1 段（试点）＝右向 10 帧**（walk 3 + atk 4 + jump 3，即 `seq278/279` 那组）；
2. PM2 门检 + **与现行 v2 批对照**（同姿势同向应有相近高度：jump 约 210~230）；
3. 试点通过后铺**右向其余 20 帧 + 右上/右下 20 帧**；最后重镜像左向。

## 八、验收（PM2 独立复跑）

| # | 项 | 通过条件 |
|---|---|---|
| 1 | 刚体一致性 | 输出刚体宽组内极差 **≤5%** |
| 2 | 姿势高度 | 蹲/跃帧 < 站立帧（**不再是全 256**） |
| 3 | 与 v2 批互校 | 同向同族高度差 **≤±5%** |
| 4 | 无裁切 | 逐帧 `±1` 断言 |
| 5 | 几何门 | 240×320 / 脚底 300 / 质心 / 单连通 / 四边零 alpha |
| 6 | 左向镜像 | 逐像素差 = 0 |
| 7 | 与动画一致 | PM2 出 **基准+各帧循环动画**目验无大小跳 |

## 九、风险与待确认项

1. **源图覆盖度**：初查按文件名匹配只有 ~50%（左向无需源、idle 源已定位）；**执行前须按 manifest 做一次完整映射核对**，缺源的帧单列并上报（禁拿"差不多"的图替代）。
2. **刚体测量噪声**：青玉实测宽 24~27px，±1px 即 ±4%；故判据用"**组内极差 ≤5%**"而非单帧绝对值，并要求小件与**红/青叠加**互证。
3. **各 sheet 内嵌参照的漂移**：旧 raw sheet 的左格参照帧自身高 746~780（4.5% 漂移）→ 说明旧批**连参照帧都不恒定**；本方案不依赖该内嵌参照（只用锚帧 raw 定标），但需在报告里登记该事实。
4. **`die_common`**：横躺帧无高度语义，建议按同法处理后单独目验，或保持现状并登记原因。

## 十、与现行口径的关系

- 本方案**不推翻 v2 单系数**——v2 是本方法在"同源同尺度"下的特例；
- 本方案**新增**的是：**跨源尺度的桥接**（刚体归一），用于修复旧批（源尺度不齐的历史产物）；
- **新批次仍按 v2 生成**（同批同尺度 → 单系数），本方案只用于**旧批修复**。
