## 六、判据（必须由系统执行，不由执行者自报）

- 画布 240×320 RGBA / 脚底 y=300 / 四边零 alpha / `alpha>32`+4 邻接单连通 / 质心 x=120±1（动作帧 ±20）/ 宽度 ≤238
- **无裁切断言**：`输出 bbox == round(源 bbox × 批次系数) ±1`（宽高各一项）
- **尺度表比对**：`输出 bbox 高 == 「动作族×方向」表值 ±1`；**只有 idle 族锚 256**，动作族表值=自然高（Leo 圈定后落 `batches.scale_table_json`）
- **帧间 SHA 互异** + 帧间互异断言
- **清杂零副作用**：清除单位=连通域；附"主体域删除像素=0"差分证明
- **跨帧一致性**：刚体件探针（发冠/固定饰品）各帧一致（小件 <20px 须与红/青轮廓叠加互证）
- **对照图必须含基准帧**，且交付前须附逐帧画面描述（"只给路径不算交付"）
- 任一不过 → **退出码非零，状态原地退栈**，不产"自报通过"

## 七、验收（DoD）

1. **回归复现**：系统从其 `raw/` 源图**逐字节复现** 2026-09-10 已过门的 4 帧（`assets/_trial_20260910/t45_v2_right_batch_seq328/normalized/`，SHA 已知）。
2. **状态可重建**：批次与帧的完整状态（含每道门的证据路径）可从 DB 重建，**不依赖任何会话**。
3. **越权不可能**：执行者（人或模型）只能提交产物，**不能改状态**；状态推进只由门结果触发。
4. **零回归**：既有 4 帧的产线与 runtime 契约不受影响。

## 八、待定架构问题（请方案中给结论）

## 九、边界（方案与本系统都不得越界）

- **系统管流程与判据，不改善画面质量**——生成仍随机、审美仍归 Leo；
- 审美门是**人工工位**（Leo 看对照图页点通过/打回，结果落库）；
- 本地优先（Python + SQLite + 本地页面），不引云服务与外部依赖；
- 不修改历史验收过的 runtime 契约。
