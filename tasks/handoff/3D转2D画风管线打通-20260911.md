# 3D→2D 画风管线已打通（量化 + 描边 + 平涂着色）· 2026-09-11 · PM2

**结论：能直接做，已经做出来了。** 我按之前调研的工业做法补上了缺的三个件（**平涂着色 / 调色板量化 / 描边**），现在 3D 渲染出来**有黑描边、颜色被压成色块、接近平涂**——画风距离明显拉近了。

## 一、做了什么（管线四步）

```
① 渲染（flatcel 模式：接近平涂的光照，亮度压到 0.86~1.00）
     ↓  同时输出 depth / normal 缓冲
② 边缘检测（三源：外轮廓 / 深度不连续 / 法线突变）
     ↓
③ 描边（外轮廓可加粗、体内线条固定 1px）
     ↓
④ 调色板量化（k-means 取 N 色）+ 去斑
```

工具（都在 `tools/glb2d/`）：
- `render.mjs` —— 新增 **`flatcel` 着色模式** + 导出 depth/normal 辅助缓冲
- `postprocess.mjs` —— **新写的后处理器**（描边 + 量化 + 去斑）

**全套 0 积分**（纯本地计算）。

## 三、过程中踩的两个坑（都返工了）

**坑 1：描边把整个人涂黑（86.5% 像素判为边缘）。**
我第一版用**相对深度差**（除以 `min(|z|)`）判深度边。但模型深度**跨零点**，分母趋近 0 时差值爆炸 → 86% 像素被判成边缘，人物变成一坨黑。
**修正**：改用**绝对深度差**，并按实测分布标定阈值（相邻深度差 p90=0.008、p99=0.048 → 取 0.05）。

**坑 2：脸上和头发上出现红绿色斑。**
我第一版量化用的是**逐通道独立取整**（每通道各自量化到 N 级）——这会把色相改掉，例如 `(60,30,25)` 被量化成 `(77,26,26)`，棕色变红。
**修正**：改用 **k-means 调色板量化**（颜色作为三维向量聚类，色相关系被保留）。

**坑 3（顺带发现）：头发上有孤立的彩色单像素。**
渲染时贴图采样的异常值，量化会把它固定下来。
**修正**：加一道**去斑**（与邻域多数显著不同的像素，替换为邻域亮度最接近者的颜色）。

## 六、我没做的（如实登记）

1. **没做成真正的 cel-shader** —— 我这是**软件后处理近似**（量化 + 边缘检测描边），不是 Blender/Unity 里那种基于 ramp 贴图/SDF 的真卡通着色。**真正的 cel-shader 效果会更好**，但要装 Blender/Unity。
2. **脸部没做特化** —— 现在脸是"顺带被量化"的，没有单独处理。
3. **只渲了静止六向 + 行走** —— 攻击/受击等动作族没渲（模型里也没有这些动作，要先套）。
4. **没和 Leo 确认这套画风能不能接受** —— 这是**审美判断，只有 Leo 能定**。
