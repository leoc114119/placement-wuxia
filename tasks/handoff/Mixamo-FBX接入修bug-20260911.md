## 二、Bug 1：手消失 —— rest 基准用错了

### 现象（硬数据）

```
模型 rest:  L_Hand = (0.253, 0.541, 0.069)
动作帧 0:   L_Hand = (0.068, 0.416,-0.053)   ← 偏了 0.255 个身长，手收进身体
```

### 根因

我用了「世界系增量」公式：`W_tgt = (W_src_anim × W_src_rest⁻¹) × W_tgt_rest`。
**它只在两边 rest 姿态相同时才成立**——但：

| | rest 姿态 |
|---|---|
| **Mixamo** | **T-pose**（`LeftArm` rest 旋转 = **0°**，手臂水平） |
| **我们的模型** | **A-pose**（手臂已下垂约 45°） |

而 Mixamo 的动画曲线是**绝对旋转**——帧 0 就已经是「手臂下垂 **71°**」。我的公式把这 71° **又叠加**到我们已有的 45° 上 → 116°，**手臂穿进身体**。

**我中途还试过第二个错误公式**（`(W_tgt_rest × W_src_rest⁻¹) × W_src_anim`），错在把「源 rest（T-pose）」当成了「目标 rest（A-pose）」的对应姿态，结果更偏。

### 正确公式（最终采用）

**以「动画自己的第 0 帧」为基准**，把运动当**相对量**施加到目标 rest 上：

```
D(t)     = W_src_rest⁻¹ × W_src_anim(t)      源姿态（骨骼局部系）
E(t)     = D(0)⁻¹ × D(t)                      相对第 0 帧的增量
W_tgt(t) = W_tgt_rest × E(t)                  从我们自己的 rest 出发
```

**效果**：帧 0 **精确落在我们模型自己的 rest 上**，之后是相对运动。

## 三、Bug 2：人横躺 —— 一个静默的参数丢失

修好手之后，**整个人横过来了**。查出来是我的代码错误：

```js
mul(Wtgt[p], invRot(rotPart(restWorld[p])), restWorld[i]);   // ❌ 传了 3 个参数
```

**我的 `mul(a, b)` 只接受两个参数，第三个被静默丢弃**。而 `Root` 恰好是「未映射骨骼」、`Hip` 是它的已映射子级 → `Root` 的世界矩阵算错 → **`Hip` 偏 90°**（实测 `Hip` 差 **90.0°**、`L_Thigh` 差 **180.0°**）→ 人物横躺。

**修正**：未映射骨骼保持自己的局部 rest、跟随已映射父级。

> ⚠️ 这个 bug 只在「未映射骨骼有已映射子级」时暴露——所以之前 CMU 那条路（走另一套增量继承逻辑）没踩到。**这是 JS 静默丢参数的典型陷阱。**
