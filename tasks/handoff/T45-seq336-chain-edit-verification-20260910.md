**成本口径（09-10 更正）**：Codex **原生生图走 Plus 订阅、不扣积分**——本单**不产生积分消耗**（此前写作"3 张 = 6 分"是把 mxai 计价错套到原生通道，作废）。真实约束是 **`image_gen` 用量限制**（app 内 `usageLimitExceeded / limitId="image_gen"`，带 `resetsAt` 重置）与**轮次预算**，故仍限"**只跑 3 张**"。
**性质：一次性验证，不产正式资产、不动 runtime、不铺量。**

## 一、要回答的一个问题

> Codex 内置生图（Images 2.5）的「**多次编辑之间细节保持一致**」，在**链式喂图**下是否真成立？

- **成立** → 头身比问题结构性消失，动作帧主力改走链式；尺度表/三锁退居二线。
- **不成立** → 干净地否掉这条路，回「减帧数 + runtime 补」或骨骼方案，不再耗。

**为什么现在要重测**：2026-09-10 下午批的 15 次生图**全部** `referenced_image_paths=[battle_idle_right.png]`（同一锚帧、参照数恒 1）、**模式全为 generate、零次 edit**——试的是**独立并行生成**，不是链式。**链式从未跑过**，2.5 的这条能力**尚未被检验**。

## 二、链的定义（**本单的核心，写死了，禁改写**）

**链式 = 第 N 步的参考图，是第 N−1 步的产物**，不是锚帧。

```
起点：assets/_trial_20260910/t45_v2_right_batch_seq328/normalized/idle_right.png   ← 现有产物，不重生成
  ↓ 第 1 步
walk_right_1   参考 = idle_right.png（上一步产物）
  ↓ 第 2 步
walk_right_2   参考 = walk_right_1.png（上一步产物）
  ↓ 第 3 步
walk_right_3   参考 = walk_right_2.png（上一步产物）
```

**共 3 次新生成**。每步**只改一个可观察目标 = 动作姿势**，其余（身份/头身比/服饰/画风/朝向）一律不动。

**机械检查项（PM2 必核，交付须自证）**：把 3 次的调用参数逐条列出，**第 N 步的 `referenced_image_paths` 必须指向第 N−1 步的产物路径、且参照数 = 1**。若任一步指向锚帧或参照数 >1，**该步作废、按 E-GEN 重跑一次**——这正是下午跑错的形态。

## 三、技术前提（必须先解决，否则走不到链式）

内置工具的 **edit 模式只作用于「对话上下文里可见的图」，不能按文件路径编辑**（imagegen skill 原文）。因此：

1. 先把上一步的产物用 `view_image` **放进对话上下文**；
2. 再走 edit 流程，prompt 只描述姿势变更；
3. 若 `view_image` 或 edit 路径不可用，**停手上报**（不要退回 generate+锚帧，那就不是链式了）。

## 五、判据（PM2 独立复跑，不采信自报）

| # | 项 | 通过条件 |
|---|---|---|
| 1 | 链式真实性 | 3 步参照图**均指向上一步产物**，参照数=1 |
| 2 | **刚体探针一致性** | 四帧发冠宽、脸宽**极差 ≤5%**（对齐 v2 保留帧组实测口径） |
| 3 | 无裁切 | `输出 bbox == round(源 bbox × 系数) ±1` |
| 4 | 几何门 | 240×320 / 脚底 300 / 四边零 alpha / `alpha>32` 单连通 |
| 5 | 对照图 | 含**并行版 walk 三帧**（同批次已过门产物）与链式三帧并排、同基线 1:1 |

**结论口径**：刚体探针极差 ≤5% → **链式成立**；>5% → **链式不成立**，本单就此关闭、回退到其他路线。

## 七、红线

- **只跑这 3 张**，不铺其余帧、不重跑 walk 正式产物；
- runtime 不动、正式资产不动（产物落试产隔离目录）；
- 一次生成 = 一次尝试；机械失败（报错/文字/多主体/尺寸不符）同命令重跑至多 1 次，再失败停手上报；
- **不修改 prompt 里的客观条款**（锚定身份/比例/服饰/朝向），只改姿势描述；
- 交付须附**画面逐项描述**（哪只手在画面哪侧、姿势、朝向）——只给路径不算交付；
- 结论无论成败**都写进交付**，失败同样有价值（用来关闭该路线）。
