# 贴图细节优化（8 角度渲染图加细节）—— 美术线任务

- 日期：2026-09-12
- 发起：美术 PM2
- 目标载体：**美术线（Codex art 窗口）**
- 上游决定：Leo 拍板「转 3D 贴图路线」——**细节由 AI 加在 2D 渲染图上，再由 PM2 回填进贴图，最后用 3D 管线重渲**。
  这样人物比例 100% 由 3D 管线保证，AI 只负责"加细节"，不负责"重画角色"。

---

## 1. 为什么这样做（先读，能避免重复踩坑）

之前那条「把整张精灵图交给生成模型做精修」的路已经作废，实测三连败：
- 整图 30 格送进去，模型输出预算 ≈1.5MP，图纸被等比缩到 0.812×，每格只剩源像素 59% → 净降采样（锐度 −10.86%）
- 改成"一条方向一张图"后细节确实上来了（+30%），但**模型会重画角色**：整体放大 2%~15%、头发体积每次不同
- 事后缩放只能对齐整体，**对齐不了"头变大"这类内部比例** → Leo 判「大小又变形了」

**所以本任务换了完全不同的切口**：让 AI 在**已经渲好的人物图上加细节**，而不是让它重新画一个人。
形状/比例/朝向/轮廓全部来自 3D 渲染，我们只取 AI 加在**表面上的纹理信息**。

---

## 2. 输入

```
assets/_trial_20260912/贴图回填_美术线输入/
├── 角度图/view_yaw{000,045,090,135,180,225,270,315}.png   1024×1365，同一个角色绕竖轴转一圈
└── alpha/view_yaw*_alpha.png                              对应的轮廓遮罩（做"轮廓校验"时用）
```

8 张图是**同一个模型、同一姿势、同一光照**，只是观察角度不同（每 45° 一张）。
背景是纯色 `#141418`。

---

## 3. 要做的

在**每一张**图上把人物的**表面细节画清楚**，具体是：
1. **头发**：分缕（一缕一缕的走向）、发梢明暗、马尾的束感
2. **衣服**：衣襟走线、袖子与衣摆的褶皱线、布料的织物感
3. **腰带**：织纹、绑结的层次
4. **靴子**：车线、鞋底分层、皮革质感
5. **五官**：眉毛/睫毛、眼睛结构、鼻梁、嘴线、耳廓

## 4. 绝对不能做的（这是本次的硬边界，越界即打回）

- ✗ **不许改形状**：轮廓、头身比、四肢长短、头发体积**一律不动**
- ✗ **不许移动或缩放**：人物在图里的位置与大小必须与原图**逐像素对齐**（PM2 会量：轮廓 bbox 偏移 ≤2px、缩放差 ≤1%）
- ✗ **不许改配色**：衣服还是那个绿、皮肤还是那个肤色，**只加明暗与线条，不换色**（PM2 会量：人物区平均色偏 ≤6/255）
- ✗ **不许改背景**：保持纯色 `#141418`，不许加阴影/光晕/地面/文字/水印
- ✗ **不许换画风**：保持现在的 3D 渲染质感，**不要画成平涂 2D / 线稿 / 水墨 / 厚涂插画**
- ✗ **不许用 mxai**（`gpt-image-2` 要花积分）；本次一律走 Codex 原生 `image_gen`（免费）

## 5. 关键：8 张图的风格必须一致

这 8 张最后会被**回填成同一张贴图**——同一个纹素可能同时被 2~3 个角度看到。
如果同一条衣襟线在 A 图里是深色细线、在 B 图里是浅色粗线，回填后就会出现**接缝/糊块**。

**做法**：
1. **先只做 `view_yaw270.png` 这一张**（右侧视角，信息最全），当作"**细节风格锚**"
2. 剩下 7 张，把 `view_yaw270` 的成品作为**参照图**一并送去，prompt 里写"按参照图的细节风格处理这张"
3. 8 张全部用**同一段 prompt 措辞**（不要每张换说法）

## 7. PM2 的验收门（机械可算，会逐条报数）

| 项 | 判据 |
|---|---|
| 尺寸 | 1024×1365 |
| 轮廓几何 | 与原图 alpha 求交：IoU ≥ 0.97；bbox 偏移 ≤2px、高宽差 ≤1% |
| 配色 | 人物区内 平均色偏 ≤6/255（只许加细节，不许改色） |
| 细节 | 主体内部（腐 3px）梯度均值 **≥** 原图，且逐角度都不得为负 |
| 背景 | 非人物区像素与原图一致（纯色不变） |
| ★人眼 | PM2 会**实际打开图看**并写画面描述，不看不算交付 |

**过门后由 PM2 做回填**（已有工具 `tools/glb2d/backfill_tex.mjs`，闭环回归实测 0.45/255）→ 出贴图 → 重渲六向五帧 → 交 Leo 目验。
