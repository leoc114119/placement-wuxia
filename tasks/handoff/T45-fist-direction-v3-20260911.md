# T45 · 拳交替验证 v3：**方向锁死**（Leo 2026-09-11 令）

**背景**：v2（seq=352）腿链 PASS，但拳链第三帧被 Leo 判**方向错**：

> **「第三帧是右手，但打向了右边」/「第三帧是方向错了…三张都是和右出拳看看」**

## 一、v2 实测定位（PM2 复核，确认 Leo 判断）

三帧出拳拳（距躯干中线最远的那只，原始 1086 画布）：

| 帧 | 出拳拳 | 距中线 | 拳心 y | 结论 |
|---|---|---|---|---|
| atk_1 | 画面右拳 | **+398px** | **751**（肩高） | ✅ 正确：向前（画面右）水平打出 |
| atk_2 | 画面左拳 | −333px | 746 | ✅ 换手正确 |
| **atk_3** | 画面右拳 | **+322px** | **861**（腰腹高） | ❌ **下沉 110px、内收 76px**：只是把拳挪到身前，**没有向前打出** |

**根因**：fist_3 的 prompt 只写 "reaches the front"（伸到最前）——**"前"是相对词**。模型把"往前"理解成"从腰侧挪到身前"就停手，**拳停在腰腹高度、没有沿水平方向打出去**。
→ **缺的是方向与高度的绝对约束**，不是幅度。

## 二、v3 修正（两条，都写死）

### 2.1 方向锁死：三帧**都必须朝画面右出拳**（Leo 令）

**动作语义**（写入 prompt）：**这是一个"连续右直拳"序列**——每一帧都是**同一只右手向右前方水平打出**，不是左右手轮流。

| 帧 | 要求 |
|---|---|
| atk_1 | 右拳向前（画面右）水平打出，与肩同高 |
| atk_2 | **同一方向、同一高度**，右拳再次打出（相位/幅度略有变化即可） |
| atk_3 | **同上**——方向、高度、伸展程度**必须与 atk_1 一致** |

**禁**：把"换手"当作交替（v2 的错法）；禁把拳停在身前/腰腹。

### 2.2 绝对锚：**atk_1 成品作第三参照**

prompt 必须声明三个参照的分工：

```
Image 1 = 上一步产物          （身份/画风/连续性）
Image 2 = PM2 姿势示意图      （只取肢体相位）
Image 3 = atk_1 成品图        （★出拳终点锚：右拳须到达与该图相同的位置与高度）
```

**并写入可量化的绝对目标**（原始 1086 画布）：
- 拳心 **距躯干中线 +398px ±40**（即拳到达画面右侧最外）；
- 拳心 **y ≈ 751 ±40**（肩高，**不得低于 820**，禁下沉到腰腹）；
- 手臂**完全伸直**（肘部不可弯）。

## 三、链与范围（只跑 3 张）

```
链 B：idle_right → atk_1 → atk_2 → atk_3
每步输入 = 上一步产物（SEQUENTIAL，非首帧并行）
每步参照 = [上一步产物, 姿势示意图, atk_1 锚图]
```
- **atk_1 可用 v2 成品**（已正确，不必重生成）→ **本单实际只需 2 张新图**（atk_2、atk_3）；
- 若美术线判断 atk_2 也需重做，最多 3 张。

**目标姿势示意图**：`pose_diagrams/fist_A_right_out.png`（**三帧都用这一张**——因为方向恒定）。

## 四、判据（v3，写死）

| # | 判据 | 通过条件 |
|---|---|---|
| C1 | **方向** | 三帧出拳拳**均在躯干中线右侧**（距中线 **> 0**），且**距中线的极差 ≤ 60px** |
| C2 | **高度** | 三帧出拳拳的 y **极差 ≤ 60px**（原始画布），且**均 ≤ 820**（肩高带，禁下沉） |
| C3 | **伸展** | 每帧出拳拳距中线 **≥ 350px**（atk_1 实测 398，留 12% 容差） |
| C4 | 拳数 | 每帧恰好 **2 只拳** |
| C5 | 链真实性 | 第 N 步输入 = 第 N−1 步产物（SHA 对上） |

**核心是 C1+C2**——它们才能真正抓住 Leo 指出的"方向错了"；v2 的判据（只看最外侧拳的位移量）**漏掉了方向**，已废止。

## 六、红线

- **最多 3 张**，不铺量；
- 透明/背景不判；**比例不判**（本单只验出拳方向与一致性）；
- **不许把"换手"当成交替**（v2 的错法）；
- 若 v3 仍出现"拳下沉/朝内"，**如实交结论并停**——届时 PM2 上报 Leo：该动作可能不适合用 AI 逐帧生成，考虑改为**单帧生成 3 个候选由 Leo 选**，或走**参数化位移**方案。
