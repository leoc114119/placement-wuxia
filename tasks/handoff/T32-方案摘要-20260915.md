## 一句话版

剑 = 挂在右手骨上的**静态网格第二条 draw call**：世界变换 = `人物摆放矩阵 × 手骨世界矩阵 × 挂点矩阵 M`，M 在装配期按 A4 现成参数合成（金标准=其参考矩阵+四关键点自检）；不绑骨、不并网、角色蒙皮管线零改动；首版无光照复刻 Leo 已批观感；run/jump 收剑、长度 0.5~1.2 与四部件换色全部参数化（喂装备系统零新增资产）。

## 验收（W1~W9 全转机械，详见方案 §7）

## 拍板节（4 条，均有推荐；拍板1 阻断发卡）

1. **W6 语义**：推荐**甲**＝按 clip 名（run|jump 收剑 ⇒ 普通移动也收）——Leo 在观感台批的就是 run 收剑，游戏移动播 run 资产，武侠语义自然；乙＝按槽位（walk 持剑、仅轻功收）。规格「walk 可见」字句系 walk→run 并轨前语境，两读不可兼得。
2. **剑首版光照**：推荐**无光照**（复刻已批 MeshBasic 观感，「所见即所批」）；备选受光版（与角色材质统一，偏离对照图）。
3. **T29 2D 武器层**：推荐**休眠不删**（不动历史验收代码）；S2 敌方 3D 化时随大扫除清点。Codex 若判死代码负担大可改「随卡移除」。
4. **武器加载失败降级**（技术裁定，复核确认）：无剑进战斗+诊断，不阻塞；角色失败仍阻塞。
