## 三、本次修掉的缺陷（BUG-20250912-13）

### 现象
重定向出的帧**集体低头**——idle 每帧勾着脖子、下巴朝胸；轻功同样。Leo 原文：
「为什么会莫名奇妙的低头，轻功也是。。。不正常啊」。

### 根因
`collada2anim.mjs` 的 `aim2` 分支，「骨骼指向」两侧取法**不同源**：

| | 源侧 | 目标侧 |
|---|---|---|
| aim2（旧） | `子骨骼位置 − 自身位置` | `自身位置 − 父骨骼位置` |
| aim3（今） | **骨骼自身世界 Y 轴** | **骨骼自身世界 Y 轴** |

两者只在「子骨骼正好落在骨骼末端」时等价。22 根映射骨里**恰好 5 根不等价**：

| 骨 | 偏差 | 病灶 |
|---|---|---|
| `Head` | **25.78°** | Mixamo 的 `HeadTop_End` 不在头骨 Y 轴上（差约 26°）；模型 Head 是叶子骨，参照退化成「父→自身」＝头骨 Y 轴本身 → **头被恒定多拧 25.78°** |
| `Hip` | 50.65° | `Waist − Hip` 实测长度 **0.0000**（Tripo 绑定里两者同位置）→ 参照是零向量 → `hypot > 1e-9` 守卫**静默跳过修正**，身体整体偏 50° |
| `L_Hand` / `R_Hand` | 71.72° / 48.14° | 同「子−自身」与「自身−父」不等价 |
| `NeckTwist01` | 16.92° | 同上 |

其余 17 根骨 ≤0.06°（即：aim3 对它们**零影响**，改动面精确等于出问题的 5 根）。

### 验证

新增门检 `tools/glb2d/qa_retarget_bones.mjs`（逐骨朝向残差，可当门调用，退出码 0/1）：

```
aim3  idle  → ✅ 22/22 骨残差 0.000°  退出码 0
aim3  轻功  → ✅ 22/22 骨残差 0.000°  退出码 0
aim2  idle  → ❌ 5 项超容差（最大 71.72°）退出码 1     ← 负例对照
aim2  轻功  → ❌ 5 项超容差（最大 70.87°）退出码 1     ← 负例对照（09-11 交付件确有此病）
```

另有人眼证据：修后 idle/轻功渲染帧头部**直立**（与模型 rest 帧一致），轻功火柴人对比图
（源 vs 我们，5 帧）逐帧姿态吻合。

### 影响范围

- **受影响**：只走 `collada2anim` 的产物 —— idle（本日新产）、轻功（09-11 交付的 30 帧，已重渲）
- **不受影响**：`walk` / `run` 是模型自带动画（`preset:biped:*`，不经重定向）；
  `retarget.mjs`(BVH) 与 `fbx2anim.mjs` 不含该 aim 逻辑

### 为什么旧门检没拦住（🔴 全绿假象）

①「帧 0 校验」只比**源自己 rest vs 源自己帧 0**（恒等），与跨骨架映射对不对无关；
②「火柴人对比图」只看整体形状，头 25° 的偏差被躯干四肢的大位移掩盖；
③门检里**没有任何「骨骼朝向保真度」判据**——而"姿态对不对"恰恰是重定向的唯一目的。
与 BUG-11/BUG-12 同一类病：**门检没查本次改动的目的项本身**。已补入产线手册 §2.4①。

## 四、待 Leo 拍板的一项

**idle 站姿的"地面线"比 walk/run 高约 11px**（画布 320 的 3.4%）：

| 动作 | left 向脚底 y（rest 基准线 = 307） |
|---|---|
| **idle（aim3）** | **296（线上方 11px）** |
| walk（模型自带） | 310~315 |
| run（模型自带） | 307~319 |

原因有二：①源 Mixamo `Standing Idle` 本身是**屈膝错步站姿**（实测源膝弯 38~48°，而直立站姿应 ~0~10°），
而 Tripo 自带的 walk/run 站姿更直；②重定向把**髋关节钉在模型 rest 的髋高**上，腿一弯脚就抬起来。
后果：战斗里 walk→idle 切换时角色会有约 11~16px 的上跳。

**三个选项**（请 Leo 选）：
- **A 接受现状**：11px ≈ 小人高的 4.4%，战斗中大部分时间在跑动，影响有限
- **B 地面锁定**：给每个动作算一个 root Y 补偿，让脚底对齐同一地面线（需要改管线约定，且 walk/run 是自带动画、要一并处理）
- **C 换源动作**：换一个站姿更直的 Mixamo idle（如 `Breathing Idle` / `Standing Idle 02`），代价是重下一份 `.dae`
