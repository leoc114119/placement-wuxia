# 派单：主角「正面站立」基准图 ×1（供 Tripo 3D 建模手动试跑）· 2026-09-11 · PM2

## 一、背景（一句话）

Leo 已订阅 Tripo（3D 生成网站，**只能手动操作网页、不能走 API**）。要试「图 → 3D 模型 → 绑骨 → 动作」，需要**一张干净的正面站立图**作输入。现有素材全是 3/4 侧视，喂进去出来的模型会歪，所以要专门出一张正面图。

**为什么必须是正面**：Tripo 的 `image_to_model` 从单图推断立体形状——**正面正视图的信息最完整、左右对称、无自遮挡**，生成的模型比例与对称性最好；3/4 侧视图会让模型继承侧偏。

## 二、交付物（一张，只要一张）

| 项 | 要求 |
|---|---|
| **文件** | `assets/_trial_20260911/tripo_front_input/hero_front_standing_final.png` |
| **内容** | 主角**单人全身、正视图、标准站立**，纯白底 |
| **尺寸** | 长边 ≥ 1024px（Tripo 建议 ≥256×256，我们给足），**3:4 竖构图**、人物居中、四周留白 ≥8% |
| **成本** | Codex 原生直出（`image_gen`，**走订阅 0 积分**）——**禁用 seedream/mxai**（本件不满足 §五 例外条件） |

### 姿势硬要求（这几条都是给 3D 建模/绑骨用的，不是审美）

1. **完全正面朝向观者**——脸正面、双眼平视观者，**不是侧身、不是 3/4**；
2. **双臂自然垂放身体两侧、略离开躯干**（手臂与躯干之间要有可见缝隙，**不要贴着或挡在身前**）——手臂与躯干粘连会导致 3D 模型把手臂融进身体、无法绑骨；
3. **双腿并拢自然直立、双脚左右分开约与肩同宽**，鞋尖朝向观者、双脚踩实；
4. **左右对称**（正面站立姿态天然对称）；
5. 头部正视，**不要低头/仰头/歪头**。

### 形象要求（锁死为我们现有主角）

以参照图为准，**以下特征全部保持不变**：脸型与五官、发型与刘海、**马尾与发冠**、服装款式与层次（青绿长袍／白色内衬／黑腰带金饰）、配色、画风笔触与描边质感、**Q 版大头身比例**。

### 禁止项

- 画面**不出现任何文字/水印/标注线**；
- **无背景元素**（不要地面、不要阴影、不要投影、不要装饰）——纯白底；
- **只要这一个角色**，不出现第二人/部件拆解图/多视图拼贴；
- **不要武器**（剑本身是独立层，不进身体图）。

## 四、交付与门检

**交付回执最小集**：产物路径 + SHA256 + 尺寸 + 消耗（0 积分）+ 机械门检结果。

**机械门检**（程序化，不看图）：
1. 尺寸：长边 ≥1024、比例 3:4（±2%）；
2. 背景：四角与边缘为纯白（≥250）；
3. 单一主体：全图非白像素**连通域数 = 1**；
4. 无文字：目视确认（此项允许一次目验）；
5. **入画完整**：主体 bbox 四边**不贴画布边缘**（各留 ≥8% 留白）。

**不过门 → 登记失败并停报**，不自行换源/加试第二张。
