# 2026-09-11 研发线工作总结（ZCode 侧）

## 一、今日主线：3D→2D 动作帧产线从零打通（美术 PM2 主导，研发线配合）

**突破**：外部动捕/Mixamo 动作 → 我们的 3D 模型 → 2D 游戏帧，全链本地零积分跑通。

- **三解析器全通**：BVH/CMU 动捕、Mixamo FBX、**Collada(.dae)**
  - 实测结论：**Collada 比 FBX 干净**（直接给 4×4 矩阵，无欧拉角顺序歧义；声明 up_axis/unit；名称无 \x00\x01 尾巴）→ 后续优先 Collada
  - 本次踩的 3 个坑全在 Collada 解析（同名 input 标签、matrix 行主序要转置、局部/世界矩阵语义混淆）
- **重定向算法定案：两段式 aim2**（带扭转约束）——纯 aim 只约束指向、绕轴扭转任意 → 头/脚朝向帧间乱跳
- **渲染器两缺陷修复**：①每帧自适应缩放吃掉上下位移（改固定机位）②最近邻采样无超采样（改双线性+4× 降采样）
- **规格定稿（Leo）**：5 帧/动作 · 220ms/帧（220ms 是预览 GIF 速度，游戏内由演出时钟驱动）；降帧用贪心最远点采样（禁均匀抽样）
- **素材产出**：jump 六向 30 张（301KB）、run 六向 30 张（355KB，PNG-8 无损）
