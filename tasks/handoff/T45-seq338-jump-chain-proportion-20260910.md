# T45 · 验证单 v2：链式生成的人物比例（复杂动作=轻功三帧）· Leo 2026-09-10 令

**本单取代 `T45-seq336-chain-edit-verification-20260910.md` 的动作选择与停止条款。**
**性质：一次性验证。不产正式资产、不动 runtime、不铺量。**

## 一、Leo 两条指令（本单依据）

1. **「先不要管背景了，后面都可以扣掉」** → **透明/背景不再是门**（详见 §四）；
2. **「不要弄 walk，walk 太简单了，弄个复杂一点的」** → 动作改为 **轻功（jump）**。

---

## 二、动作选择：轻功三帧（理由）

| 理由 | 依据 |
|---|---|
| **历史麻烦源** | Leo 两次目视判「jump 头的大小比例差距太大，完全不可用」 |
| **姿势跨度最大** | 单系数下自然高 jump **212/225/229**（极差 17px=7.4%），而 walk 246/255/248（3.5%）、atk 246/238/234（4.9%） |
| **天然时序** | 起跳（蹲）→ 腾空 → 落地 = 真运动序列，链式语义最顺 |
| **比例最易暴露** | 蹲姿时身体缩短而头不变——正是「头被画大」最容易看出来的姿势 |

## 三、链的定义（写死，禁改写）

```
起点：assets/_trial_20260910/t45_v2_right_batch_seq328/normalized/idle_right.png   ← 现有产物，不重生成
  ↓ 第 1 步  jump_right_1（起跳/蹲）
    输入 = idle_right.png
  ↓ 第 2 步  jump_right_2（腾空）
    输入 = 第 1 步的产物（原样，含背景，不剥）
  ↓ 第 3 步  jump_right_3（落地）
    输入 = 第 2 步的产物（原样）
```

- **共 3 次新生成**（原生通道，不扣积分）。
- **每步只改动作姿势**；身份/头身比/服饰/发色/朝向/画风一律不动。
- **机械检查（PM2 必核）**：第 N 步的输入图 **必须是第 N−1 步的产物**（路径 + SHA 对上），不是锚帧、不是别的帧。任一步不符 → **该步作废重跑一次**（这正是 09-10 下午 15 次全跑成并行的形态）。
- **输入用原样产物、不剥背景**（Leo：背景后面扣）——链的语义是「在上一步的图上继续改姿势」，模型看到棋盘格不影响它改姿势。

## 四、什么不再是门 / 什么仍是门

**不再是门（Leo 09-10 令）**：
- 透明通道、棋盘格烘入、`alpha` 极值、四边零 alpha —— **一律只记录、不停止**。
- 产物本阶段**允许是 RGB 不透明、允许带棋盘格背景**。

**仍然是门（机械失败，重跑 1 次后停报）**：
- API 报错 / 超时 / 返回图损坏打不开；
- 画面出现文字、数字、水印；
- 主体缺失、多主体、画成多格 sheet；
- **链断了**（输入不是上一步产物）。

**仍是最终交付要求（本阶段不验、后续扣底解决）**：正式资产须 240×320 RGBA、脚底与质心合规——**但那是「扣背景」工序的事，不在本单判据内**。

## 五、比例测量（改用色彩掩膜，因 alpha 不可用）

分辨率差异下不能用 `alpha>32` 定人物 bbox，改用**像素判据掩膜**（PM2 已实测可用）：

- **角色掩膜** = `max(R,G,B)−min(R,G,B) ≥ 30`（有彩色：绿袍/肤色/青玉）**或** `max(R,G,B) < 150`（暗像素：黑发/描边）；
- 由该掩膜取最大连通域 = 人物；**脸掩膜** = 原肤色判据（`R>195 且 R>G>B 且 R−B>45`），取上半身内最大块。

**逐帧实测三项**：
1. **发冠像素宽**（白底青玉夹，刚体、不随姿势变）；
2. **脸部像素宽**；
3. 人物 bbox 宽×高（登记用）。

**同输出画布下做绝对像素比较**（实测两次尝试输出均为 1086×1448，可比）。若画布尺寸不一致，以「发冠宽 ÷ 人物 bbox 高」作归一量比较并注明。

## 六、判据

| # | 项 | 通过条件 |
|---|---|---|
| 1 | **链真实性** | 3 步输入**均为上一步产物**（路径+SHA 对上） |
| 2 | **比例一致性（核心）** | 四帧（idle + jump 1/2/3）的 **发冠宽**、**脸宽** 绝对像素**极差 ≤5%** |
| 3 | 对照基线 | 与并行版 `jump_right_1/2/3`（seq=335 已过门）同口径对比 |

**结论口径**：探针极差 **≤5% → 链式在复杂动作下成立**；**>5% → 不成立**，据此关闭链式路线。
**无论成败都交结论**（失败同样关闭一条路线，有价值）。

## 八、红线

- **只跑这 3 张**，不铺其余帧、不重跑正式产物；
- runtime 不动、正式资产不动（产物落试产隔离目录）；
- 每步机械失败（§四第二组）重跑至多 1 次，再失败停手上报；
- **不改 prompt 里的客观条款**（身份/比例/服饰/朝向），只改姿势描述；
- 交付须附**画面逐项描述**（哪只手在画面哪侧、蹲/跃/落、朝向）——只给路径不算交付；
- 比例结论**由 PM2 独立复跑**为准，自报数据仅供比对。
