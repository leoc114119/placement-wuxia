## 二、你踩的坑：纯色值+位置启发式必然伤「本体白」

六轮b 判据：`不接壤透明 + 面积≥250 + 身体下半 40%~97% 带` → 对**白毛狼**（白毛=本体）和**白衣主角**全灭：
- lang 帧 25,067~31,556px/帧本体被清成透明
- hero_07 被挖 28,976px

**根因**：背景白（255,255,255）和白毛/白衣/高光（230~255 暖白）在色值上几乎不可分。任何「白+位置」启发式都会把本体挖掉。

**铁律：清理素材前，先定义「哪些像素是本体」并保护**——保护维度优先于清理维度。

## 三、正确判据（已沉淀为 `scripts/clean_white_residue.py`，可复用）

```
判据1 贴边残留：不透明(alpha>180) + 近白(minRGB>200) + 低彩度(彩度<25) + 8邻域贴透明(alpha<10) → 清
判据2 孤立白岛：不触边 + 面积<2000 + 均亮>200 + 均彩度<25 → 岛内像素级过滤(亮度>190 且 彩度<30) → 清
保护域：不触边 + 面积≥2000 的连通域 = 角色主体 → 永不触碰（判据1级联剥背景白到净即止）
```

**三个关键设计**：
1. **亮度+彩度双通道**——单用 mn(min-RGB) 会漏「亮灰过渡」（(192,192,176) mn=176 但亮度 190+，深色背景上仍是白点）；彩度区分背景白(≈0)与肤色彩度(60)/暖白毛(30+)
2. **保护域级联**——判据1 只清「贴透明+近白+低彩度」且跳过保护域；背景白剥到净即止，本体白描边永不碰
3. **迭代收敛**——清掉白块会暴露新「贴透明」边缘（剥洋葱），必须迭代到无新增

实测：清除 201,613px 残留 / **本体误伤 0px** / 残留归零。对比六轮b：清 24~64k/帧但误伤本体。

## 四、流程教训

1. **素材处理前后必须 diff**——本体零损失断言（被清像素须全部满足清理判据，否则 FAIL）
2. **逐帧对比审计**——「待机 vs 走姿的差异」才是异常线索（裙下白袍只有待机帧有，跨帧对比一抓一个准）
3. **先取证再动手**——像素剖面（连通块分割）优于区域均色采样（8x8 均色会稀释小白块）
4. **一任务一提交**（Leo 定铁律）——素材变更即时 commit+push，随时可回滚
