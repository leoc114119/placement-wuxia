1. **不接受擅自缩小 / 裁切 / 改动作**——你们停下来的做法是对的，继续禁用这三条。
2. **宽度上限改判「画布贴合」（Leo 09-10 终裁）**：主体须完整落在 240 画布内且**四边零 alpha**，即最宽 **≤238**（左右各 1px 透明）。**原 `≤236` 作废**——它只是旧管线留 2px 余量的实现选择，不是物理边界；运行时按固定高度绘制整张画布、不旋转身体，1px 余量不会截到人。此口径已落盘四处：规范 §1.3 红线 9 / 角色帧规范 §1 / PM2 onboard §3 / 任务单 §7。

   - `rigid_head` 基准值 141 = 扫描窗上限 0.55×256，测值已饱和、无分辨力。
4. **Phase B 继续冻结**，runtime 不动。
5. 本帧**不单独放行或单独驳回**；它与其余 29 帧同批，按 seq=291 的打回项一并修完再整体复检。
